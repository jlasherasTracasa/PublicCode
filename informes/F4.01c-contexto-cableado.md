# F4.01c-contexto-cableado
## Hecho
- `Agent` gana el campo `context: Option<ContextLedger>` y el método `with_context_tool` (junto a `with_memory`).
- `run_messages`: sincroniza el registro con el historial al empezar; anuncia la spec `contexto` si hay registro y la tool no está oculta; intercepta las llamadas a `contexto` (sin etiquetar su resultado, con auditoría `allow`); etiqueta con `[rN]` el resultado de cada tool normal.
- `chat.rs` (`prepare`): añade `.with_context_tool()` después de `.with_memory()`.
- Los 3 tests `contexto_*` pasan con el mock. La suite completa de `pcode-core` pasa.
