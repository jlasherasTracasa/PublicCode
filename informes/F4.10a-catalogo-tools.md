## Decisiones
- `visible` compara el umbral `max_visible` con el número de specs recibidas (antes de filtrar), tal como describe la tarea. Así, el catálogo se activa aunque las tools de MCP ya estén ocultas en la lista.
- `dedupe` conserva las aplazables con descripción normalizada vacía (la tarea solo deduplica si no está vacía).
- `search` limita `k` a 1..=10 con `clamp`, y recorta la descripción a 200 caracteres (`chars()`).
