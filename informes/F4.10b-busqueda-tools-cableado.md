# F4.10b-busqueda-tools-cableado
## Hecho
- `Agent` gana el campo `catalog: Option<ToolCatalog>` y el método `with_tool_search(max_visible)`, junto a `with_context_tool`.
- `run_messages`: tras calcular `specs`, aplica `catalog.visible(dedupe(specs))` antes de añadir `preguntar`, `recordar` y `contexto`.
- `run_messages`: intercepta `buscar_tools` (sin etiqueta `[rN]`, con auditoría `allow`), busca sobre la lista completa deduplicada y desbloquea las tools encontradas.
- `chat.rs` (`prepare`): añade `.with_tool_search(pcode_tools::catalog::DEFAULT_MAX_VISIBLE)` tras `.with_context_tool()`.
- Los 3 tests `buscar_tools_*` pasan con el mock. La suite completa de `pcode-core` pasa.

- En la interceptación, `ro` se reutiliza de la variable que el bucle ya define (`let ro = self.read_only;`), en lugar de volver a leer `self.read_only`.
