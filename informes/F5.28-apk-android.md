# F5.28
## Hecho
- `pcode daemon --escuchar <IP>` (por defecto loopback, con aviso fuera de ella) y token fijo opcional con `PCODE_DAEMON_TOKEN`.
- App Android `apps/android` en Java sin AndroidX: emparejamiento con la URL del demonio, WebView limitado a su origen, menú recargar/cambiar servidor y vuelta al emparejamiento ante un 401.
- Tests JUnit de `Conexion` (5 tests, 0 fallos) y lint sin errores (5 avisos revisados: JavaScript activado, HTTP en claro, `allowBackup`, guiones tipográficos).
- APK firmado (clave de depuración en local) de 14 KB: `dev.publiccode.app` 0.1.0, minSdk 26, targetSdk 35; `apksigner verify` correcto.
- CI (job `android`) y release (`pcode-<versión>-android.apk` en `SHA256SUMS`).
## Archivos
- `apps/android/` (settings.gradle, build.gradle, gradle.properties, .gitignore, app/build.gradle, AndroidManifest.xml, MainActivity.java, Conexion.java, ConexionTest.java, recursos)
- `crates/pcode-cli/src/main.rs`
- `.github/workflows/ci.yml`, `.github/workflows/release.yml`
- `docs/adr/ADR-0006-apk-android.md`
## Salida de acepta
```
$ gradle -p apps/android -q testDebugUnitTest assembleRelease && test -s apps/android/app/build/outputs/apk/release/app-release.apk && cargo build -q -p pcode-cli && ./target/debug/pcode daemon --help | grep -q -- --escuchar
(sin salida; código de salida 0)
```
## Decisiones
- Java con el plugin de Android para Gradle (8.7.3) y JUnit 4 solo en tests: dependencias fuera de la sección 7 de AGENTS.md, aprobadas por el coordinador en ADR-0006.
- HTTP en claro permitido porque el demonio aún no sirve TLS.
- Sin keystore en los secretos, el APK de la release se firma con la clave de depuración (instalable, pero no apto para tiendas).
## Pendiente
- TLS en el demonio y PWA instalable; notificaciones push (F5.24).
- Secretos `PCODE_ANDROID_KEYSTORE_B64`, `PCODE_ANDROID_KEYSTORE_PASSWORD`, `PCODE_ANDROID_KEY_ALIAS` y `PCODE_ANDROID_KEY_PASSWORD` para firmar con una clave propia.
