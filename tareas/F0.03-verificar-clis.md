## Objetivo

Con las CLIs instaladas y la sesión iniciada con credenciales propias, documenta para cada backend
(sección `## <backend>`):
1. Versión probada (`--version`).
2. Orden exacta de modo no interactivo, cómo pasar el prompt, cómo elegir el modelo, cómo pedir salida
   estructurada (JSON/stream-JSON) y cómo autoaprobar herramientas dentro de una sandbox.
3. Dónde lee instrucciones (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`)
   y skills.
4. Cómo se configura un servidor MCP.
5. Una salida real de ejemplo (recortada) guardada como fixture en `crates/pcode-backends/tests/fixtures/`
   (la crean las tareas F2.07–F2.10; aquí solo se anota).
6. Para opencode: verificar las capacidades citadas en la comparación del README (skills, subagentes,
   ACP) y corregir el README si alguna afirmación ha quedado vieja.
Solo vías oficiales; nada de endpoints no documentados.
