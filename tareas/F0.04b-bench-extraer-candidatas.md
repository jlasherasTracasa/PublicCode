## Objetivo

Una tarea hecha tiene `informes/<id>.md`. El commit que AÑADIÓ ese informe es `aceptada_en` y su padre es `base`.
1. Crea `extraer.py` (ejecutable, `#!/usr/bin/env python3`, solo biblioteca estándar) con las funciones de abajo.
2. `acepta_de(md)`: devuelve el texto de la cabecera `<!-- acepta: … -->` (primeras 12 líneas) o `None`.
3. `crates_de(rutas)`: nombres distintos y ordenados de los crates tocados (`crates/<nombre>/…` → `<nombre>`).
4. `candidata(repo, id)`: usa git (`subprocess.run([... "git", "-C", repo, …], capture_output=True, text=True)`):
   - `aceptada_en` = última línea de `git log --diff-filter=A --format=%H -- informes/<id>.md`; sin salida → `None`;
   - `base` = `git rev-parse <aceptada_en>^`; si falla (commit raíz) → `None`;
   - el texto de la tarea = `git show <aceptada_en>:tareas/<id>.md`; si falla o no tiene `acepta` → `None`;
   - `crates` = `crates_de` sobre `git diff --name-only <base> <aceptada_en>`.
   Devuelve `{"id", "acepta", "tarea": "tareas/<id>.md", "base", "aceptada_en", "crates"}`.
5. `main(argv)`: `extraer.py [--repo R]`; recorre `informes/*.md` de `R` en orden alfabético (id = nombre sin
   `.md`), imprime una línea JSON por candidata (`ensure_ascii=False`) y, en stderr, `omitida: <id>` por cada
   `None`. Devuelve 0.
6. Crea `test_extraer.py`: los tests de git montan un repo temporal con dos commits (el primero con
   `tareas/T1.md`; el segundo añade `informes/T1.md` y `crates/x/src/lib.rs`).

## Tests (con estos nombres)

- `test_acepta_de_la_cabecera`: la entrada del ejemplo devuelve la orden; un texto sin cabecera devuelve None
- `test_crates_distintos_y_ordenados`: la lista del ejemplo devuelve los dos crates
- `test_candidata_con_base_y_aceptada`: en el repo temporal los dos commits salen en su sitio y crates es x
- `test_sin_informe_no_hay_candidata`: un id sin informe devuelve None
- `test_main_imprime_jsonl`: main sobre el repo temporal imprime una línea JSON que pasa `conjunto.validar_linea`
