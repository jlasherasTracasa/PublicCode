# F0.07-ci-windows-release — CI en Linux y Windows, y release de la CLI con instaladores

**Fase** F0 · **Ejecutor** coordinador · **Depende de** F0.02-ci, F1.20-cli-run

## Objetivo

1. `ci.yml`: además de `rust` en Linux, un job `windows` (`windows-latest`) con clippy de todo el
   workspace, tests de los crates portables y una prueba de humo de `pcode.exe run` con un guion
   simulado (crea un archivo y escribe `.pcode\audit.jsonl`).
2. `release.yml`: al subir una etiqueta `v*` (o a mano), compila `pcode` para
   `x86_64-pc-windows-msvc` (zip con `install.ps1`) y `x86_64-unknown-linux-gnu` (tar.gz con
   `install.sh`), calcula `SHA256SUMS` y publica la release de GitHub.
3. `install.ps1`: instalación por usuario en `%LOCALAPPDATA%\PublicCode\bin` y PATH de usuario;
   `install.sh`: en `~/.local/bin`. Ambos verifican el SHA-256 si se les pasa.

## Tests (con estos nombres)

- `(CI)`: los jobs `windows` y `linux` en verde; la release publica los dos archivos y `SHA256SUMS`

## Aceptación (ejecútala una vez al final)

```bash
grep -q 'windows-latest' .github/workflows/ci.yml && grep -q 'x86_64-pc-windows-msvc' .github/workflows/release.yml && grep -q 'SHA256SUMS' .github/workflows/release.yml && test -x install.sh && test -s install.ps1
```
