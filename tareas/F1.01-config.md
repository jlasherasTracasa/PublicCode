## Objetivo

1. Estructuras de abajo con `serde::Deserialize`. Las claves del TOML van en español (`rename`); los
   campos de Rust, en inglés.
2. `expand_env(s)` sustituye cada `{env:NOMBRE}` por la variable de entorno; si no existe, devuelve
   `ConfigError::MissingEnv(NOMBRE)`.
3. `Config::from_str(toml)` parsea y después aplica `expand_env` a `ProviderCfg::api_key` y `url`.
4. `Config::load(path)` lee el archivo; si no existe, devuelve `Config::default()`.
5. Ninguna clave es obligatoria: todo con `#[serde(default)]`.

## Firmas (cópialas tal cual)

```rust
use std::collections::BTreeMap;
use std::path::Path;

#[derive(Debug, thiserror::Error)]
pub enum ConfigError {
    #[error("no se pudo leer {0}: {1}")]
    Io(String, std::io::Error),
    #[error("TOML inválido: {0}")]
    Toml(#[from] toml::de::Error),
    #[error("falta la variable de entorno {0}")]
    MissingEnv(String),
}

#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default)]
pub struct Config {
    #[serde(rename = "proyecto")] pub project: ProjectCfg,
    #[serde(rename = "proveedores")] pub providers: BTreeMap<String, ProviderCfg>,
    #[serde(rename = "backends")] pub backends: BTreeMap<String, BackendCfg>,
    #[serde(rename = "roles")] pub roles: BTreeMap<String, String>,
    #[serde(rename = "sandbox")] pub sandbox: SandboxCfg,
}

#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default)]
pub struct ProjectCfg {
    #[serde(rename = "instrucciones")] pub instructions: Vec<String>,
}

#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default)]
pub struct ProviderCfg {
    #[serde(rename = "tipo")] pub kind: String,          // "openai-compatible" | "anthropic" | "gemini"
    pub url: String,
    #[serde(rename = "clave")] pub api_key: Option<String>,
}

#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default)]
pub struct BackendCfg {
    #[serde(rename = "tipo")] pub kind: String,          // "agente-cli" | "agente-github" | "modelo"
    #[serde(rename = "binario")] pub binary: Option<String>,
    #[serde(rename = "modelo")] pub model: Option<String>,
}

#[derive(Debug, Clone, serde::Deserialize)]
#[serde(default)]
pub struct SandboxCfg {
    #[serde(rename = "nivel_por_defecto")] pub default_level: String,   // "N1"
    #[serde(rename = "red")] pub network: String,                        // "denegar" | "permitir"
}
impl Default for SandboxCfg { /* N1, denegar */ }

pub fn expand_env(s: &str) -> Result<String, ConfigError>;

impl Config {
    pub fn from_str(s: &str) -> Result<Config, ConfigError>;
    pub fn load(path: &Path) -> Result<Config, ConfigError>;
}
```
