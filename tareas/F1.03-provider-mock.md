## Objetivo

1. `provider.rs`: `ModelError` y el trait asíncrono `Provider` (con `async-trait`).
2. `mock.rs`: `MockProvider` devuelve respuestas en orden desde un guion y guarda las peticiones que
   recibe (para los tests del bucle). Cuando se agota el guion, devuelve `ModelError::MockExhausted`.
3. `MockProvider::from_script_file(path)` lee un JSON con un array de `ChatResponse`. Lo usa la CLI con
   la variable `PCODE_MOCK_SCRIPT`.
4. Re-exporta todo en `lib.rs`.
