## Objetivo

`repair_json_arguments(raw)` prueba en orden y devuelve el primer resultado que sea un OBJETO JSON:
1. parseo estricto;
2. quitar vallas de código (```json … ``` o ``` … ```);
3. recortar desde el primer `{` hasta el último `}`;
4. quitar comas finales antes de `}` o `]`;
5. si no hay comillas dobles, cambiar las simples por dobles;
6. si el resultado es un string JSON que contiene un objeto (doble codificación), parsearlo otra vez.
Si nada funciona, `None`. Después, en `openai::from_response_body`, usar `repair_json_arguments`
antes de caer en `Value::String`.
