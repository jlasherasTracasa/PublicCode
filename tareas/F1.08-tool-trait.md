## Objetivo

1. `Effect` y `privilege()`: Read = 0, Write = 1, Network = 2, Exec = 3, Irreversible = 4; el
   privilegio de una tool es el máximo de sus efectos (0 si no tiene).
2. `ToolRegistry`: registrar, obtener por nombre (sin duplicados: si ya existe el nombre, `register`
   devuelve `Err`), y `specs_filtered` que devuelve solo las tools que el filtro permite, ORDENADAS
   de menor a mayor privilegio y, a igual privilegio, por nombre.
3. `resolve_in_root(root, p)`: une `p` a `root`, normaliza `.` y `..` sin tocar el disco y devuelve
   `Err` si el resultado sale de `root` o si `p` es absoluta y no está bajo `root`.

```rust
use std::path::{Path, PathBuf};
use std::sync::Arc;
use std::time::Duration;
use pcode_models::ToolSpec;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord, serde::Serialize, serde::Deserialize)]
pub enum Effect { Read, Write, Network, Exec, Irreversible }

pub fn privilege(effects: &[Effect]) -> u8;

#[derive(Debug, Clone)]
pub struct ToolContext { pub root: PathBuf, pub timeout: Duration }

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ToolOutput { pub content: String, pub is_error: bool }
impl ToolOutput { pub fn ok(s: impl Into<String>) -> Self; pub fn error(s: impl Into<String>) -> Self; }

#[async_trait::async_trait]
pub trait Tool: Send + Sync {
    fn spec(&self) -> ToolSpec;
    fn effects(&self) -> &'static [Effect];
    async fn call(&self, args: serde_json::Value, ctx: &ToolContext) -> ToolOutput;
}

#[derive(Default)]
pub struct ToolRegistry { /* Vec<Arc<dyn Tool>> */ }
impl ToolRegistry {
    pub fn new() -> Self;
    pub fn register(&mut self, tool: Arc<dyn Tool>) -> Result<(), String>;
    pub fn get(&self, name: &str) -> Option<Arc<dyn Tool>>;
    pub fn specs_filtered(&self, allow: impl Fn(&str, &[Effect]) -> bool) -> Vec<ToolSpec>;
}

pub fn resolve_in_root(root: &Path, p: &str) -> Result<PathBuf, String>;
```
