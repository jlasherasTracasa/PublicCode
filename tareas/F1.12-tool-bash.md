## Objetivo

`Bash` (`bash`, `[Exec]`): `{"command", "timeout_secs"?}`.
1. `tokio::process::Command::new("sh").arg("-c").arg(cmd)` con `current_dir(root)`, `kill_on_drop(true)`
   y la entrada estándar cerrada.
2. Tiempo máximo = mínimo entre `timeout_secs` y `ctx.timeout`; si vence, mata el proceso y devuelve
   un error `"tiempo agotado tras N s"`.
3. Salida: `"exit=<código>\n--- stdout ---\n…\n--- stderr ---\n…"`. Cada flujo se recorta con
   `head_tail(texto, 200, 200)`: primeras 200 y últimas 200 líneas con
   `"[… N líneas omitidas …]"` en medio.
4. `is_error` = código distinto de 0.
