## Objetivo

1. `Capabilities` (deserializable desde `[politica]` del TOML) con patrones glob (`globset`).
   - Regla general por capa: una lista de permitidos VACÍA significa «esta capa no restringe eso».
   - Escritura: Deny si casa con algún `deny_write`; si `write` no está vacío y no casa con ninguno, Deny; si no, Allow.
   - Lectura: Allow si `read` está vacío o casa con algún `read`.
   - Órdenes: normaliza espacios; Deny si casa con algún `deny_commands` (glob sobre la orden
     entera); si `allow_commands` no está vacío y no casa con ninguno, Deny; si no, Allow.
   - Dominios (excepción: la red está cerrada por defecto): Allow solo si casa con algún `net_allow`
     (admite `*.dominio`); con `net_allow` vacío, Deny.
   - Una tool con efecto `Irreversible` y `ask_irreversible = true` → Ask.
2. `Policy` = pila de capas. La decisión es la más restrictiva de todas (Deny > Ask > Allow) y el
   motivo es el de la capa que deniega. `child(caps)` devuelve una política nueva con una capa más:
   un subagente **nunca** puede tener más permisos que su padre.
3. `tool_visible(name, effects)`: false si la tool está en `hidden_tools` de alguna capa o si alguna
   capa tiene `deny_effects` que incluya alguno de sus efectos. Las tools no visibles ni siquiera se
   anuncian al modelo.

## Firmas (cópialas tal cual)

```rust
use pcode_tools::Effect;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Decision { Allow, Ask(String), Deny(String) }

#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default)]
pub struct Capabilities {
    #[serde(rename = "leer")] pub read: Vec<String>,
    #[serde(rename = "escribir")] pub write: Vec<String>,
    #[serde(rename = "no_escribir")] pub deny_write: Vec<String>,
    #[serde(rename = "denegar_ordenes")] pub deny_commands: Vec<String>,
    #[serde(rename = "permitir_ordenes")] pub allow_commands: Vec<String>,
    #[serde(rename = "red_permitir")] pub net_allow: Vec<String>,
    #[serde(rename = "preguntar_irreversibles")] pub ask_irreversible: bool,
    #[serde(rename = "tools_ocultas")] pub hidden_tools: Vec<String>,
    #[serde(rename = "efectos_denegados")] pub deny_effects: Vec<Effect>,
}

impl Capabilities {
    pub fn check_read(&self, rel_path: &str) -> Decision;
    pub fn check_write(&self, rel_path: &str) -> Decision;
    pub fn check_command(&self, command: &str) -> Decision;
    pub fn check_domain(&self, host: &str) -> Decision;
    pub fn check_effects(&self, effects: &[Effect]) -> Decision;
}

#[derive(Debug, Clone, Default)]
pub struct Policy { layers: Vec<Capabilities> }
impl Policy {
    pub fn new(base: Capabilities) -> Self;
    pub fn child(&self, caps: Capabilities) -> Policy;
    pub fn check_read(&self, rel_path: &str) -> Decision;
    pub fn check_write(&self, rel_path: &str) -> Decision;
    pub fn check_command(&self, command: &str) -> Decision;
    pub fn check_domain(&self, host: &str) -> Decision;
    pub fn check_effects(&self, effects: &[Effect]) -> Decision;
    pub fn tool_visible(&self, name: &str, effects: &[Effect]) -> bool;
}
```
