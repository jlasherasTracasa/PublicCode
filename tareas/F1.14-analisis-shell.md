## Objetivo

Que `bash -c 'git stash'` o `true && git push` no esquiven la política.
1. `simple_commands(cmd)` devuelve las órdenes simples que ejecutaría la línea:
   - parte por `&&`, `||`, `;`, `|`, `&` y saltos de línea, respetando comillas (usa `shell-words`
     para tokenizar cada trozo);
   - extrae el contenido de `$( … )` y de las comillas invertidas, y lo analiza recursivamente;
   - si la orden es `sh|bash|zsh -c "<script>"`, analiza `<script>` recursivamente;
   - quita los prefijos `sudo`, `env VAR=x …`, `VAR=x`, `nohup`, `time`, `command` y `exec`;
   - devuelve cada orden simple normalizada (palabras unidas por un espacio).
   - Profundidad máxima de recursión: 4. Si se supera, devuelve la orden tal cual y `check_command`
     da Deny ("orden demasiado anidada").
2. `Capabilities::check_command` aplica las reglas a CADA orden simple; basta una denegada.
