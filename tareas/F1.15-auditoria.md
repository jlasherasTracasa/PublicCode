## Objetivo

1. Archivo JSONL; cada línea es un `AuditEntry`.
2. `hash` = sha256 en hex de `prev_hash + "\n" + JSON canónico de la entrada sin el campo hash`
   (JSON canónico = `serde_json::to_string` de un `BTreeMap` con las claves ordenadas). La primera
   entrada usa `prev_hash = "0" * 64`.
3. `open` lee el archivo existente (si lo hay) para continuar `seq` y `last_hash`.
4. `verify` recorre el archivo, recalcula y devuelve el número de entradas o el primer `seq` roto.
5. `provenance` dice de dónde viene la acción: `"usuario"`, `"agente:<id>"`,
   `"subagente:<padre>/<id>"` o `"tool:<nombre>"`.

```rust
#[derive(Debug, Clone, PartialEq, serde::Serialize, serde::Deserialize)]
pub struct AuditEntry {
    pub seq: u64, pub ts_ms: u64, pub actor: String, pub provenance: String,
    pub action: String, pub detail: serde_json::Value, pub decision: String,
    pub prev_hash: String, pub hash: String,
}

#[derive(Debug, thiserror::Error)]
pub enum AuditError {
    #[error("E/S: {0}")] Io(#[from] std::io::Error),
    #[error("entrada {0} corrupta o manipulada")] Broken(u64),
}

pub struct AuditLog { /* path, seq, last_hash */ }
impl AuditLog {
    pub fn open(path: &std::path::Path) -> Result<AuditLog, AuditError>;
    pub fn append(&mut self, actor: &str, provenance: &str, action: &str,
                  detail: serde_json::Value, decision: &str) -> Result<AuditEntry, AuditError>;
    pub fn verify(path: &std::path::Path) -> Result<u64, AuditError>;
}
```
