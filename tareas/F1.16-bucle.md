## Objetivo

`Agent::run(task)`:
1. `messages = [system(cfg.system_prompt), user(task)]`.
2. Bucle mientras queden pasos y tokens:
   a. `tools` = `registry.specs_filtered(|n, e| policy.tool_visible(n, e))`.
   b. `provider.chat(ChatRequest{model, messages, tools, ..})`; suma el uso; añade el mensaje del asistente.
   c. Sin `tool_calls` → `Outcome::Done { final_message }`.
   d. Por cada llamada: si la tool no existe → resultado de error `"tool desconocida: X"`. Si no,
      decide con la política: `check_effects(effects)`; si tiene Write y hay `args.path` →
      `check_write(path)`; si tiene Exec y hay `args.command` → `check_command(command)`.
      Deny → resultado `"denegado por la política: <motivo>"`; Ask → resultado
      `"requiere aprobación humana: <motivo>"` (en F1 no se ejecuta; la aprobación llega en F5).
      Allow → ejecuta la tool.
   e. Audita cada llamada (actor = `cfg.agent_id`, provenance = `"agente:<id>"`, action = nombre de
      la tool, detail = args, decision).
   f. Añade `Message::tool_result(call.id, contenido)`.
3. Si se agotan los pasos o los tokens → `Outcome::BudgetExhausted`. Un error del proveedor →
   `Outcome::Failed(msg)`.

## Firmas (cópialas tal cual)

```rust
use std::sync::Arc;
use pcode_models::{Message, Provider, Usage};
use pcode_policy::{AuditLog, Policy};
use pcode_tools::{ToolContext, ToolRegistry};

#[derive(Debug, Clone)]
pub struct Budget { pub max_steps: u32, pub max_input_tokens: u64, pub max_output_tokens: u64 }
impl Default for Budget { /* 50 pasos, 2_000_000 de entrada, 200_000 de salida */ }

#[derive(Debug, Clone)]
pub struct AgentConfig { pub agent_id: String, pub model: String, pub system_prompt: String, pub budget: Budget }

#[derive(Debug, Clone, PartialEq)]
pub enum Outcome { Done { final_message: String }, BudgetExhausted, Stuck(String), Failed(String) }

#[derive(Debug, Clone)]
pub struct RunReport { pub outcome: Outcome, pub usage: Usage, pub steps: u32, pub transcript: Vec<Message> }

pub struct Agent { /* provider, tools, policy, audit, cfg, ctx */ }
impl Agent {
    pub fn new(provider: Arc<dyn Provider>, tools: ToolRegistry, policy: Policy,
               audit: Option<AuditLog>, cfg: AgentConfig, ctx: ToolContext) -> Self;
    pub async fn run(&mut self, task: &str) -> RunReport;
}
```
