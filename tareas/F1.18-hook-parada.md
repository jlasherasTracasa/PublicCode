## Objetivo

1. `AgentConfig` gana `stop_hook: Option<StopHook>`.
2. Cuando el modelo termina (sin tool calls) y hay hook:
   a. Si `checklist` no está vacía, el mensaje final debe contener `- [x] <item>` para cada item. Si
      falta alguno → mensaje de usuario `"Faltan restricciones por confirmar: …"` y se sigue.
   b. Ejecuta `command` (sh -c, cwd = root, timeout). Si sale con 0 → `Done`.
   c. Si falla → mensaje de usuario: `"La aceptación falló (ronda r/max). Salida:\n<compress_tool_output>\nCorrige y vuelve a intentarlo."`, y se sigue.
   d. Tras `max_rounds` fallos → `Outcome::Failed("aceptación no superada tras N rondas")`.
3. `RunReport` gana `acceptance_output: Option<String>` (la última salida real), para que el informe
   no pueda afirmar lo que `acepta` no comprobó.
