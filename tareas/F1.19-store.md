## Objetivo

1. `rusqlite` con `bundled`. Esquema versionado con `PRAGMA user_version`:
   `sessions(id INTEGER PK, created_ms, model TEXT, task TEXT, outcome TEXT NULL)` y
   `events(id INTEGER PK, session_id REF, ts_ms, kind TEXT, payload TEXT /* JSON */)`.
2. `open` crea el archivo y migra; `open_in_memory` para tests.
3. API síncrona (el bucle la usará con `spawn_blocking`).
