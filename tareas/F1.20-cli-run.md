## Objetivo

Subcomando `pcode run <TAREA> [--modelo M] [--proveedor P] [--acepta CMD] [--max-pasos N] [--config RUTA]`:
1. Carga `pcode.toml` (o `--config`). Política: `[politica]` del TOML (añade a `Config` en este
   mismo crate con un `#[derive(Deserialize)] struct CliToml { politica: Capabilities }` si hace
   falta; no toques pcode-config).
2. Proveedor: si existe la variable `PCODE_MOCK_SCRIPT` → `MockProvider::from_script_file`; si no,
   el proveedor `--proveedor` (o el primero) de tipo `openai-compatible`.
3. Registra las tools `leer`, `escribir`, `editar`, `buscar`, `listar` y `bash` con root = directorio actual.
4. Audita en `.pcode/audit.jsonl` y guarda la sesión y los eventos en `.pcode/pcode.db`.
5. Imprime el mensaje final y un resumen de una línea (`resultado`, pasos, tokens de entrada y salida).
6. Código de salida: 0 = Done, 2 = Failed, 3 = BudgetExhausted, 4 = Stuck.
