## Objetivo

1. `StuckDetector::observe(call, output)` devuelve una señal cuando:
   - la misma llamada (nombre + args en JSON canónico) se repite `max_repeats` veces seguidas;
   - el mismo error (primeras 200 letras de una salida con `is_error`) se repite `max_repeats` veces;
   - pasan `max_steps_without_write` pasos sin ninguna tool con efecto Write.
2. `hint_for(output)`: tabla de pistas por fallo típico, por ejemplo:
   - "no se encontró el texto a reemplazar" → "Vuelve a leer el archivo con `leer` antes de editar.";
   - "rustfmt" o "cargo fmt" → "Ejecuta `cargo fmt --all`.";
   - "unresolved import" → "Revisa el `use` y que el módulo esté declarado en lib.rs.";
   - "denegado por la política" → "Esa acción no está permitida; busca otra forma o explica el bloqueo en el informe."
3. En el bucle: la primera señal añade un mensaje de usuario con la pista; la segunda termina con
   `Outcome::Stuck(motivo)`.
