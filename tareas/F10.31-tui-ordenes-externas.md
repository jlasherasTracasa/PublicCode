## Objetivo

Algunas órdenes necesitan datos que `pcode-tui` no tiene (configuración, skills, base de sesiones). Se
resuelven con un cierre que pasa quien arranca la TUI.
1. `commands.rs`: añade al final de `COMMANDS`, con `external: true`: `skills`/`skills` («lista las skills
   del proyecto» / «list the project's skills»), `mcp`/`mcp` («servidores MCP configurados» / «configured MCP
   servers») y `permisos`/`permissions` («reglas de permisos en vigor» / «permission rules in force»).
2. `app.rs`: añade `Command::Extra { name: String, arg: String }` (doc: «Orden que resuelve quien arranca la
   TUI; `name` es el nombre en español»). En el `match name` de `submit`, justo antes del brazo `_ =>`:
   `n if crate::commands::find(n).is_some_and(|c| c.external) => vec![Command::Extra { name: crate::commands::find(n).unwrap().name.to_string(), arg: arg.to_string() }]`.
3. `run.rs`: añade `Reply`, `Extras` y `apply_reply` (firmas abajo) y a `TuiOptions` el campo
   `pub extras: Extras` (doc: «Resuelve las órdenes externas»). `apply_reply`: con `Reply::Info(s)` añade
   `Entry::Info(s)` y devuelve `None`; con `Reply::Prompt { label, text }`: si `app.busy`, añade
   `Entry::Info(t(app.lang, "wait").into())` y devuelve `None`; si no, añade `Entry::User(label.clone())`,
   pone `app.busy = true` y `app.scroll = 0`, y devuelve `Some((label, text))`.
4. `run.rs`, `run_tui`: guarda `let mut extras = opts.extras;` al principio. En el `match cmd`:
   `Command::Extra { name, arg }` → `if let Some((label, text)) = apply_reply(&mut app, extras(&name, &arg))`
   lanza un turno igual que el brazo `Command::Send`, pero con `text` como mensaje completo (sin
   `expand_message`) y `Msg::Turn(label, r)` al terminar.
5. `chat.rs`, función `tui`: pasa en `TuiOptions`
   `extras: Box::new(|name, _| pcode_tui::run::Reply::Info(format!("La orden /{name} no está disponible.")))`
   (F10.32 la sustituye por la real).

// crates/pcode-tui/src/run.rs
/// Respuesta a una orden externa.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Reply {
    /// Texto que se muestra como aviso.
    Info(String),
    /// Mensaje que se envía al agente: `label` es lo que se ve en la conversación y `text` lo que recibe el modelo.
    Prompt { label: String, text: String },
}

/// Resuelve una orden externa: recibe el nombre (en español) y el argumento.
pub type Extras = Box<dyn FnMut(&str, &str) -> Reply + Send>;

/// Aplica la respuesta al estado; devuelve `(label, text)` si hay que lanzar un turno con `text`.
pub fn apply_reply(app: &mut App, reply: Reply) -> Option<(String, String)>;

// crates/pcode-tui/src/app.rs, en `pub enum Command`
    /// Orden que resuelve quien arranca la TUI; `name` es el nombre en español.
    Extra { name: String, arg: String },

## Ejemplo (entrada y resultado esperado)

```
teclear "/skills" + Intro          -> [Command::Extra { name: "skills", arg: "" }]
teclear "/permissions x" + Intro   -> [Command::Extra { name: "permisos", arg: "x" }]
apply_reply(&mut app, Reply::Info("hola".into()))                         -> None; última entrada Info("hola")
apply_reply(&mut app, Reply::Prompt{label:"/init".into(), text:"T".into()}) -> Some(("/init","T")); última entrada User("/init"); app.busy
con app.busy = true, la misma Prompt                                      -> None y un Info con el aviso de espera
```
