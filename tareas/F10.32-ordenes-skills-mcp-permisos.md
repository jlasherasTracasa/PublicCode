## Objetivo

1. `crates/pcode-cli/Cargo.toml`: añade `pcode-skills = { path = "../pcode-skills" }` en `[dependencies]`.
2. Crea `tui_extras.rs` con `ExtraCtx`, `skills_text`, `mcp_text`, `permissions_text` y `reply` (firmas abajo).
3. `skills_text(root)`: `Registry::load(&[root.join(".claude/skills"), root.join(".pcode/skills")])`. Con
   error → `"✗ skills: <error>"`. Sin skills → `"No hay skills en .claude/skills ni en .pcode/skills."`. Si
   hay → `"Skills (<n>):\n" + reg.index()`.
4. `mcp_text(mcp)`: vacío → `"No hay servidores MCP configurados. Añade uno en [mcp.<nombre>] de pcode.toml."`.
   Si no → `"Servidores MCP (<n>):"` y una línea por servidor, `"  · <nombre>: <orden unida con espacios>"`,
   con `" (desactivado)"` al final si `disabled`; última línea:
   `"pcode mcp muestra las tools de cada uno."`.
5. `permissions_text(layers)`: por cada capa `(nombre, caps)`: una línea `"<nombre>:"` y, por cada lista NO
   vacía, en este orden y con esta etiqueta, `"  <etiqueta>: <elementos unidos con ", ">"`: `leer`,
   `escribir`, `no_escribir`, `denegar_ordenes`, `preguntar_ordenes`, `permitir_ordenes`, `red_permitir`. Si
   una lista tiene más de 6 elementos, muestra los 6 primeros y `" … (+<resto>)"`. Si todas están vacías,
   `"  (sin reglas)"`.
6. `reply(ctx, name, _arg)`: `"skills"` → `Reply::Info(skills_text(&ctx.root))`; `"mcp"` →
   `Reply::Info(mcp_text(&ctx.cfg.mcp))`; `"permisos"` → `Reply::Info(permissions_text(&capas))` con las capas
   `("por defecto", Capabilities::interactive_defaults())`, `("usuario", load_capabilities(ruta))` solo si
   `pcode_config::user_config_path()` es un archivo, y `("proyecto", load_capabilities(&ctx.config_path))`;
   otro nombre → `Reply::Info(format!("La orden /{name} no está disponible."))`.
7. `main.rs`: añade `mod tui_extras;`. `chat.rs`, función `tui`: construye
   `ExtraCtx { root: cwd, cfg: Config::load_layered(&a.config)?.0, config_path: a.config.clone() }` y pasa
   `extras: Box::new(move |name, arg| crate::tui_extras::reply(&ctx, name, arg))`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/tui_extras.rs
use pcode_config::{Config, McpCfg};
use pcode_policy::Capabilities;
use pcode_tui::run::Reply;
use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

/// Lo que necesitan las órdenes externas de la TUI.
pub struct ExtraCtx {
    /// Raíz del proyecto.
    pub root: PathBuf,
    /// Configuración ya cargada.
    pub cfg: Config,
    /// Ruta del `pcode.toml` del proyecto.
    pub config_path: PathBuf,
}

/// Skills del proyecto, una por línea.
pub fn skills_text(root: &Path) -> String;
/// Servidores MCP configurados.
pub fn mcp_text(mcp: &BTreeMap<String, McpCfg>) -> String;
/// Reglas de permisos, capa a capa.
pub fn permissions_text(layers: &[(&str, Capabilities)]) -> String;
/// Respuesta a una orden externa de la TUI.
pub fn reply(ctx: &ExtraCtx, name: &str, arg: &str) -> Reply;
```
