## Objetivo

1. `commands.rs`: añade al final de `COMMANDS`, con `external: true`: `init`/`init` («crea o actualiza
   AGENTS.md con lo que el agente ve del proyecto» / «create or update AGENTS.md from the project»),
   `revisar`/`review` («revisa los cambios sin commit» / «review the uncommitted changes») y
   `exportar`/`export` («guarda la conversación en Markdown o HTML» / «save the conversation as Markdown or HTML»).
2. `tui_extras.rs`: añade la constante `INIT_PROMPT` y la función `export_session` (firmas abajo), y tres
   brazos a `reply`:
   - `"init"` → `Reply::Prompt { label: "/init".into(), text: INIT_PROMPT.into() }`.
   - `"revisar"` → `match pcode_server::assist::review_prompt(&ctx.root)`: `Ok(p)` →
     `Reply::Prompt { label: "/revisar".into(), text: p }`; `Err(e)` → `Reply::Info(format!("✗ {e}"))`.
   - `"exportar"` → `Reply::Info(export_session(&ctx.root, arg))`.
3. `INIT_PROMPT` (texto exacto, una sola cadena): «Analiza este proyecto y crea (o actualiza) `AGENTS.md` en
   la raíz con: 1) qué es el proyecto, en dos frases; 2) las órdenes para compilar, probar y comprobar el
   estilo; 3) un mapa de las carpetas principales; 4) las convenciones del código que se ven en el
   repositorio. Sé breve (menos de 60 líneas) y no inventes órdenes: compruébalas leyendo los archivos de
   configuración. Si `AGENTS.md` ya existe, consérvalo y añade solo lo que falte.»
4. `export_session(root, arg)`: `arg` vacío o `"md"` → Markdown; `"html"` → HTML; otro →
   `"Uso: /exportar [md|html]"`. Abre `Store::open(&root.join(".pcode/pcode.db"))`, toma la sesión más
   reciente (`sessions(1)`) y sus mensajes (eventos `mensaje`, como en `exportar::export`). Sin sesión o sin
   mensajes → `"Todavía no hay nada que exportar."`. Genera el texto con `to_markdown` / `to_html`, pásalo
   por `mask` (con `HOME` y `env_secrets(std::env::vars())`), escríbelo en
   `<root>/.pcode/export/sesion-<id>.<md|html>` (crea la carpeta) y devuelve
   `"Exportado a .pcode/export/sesion-<id>.<ext>"`. Cualquier error de E/S o de la base → `"✗ <error>"`.

## Ejemplo (entrada y resultado esperado)

```
reply(&ctx, "init", "")                         == Reply::Prompt { label: "/init", text: INIT_PROMPT }
reply(&ctx, "revisar", "") en una carpeta sin git == Reply::Info("✗ el proyecto no es un repositorio git")
export_session(dir sin base de sesiones, "")    == "Todavía no hay nada que exportar."
export_session(dir con la sesión 1 guardada, "html") == "Exportado a .pcode/export/sesion-1.html"  (y el archivo empieza por <!doctype html>)
export_session(dir, "pdf")                      == "Uso: /exportar [md|html]"
```
