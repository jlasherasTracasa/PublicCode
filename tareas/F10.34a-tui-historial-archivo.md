## Objetivo

1. Crea `history.rs` con `MAX_ENTRIES`, `load`, `append` y `search` (firmas abajo).
2. Formato del archivo: una entrada por línea, cada una como cadena JSON (`serde_json::to_string(&texto)`),
   así una entrada con saltos de línea ocupa una sola línea. La más antigua primero.
3. `load(path)`: si el archivo no existe o no se puede leer, `vec![]`. Las líneas que no sean una cadena JSON
   válida se saltan. Devuelve como mucho las últimas `MAX_ENTRIES`.
4. `append(path, entry)`: no hace nada si `entry.trim()` está vacío. Crea la carpeta si falta. Añade la línea
   al final (abre con `OpenOptions::new().create(true).append(true)`). Después, si el archivo tiene más de
   `MAX_ENTRIES + 100` líneas, lo reescribe con solo las últimas `MAX_ENTRIES`.
5. `search(history, query, before)`: el mayor índice `i < before` tal que `history[i]` contiene `query` sin
   distinguir mayúsculas; `None` si `query` está vacío o no hay ninguno. `before` puede ser mayor que la
   longitud (se trata como la longitud).
6. `lib.rs`: añade `pub mod history;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/history.rs
use std::path::Path;

/// Entradas que se conservan en el archivo.
pub const MAX_ENTRIES: usize = 500;

/// Entradas guardadas, de la más antigua a la más reciente.
pub fn load(path: &Path) -> Vec<String>;
/// Añade una entrada al archivo (y lo recorta si ha crecido demasiado).
pub fn append(path: &Path, entry: &str) -> std::io::Result<()>;
/// Índice de la entrada más reciente anterior a `before` que contiene `query`.
pub fn search(history: &[String], query: &str, before: usize) -> Option<usize>;
```

## Ejemplo (entrada y resultado esperado)

```
append(p, "hola"); append(p, "dos\nlíneas"); append(p, "  ");
contenido del archivo: "\"hola\"\n\"dos\\nlíneas\"\n"
load(p) == ["hola", "dos\nlíneas"]
h = ["cargo test", "git status", "Cargo build"]
search(&h, "cargo", 3) == Some(2);  search(&h, "cargo", 2) == Some(0);  search(&h, "cargo", 0) == None
search(&h, "", 3) == None;  search(&h, "zzz", 99) == None
```

## Tests (con estos nombres)

- `guarda_y_carga_con_saltos_de_linea`: los `append` del ejemplo dejan ese archivo y `load` devuelve las dos entradas
- `carga_sin_archivo_es_vacio`: `load` de una ruta que no existe es `[]`
- `lineas_corruptas_se_saltan`: un archivo con `"a"`, `basura` y `"b"` carga `["a", "b"]`
- `recorta_cuando_crece`: tras 601 `append`, el archivo tiene 500 líneas y la última entrada es la última añadida
- `busca_hacia_atras_sin_distinguir_mayusculas`: los cinco casos de `search` del ejemplo
