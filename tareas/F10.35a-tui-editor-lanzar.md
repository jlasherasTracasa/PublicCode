# F10.35a-tui-editor-lanzar — TUI: elegir el editor (`$VISUAL`, `$EDITOR`) y editar un texto en un archivo temporal

## Objetivo

1. Crea `editor.rs` con `editor_argv` y `edit_text` (firmas abajo).
2. `editor_argv(visual, editor)`: usa `visual` si es `Some` y no está en blanco; si no, `editor` igual; si
   no, `["vi"]` (en Windows, tras `#[cfg(windows)]`, `["notepad"]`). El valor se parte por espacios en blanco
   (`split_whitespace`): `"code --wait"` → `["code", "--wait"]`.
3. `edit_text(argv, dir, text)`: crea `dir` si falta; escribe `text` en `dir/mensaje.md`; ejecuta
   `argv[0]` con el resto de `argv` y, como último argumento, la ruta del archivo, heredando la entrada y la
   salida (`Command::new(..).args(..).arg(&ruta).status()`); espera a que termine. Si el estado no es éxito →
   `Err(io::Error::other("el editor terminó con error"))`. Si va bien, lee el archivo, quita los saltos de
   línea finales (`trim_end_matches('\n')`, y también `\r`) y lo devuelve. Borra el archivo en los dos casos.
   Con `argv` vacío → `Err(io::Error::other("no hay editor configurado"))`.
4. `lib.rs`: añade `pub mod editor;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/editor.rs
use std::io;
use std::path::Path;

/// Orden del editor: `$VISUAL`, `$EDITOR` o el de por defecto, partida por espacios.
pub fn editor_argv(visual: Option<&str>, editor: Option<&str>) -> Vec<String>;

/// Abre `text` en el editor (archivo `dir/mensaje.md`) y devuelve lo que quede al cerrarlo.
pub fn edit_text(argv: &[String], dir: &Path, text: &str) -> io::Result<String>;
```

## Ejemplo (entrada y resultado esperado)

```
editor_argv(Some("code --wait"), Some("nano")) == ["code", "--wait"]
editor_argv(None, Some("nano"))                == ["nano"]
editor_argv(Some("  "), None)                  == ["vi"]            (en Linux)
editor falso para los tests (solo Unix): argv = ["sh", "-c", "printf 'nuevo\\n' > \"$1\"", "x"]
  edit_text(&argv, dir, "viejo") == Ok("nuevo")   y dir/mensaje.md ya no existe
editor que solo añade: argv = ["sh", "-c", "printf ' más' >> \"$1\"", "x"]
  edit_text(&argv, dir, "hola") == Ok("hola más")
argv = ["false"]  -> Err (y el archivo temporal se borra)
```

## Tests (con estos nombres)

- `editor_prefiere_visual_y_parte_argumentos`: los tres casos de `editor_argv` del ejemplo
- `editor_devuelve_el_texto_editado`: (con `#[cfg(unix)]`) el editor falso que escribe `nuevo` devuelve `Ok("nuevo")` y borra el archivo
- `editor_recibe_el_texto_actual`: (con `#[cfg(unix)]`) el editor que añade ` más` devuelve `hola más`
- `editor_que_falla_es_error`: (con `#[cfg(unix)]`) con `["false"]` devuelve `Err` y `dir/mensaje.md` no existe
- `editor_sin_orden_es_error`: con `argv` vacío devuelve `Err`
