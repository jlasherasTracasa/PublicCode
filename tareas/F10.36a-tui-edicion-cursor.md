## Objetivo

Funciones libres que editan un `String` con un cursor. El cursor es un índice en BYTES que siempre cae en un
límite de carácter (`text.is_char_boundary(cursor)`) y está entre 0 y `text.len()`.
1. Crea `edit.rs` con las funciones de las firmas. Todas dejan el cursor en un límite de carácter.
2. `insert` / `insert_str`: insertan en el cursor y lo avanzan tras lo insertado.
3. `backspace`: borra el carácter anterior al cursor (nada si el cursor es 0). `delete`: borra el carácter
   bajo el cursor (nada si está al final).
4. `left` / `right`: un carácter (no un byte). `home` / `end`: al principio / al final de la LÍNEA en la que
   está el cursor (las líneas se separan con `\n`).
5. `up` / `down`: a la línea anterior / siguiente, a la misma columna (contada en caracteres) o al final de
   esa línea si es más corta. Devuelven `false`, sin mover nada, si no hay línea anterior / siguiente.
6. `word_left`: retrocede sobre los espacios en blanco y después hasta el principio de la palabra.
   `word_right`: avanza hasta el final de la palabra y después sobre los espacios en blanco.
7. `delete_word_back`: borra desde `word_left` hasta el cursor. `kill_to_end`: borra desde el cursor hasta
   el final de la línea (sin el `\n`).
8. `row_col`: fila (líneas antes del cursor) y columna (caracteres desde el principio de su línea).
9. `lib.rs`: añade `pub mod edit;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/edit.rs
/// Inserta un carácter en el cursor.
pub fn insert(text: &mut String, cursor: &mut usize, c: char);
/// Inserta una cadena en el cursor.
pub fn insert_str(text: &mut String, cursor: &mut usize, s: &str);
/// Borra el carácter anterior al cursor.
pub fn backspace(text: &mut String, cursor: &mut usize);
/// Borra el carácter bajo el cursor.
pub fn delete(text: &mut String, cursor: &mut usize);
/// Mueve el cursor un carácter a la izquierda / derecha.
pub fn left(text: &str, cursor: &mut usize);
pub fn right(text: &str, cursor: &mut usize);
/// Principio / final de la línea del cursor.
pub fn home(text: &str, cursor: &mut usize);
pub fn end(text: &str, cursor: &mut usize);
/// Línea anterior / siguiente (`false` si no hay).
pub fn up(text: &str, cursor: &mut usize) -> bool;
pub fn down(text: &str, cursor: &mut usize) -> bool;
/// Palabra anterior / siguiente.
pub fn word_left(text: &str, cursor: &mut usize);
pub fn word_right(text: &str, cursor: &mut usize);
/// Borra la palabra anterior al cursor.
pub fn delete_word_back(text: &mut String, cursor: &mut usize);
/// Borra hasta el final de la línea.
pub fn kill_to_end(text: &mut String, cursor: &mut usize);
/// Fila y columna (en caracteres) del cursor.
pub fn row_col(text: &str, cursor: usize) -> (usize, usize);
```

## Ejemplo (entrada y resultado esperado)

```
text = "año", cursor = 4 (final): backspace -> "añ", cursor 3;  left -> cursor 1 (la `ñ` ocupa 2 bytes)
text = "hola mundo", cursor = 4: insert('!') -> "hola! mundo", cursor 5
text = "uno\ndos tres\nx", cursor = 8 (tras "dos "): home -> 4; end -> 12; up -> true, cursor 3 (columna 4 no existe en "uno": final de línea);
     down desde 8 -> true, cursor 14 (final de "x"); up desde 2 -> false
text = "git  commit -m", cursor = 14: word_left -> 12; word_left -> 5; delete_word_back con cursor 11 -> "git   -m" (tres espacios), cursor 5
text = "a b\nc", cursor = 1: kill_to_end -> "a\nc", cursor 1
row_col("uno\ndos", 6) == (1, 2)
```

## Tests (con estos nombres)

- `insertar_y_borrar_con_acentos`: el caso `año` y el de `hola mundo` del ejemplo
- `inicio_y_fin_de_linea`: `home` y `end` del tercer caso del ejemplo
- `arriba_y_abajo_conservan_la_columna`: los casos `up` y `down` del ejemplo, incluido el que devuelve false
- `palabras_a_izquierda_y_derecha`: los `word_left` del ejemplo y `word_right` desde 0 en `git  commit` deja el cursor en 5
- `borrar_palabra_y_hasta_fin_de_linea`: `delete_word_back` y `kill_to_end` del ejemplo
- `limites_no_fallan`: `left` en 0, `right` y `delete` al final y `backspace` en 0 no cambian nada ni entran en pánico
- `fila_y_columna`: `row_col("uno\ndos", 6) == (1, 2)` y `row_col("", 0) == (0, 0)`

## No hagas

- No uses índices de `char` como si fueran bytes: usa `char_indices`, `is_char_boundary` o `chars().rev()`
- No toques `app.rs` (es F10.36b)
