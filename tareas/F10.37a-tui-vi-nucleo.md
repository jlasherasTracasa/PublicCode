## Objetivo

1. Crea `vi.rs` con `ViMode`, `ViOutcome` y `Vi` (firmas abajo). `Vi::new()` empieza en `Insert`.
2. `Vi::key(text, cursor, k)` en modo `Insert`: `Esc` → pasa a `Normal`, devuelve `Handled`. Cualquier otra
   tecla → `PassThrough` (la trata la TUI como siempre).
3. En modo `Normal`: si la tecla lleva CONTROL o ALT → `PassThrough`. `Enter` → `Submit`. Para
   `KeyCode::Char(c)` (todas devuelven `Handled`):
   - movimiento: `h` → `left`; `l` → `right`; `k` → `up`; `j` → `down`; `0` → `home`; `$` → `end`;
     `w` → `word_right`; `b` → `word_left`.
   - a inserción: `i` (sin mover); `a` (`right` y después inserción); `I` (`home`); `A` (`end`);
     `o` (`end`, inserta `\n`).
   - borrado: `x` → `delete`; `D` → `kill_to_end`; `d` seguido de `d` → borra la línea del cursor entera,
     con su salto de línea (si es la última línea, el salto anterior), y deja el cursor al principio de la
     línea que queda en su lugar. Una `d` suelta se recuerda en `pending`; cualquier otra tecla la cancela.
   - cualquier otro carácter: no hace nada.
   Las demás teclas (flechas, Backspace, Tab…) → `PassThrough`.
4. `lib.rs`: añade `pub mod vi;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/vi.rs
use ratatui::crossterm::event::KeyEvent;

/// Modo de vi.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ViMode { Insert, Normal }

/// Qué hizo vi con una tecla.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ViOutcome {
    /// Tratada: no hay nada más que hacer.
    Handled,
    /// No es de vi: que la trate la TUI.
    PassThrough,
    /// Enviar el mensaje.
    Submit,
}

/// Estado del modo vi de la entrada.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Vi {
    /// Modo actual.
    pub mode: ViMode,
    pending: Option<char>,
}

impl Vi {
    /// Empieza en modo inserción.
    pub fn new() -> Vi;
    /// Trata una tecla sobre `text` con el cursor `cursor` (índice en bytes).
    pub fn key(&mut self, text: &mut String, cursor: &mut usize, k: KeyEvent) -> ViOutcome;
}
```

## Ejemplo (entrada y resultado esperado)

```
modo Insert, tecla `x`            -> PassThrough (el texto no cambia aquí)
Esc                               -> Handled, mode == Normal
text "hola mundo", cursor 10, Normal:  `0` -> cursor 0;  `w` -> 5;  `x` -> "hola undo";  `$` -> 9
`A` -> cursor al final y mode == Insert;  `i` -> mode == Insert sin mover
text "uno\ndos\ntres", cursor 5 (en "dos"), Normal: `d`,`d` -> "uno\ntres", cursor 4
text "uno\ndos", cursor 5: `d`,`d` -> "uno", cursor 0
text "solo", `d`,`d` -> "", cursor 0
`d`, `w` -> no borra nada (la `d` pendiente se cancela) y el cursor avanza una palabra
Enter en Normal -> Submit;  Ctrl+C en Normal -> PassThrough
```
