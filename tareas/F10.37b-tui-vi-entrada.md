# F10.37b-tui-vi-entrada — TUI: usar el modo vi en la entrada y mostrar el modo

## Objetivo

1. `app.rs`: añade a `App` `pub vi: Option<crate::vi::Vi>` (doc: «Modo vi de la entrada, si está activado»),
   `None` en `App::new`.
2. `app.rs`, `key`: después de los bloques modales (aprobación, ayuda, revisión, selector, búsqueda y líder)
   y ANTES del bloque de sugerencias, si `self.vi` es `Some(vi)` y no se cumple
   `self.busy && k.code == KeyCode::Esc` (Esc sigue interrumpiendo al agente):
   `match vi.key(&mut self.input, &mut self.cursor, k)`: `Handled` → `return vec![]`; `Submit` →
   `return self.submit()`; `PassThrough` → sigue con el código actual.
3. `i18n.rs`: añade al final de `ES` y `EN`: `vi_normal` = `" -- NORMAL -- "` y `vi_insert` =
   `" -- INSERT -- "` (iguales en los dos idiomas).
4. `render.rs`, caja de la entrada: si `app.vi` es `Some(vi)`, añade al `Block` un título arriba a la derecha:
   `.title_top(Line::from(Span::styled(t(app.lang, clave), estilo)).right_aligned())`, con `vi_normal` y
   `th.warning()` en modo `Normal`, o `vi_insert` y `th.dimmed()` en modo `Insert`.

Sin firmas: Solo añade el campo `vi` a App; el resto es una llamada a `Vi::key`, dos textos y un título

## Ejemplo (entrada y resultado esperado)

```
app.vi = Some(Vi::new()); teclear "hola" -> input == "hola" (inserción: las teclas pasan)
Esc                      -> modo Normal; input sigue "hola"; ninguna orden
`0`, `x`                 -> input == "ola"
`i`, teclear "H"         -> input == "Hola"
Esc, Intro               -> [Command::Send("Hola")]
con app.busy = true y vi en inserción, Esc -> [Command::Cancel] (no cambia de modo)
con app.vi == None, la tecla `x` se escribe como siempre
pantalla 80×24: en Normal la fila 20 acaba en "-- NORMAL -- ╮"; en inserción, en "-- INSERT -- ╮"
```

## Tests (con estos nombres)

- `vi_entrada_edita_en_normal_y_vuelve_a_insertar`: los cinco primeros pasos del ejemplo
- `vi_entrada_esc_interrumpe_si_esta_ocupado`: con `busy = true`, Esc devuelve `[Command::Cancel]` y el modo sigue siendo `Insert`
- `vi_entrada_desactivado_no_cambia_nada`: con `vi == None`, Esc y `x` se comportan como antes (`x` se escribe)
- `vi_entrada_render_muestra_el_modo_80x24`: la fila 20 contiene `-- NORMAL --` en modo normal y `-- INSERT --` en inserción; sin vi, ninguna de las dos

## No hagas

- No actives vi por defecto
- No dejes que vi capture teclas cuando hay una ventana modal abierta (aprobación, ayuda, revisión, selector, búsqueda)
- No cambies el título izquierdo de la caja ni el título inferior del modo Build/Plan
