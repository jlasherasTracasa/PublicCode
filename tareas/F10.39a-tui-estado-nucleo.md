## Objetivo

1. Crea `status.rs` con `StatusItem`, `parse_items`, `StatusData`, `cost_usd` y `status_text` (firmas abajo).
2. Nombres en la configuración: `modelo` → `Model`, `tokens` → `Tokens`, `contexto` → `Context`, `coste` →
   `Cost`, `rama` → `Branch`, `modo` → `Mode`. `parse_items` devuelve los elementos en el orden recibido; un
   nombre desconocido →
   `Err("elemento de estado desconocido «<nombre>»: usa modelo, tokens, contexto, coste, rama o modo")`.
3. `cost_usd(usage, price_in, price_out)`: precios en dólares por MILLÓN de tokens:
   `(input_tokens * price_in + output_tokens * price_out) / 1_000_000`.
4. `status_text(items, d, lang)`: el texto de cada elemento, unidos con `" · "`. Los que no tienen dato se
   omiten (sin dejar separador):
   - `Model` → `d.model`.
   - `Tokens` → `"↑<in> ↓<out>"` con `human_tokens`.
   - `Context` → `"<contexto> <pct> %"` con `t(lang, "context")`; se omite si `context_percent` es `None`.
   - `Cost` → `"$<coste con 2 decimales>"`; se omite si `cost` es `None`.
   - `Branch` → `"⎇ <rama>"`; se omite si `branch` es `None`.
   - `Mode` → `t(lang, "plan")` si `d.plan`; se omite si no.
5. `lib.rs`: añade `pub mod status;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/status.rs
use crate::i18n::Lang;
use pcode_models::Usage;

/// Un elemento de la línea de estado.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StatusItem { Model, Tokens, Context, Cost, Branch, Mode }

/// Elementos a partir de sus nombres en `[preferencias] estado`.
pub fn parse_items(names: &[String]) -> Result<Vec<StatusItem>, String>;

/// Datos que puede mostrar la línea de estado.
#[derive(Debug, Clone, PartialEq)]
pub struct StatusData<'a> {
    pub model: &'a str,
    pub usage: Usage,
    pub context_percent: Option<u64>,
    pub cost: Option<f64>,
    pub branch: Option<&'a str>,
    pub plan: bool,
}

/// Coste en dólares con precios por millón de tokens.
pub fn cost_usd(usage: &Usage, price_in: f64, price_out: f64) -> f64;

/// Texto de la línea de estado.
pub fn status_text(items: &[StatusItem], d: &StatusData, lang: Lang) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
d = StatusData { model: "glm-4", usage: Usage { input_tokens: 12_300, output_tokens: 950, cached_input_tokens: 0 },
                 context_percent: Some(25), cost: Some(0.4267), branch: Some("main"), plan: true }
status_text(&[Model, Tokens, Context, Cost, Branch, Mode], &d, Lang::Es) ==
  "glm-4 · ↑12.3k ↓950 · contexto 25 % · $0.43 · ⎇ main · PLAN"
con context_percent: None, cost: None, branch: None, plan: false ->  "glm-4 · ↑12.3k ↓950"
status_text(&[], &d, Lang::Es) == ""
cost_usd(&Usage { input_tokens: 1_000_000, output_tokens: 500_000, .. }, 3.0, 15.0) == 10.5
parse_items(&["rama".into(), "modelo".into()]) == Ok(vec![Branch, Model])
```
