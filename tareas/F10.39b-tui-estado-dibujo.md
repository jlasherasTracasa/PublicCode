## Objetivo

1. `app.rs`: añade a `App` tres campos con su `///`: `pub status_items: Vec<crate::status::StatusItem>`
   («Elementos de la línea de estado; vacío = la de siempre»), `pub branch: Option<String>` («Rama de git
   del proyecto») y `pub prices: Option<(f64, f64)>` («Precio de entrada y de salida, en dólares por millón
   de tokens»). En `App::new`: `vec![]`, `None`, `None`.
2. `render.rs`, barra de estado: si `app.status_items` está vacío, TODO se dibuja exactamente como ahora. Si
   no, la parte izquierda (lo que hoy son los tokens y el medidor de contexto) se sustituye por un solo
   `Span::styled(format!(" {} ", texto), th.dimmed())`, con `texto = status_text(&app.status_items, &datos, app.lang)` y
   `datos = StatusData { model: &app.model, usage: app.usage, context_percent: (app.context_limit > 0).then(|| app.context_percent()), cost: app.prices.map(|(i, o)| cost_usd(&app.usage, i, o)), branch: app.branch.as_deref(), plan: app.plan }`.
   `used` pasa a ser el número de caracteres de ese span. La parte derecha (atajos `hint` / `hint_short`,
   relleno) no cambia.

Sin firmas: Solo añade los campos `status_items`, `branch` y `prices` a App; el dibujo usa las funciones de F10.39a

## Ejemplo (entrada y resultado esperado)

```
app.status_items = [Model, Branch, Context]; app.model = "glm-4"; app.branch = Some("main"); límite 160000, uso 40000
pantalla 80×24: la fila 23 empieza por " glm-4 · ⎇ main · contexto 25 % " y acaba en "Ctrl+C sale"
app.status_items = [Cost]; app.prices = Some((3.0, 15.0)); usage 1_000_000 / 500_000 -> la fila 23 empieza por " $10.50 "
app.status_items vacío -> la fila 23 empieza por " ↑0 ↓0 tokens" (como siempre)
```

## Tests (con estos nombres)

- `status_linea_configurada_80x24`: el primer caso del ejemplo
- `status_linea_configurada_120x40`: lo mismo a 120×40 (fila 39)
- `status_linea_con_coste`: el segundo caso del ejemplo
- `status_linea_por_defecto_no_cambia`: con `status_items` vacío la fila 23 empieza por ` ↑0 ↓0 tokens`

## No hagas

- No cambies la barra por defecto: los tests `render_80x24_transcripcion_entrada_y_estado` y `medidor_de_contexto_en_la_barra_80x24_y_120x40` deben seguir pasando
- No cambies la barra cuando la tecla líder está activa (`app.leader`)
- No leas la rama de git desde `render.rs`
