## Objetivo

1. Crea `sesiones.rs` con `SessionsArgs`, `SessionsCmd` y `pub fn sessions(a: SessionsArgs) -> anyhow::Result<i32>`
   (firmas abajo). Abre `Store::open(&cwd.join(".pcode/pcode.db"))`.
2. Sin suborden o con `listar`: las 50 últimas (`sessions(50)`). En texto, una línea por sesión:
   `"#<id>  <n> mensajes  <modelo>  <título>"` (el título es `task`); si no hay ninguna,
   `"No hay conversaciones guardadas en este proyecto."`. Con `--formato json`, una sola línea con una lista de
   objetos `{"id", "titulo", "modelo", "mensajes", "creado_ms"}`.
3. `buscar <texto>`: `search(texto, 20)`. En texto, por cada resultado dos líneas: `"#<id>  <título>"` y
   `"    <fragmento>"`; sin resultados, `"Sin resultados."`. Con `--formato json`, lista de
   `{"id", "titulo", "fragmento"}`.
4. `bifurcar <id>`: `fork(id)`: con `Some(nuevo)` imprime
   `"Sesión <id> bifurcada en la <nuevo>. Retómala con: pcode tui --sesion <nuevo>"` y devuelve 0; con `None`,
   escribe en stderr `"no existe la sesión <id>"` y devuelve 2.
5. `--formato` distinto de `texto` y `json` → `anyhow::bail!("formato desconocido «…»: usa texto o json")`.
6. `main.rs`: `mod sesiones;`, variante `Sesiones(sesiones::SessionsArgs)` en `Cmd` con el doc
   `/// Conversaciones guardadas de este proyecto: listar, buscar texto y bifurcar.` y el brazo
   `Some(Cmd::Sesiones(a)) => std::process::exit(sesiones::sessions(a)?),`.
7. Crea `tests/sesiones.rs` (copia los ayudantes `resp` y `pcode` de `tests/chat.rs`); todos los tests de
   esta tarea empiezan por `orden_`.

```rust
// crates/pcode-cli/src/sesiones.rs
/// Argumentos de `pcode sesiones`.
#[derive(Debug, clap::Args)]
pub struct SessionsArgs {
    #[command(subcommand)]
    pub cmd: Option<SessionsCmd>,
    /// `texto` (por defecto) o `json`.
    #[arg(long = "formato", default_value = "texto", global = true)]
    pub format: String,
}

/// Subórdenes de `pcode sesiones`.
#[derive(Debug, clap::Subcommand)]
pub enum SessionsCmd {
    /// Lista las últimas conversaciones (es lo que hace `pcode sesiones` a secas).
    Listar,
    /// Busca un texto en los mensajes de las conversaciones guardadas.
    Buscar { texto: String },
    /// Crea una copia de una conversación para seguir por otro camino.
    Bifurcar { id: i64 },
}

/// Ejecuta `pcode sesiones` y devuelve el código de salida.
pub fn sessions(a: SessionsArgs) -> anyhow::Result<i32>;
```
