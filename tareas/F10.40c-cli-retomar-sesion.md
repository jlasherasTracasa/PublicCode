# F10.40c-cli-retomar-sesion — CLI: `pcode chat --sesion <id>` y `pcode tui --sesion <id>` retoman una conversación concreta

- crates/pcode-cli/tests/chat.rs (test `chat_continuar_retoma_la_conversacion`: el modelo de test)

## Objetivo

1. `chat.rs`, `ChatArgs`: añade el campo `session` (firma abajo) y `session: None` en `default_args`.
2. `chat.rs`, `prepare`: antes del bloque de `a.resume`, si `a.session` es `Some(id)`:
   `match load_session(&persist.store, id)`: con `None` →
   `anyhow::bail!("no existe la sesión {id} en este proyecto (mira `pcode sesiones`)")`; con `Some(msgs)`,
   haz lo mismo que el bloque de `--continuar` con `sid = id`: sustituye el primer mensaje por el prompt de
   sistema actual si es de sistema, `persist.session = Some(id)`, `persist.saved = msgs.len()`,
   `resumed = Some((id, msgs.len()))` y `history = msgs`. Para no duplicar, saca esas líneas a un cierre o a
   una función privada que usen los dos caminos.
3. Añade a `tests/sesiones.rs` los tests de la lista (empiezan por `retomar_`).

## Ejemplo (entrada y resultado esperado)

```
$ pcode chat primero             (mock «uno»)   -> sesión 1
$ pcode chat otra cosa           (mock «dos»)   -> sesión 2
$ pcode chat --sesion 1 sigue    (mock «tres»)  -> stdout contiene «Retomando la sesión 1» y «tres»
$ pcode chat --sesion 9 hola     -> código distinto de 0; stderr contiene «no existe la sesión 9»
$ pcode chat --sesion 1 --continuar x -> error de clap (opciones incompatibles)
```

## Tests (con estos nombres)

- `retomar_por_numero_de_sesion`: los tres primeros pasos del ejemplo; además `pcode sesiones` sigue listando 2 sesiones (no se crea una tercera)
- `retomar_sesion_inexistente_falla`: `--sesion 9` sale con código distinto de 0 y stderr contiene `no existe la sesión 9`
- `retomar_es_incompatible_con_continuar`: `--sesion 1 --continuar` sale con código distinto de 0
