## Objetivo

1. `assist.rs`: añade `ReviewTarget` y `review_prompt_for` (firmas abajo).
2. `review_prompt_for(root, target)`: si `!is_git(root)` → `Err("el proyecto no es un repositorio git")`.
   El diff depende de `target`:
   - `Worktree`: como ahora (`git diff --no-color --no-ext-diff HEAD`, y si falla, sin `HEAD`). Vacío →
     `Err("no hay cambios que revisar")`.
   - `Staged`: `git diff --no-color --no-ext-diff --cached`. Vacío →
     `Err("no hay cambios preparados (git add) que revisar")`.
   - `Base(rama)`: primero valida el nombre: no vacío, no empieza por `-` y solo letras, cifras y `._/-`; si
     no → `Err("nombre de rama no válido")`. Diff: `git diff --no-color --no-ext-diff <rama>...HEAD`. Vacío →
     `Err(format!("no hay cambios respecto a {rama}"))`.
   Con el diff, el resto es idéntico a lo que hoy hace `review_prompt` (mismo texto, `touched_symbols` y
   `clip(&diff, MAX_DIFF)`).
3. `review_prompt(root)` pasa a ser `review_prompt_for(root, &ReviewTarget::Worktree)`: mueve el cuerpo, no
   lo dupliques.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/assist.rs
/// Qué cambios se revisan.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ReviewTarget {
    /// Todo lo que no está en un commit.
    Worktree,
    /// Solo lo preparado con `git add`.
    Staged,
    /// Los commits de la rama actual que no están en esa rama base.
    Base(String),
}

/// Prompt para revisar los cambios de `target`.
pub fn review_prompt_for(root: &Path, target: &ReviewTarget) -> WsResult<String>;
```

## Ejemplo (entrada y resultado esperado)

```
repositorio con un commit; se cambia lib.rs sin `git add`:
  review_prompt_for(r, &Worktree) -> Ok(prompt con el diff)
  review_prompt_for(r, &Staged)   -> Err("no hay cambios preparados (git add) que revisar")
tras `git add lib.rs`:
  review_prompt_for(r, &Staged)   -> Ok(prompt que contiene "Mantenibilidad" y la línea cambiada)
tras `git branch base`, y un commit nuevo con el cambio:
  review_prompt_for(r, &Base("base".into())) -> Ok(prompt con el diff del commit)
  review_prompt_for(r, &Base("--output=x".into())) -> Err("nombre de rama no válido")
```

## Tests (con estos nombres)

- `revisar_staged_solo_lo_preparado`: sin `git add` da el `Err` del ejemplo; tras `git add`, `Ok` con `Mantenibilidad` y la línea nueva
- `revisar_respecto_a_una_rama`: el caso `Base("base")` del ejemplo contiene la línea del commit nuevo
- `revisar_rama_no_valida_es_error`: `Base("--output=x")` y `Base("")` dan `nombre de rama no válido`
- `revisar_rama_sin_cambios_lo_dice`: `Base("base")` justo después de crear la rama da `no hay cambios respecto a base`
- `revisar_worktree_sigue_igual`: `review_prompt(r)` y `review_prompt_for(r, &Worktree)` devuelven lo mismo
