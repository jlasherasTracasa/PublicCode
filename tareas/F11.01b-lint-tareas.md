## Objetivo

1. Crea `lint.rs` con las firmas de abajo. `lint_task` devuelve los problemas de UNA tarea; `b` es
   `parse_brief(&t.body)`. Longitudes con `.chars().count()`. Cada problema lleva `rule` y `message`:
   - `acepta`: `t.accept` tiene más de una línea, o (quitando espacios) contiene `||true` o acaba en `;true`.
   - `pendiente`: el cuerpo contiene `PENDIENTE:` («quedan partes sin rellenar»).
   - Si `b.executor == "coordinador"`: `coordinador` si `coordinator_reason` es None; y no se mira nada más.
   - `talla`: `size` no es `S` ni `M`.
   - `toca`: vacío sin ser de cierre (`b.closing`); más de `MAX_TOUCHES`; rutas repetidas; o una ruta cuyo
     nombre de archivo (lo que sigue a la última `/`) no aparece en objetivo + firmas + notas.
   - `contexto`: `context` vacío.
   - `objetivo` (solo si no es de cierre): menos de `MIN_OBJECTIVE` caracteres o menos de 2 pasos numerados
     (líneas que, sin espacios iniciales, empiezan por cifras seguidas de `. `).
   - `longitud`: objetivo + firmas + ejemplo + notas suman más de `MAX_TEXT`.
   - `firmas`: alguna ruta de `touches` acaba en `.rs .ts .tsx .js .jsx .py .kt .sh .ps1`, `signatures` está
     vacío y `no_signatures` es false.
   - `tests`: por cada test que no empiece por `(`: se parte en el primer `:`; el nombre debe empezar por
     letra o `_` y la descripción tener al menos `MIN_TEST_DESC` caracteres.
   - `rutas`: por cada palabra del contexto (separa por espacios, paréntesis, comas y comillas invertidas;
     quita `.,:;` finales) que contenga `/`, no contenga `*` ni `<`, y cuyo último tramo contenga `.` o que
     acabe en `/`: si `exists(palabra)` es false → problema.
2. `lint_all`: aplica `lint_task` a cada tarea cuyo id no esté en `done`. Para la regla `rutas`, una ruta
   también «existe» si está en `touches` o `extra` de cualquier tarea de la lista.
3. `lib.rs`: añade `pub mod lint;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-flow/src/lint.rs
use crate::brief::Brief;
use crate::task::TaskDef;
use std::collections::HashSet;

pub const MAX_TOUCHES: usize = 4;
pub const MIN_OBJECTIVE: usize = 300;
pub const MAX_TEXT: usize = 7000;
pub const MIN_TEST_DESC: usize = 12;

/// Un problema de una tarea.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct LintIssue {
    #[serde(rename = "tarea")]
    pub task: String,
    #[serde(rename = "regla")]
    pub rule: &'static str,
    #[serde(rename = "mensaje")]
    pub message: String,
}

/// Problemas de una tarea. `exists` dice si una ruta citada existe en el proyecto.
pub fn lint_task(t: &TaskDef, b: &Brief, exists: &dyn Fn(&str) -> bool) -> Vec<LintIssue>;

/// Problemas de todas las tareas abiertas (las de `done` se saltan).
pub fn lint_all(tasks: &[TaskDef], done: &HashSet<String>, exists: &dyn Fn(&str) -> bool) -> Vec<LintIssue>;
```

## Tests (con estos nombres)

- `tarea_valida_sin_problemas`: la tarea del ejemplo da una lista vacía
- `acepta_que_siempre_pasa`: `acepta` igual a `cargo test || true` da la regla acepta
- `objetivo_corto_o_sin_pasos`: un objetivo de una frase da la regla objetivo
- `codigo_sin_firmas`: toca a.rs sin sección Firmas ni «Sin firmas:» da la regla firmas
- `toca_no_mencionado`: una ruta de toca cuyo nombre no sale en el objetivo da la regla toca
- `mas_de_cuatro_archivos`: cinco rutas en toca dan la regla toca
- `test_sin_descripcion`: el test `x: corto` da la regla tests
- `coordinador_sin_motivo`: ejecutor coordinador sin motivo da solo la regla coordinador
- `cierre_con_toca_vacio_vale`: una tarea con sección Subtareas y sin toca no da la regla toca ni objetivo
- `ruta_de_contexto_que_no_existe`: contexto `src/no.rs (función x)` con exists siempre false da la regla rutas
- `pendiente_sin_rellenar`: un cuerpo con `PENDIENTE:` da la regla pendiente
- `lint_all_salta_las_hechas`: una tarea con problemas cuyo id está en done no aparece

## No hagas

- No añadas dependencias (ni `regex`)
- No leas el disco en `lint.rs`: la existencia de rutas entra por `exists`
