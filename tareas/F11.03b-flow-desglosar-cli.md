# F11.03b-flow-desglosar-cli — CLI: `pcode flow desglosar <tarea>` escribe las subtareas como borrador

## Objetivo

1. En `flow_cmd.rs`, variante `Desglosar { tarea: String, tareas: PathBuf, overwrite: bool, model, provider,
   config }` con `--tareas` (por defecto `tareas`), `--sobrescribir`, `--modelo`, `--proveedor` y `--config`
   (por defecto `pcode.toml`), como en `AskArgs`.
2. Rama `Desglosar`: carga `task::load_dir(&tareas)`; si `tarea` no existe → `anyhow::bail!("no existe la
   tarea <id>")`. Calcula `lint_task` (con `parse_brief(&t.body)` y `|p| root.join(p).exists()`); sin
   problemas imprime `la tarea <id> ya es apta: no hace falta partirla` y devuelve 0.
3. Pide el desglose: `Config::load_layered(&config)`, `build_provider`, `pick_model` y
   `sel.provider.chat(&ChatRequest { model, messages: vec![Message::user(prompt)], tools: vec![],
   max_tokens: Some(8000), ..Default::default() })`. Hasta 3 rondas (bucle `for` con cota): `parse_blocks`
   sobre `r.message.content` y `check_split`; si hay problemas, la ronda siguiente usa
   `split_prompt(.., Some((&respuesta, &problemas)))`.
4. Si tras 3 rondas quedan problemas: imprímelos en stderr y devuelve 2 SIN escribir nada.
5. Si vale: los archivos van a `<tareas>/borradores/<id>.md`. Si alguno existe y no hay `--sobrescribir`,
   no escribas ninguno: stderr `ya existe <ruta> (usa --sobrescribir)` y devuelve 2. Si no, crea la carpeta,
   escribe todos e imprime una línea `borrador: <ruta>` por archivo y, al final,
   `Revísalas y muévelas a <tareas>/ cuando estén bien.`
6. Añade a `tests/flow.rs` los tests de la lista, con el guion del modelo simulado (`PCODE_MOCK_SCRIPT`).

Sin firmas: solo añade una variante de `FlowCmd` y su rama; la API está en `pcode_flow::split`

## Ejemplo (entrada y resultado esperado)

```
tareas/T1.md: una tarea que no pasa el lint (objetivo de una frase).
Guion del modelo: una respuesta cuyo content es "<<<T1a.md\n{valida T1a}\n>>>\n<<<T1b.md\n{valida T1b}\n>>>\n"
$ pcode flow desglosar T1     → código 0, existen tareas/borradores/T1a.md y T1b.md, stdout contiene "borrador: tareas/borradores/T1a.md"
$ pcode flow desglosar T1     (otra vez, mismo guion) → código 2, stderr contiene "ya existe"
```

## Tests (con estos nombres)

- `desglosar_escribe_borradores`: con el guion del ejemplo se crean los dos archivos en tareas/borradores
- `desglosar_no_pisa_sin_permiso`: la segunda ejecución sale con 2 y no cambia el contenido del borrador
- `desglosar_respuesta_mala_no_escribe`: tres respuestas sin bloques dan código 2 y no existe tareas/borradores
- `desglosar_tarea_apta_no_llama_al_modelo`: una tarea válida y un guion vacío dan código 0 y el mensaje «ya es apta»

## No hagas

- No escribas nunca en `<tareas>/` directamente: solo en `borradores/`
- No uses tools ni el bucle del agente: es una sola petición de chat por ronda
- No pongas un bucle sin cota

## Notas

En los tests, las subtareas válidas se construyen con un auxiliar `valida(id, depende)` (misma forma que en
los tests de `lint.rs`: cabeceras `acepta`/`modo`/`depende`, ficha con Talla S, Toca con un archivo que el
objetivo nombra, Contexto, Objetivo con 2 pasos y más de 300 caracteres, Firmas y Tests).
