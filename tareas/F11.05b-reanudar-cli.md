## Objetivo

1. En `flow_cmd.rs`, cambia `session` a la firma de abajo: con `fresh == false` hace lo de ahora (reutiliza la
   sesión cuyo `task == "flujo"` o la crea); con `fresh == true` crea siempre una nueva con
   `store.create_session("flujo", "flujo")`. Como `store.sessions(50)` devuelve primero las más recientes, la
   nueva pasa a ser la que se reutiliza después. Pasa `fresh` a través de `runner(...)` (parámetro nuevo).
2. Rama `Run`: flag `--nuevo` (bool, «Empieza un flujo nuevo en lugar de retomar el anterior.»). Antes de
   `run_until_idle`: borra `.pcode/STOP` si existe (`let _ = std::fs::remove_file(..)`), llama a
   `r.recover()` y, si devuelve algo, imprime en stderr `retomo <N> tareas interrumpidas: a, b`.
3. Variante nueva `Parar` («Pide parar el flujo: no se lanzan más tareas.»): crea `.pcode/` si falta, escribe
   el archivo vacío `.pcode/STOP`, imprime `parada pedida: las tareas en marcha terminan y no se lanzan más`
   y devuelve 0.
4. Tests: el de `session` en un módulo `#[cfg(test)] mod tests` al final de `flow_cmd.rs`; el de `parar` en
   `tests/flow.rs`.

## Ejemplo (entrada y resultado esperado)

```
let store = Store::open_in_memory()?;
let a = session(&store, false)?;   // crea
let b = session(&store, false)?;   // reutiliza → a == b
let c = session(&store, true)?;    // nueva → c != a
let d = session(&store, false)?;   // reutiliza la más reciente → d == c
$ pcode flow parar   → código 0 y existe .pcode/STOP
```

## Tests (con estos nombres)
