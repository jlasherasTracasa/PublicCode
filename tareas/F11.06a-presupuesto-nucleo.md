## Objetivo

1. Crea `budget.rs` con los tipos y métodos de abajo.
2. `Spent::add`: suma campo a campo.
3. `FlowBudget::cost_eur`: `tokens_in / 1_000_000 * eur_per_mtok_in + tokens_out / 1_000_000 *
   eur_per_mtok_out` (en `f64`).
4. `FlowBudget::exceeded`: devuelve el primer límite alcanzado (gastado >= límite), en este orden y con estos
   textos exactos:
   - tokens (entrada + salida): `presupuesto de tokens agotado: <gastado> de <límite>`
   - euros: `presupuesto de coste agotado: <gastado con 2 decimales> € de <límite con 2 decimales> €`
   - minutos (`seconds / 60`, división entera): `presupuesto de tiempo agotado: <min> min de <límite> min`
   Un límite a `None` no se comprueba. Con todo a `None` devuelve siempre `None`.
5. `lib.rs`: añade `pub mod budget;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-flow/src/budget.rs
/// Límites de un flujo entero (None = sin límite) y precios para estimar el coste.
#[derive(Debug, Clone, Copy, Default, PartialEq)]
pub struct FlowBudget {
    pub max_tokens: Option<u64>,
    pub max_eur: Option<f64>,
    pub max_minutes: Option<u64>,
    /// Euros por millón de tokens de entrada.
    pub eur_per_mtok_in: f64,
    /// Euros por millón de tokens de salida.
    pub eur_per_mtok_out: f64,
}

/// Lo gastado hasta ahora.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Spent { pub tokens_in: u64, pub tokens_out: u64, pub seconds: u64 }

impl Spent {
    /// Suma otro gasto.
    pub fn add(&mut self, other: &Spent);
}

impl FlowBudget {
    /// Coste estimado en euros.
    pub fn cost_eur(&self, s: &Spent) -> f64;
    /// Motivo de parada si se alcanzó algún límite.
    pub fn exceeded(&self, s: &Spent) -> Option<String>;
}
```

## Ejemplo (entrada y resultado esperado)

```
b = FlowBudget { max_tokens: Some(1000), ..Default::default() }
b.exceeded(&Spent { tokens_in: 900, tokens_out: 300, seconds: 0 }) → Some("presupuesto de tokens agotado: 1200 de 1000")
b.exceeded(&Spent { tokens_in: 500, tokens_out: 100, seconds: 0 }) → None
FlowBudget { max_eur: Some(1.0), eur_per_mtok_in: 2.0, eur_per_mtok_out: 10.0, ..Default::default() }
  .exceeded(&Spent { tokens_in: 250_000, tokens_out: 100_000, seconds: 0 }) → Some("presupuesto de coste agotado: 1.50 € de 1.00 €")
```

## Tests (con estos nombres)

- `tokens_agotados`: el primer caso del ejemplo devuelve el texto exacto
- `dentro_del_presupuesto`: el segundo caso devuelve None
- `coste_en_euros`: el tercer caso devuelve el texto con dos decimales

- `sin_limites_nunca_para`: FlowBudget::default() devuelve None con cualquier gasto
