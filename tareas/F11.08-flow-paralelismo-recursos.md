## Objetivo

Hoy `pcode flow run` lanza 4 tareas a la vez en cualquier equipo. En un equipo modesto (perfil ligero) deben ir
de una en una, salvo que la persona suba el límite en la configuración.
1. `crates/pcode-config/src/lib.rs`: añade a `ResourcesCfg` el campo
   `#[serde(rename = "flujo_paralelo")] pub flow_parallel: Option<usize>` («Tareas de un flujo en paralelo
   como máximo.») y el método `ResourcesCfg::flow_parallel_limit` (firma abajo):
   `self.flow_parallel.unwrap_or(si self.resolve(sys).light → 1, si no → 4).max(1)`. No cambies el struct
   `Resources` (lo construyen otros crates).
2. `flow_cmd.rs`: el flag `--paralelo` pasa a ser `Option<usize>` (sin valor por defecto; comentario
   «Tareas en paralelo como máximo (por defecto, el límite del perfil de recursos).»). Añade la función
   `effective_parallel` (firma abajo): `flag.unwrap_or(limit).min(limit).max(1)`.
3. Rama `Run`: `let limit = conf.resources.flow_parallel_limit(pcode_config::SystemInfo::detect());` y
   `max_parallel: effective_parallel(paralelo, limit)`. Si el flag pedía más que el límite, imprime en stderr
   `paralelo limitado a <limit> por el perfil de recursos (súbelo con [recursos] flujo_paralelo)`.
4. Tests: `flujo_paralelo_*` en el módulo `tests` de `crates/pcode-config/src/lib.rs`; `paralelo_efectivo_*`
   en el módulo `tests` de `flow_cmd.rs`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-config/src/lib.rs
impl ResourcesCfg {
    /// Tareas de un flujo en paralelo como máximo: lo configurado o, si no, 1 en perfil ligero y 4 en normal.
    pub fn flow_parallel_limit(&self, sys: SystemInfo) -> usize;
}

// crates/pcode-cli/src/flow_cmd.rs
/// Paralelismo real: lo pedido con `--paralelo`, sin pasar del límite del perfil.
pub fn effective_parallel(flag: Option<usize>, limit: usize) -> usize;
```

## Ejemplo (entrada y resultado esperado)

```
modesto = SystemInfo { mem_total_mb: Some(3735), cpus: 2 }; grande = SystemInfo { mem_total_mb: Some(32768), cpus: 16 }
ResourcesCfg::default().flow_parallel_limit(modesto) → 1
ResourcesCfg::default().flow_parallel_limit(grande)  → 4
Config::from_str("[recursos]\nflujo_paralelo = 8\n")?.resources.flow_parallel_limit(modesto) → 8
effective_parallel(None, 4) → 4    effective_parallel(Some(2), 4) → 2    effective_parallel(Some(9), 4) → 4    effective_parallel(Some(0), 4) → 1
```

## Tests (con estos nombres)

- `flujo_paralelo_por_perfil`: sin configurar da 1 en el equipo modesto y 4 en el grande
- `flujo_paralelo_configurado_manda`: `flujo_paralelo = 8` da 8 aunque el perfil sea ligero, y 0 se queda en 1
- `paralelo_efectivo_respeta_el_limite`: los cuatro casos de effective_parallel del ejemplo
