## Objetivo

1. `retry.rs`: añade a `RetryPolicy` los campos `pub escalate_at: u32` («Intento a partir del cual se escala
   (1 = desde el primero).») y `pub escalate_model: Option<String>` («Modelo fuerte al que cambiar desde ese
   intento, sin cambiar de backend.»).
2. `next_backend`: sustituye la condición fija `attempt >= 3` por `attempt >= policy.escalate_at.max(1)`.
3. Añade `next_model` (firma abajo): `Some(modelo)` si `attempt >= policy.escalate_at.max(1)` y hay
   `escalate_model`; si no, `None`.
4. `runner.rs`: `Runner::execute` recibe el modelo: tras `let mut job = Job::new(&id, &t.body);` pon
   `job.model = crate::retry::next_model(attempt, &self.cfg.retry);`.
5. Actualiza todas las construcciones `RetryPolicy { … }` (`grep -rn "RetryPolicy {" crates/`): en los tests
   existentes, `escalate_at: 3, escalate_model: None`.
6. `flow_cmd.rs`, rama `Run`: flags `--escalar-en` (`u32`, por defecto 3, «Intento a partir del cual se usa
   el backend o el modelo de escalado.») y `--escalar-modelo` (`Option<String>`, «Modelo fuerte para los
   intentos escalados.»). Cambia el comentario de `--escalar` a «Backend al que escalar.».
7. Tests en el módulo `tests` de `retry.rs`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-flow/src/retry.rs
/// Modelo del intento `attempt` (None = el del backend).
pub fn next_model(attempt: u32, policy: &RetryPolicy) -> Option<String>;
```

## Ejemplo (entrada y resultado esperado)

```
p = RetryPolicy { max_attempts: 4, escalate_to: Some("claude".into()), escalate_at: 2, escalate_model: Some("opus".into()) }
next_backend("glm", 1, &p) → Some("glm")     next_backend("glm", 2, &p) → Some("claude")     next_backend("glm", 5, &p) → None
next_model(1, &p) → None                     next_model(2, &p) → Some("opus")
```

## Tests (con estos nombres)

- `escala_en_el_intento_configurado`: con escalate_at 2 el segundo intento usa el backend de escalado
- `escala_modelo_desde_el_intento`: next_model devuelve None en el 1 y el modelo fuerte en el 2
- `escala_sin_modelo_configurado`: con escalate_model None, next_model devuelve siempre None
- `escala_cero_cuenta_como_uno`: escalate_at 0 escala desde el primer intento

## No hagas

- No cambies la firma de `next_backend`
- No borres los tests `escala_en_el_tercero` y `bloquea_tras_maximo`: solo añádeles los campos nuevos
