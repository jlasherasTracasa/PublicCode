# F11.11b-flow-nueva-cli — CLI: `pcode flow nueva <id>` crea el archivo de la tarea sin pisar nada

## Objetivo

1. En `flow_cmd.rs`, variante nueva `Nueva { id: String, title: Option<String>, accept: String, touches:
   Vec<String>, tareas: PathBuf }` («Crea el esqueleto de una tarea.»): `id` posicional; `--titulo`;
   `--acepta` (obligatorio: `#[arg(long = "acepta")]` sin valor por defecto); `--toca` repetible
   (`#[arg(long = "toca")]` sobre `Vec<String>`); `--tareas` (por defecto `tareas`).
2. Rama `Nueva`:
   - el id solo admite letras, cifras, `.`, `-` y `_` y no puede estar vacío; si no, stderr
     `id no válido: <id> (letras, cifras, punto, guion y guion bajo)` y devuelve 2;
   - ruta = `<tareas>/<id>.md`; si ya existe: stderr `ya existe <ruta>: no se toca` y devuelve 2;
   - crea la carpeta si falta, escribe `task_template(&id, título o el propio id, &accept, &touches)` e
     imprime `creada: <ruta>` y, en otra línea,
     `Rellena lo marcado con PENDIENTE y comprueba con: pcode flow comprobar`. Devuelve 0.
3. Añade a `tests/flow.rs` los tests de la lista.

Sin firmas: solo añade una variante de `FlowCmd` y su rama; la plantilla está en `pcode_flow::template`

## Ejemplo (entrada y resultado esperado)

```
$ pcode flow nueva T7 --titulo "Exportar a CSV" --acepta "cargo test csv::" --toca src/csv.rs
creada: tareas/T7.md
Rellena lo marcado con PENDIENTE y comprueba con: pcode flow comprobar
$ pcode flow nueva T7 --acepta true      → código 2, stderr "ya existe tareas/T7.md: no se toca"
$ pcode flow nueva "a b" --acepta true   → código 2, stderr empieza por "id no válido"
```

## Tests (con estos nombres)

- `nueva_crea_el_archivo`: la primera orden del ejemplo crea tareas/T7.md con la cabecera acepta y la ruta en Toca
- `nueva_no_pisa`: repetir la orden sale con 2 y el archivo conserva su contenido
- `nueva_id_no_valido`: un id con espacio sale con 2 y no crea nada
- `nueva_y_comprobar_avisa_de_pendientes`: tras crearla, `flow comprobar` sale con 2 y menciona `[pendiente]`
