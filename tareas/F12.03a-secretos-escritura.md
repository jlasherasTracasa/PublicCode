# F12.03a-secretos-escritura — Agente: escribir un archivo que contiene un secreto requiere aprobación

**Fase** F12 · **Ejecutor** haiku · **Hito** 1.5 · **Talla** S · **Depende de** F12.02-censurar-secretos-auditoria

## Contexto (lee esto y nada más)

- crates/pcode-core/src/agent.rs (método `Agent::run_call`: el bloque que calcula `decision` con `check_effects`, `check_write` y `check_command`; y en `mod tests` los ayudantes `agent(&d, script, caps, hook)`, `tool(nombre, args)` y `text(…)`)
- crates/pcode-policy/src/secrets.rs (`pcode_policy::find_secrets(text) -> Vec<SecretHit>`; cada acierto tiene `kind: &'static str`)

## Objetivo

1. En `agent.rs`, método `run_call`: después del bloque que llama a `self.policy.check_command(&c)` y
   antes del `match decision`, añade: si `decision` es `Decision::Allow` y `effects` contiene
   `Effect::Write`, junta el texto de los argumentos `content` y `new` de la llamada (los que existan y
   sean cadenas; son los de las tools `escribir` y `editar`) y pásalo por
   `pcode_policy::find_secrets`. Si hay algún acierto:
   `decision = Decision::Ask(format!("el contenido parece contener un secreto ({})", tipos))`, donde
   `tipos` son los `kind` distintos, en orden de aparición, separados por `, `.
2. No cambies nada más: el `match decision` ya existente hace el resto (con aprobador pregunta; sin
   aprobador devuelve «requiere aprobación humana: …» y audita `ask-denied`; el archivo no se escribe).
3. Una decisión `Deny` o `Ask` anterior (política) no se toca: el secreto solo se mira si iba a ser `Allow`.
4. Tests en el `mod tests` de `agent.rs` con el prefijo `secreto_escritura_`, usando los ayudantes
   `agent`, `tool` y `text`. La clave de prueba se construye en el test
   (`format!("AKIA{}", "A".repeat(16))`), nunca literal.

## Ejemplo (entrada y resultado esperado)

```
llamada: escribir { path: "config.py", content: "KEY = '" + "AKIA" + 16 × "A" + "'" }   (sin aprobador)
resultado de la tool: "requiere aprobación humana: el contenido parece contener un secreto (aws-access-key)"
config.py no existe.
```

## Tests (con estos nombres)

- `secreto_escritura_sin_aprobador_no_escribe`: `escribir` con una clave en `content` devuelve un resultado que contiene `requiere aprobación humana` y `secreto`, y el archivo no existe
- `secreto_escritura_editar_tambien`: `editar` cuyo argumento `new` contiene una clave tampoco modifica el archivo
- `secreto_escritura_normal_pasa`: `escribir` con contenido sin secretos crea el archivo como antes
- `secreto_escritura_marcador_pasa`: `escribir` con `password = {env:DB_PASS}` crea el archivo (no es un secreto)

## No hagas

- No cambies la firma de `run_call` ni el `match decision`
- No toques los tests que ya existen en `agent.rs`
- No escribas tokens literales en los tests
