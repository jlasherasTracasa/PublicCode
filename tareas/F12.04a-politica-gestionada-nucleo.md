## Objetivo

1. `Cargo.toml` del crate: mueve `toml.workspace = true` de `[dev-dependencies]` a `[dependencies]`.
2. Crea `managed.rs` con `SYSTEM_POLICY`, `MANAGED_ENV`, `ManagedPolicy`, `managed_path`,
   `parse_managed`, `load_managed` y los métodos `model_allowed` y `summary` (firmas abajo).
3. Formato del archivo (TOML):
   ```
   modelos_permitidos = ["claude-*", "gpt-5*"]   # globs; vacío o ausente = cualquiera
   sin_red = false
   [politica]                                     # mismas claves que [politica] de pcode.toml
   denegar_ordenes = ["git push*"]
   red_permitir = ["api.anthropic.com"]
   ```
4. `managed_path(env_value, system)`: si `system` es un archivo que existe, devuelve `system` (el
   archivo del sistema SIEMPRE gana: la variable de entorno no puede esquivarlo). Si no, y `env_value`
   es `Some` y no está vacío, devuelve esa ruta. Si no, `None`.
5. `parse_managed(text)`: `toml::from_str`; el error se devuelve como `String` con el prefijo
   `política gestionada no válida: `. Las claves desconocidas son un error (`#[serde(deny_unknown_fields)]`
   en `ManagedPolicy`): un error de escritura no debe relajar la política en silencio.
6. `load_managed(path)`: `Ok(None)` si el archivo no existe; `Err` si no se puede leer o no se
   entiende (fallo cerrado: quien llama debe negarse a continuar); `Ok(Some(p))` si todo va bien.
7. `model_allowed(model)`: true si `allowed_models` está vacío o algún glob casa con `model`.
8. `summary()`: líneas legibles, solo de lo que no está vacío, en este orden:
   `modelos permitidos: a, b` · `sin red` · `órdenes denegadas: N` · `rutas no escribibles: N` ·
   `dominios permitidos: a, b` · `tools ocultas: a, b`.
9. `lib.rs`: `pub mod managed;` y `pub use managed::{MANAGED_ENV, ManagedPolicy, SYSTEM_POLICY, load_managed, managed_path};`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-policy/src/managed.rs
/// Ruta del archivo de política del sistema.
pub const SYSTEM_POLICY: &str = "/etc/pcode/politica.toml";
/// Variable de entorno con la ruta de la política del equipo (solo si no hay archivo del sistema).
pub const MANAGED_ENV: &str = "PCODE_POLITICA";

/// Política gestionada: capa que ni el proyecto ni el usuario pueden relajar.
#[derive(Debug, Clone, Default, serde::Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct ManagedPolicy {
    #[serde(rename = "politica")] pub capabilities: crate::Capabilities,
    #[serde(rename = "modelos_permitidos")] pub allowed_models: Vec<String>,
    #[serde(rename = "sin_red")] pub offline: bool,
}
impl ManagedPolicy {
    pub fn model_allowed(&self, model: &str) -> bool;
    pub fn summary(&self) -> Vec<String>;
}
pub fn managed_path(env_value: Option<&str>, system: &std::path::Path) -> Option<std::path::PathBuf>;
pub fn parse_managed(text: &str) -> Result<ManagedPolicy, String>;
pub fn load_managed(path: &std::path::Path) -> Result<Option<ManagedPolicy>, String>;
```

## Tests (con estos nombres)

- `parsea_el_ejemplo`: el TOML del objetivo da dos modelos permitidos, `offline` false, una orden denegada y un dominio
- `clave_desconocida_es_error`: `modelos_permitido = []` (mal escrita) devuelve `Err` que empieza por `política gestionada no válida`
- `ruta_del_sistema_gana`: si el archivo `system` existe, `managed_path(Some("otra"), system)` devuelve `system`
- `ruta_por_variable_si_no_hay_sistema`: sin archivo del sistema devuelve la de la variable; con variable vacía o `None`, `None`
- `modelo_permitido_por_glob`: con `["claude-*"]`, `claude-haiku-5-5` vale y `gpt-5` no; con la lista vacía vale cualquiera
- `cargar_inexistente_es_none_y_roto_es_error`: una ruta que no existe da `Ok(None)` y un archivo con TOML inválido da `Err`
- `resumen_solo_lo_definido`: el ejemplo da las líneas de modelos, órdenes denegadas y dominios, y no la de `sin red`

## No hagas

- No leas la variable de entorno dentro de `managed_path`: llega como argumento (así se prueba sin tocar el entorno)
- No cambies `Capabilities` ni `Policy`
