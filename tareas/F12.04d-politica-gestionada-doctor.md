## Objetivo

Función que ya existe: `crate::managed::load() -> anyhow::Result<Option<(PathBuf, ManagedPolicy)>>`
(devuelve error si el archivo de política existe pero no se entiende).

1. `doctor.rs`, función `doctor`: después del `line(true, "configuración del proyecto", …)` añade:
   - `Ok(None)` → `line(true, "política gestionada", "ninguna (opcional: /etc/pcode/politica.toml o PCODE_POLITICA)")`;
   - `Ok(Some((ruta, p)))` → `line(true, "política gestionada", &ruta.display().to_string())` y, debajo,
     cada línea de `p.summary()` impresa con cuatro espacios de sangría (`println!("    {l}")`); si
     `summary()` está vacío, una sola línea `    (no restringe nada)`;
   - `Err(e)` → `line(false, "política gestionada", &e.to_string())` y el código de salida de `doctor`
     pasa a ser 1 (pon `code = 1` donde corresponda: declara `let mut code = 0;` antes de este bloque
     si hoy se declara después).
2. `tests/politica_gestionada.rs` (ya existe): añade los tests de la lista con el prefijo `doctor_`.
   Lanza `pcode doctor` en un directorio temporal con `.env("PCODE_POLITICA", ruta)` y comprueba la
   salida estándar (no el código de salida: sin modelo configurado `doctor` devuelve 1 de todos modos).

Sin firmas: no añade API: unas líneas más en la salida de `pcode doctor`

## Ejemplo (entrada y resultado esperado)

```
✓ configuración del proyecto sin pcode.toml (opcional)
✓ política gestionada        /tmp/x/politica.toml
    modelos permitidos: claude-*
    órdenes denegadas: 1
```

## Tests (con estos nombres)

- `doctor_muestra_la_politica`: con una política con un modelo permitido y una orden denegada, la salida contiene `política gestionada`, la ruta, `modelos permitidos: claude-*` y `órdenes denegadas: 1`
- `doctor_sin_politica_dice_ninguna`: sin `PCODE_POLITICA`, la salida contiene `política gestionada` y `ninguna`
- `doctor_politica_rota_la_marca`: con un archivo de política inválido, la salida contiene `✗ política gestionada`
