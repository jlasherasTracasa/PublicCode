## Objetivo

1. En `audit.rs` añade `ExportFormat`, `read_entries` y `export_entries` (firmas abajo).
2. `read_entries(path)`: lee el archivo y devuelve todas las entradas en orden (una por línea no
   vacía). Una línea que no se puede parsear → `AuditError::Broken(n)` con n = número de entrada (desde
   1). NO comprueba la cadena de hashes (para eso está `AuditLog::verify`).
3. `export_entries(entries, format, out)`; devuelve cuántas entradas escribió:
   - `Json`: una lista JSON con todas las entradas (`serde_json::to_writer_pretty`) y un salto de línea final.
   - `Csv`: cabecera `seq,ts_ms,actor,provenance,action,decision,detail,hash` y una fila por entrada;
     `detail` es el JSON compacto (`detail.to_string()`). Cada campo de texto va entre comillas dobles
     con las comillas internas duplicadas (`"` → `""`); `seq` y `ts_ms` van sin comillas. Fin de línea `\n`.
   Los errores de escritura se devuelven como `AuditError::Io`.
4. `lib.rs`: añade `ExportFormat`, `export_entries` y `read_entries` a la línea `pub use audit::{…}`.
5. Tests en `mod audit_tests` con el prefijo `exporta_`, escribiendo en un `Vec<u8>`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-policy/src/audit.rs
/// Formato de exportación de la auditoría.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ExportFormat { Json, Csv }

/// Todas las entradas del registro, en orden (sin verificar la cadena).
pub fn read_entries(path: &Path) -> Result<Vec<AuditEntry>, AuditError>;

/// Escribe las entradas en el formato pedido; devuelve cuántas.
pub fn export_entries(entries: &[AuditEntry], format: ExportFormat, out: &mut dyn std::io::Write) -> Result<u64, AuditError>;
```

## Ejemplo (entrada y resultado esperado)

```
CSV de una entrada (actor "chat", acción "bash", detalle {"command":"echo \"hola\""}, decisión "allow"):
seq,ts_ms,actor,provenance,action,decision,detail,hash
1,1700000000000,"chat","agente:chat","bash","allow","{""command"":""echo \""hola\""""}","ab12…"
```

## Tests (con estos nombres)

- `exporta_lee_todas_las_entradas`: tras tres `append`, `read_entries` devuelve tres entradas con `seq` 1, 2 y 3
- `exporta_linea_rota_es_broken`: si la segunda línea del archivo no es JSON, `read_entries` devuelve `AuditError::Broken(2)`
- `exporta_json_es_una_lista`: el JSON exportado se vuelve a leer como lista de `AuditEntry` igual a la original
- `exporta_csv_cabecera_y_filas`: el CSV de dos entradas tiene tres líneas y la primera es la cabecera exacta
- `exporta_csv_duplica_comillas`: un detalle con comillas aparece con las comillas duplicadas y la fila sigue en una sola línea
- `exporta_vacio`: sin entradas, el JSON es una lista vacía, el CSV solo la cabecera y el resultado es 0
