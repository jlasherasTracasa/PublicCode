## Objetivo

1. Crea `audit_cmd.rs` con el enum `AuditCmd` y la función `audit_cmd` (firmas abajo).
   Las dos variantes aceptan `--archivo <ruta>` (por defecto `.pcode/audit.jsonl`).
2. `Verificar`: si el archivo no existe, imprime en stderr `sin auditoría en <ruta>` y devuelve 1. Si
   `AuditLog::verify` da `Ok(n)`, imprime `✓ auditoría íntegra: <n> entradas` y devuelve 0. Si da
   `Err(e)`, imprime en stderr `✗ <e>` (p. ej. «entrada 2 corrupta o manipulada») y devuelve 2.
3. `Exportar { formato, salida, forzar }`: `--formato json|csv` (por defecto `json`; otro valor →
   `anyhow::bail!("formato desconocido: {formato} (json o csv)")`), `--salida <archivo>` (si falta, a la
   salida estándar) y `--forzar`. Primero verifica la cadena: si está rota y no hay `--forzar`, imprime
   en stderr `✗ <error>; usa --forzar para exportar de todos modos` y devuelve 2 sin escribir nada. Si
   no, `read_entries` + `export_entries` y, en stderr, `<n> entradas exportadas`; devuelve 0. Archivo
   inexistente: igual que en `Verificar` (1).
4. `main.rs`: `mod audit_cmd;`, en `Cmd` la variante
   `#[command(subcommand)] Auditoria(audit_cmd::AuditCmd)` («Registro de auditoría: comprobar que nadie
   lo ha manipulado y exportarlo») y, en el `match`,
   `Some(Cmd::Auditoria(c)) => std::process::exit(audit_cmd::audit_cmd(c)?),`.
5. Crea `tests/auditoria.rs`: cada test prepara `<tmp>/.pcode/audit.jsonl` con
   `pcode_policy::AuditLog::open` y tres `append`, y lanza `pcode auditoria …` con
   `assert_cmd::Command::cargo_bin("pcode")` y `.current_dir(tmp)`. Para romper la cadena, sustituye en
   la segunda línea del archivo `"allow"` por `"deny"`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/audit_cmd.rs
/// Subcomandos `pcode auditoria …`.
#[derive(Debug, clap::Subcommand)]
pub enum AuditCmd {
    /// Comprueba la cadena de hashes del registro.
    Verificar { #[arg(long, default_value = ".pcode/audit.jsonl")] archivo: std::path::PathBuf },
    /// Exporta el registro a JSON o CSV.
    Exportar {
        #[arg(long, default_value = ".pcode/audit.jsonl")] archivo: std::path::PathBuf,
        #[arg(long, default_value = "json")] formato: String,
        #[arg(long)] salida: Option<std::path::PathBuf>,
        #[arg(long)] forzar: bool,
    },
}
/// Ejecuta el subcomando; devuelve el código de salida (0 bien, 1 sin registro, 2 cadena rota).
pub fn audit_cmd(c: AuditCmd) -> anyhow::Result<i32>;
```

## Ejemplo (entrada y resultado esperado)

```
$ pcode auditoria verificar
✓ auditoría íntegra: 3 entradas                         (código 0)
$ pcode auditoria verificar            (tras manipular la línea 2)
✗ entrada 2 corrupta o manipulada                       (stderr, código 2)
$ pcode auditoria exportar --formato csv --salida a.csv
3 entradas exportadas                                    (stderr, código 0; a.csv tiene 4 líneas)
```

## Tests (con estos nombres)

- `verificar_integra_sale_con_0`: con tres entradas válidas imprime `auditoría íntegra: 3 entradas` y sale con 0
- `verificar_manipulada_sale_con_2`: tras cambiar `allow` por `deny` en la línea 2, sale con 2 y stderr menciona `entrada 2`
- `verificar_sin_archivo_sale_con_1`: en un directorio sin `.pcode/` sale con 1 y stderr contiene `sin auditoría`
- `exportar_json_a_stdout`: la salida estándar es una lista JSON de tres elementos
- `exportar_csv_a_archivo`: con `--formato csv --salida a.csv` el archivo tiene la cabecera y tres filas
- `exportar_cadena_rota_exige_forzar`: con la cadena rota sale con 2 y no crea el archivo; con `--forzar` sale con 0 y lo crea
- `exportar_formato_desconocido_falla`: `--formato xml` termina con código distinto de 0
