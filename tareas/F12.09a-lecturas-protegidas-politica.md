# F12.09a-lecturas-protegidas-politica — Política: listas `no_leer` y `preguntar_leer` con valores seguros en el uso interactivo

## Objetivo

Hoy `check_read` solo tiene una lista de permitidos (`leer`); no se puede decir «todo menos los
archivos con secretos».

1. `caps.rs`, struct `Capabilities`: dos campos nuevos, con su comentario `///`:
   `#[serde(rename = "no_leer")] pub deny_read: Vec<String>` (rutas que no se pueden leer) y
   `#[serde(rename = "preguntar_leer")] pub ask_read: Vec<String>` (rutas que piden confirmación).
2. `check_read(rel)`, en este orden (con `let r = norm(rel);`):
   a) casa con `deny_read` → `Decision::Deny(format!("lectura prohibida: {rel}"))`;
   b) `read` no está vacío y no casa → `Decision::Deny(format!("lectura no permitida: {rel}"))` (como hoy);
   c) casa con `ask_read` → `Decision::Ask(format!("el archivo puede contener secretos: {rel}"))`;
   d) si no, `Allow`.
3. `interactive_defaults`: añade
   `ask_read: v(&["**/.env", "**/.env.*", "**/*.pem", "**/*.key", "**/.npmrc", "**/.netrc"])` y
   `deny_read: v(&["**/id_rsa", "**/id_ed25519", "**/id_ecdsa", "**/.ssh/**", "**/.aws/credentials"])`.
   (En `globset`, `**/x` también casa con `x` en la raíz.)
4. Tests en el `mod tests` de `caps.rs` con el prefijo `lectura_`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-policy/src/caps.rs  (campos nuevos de `Capabilities`)

/// Rutas que piden confirmación humana antes de leerse.
#[serde(rename = "preguntar_leer")]
pub ask_read: Vec<String>,
```

## Ejemplo (entrada y resultado esperado)

```
p = Policy::new(Capabilities::interactive_defaults())
p.check_read(".env")                 → Ask("el archivo puede contener secretos: .env")
p.check_read("config/.env.local")    → Ask(…)
p.check_read("deploy/id_rsa")        → Deny("lectura prohibida: deploy/id_rsa")
p.check_read("src/main.rs")          → Allow
p.check_read(".envrc")               → Allow
```

## Tests (con estos nombres)

- `lectura_env_pide_confirmacion`: `.env`, `./.env` y `config/.env.local` dan `Ask` con la capa interactiva
- `lectura_claves_privadas_denegada`: `deploy/id_rsa` y `.ssh/config` dan `Deny` que empieza por `lectura prohibida`
- `lectura_normal_permitida`: `src/main.rs`, `README.md` y `.envrc` dan `Allow`
- `lectura_no_leer_gana_a_leer`: con `read = ["**"]` y `deny_read = ["secretos/**"]`, `secretos/a` da `Deny`
- `lectura_se_lee_de_toml`: `no_leer = ["a"]` y `preguntar_leer = ["b"]` en TOML rellenan los dos campos
- `lectura_capa_vacia_no_restringe`: `Capabilities::default().check_read(".env")` da `Allow`
