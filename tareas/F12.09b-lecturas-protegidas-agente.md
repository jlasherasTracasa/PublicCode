# F12.09b-lecturas-protegidas-agente — Agente: comprobar `check_read` antes de ejecutar una tool de lectura

## Contexto (lee esto y nada más)

- crates/pcode-core/src/agent.rs (método `Agent::run_call`: el bloque que calcula `decision`; hoy llama a `check_effects`, `check_write` y `check_command`, pero NUNCA a `check_read`; ayudantes de test `agent`, `tool` y `text`)
- crates/pcode-policy/src/caps.rs (`Policy::check_read(&self, p: &str) -> Decision`; campos `deny_read` y `ask_read` de `Capabilities`)

## Objetivo

1. En `agent.rs`, método `run_call`: justo después de `let mut decision = self.policy.check_effects(effects);`
   añade, con el mismo estilo que el bloque de `check_write`:
   si `decision` es `Decision::Allow`, `effects` contiene `Effect::Read` y la llamada tiene el argumento
   de texto `path`, entonces `decision = self.policy.check_read(&p);`.
2. Nada más: el `match decision` existente ya convierte `Deny` en «denegado por la política: …» y `Ask`
   en una pregunta al aprobador (o «requiere aprobación humana: …» si no hay aprobador), y audita.
3. Las tools de lectura sin argumento `path` (o con `path` ausente) no cambian.
4. Tests en el `mod tests` de `agent.rs` con el prefijo `lectura_`, usando los ayudantes
   `agent(&d, script, caps, hook)`, `tool(nombre, args)` y `text(…)`. Crea los archivos en el
   directorio temporal antes de ejecutar; la tool de lectura se llama `leer` y recibe
   `json!({"path": "…"})`.

Sin firmas: no añade API: un bloque más en el cálculo de `decision` de `Agent::run_call`

## Ejemplo (entrada y resultado esperado)

```
caps: Capabilities { deny_read: vec!["secretos/**".into()], ..Default::default() }
llamada: leer { path: "secretos/clave.txt" }
resultado de la tool: "denegado por la política: lectura prohibida: secretos/clave.txt"
```

## Tests (con estos nombres)

- `lectura_denegada_por_politica`: con `deny_read = ["secretos/**"]`, leer `secretos/clave.txt` devuelve un resultado con `denegado` y el contenido del archivo no aparece en la transcripción
- `lectura_con_pregunta_sin_aprobador`: con `ask_read = ["**/.env"]`, leer `.env` devuelve `requiere aprobación humana` y el contenido no aparece
- `lectura_permitida_como_antes`: con la capa vacía, leer `a.txt` devuelve su contenido
- `lectura_fuera_de_la_lista_permitida`: con `read = ["src/**"]`, leer `otro.txt` devuelve `denegado`

## No hagas

- No cambies la firma de `run_call` ni el `match decision`
- No toques los tests que ya existen en `agent.rs`
