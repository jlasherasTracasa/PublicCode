## Objetivo

Portar `leer_cambios` del prototipo Python:
1. Recorre `upper` (sin seguir enlaces). Un dispositivo de caracteres con rdev 0 → `Deleted`; un
   directorio con xattr `trusted.overlay.opaque` o `user.overlay.opaque` = "y" que existe en `lower`
   → `Replaced`; un directorio vacío que no existe en `lower` → `Added`; un archivo o enlace → `Modified`
   si existe en `lower` y `Added` si no.
2. `filter_ignored`: si `lower/.git` existe, pasa las rutas por `git -C lower check-ignore --stdin`
   y quita las ignoradas.
3. Resultado ordenado por ruta. Rutas relativas con `/`.
4. `nix` solo para `major`/`minor` y xattr (o `std::os::unix::fs::MetadataExt::rdev` + `libc`/`nix::sys::stat`).

## Firmas (cópialas tal cual)

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)]
pub enum ChangeKind { Added, Modified, Deleted, Replaced }

#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct Change { pub path: String, pub kind: ChangeKind }

pub fn read_changes(upper: &std::path::Path, lower: &std::path::Path) -> std::io::Result<Vec<Change>>;
pub fn filter_ignored(lower: &std::path::Path, changes: Vec<Change>) -> std::io::Result<Vec<Change>>;
```
