## Objetivo

1. `prepare.sh` = el script `PREPARAR` del prototipo, incluido con `include_str!`.
2. `Sandbox::create(spec)`: crea `state/upper`, `state/work` y, si el repo o el estado están bajo
   `/tmp`, `state/tmp`. Rechaza un estado dentro de `root`.
3. `Sandbox::run(argv, env)`: lanza `unshare --user --map-root-user --mount --pid --fork --kill-child
   --mount-proc [--net] sh -c <prepare.sh> pcode-sandbox <argv…>` con las mismas variables de entorno
   que el prototipo, `kill_on_drop` y el tiempo máximo de `spec.timeout` (vencido → `ExitStatus`
   con código 124 y `timed_out = true`).
4. `userns_available()` prueba `unshare --user --map-root-user --mount true` una vez (`OnceLock`).
5. Los tests se saltan (con un `eprintln!`) si no hay namespaces de usuario.

## Firmas (cópialas tal cual)

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Network { None, Open, Filtered }
#[derive(Debug, Clone)]
pub struct SandboxSpec { pub root: PathBuf, pub state: Option<PathBuf>, pub network: Network, pub writable: Vec<PathBuf>, pub timeout: Duration }
#[derive(Debug, Clone, PartialEq, Eq)] pub struct RunStatus { pub code: i32, pub timed_out: bool, pub millis: u128 }
#[derive(Debug, thiserror::Error)]
pub enum SandboxError { #[error("E/S: {0}")] Io(#[from] std::io::Error), #[error("namespaces de usuario no disponibles")] NoUserns, #[error("{0}")] Invalid(String) }
pub struct Sandbox { /* spec, state dir */ }
impl Sandbox {
    pub fn create(spec: SandboxSpec) -> Result<Sandbox, SandboxError>;
    pub fn state_dir(&self) -> &Path;
    pub async fn run(&self, argv: &[String], env: &[(String, String)]) -> Result<RunStatus, SandboxError>;
    pub fn changes(&self) -> Result<Vec<Change>, SandboxError>;   // read_changes + filter_ignored
}
pub fn userns_available() -> bool;
```
