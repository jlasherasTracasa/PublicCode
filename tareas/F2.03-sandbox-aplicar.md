## Objetivo

1. `Sandbox::apply(self)`: por cada cambio filtrado: Deleted/Replaced → borrar en root (archivo o
   árbol); Replaced → copiar el árbol de upper; Added/Modified → copiar el archivo (o crear el
   directorio), conservando los enlaces simbólicos como enlaces. Después, `discard`. Devuelve los cambios.
2. `Sandbox::discard(self)`: `chmod 0700` recursivo de los directorios de `state` (overlay deja
   `work/` con permisos 000) y borrar `state`.
3. `Sandbox::diff(&self, path)`: diff unificado (`similar`) entre la versión de root y la de upper
   para archivos de texto < 1 MiB.

## Firmas (cópialas tal cual)

```rust
impl Sandbox {
    pub fn apply(self) -> Result<Vec<Change>, SandboxError>;
    pub fn discard(self) -> Result<(), SandboxError>;
    pub fn diff(&self, path: &str) -> Result<Option<String>, SandboxError>;
}
```
