## Objetivo

1. Crea `exec.rs` con `exec_restricted` (firma abajo). Pasos, en este orden:
   a) si `argv` está vacío, devuelve `SandboxError::Invalid("falta la orden".into())`;
   b) `restrict_self(&LandlockRules { writable: writable.to_vec() })`: si da `Err(e)`, devuelve `e` (no se
      ejecuta nada); si da `Ok(false)`, sigue (mejor esfuerzo; `restrict_self` ya avisó);
   c) en Unix: `use std::os::unix::process::CommandExt;` y
      `let e = std::process::Command::new(&argv[0]).args(&argv[1..]).exec();` — `exec` solo vuelve si
      falla: devuelve `SandboxError::Io(e)`. En otras plataformas (`#[cfg(not(unix))]`) devuelve
      `SandboxError::Invalid("solo disponible en Linux".into())`.
2. La función NUNCA vuelve si todo va bien (el proceso pasa a ser la orden); por eso devuelve el error
   directamente y no un `Result`.
3. `lib.rs`: añade `pub mod exec;` y `pub use exec::exec_restricted;`.
4. Tests en `exec.rs` con el patrón de proceso hijo: el test, si `child_role()` es `Some(role)`, parte
   `role` por `|` en (dirW, dirO), llama a `exec_restricted(&[dirW.into()], &argv)` con
   `argv = ["sh", "-c", "echo x > DIRW/a.txt; echo y > DIRO/b.txt; exit 0"]` (sustituye las rutas) y, si
   vuelve, hace `std::process::exit(9)`. El padre crea los dos directorios temporales, llama a
   `run_child("exec::tests::<nombre>", &role)` y comprueba los archivos.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-sandbox/src/exec.rs
/// Aplica las restricciones a este proceso y lo sustituye por `argv`. Solo vuelve si algo falla.
pub fn exec_restricted(writable: &[std::path::PathBuf], argv: &[String]) -> crate::SandboxError;
```

## Tests (con estos nombres)

- `exec_sin_orden_es_error`: `exec_restricted(&[], &[])` devuelve `SandboxError::Invalid` con el texto «falta la orden»
- `exec_ejecuta_y_escribe_en_lo_permitido`: tras el hijo, existe DIRW/a.txt con el contenido `x`
- `exec_no_escribe_fuera`: tras el hijo, si `landlock_abi() > 0`, NO existe DIRO/b.txt
- `exec_orden_inexistente_devuelve_io`: en el hijo, una orden que no existe hace que la función vuelva con `SandboxError::Io` (el hijo sale con 0 si es así)
