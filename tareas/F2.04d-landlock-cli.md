## Objetivo

Funciones que ya existen en `pcode_sandbox` y se usan aquí:
`exec_restricted(writable: &[PathBuf], argv: &[String]) -> SandboxError` (solo vuelve si falla),
`set_exec_helper(bin: Option<PathBuf>)`, `landlock_abi() -> i32`, `userns_available() -> bool`.

1. `main.rs`, enum `Cmd`: añade la variante
   `#[command(name = "__sandbox-exec", hide = true)] SandboxExec { #[arg(long)] escribible: Vec<std::path::PathBuf>, #[arg(last = true, required = true)] orden: Vec<String> }`
   con el comentario de documentación «Uso interno: último paso de la mini sandbox».
2. `main.rs`, en el `match cli.command`: rama
   `Some(Cmd::SandboxExec { escribible, orden }) => { let e = pcode_sandbox::exec_restricted(&escribible, &orden); eprintln!("pcode: {e}"); std::process::exit(126) }`.
3. `main.rs`, función `choose_sandbox_level`: al principio añade
   `pcode_sandbox::set_exec_helper(std::env::current_exe().ok());`. Desde ahora toda sandbox N1 lanzada
   por la CLI termina en el ayudante.
4. Crea `tests/sandbox_exec.rs` con los tests de la lista. Usa dos `tempfile::tempdir()` distintos para
   «dentro» y «fuera». Los tests que dependen de Landlock empiezan con
   `if pcode_sandbox::landlock_abi() == 0 { return; }` y los que usan `pcode sandbox ejecutar`, con
   `if !pcode_sandbox::userns_available() { return; }`.

Sin firmas: solo añade una variante privada al enum `Cmd` del binario; no hay API pública nueva

## Ejemplo (entrada y resultado esperado)

```
pcode __sandbox-exec --escribible /tmp/w -- sh -c 'echo x > /tmp/w/a; echo y > /tmp/o/b'
  → /tmp/w/a existe; /tmp/o/b no existe (con Landlock); código de salida 0 o distinto según el shell.

pcode sandbox ejecutar --estado /tmp/estado -- sh -c 'grep NoNewPrivs /proc/self/status'
  → la salida contiene «NoNewPrivs:» seguido de 1 (Landlock activa no_new_privs).
```

## Tests (con estos nombres)

- `sandbox_exec_ejecuta_la_orden`: `pcode __sandbox-exec -- sh -c 'echo hola'` sale con 0 y escribe `hola` en stdout
- `sandbox_exec_sin_orden_falla`: `pcode __sandbox-exec` sin `--` ni orden termina con código distinto de 0
- `sandbox_exec_deniega_fuera_de_escribible`: con `--escribible W`, la orden crea W/a pero no O/b (se salta sin Landlock)
- `sandbox_exec_no_sale_en_la_ayuda`: la salida de `pcode --help` no contiene `__sandbox-exec`
- `sandbox_ejecutar_usa_el_ayudante`: `pcode sandbox ejecutar --estado E -- sh -c 'grep NoNewPrivs /proc/self/status'` imprime una línea que termina en 1 (se salta sin userns o sin Landlock)

## No hagas

- No pongas lógica de Landlock en la CLI: solo se llama a `pcode_sandbox::exec_restricted`
- No cambies las demás variantes de `Cmd`
