## Objetivo

1. Crea `limits.rs` con `Limits`, su `Default` (nproc 4096, fsize 8 GiB = `8 << 30`, nofile 4096) y
   `apply_limits` (firmas abajo).
2. `apply_limits`, solo en Linux (`#[cfg(target_os = "linux")]`): para cada pareja
   (`libc::RLIMIT_NPROC`, nproc), (`libc::RLIMIT_FSIZE`, fsize_bytes), (`libc::RLIMIT_NOFILE`, nofile) y
   (`libc::RLIMIT_CORE`, 0): lee el límite actual con `libc::getrlimit`; el valor nuevo es
   `min(pedido, límite duro actual)` (un proceso sin privilegios no puede subir el duro); llama a
   `libc::setrlimit` con `rlim_cur = rlim_max = valor nuevo`. Si `setrlimit` devuelve distinto de 0:
   `SandboxError::Io(std::io::Error::last_os_error())`. Cada `unsafe` lleva su `// SAFETY:`.
   En otras plataformas la función devuelve `Ok(())` sin hacer nada.
3. `lib.rs`: `pub mod limits;` y `pub use limits::{Limits, apply_limits};`.
4. Tests en `limits.rs`. Los que aplican límites lo hacen en un proceso hijo (patrón: si
   `child_role()` es `Some(_)`, haz el trabajo y termina con `std::process::exit(0 o 1)`; si no,
   `assert_eq!(run_child("limits::tests::<nombre>", "x"), 0)`).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-sandbox/src/limits.rs
/// Límites de recursos del proceso que corre dentro de la sandbox.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Limits { pub nproc: u64, pub fsize_bytes: u64, pub nofile: u64 }
impl Default for Limits { /* 4096, 8 GiB, 4096 */ }

/// Aplica los límites a este proceso (y `RLIMIT_CORE = 0`). No se pueden volver a subir.
pub fn apply_limits(l: &Limits) -> Result<(), crate::SandboxError>;
```

## Ejemplo (entrada y resultado esperado)

```
// Hijo de `limits_fsize_corta_la_escritura`:
unsafe { libc::signal(libc::SIGXFSZ, libc::SIG_IGN); }   // SAFETY: ignorar una señal es seguro
apply_limits(&Limits { fsize_bytes: 1024, ..Limits::default() }).unwrap();
let r = std::fs::write(dir.join("grande"), vec![0u8; 8192]);
let ok = r.is_err_and(|e| e.raw_os_error() == Some(libc::EFBIG));
std::process::exit(if ok { 0 } else { 1 });
```

## Tests (con estos nombres)

- `limits_por_defecto`: `Limits::default()` vale nproc 4096, fsize_bytes 8589934592 y nofile 4096
- `limits_fsize_corta_la_escritura`: en el hijo, con fsize 1024, escribir 8192 bytes falla con EFBIG
- `limits_nofile_se_aplica`: en el hijo, tras `apply_limits` con nofile 64, `getrlimit(RLIMIT_NOFILE)` da 64 en el límite blando
- `limits_core_a_cero`: en el hijo, tras `apply_limits`, `getrlimit(RLIMIT_CORE)` da 0
