## Objetivo

1. Tipos de abajo, serializables.
2. `Handoff::render_for_agent()`: texto Markdown estable con secciones «Qué se probó», «Por qué
   falló», «Paso crítico», «Archivos tocados» y «Límites (no negociables)». Para los agentes externos.
3. `Handoff::to_json()`: para los componentes internos (formato estructurado, *Routed Graph Handoff*).
4. `MockBackend`: escribe en la sandbox los archivos de un guion `{ruta: contenido}` ejecutando
   `sh -c 'mkdir -p … && printf … > …'` vía `Sandbox::run`, y devuelve un `BackendResult` fijo.

```rust
#[derive(Debug, Clone, Default, serde::Serialize, serde::Deserialize)]
pub struct Boundaries { pub capabilities: Vec<String>, pub data_class: String, pub audience: Vec<String> }

#[derive(Debug, Clone, Default, serde::Serialize, serde::Deserialize)]
pub struct Handoff { pub attempt: u32, pub tried: Vec<String>, pub failed_because: String,
                     pub critical_step: Option<String>, pub files: Vec<String>, pub boundaries: Boundaries }
impl Handoff { pub fn render_for_agent(&self) -> String; pub fn to_json(&self) -> serde_json::Value; }

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct Job { pub id: String, pub task: String, pub accept: Option<String>, pub handoff: Option<Handoff>,
                 pub skills: Vec<String>, pub model: Option<String>, pub max_minutes: u32 }

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub enum TranscriptItem { Text(String), ToolCall { name: String, input: serde_json::Value }, ToolResult { output: String, is_error: bool } }

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct BackendResult { pub exit: i32, pub final_message: String, pub transcript: Vec<TranscriptItem>, pub usage: Option<pcode_models::Usage> }

#[derive(Debug, Clone, Default)]
pub struct BackendCaps { pub needs_network: Vec<String>, pub reads_agents_md: bool, pub supports_mcp: bool }

#[derive(Debug, thiserror::Error)]
pub enum BackendError { #[error("sandbox: {0}")] Sandbox(#[from] pcode_sandbox::SandboxError), #[error("salida no reconocida: {0}")] Parse(String), #[error("{0}")] Other(String) }

#[async_trait::async_trait]
pub trait Backend: Send + Sync {
    fn id(&self) -> &str;
    fn caps(&self) -> BackendCaps;
    async fn run(&self, job: &Job, sandbox: &pcode_sandbox::Sandbox) -> Result<BackendResult, BackendError>;
}
```
