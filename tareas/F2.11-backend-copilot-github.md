## Objetivo

1. En un repositorio de pruebas con Copilot coding agent activado, exporta `GITHUB_TOKEN` y lanza una tarea
   pequeña con el backend (`CopilotGitHub` sobre `GitHubHttp::from_env`): debe crear el issue, asignarlo,
   esperar al PR, bajar el diff a la sandbox y pasar `acepta` en local. Nunca se fusiona el PR desde pcode.
2. Corrige lo que difiera de la API real (nombre del asignatario en `COPILOT_ASSIGNEE`, forma del evento de la
   cronología que enlaza el PR, cabeceras) y ajusta los tests del servidor falso a lo observado.
3. Añade a `docs/backends-verificado.md` la sección `## Copilot coding agent` con la fecha, los permisos
   mínimos del token, los tiempos observados y los límites; actualiza la tabla de `docs/backends.md`.
