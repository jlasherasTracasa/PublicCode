## Objetivo

1. Crea `github_api.rs` con el trait `GitHubApi`, `FakeGitHub`, `issue_body` y `parse_remote` (firmas abajo).
2. `FakeGitHub` guarda todo en memoria tras un `std::sync::Mutex` y es pública (NO va tras `#[cfg(test)]`: la
   usan los tests de otros crates):
   - `create_issue` guarda `(título, cuerpo)` y devuelve 1, 2, 3… por orden;
   - `assign_to_copilot` apunta el número en `assigned`;
   - `find_linked_pr` cuenta las consultas; devuelve `None` hasta que el número de consultas llega a
     `pr_after_polls`; desde entonces `Some(100 + issue)`. Con `pr_after_polls == 0` nunca hay PR;
   - `pr_diff` devuelve `diff`; `comment` guarda `(número, cuerpo)`.
   Con `fail: Some(texto)`, todas las llamadas devuelven `Err(BackendError::Other(texto))`.
3. `issue_body(job)`: `job.task`, después (si hay relevo) `\n\n## Relevo del intento anterior\n` +
   `handoff.render_for_agent()`, y (si hay `accept`) `\n\n## Criterio de aceptación\nEsta orden debe terminar
   con código 0:\n\n` + la orden en un bloque de código.
4. `parse_remote(url)`: `(dueño, repo)` de una URL de GitHub: `https://github.com/o/r.git`,
   `https://github.com/o/r`, `git@github.com:o/r.git` y `ssh://git@github.com/o/r`. Cualquier otra → `None`.
5. `lib.rs`: añade `pub mod github_api;` y `pub use github_api::{FakeGitHub, GitHubApi, issue_body, parse_remote};`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-backends/src/github_api.rs
use crate::types::{BackendError, Job};

/// Lo que PublicCode necesita de GitHub. No hay ninguna operación de fusionar: es deliberado.
#[async_trait::async_trait]
pub trait GitHubApi: Send + Sync {
    async fn create_issue(&self, title: &str, body: &str) -> Result<u64, BackendError>;
    async fn assign_to_copilot(&self, issue: u64) -> Result<(), BackendError>;
    async fn find_linked_pr(&self, issue: u64) -> Result<Option<u64>, BackendError>;
    async fn pr_diff(&self, pr: u64) -> Result<String, BackendError>;
    async fn comment(&self, number: u64, body: &str) -> Result<(), BackendError>;
}

/// Estado observable de la API falsa.
#[derive(Debug, Default, Clone, PartialEq)]
pub struct FakeState {
    pub issues: Vec<(String, String)>,
    pub assigned: Vec<u64>,
    pub polls: u32,
    pub comments: Vec<(u64, String)>,
}

/// API falsa en memoria para tests.
#[derive(Default)]
pub struct FakeGitHub {
    pub pr_after_polls: u32,
    pub diff: String,
    pub fail: Option<String>,
    pub state: std::sync::Mutex<FakeState>,
}

pub fn issue_body(job: &Job) -> String;
pub fn parse_remote(url: &str) -> Option<(String, String)>;
```

## Ejemplo (entrada y resultado esperado)

```
let gh = FakeGitHub { pr_after_polls: 2, diff: "d".into(), ..Default::default() };
gh.create_issue("T1", "cuerpo").await → Ok(1)
gh.find_linked_pr(1).await → Ok(None)      (consulta 1)
gh.find_linked_pr(1).await → Ok(Some(101)) (consulta 2)
parse_remote("git@github.com:acme/app.git") → Some(("acme", "app"))      parse_remote("https://gitlab.com/a/b") → None
issue_body(job con accept "cargo test") contiene "## Criterio de aceptación" y "cargo test"
```
