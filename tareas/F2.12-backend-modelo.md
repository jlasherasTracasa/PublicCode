## Objetivo

1. Ejecuta el propio binario `pcode run <tarea> --acepta <cmd> --modelo <m>` DENTRO de la sandbox
   (así las tools escriben en la capa del overlay).
2. Red: `Network::Filtered` con el dominio y puerto del proveedor (p. ej. `127.0.0.1:30400` para
   LiteLLM a través del proxy de F2.19); las variables `HTTP_PROXY` y `HTTPS_PROXY` las pone la sandbox.
3. Lee la sesión de `.pcode/pcode.db` del estado de la sandbox para rellenar transcripción y uso.
   Si no puede, deja la transcripción vacía.
4. Tests con `PCODE_MOCK_SCRIPT` (sin red).
