## Objetivo

1. Dependencia nueva permitida: `rmcp` (SDK oficial de MCP para Rust), transporte stdio.
2. Tools: `sandbox_ejecutar {orden, red?: bool, tiempo?: int}` → `{estado, codigo, salida}`;
   `sandbox_cambios {estado}`; `sandbox_aplicar {estado}`; `sandbox_descartar {estado}`;
   `aceptar {orden}` → `{ok, salida_comprimida}`; `buscar_repo {patron, glob?}` (reusa `Grep`).
3. Esquemas mínimos: descripciones de una línea (el coste de MCP está en el esquema, *ProMCP*).
4. Política: el servidor recibe `--politica <toml>` y **no anuncia** las tools que la política oculta.
5. `pcode mcp` arranca el servidor.
