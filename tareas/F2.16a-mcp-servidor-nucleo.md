## Objetivo

MCP por stdio son mensajes JSON-RPC 2.0, uno por línea. Este crate atiende las peticiones de un cliente MCP (Claude
Code, un IDE…) con las tools de PublicCode. El workspace ya incluye `crates/*`: no toques el Cargo.toml raíz.
1. `Cargo.toml` del crate: `name = "pcode-mcp"`, `version/edition/license.workspace = true`; dependencias
   `pcode-tools` y `pcode-policy` (por ruta `../pcode-…`), `serde_json.workspace = true`, `tokio.workspace = true`;
   en `[dev-dependencies]`, `tempfile.workspace = true`.
2. `lib.rs` con lo de *Firmas*. `new`: recorre `registry.specs_filtered(|n, e| policy.tool_visible(n, e))` y guarda
   `registry.get(&spec.name)` de cada una (lo oculto por la política no se anuncia ni se puede llamar).
3. `handle(msg)`: si `msg` no tiene `"id"` es una notificación → `None`. Si no, responde
   `{"jsonrpc":"2.0","id":<id>,"result":…}` según `msg["method"]`:
   - `initialize` → `{"protocolVersion": PROTOCOL_VERSION, "capabilities": {"tools": {}}, "serverInfo": {"name": "pcode", "version": env!("CARGO_PKG_VERSION")}}`
   - `ping` → `{}`
   - `tools/list` → `{"tools": [{"name", "description", "inputSchema": <spec.parameters>}, …]}` en el orden guardado.
   - `tools/call` → ver paso 4.
   - otro → `{"jsonrpc":"2.0","id":<id>,"error":{"code":-32601,"message":"método desconocido: <m>"}}`.
4. `tools/call`: `name = params.name`, `args = params.arguments` (o `{}`). Tool no encontrada → resultado de error
   `tool desconocida: <name>`. Decisión como el agente: `policy.check_effects(tool.effects())`; si sale `Allow`, la
   tool tiene `Effect::Write` y `args["path"]` es texto → `check_write`; si sigue `Allow`, tiene `Effect::Exec` y
   `args["command"]` es texto → `check_command`. `Deny(m)` → error `denegado por la política: <m>`; `Ask(m)` → error
   `requiere aprobación humana: <m> (el servidor MCP no puede preguntar)`; `Allow` → `tool.call(args, &ctx)`.
   Resultado: `{"content":[{"type":"text","text":<texto>}],"isError":<bool>}` (los errores de este paso también van
   así, con `isError: true`, no como error JSON-RPC).
5. `serve`: lee línea a línea; salta las vacías; si una línea no es JSON escribe
   `{"jsonrpc":"2.0","id":null,"error":{"code":-32700,"message":"JSON inválido"}}`; cada respuesta `Some` se escribe en
   una línea con `\n` y `flush`. Termina con `Ok(())` al acabar la entrada.
6. Tests en `#[cfg(test)]` de `lib.rs` (`#[tokio::test]`), con `pcode_tools::native_registry()` y la raíz en un
   `tempfile::tempdir()`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-mcp/src/lib.rs
//! Servidor MCP (stdio) con las tools de PublicCode filtradas por la política.
use pcode_policy::{Decision, Policy};
use pcode_tools::{Effect, Tool, ToolContext, ToolRegistry};
use serde_json::{Value, json};
use std::sync::Arc;

/// Versión del protocolo MCP que se anuncia en `initialize`.
pub const PROTOCOL_VERSION: &str = "2025-06-18";

/// Servidor MCP de las tools de PublicCode.
pub struct McpServer {
    tools: Vec<Arc<dyn Tool>>,
    policy: Policy,
    ctx: ToolContext,
}

impl McpServer {
    /// Servidor con las tools del registro que la política deja ver.
    pub fn new(registry: &ToolRegistry, policy: Policy, ctx: ToolContext) -> McpServer;
    /// Respuesta a un mensaje JSON-RPC (`None` para las notificaciones).
    pub async fn handle(&self, msg: &Value) -> Option<Value>;
    /// Atiende mensajes línea a línea hasta el fin de la entrada.
    pub async fn serve<R, W>(&self, input: R, output: W) -> std::io::Result<()>
    where
        R: tokio::io::AsyncBufRead + Unpin,
        W: tokio::io::AsyncWrite + Unpin;
}
```

## Tests (con estos nombres)

- `mcp_initialize_anuncia_tools`: `initialize` con id 1 → `result.protocolVersion == PROTOCOL_VERSION` y `result.capabilities.tools` es un objeto
- `mcp_lista_tools`: `tools/list` → contiene `leer` y `bash`, y cada tool tiene `inputSchema`
- `mcp_oculta_por_politica`: política con `hidden_tools = ["bash"]` → `tools/list` no trae `bash` y `tools/call` de `bash` da `isError: true`
- `mcp_llamada_denegada_por_politica`: `deny_write = ["**"]` y `tools/call` de `escribir` con `path` `a.txt` → `isError: true`, texto con `denegado` y el archivo no existe
- `mcp_leer_devuelve_el_contenido`: archivo `a.txt` con `hola` y `tools/call` de `leer` → `isError: false` y el texto contiene `hola`
- `mcp_notificacion_sin_respuesta`: `{"jsonrpc":"2.0","method":"notifications/initialized"}` → `None`
- `mcp_serve_linea_a_linea`: entrada con dos líneas (initialize id 1 y tools/list id 2) → dos líneas de salida con ids 1 y 2
