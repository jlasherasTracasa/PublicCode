## Objetivo

1. `Cargo.toml` de `pcode-cli`: si no está ya, añade en `[dependencies]`
   `pcode-skills = { path = "../pcode-skills" }`.
2. `main.rs`: enum nuevo `InstrCmd` (derive `Debug, Subcommand`) con una variante
   `Sincronizar { #[arg(long = "comprobar")] check: bool }` («Genera GEMINI.md y
   .github/copilot-instructions.md desde AGENTS.md y garantiza que CLAUDE.md lo importa»). En `Cmd`
   añade `#[command(subcommand)] Instrucciones(InstrCmd)` («Instrucciones de los agentes: AGENTS.md es la
   fuente única»).
3. `main.rs`: función `fn instr_cmd(c: InstrCmd) -> anyhow::Result<i32>` que llama a
   `pcode_skills::sync_instructions(&std::env::current_dir()?, check)`:
   - sin `--comprobar`: imprime `✓ <ruta>` por cada archivo escrito, o `Todo al día.` si no hubo
     ninguno; devuelve 0.
   - con `--comprobar`: imprime `✗ <ruta> está desfasado` por cada uno y devuelve 1 si hay alguno; si
     no, imprime `Todo al día.` y devuelve 0.
   - un error (p. ej. falta AGENTS.md) se propaga con `?`.
4. `main.rs`, en el `match cli.command`:
   `Some(Cmd::Instrucciones(c)) => std::process::exit(instr_cmd(c)?),`.
5. Crea `tests/instrucciones.rs` con los tests de la lista; cada uno trabaja en un
   `tempfile::tempdir()` con un `AGENTS.md` de prueba (`.current_dir(dir)`).

Sin firmas: solo añade un subcomando al binario; la lógica está en `pcode_skills::sync_instructions`

## Ejemplo (entrada y resultado esperado)

```
$ pcode instrucciones sincronizar
✓ CLAUDE.md
✓ GEMINI.md
✓ .github/copilot-instructions.md
$ pcode instrucciones sincronizar --comprobar
Todo al día.                                   (código 0)
$ echo "otra regla" >> AGENTS.md && pcode instrucciones sincronizar --comprobar
✗ GEMINI.md está desfasado
✗ .github/copilot-instructions.md está desfasado      (código 1)
```

## Tests (con estos nombres)

- `sincronizar_crea_los_archivos`: en un directorio con AGENTS.md, la orden sale con 0 y existen GEMINI.md y .github/copilot-instructions.md con la cabecera de generado
- `comprobar_al_dia_sale_con_0`: tras sincronizar, `--comprobar` sale con 0 e imprime `Todo al día.`
- `comprobar_desfasado_sale_con_1`: tras cambiar AGENTS.md, `--comprobar` sale con 1 y nombra GEMINI.md
- `sin_agents_md_falla`: en un directorio vacío la orden termina con código distinto de 0
