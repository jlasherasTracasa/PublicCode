## Objetivo

1. `pcode run … --backend <nombre de [backends.*]> --sandbox N1|ninguna`: construye el backend desde la
   configuración, crea la sandbox, ejecuta, imprime los cambios y deja el estado para que el usuario
   decida (`pcode sandbox aplicar <estado>`).
2. `--aplicar-si-acepta`: si `acepta` pasa DENTRO de la sandbox, aplica automáticamente.
3. `pcode sandbox ejecutar|cambios|aplicar|descartar`: mismas opciones que el prototipo de Python.
