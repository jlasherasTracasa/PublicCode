## Objetivo

1. Crea `netproxy.rs` con `host_allowed`, `ProxyRequest` y `parse_request_line` (firmas abajo). Sin red
   ni E/S: solo funciones puras.
2. `host_allowed(allow, host, port)`. Normaliza `host`: minúsculas y sin el punto final. Cada entrada de
   `allow` es `patrón` o `patrón:puerto` (el puerto es lo que va tras el ÚLTIMO `:` si son solo cifras):
   - `patrón` sin `*.`: coincide si es igual al host (sin distinguir mayúsculas).
   - `*.dominio`: coincide con cualquier subdominio (`a.dominio`, `a.b.dominio`), NO con `dominio` solo.
   - con puerto: el puerto debe ser ese. Sin puerto: solo vale para los puertos 80 y 443.
   Una lista vacía no permite nada. Las entradas vacías se ignoran.
3. `parse_request_line(line)` (la línea llega sin `\r\n`):
   - `CONNECT host:puerto HTTP/1.x` → `Connect { host, port }`.
   - `MÉTODO http://host[:puerto]/ruta HTTP/1.x` → `Http { host, port (80 si falta), rewritten }` con
     `rewritten = "MÉTODO /ruta HTTP/1.x"` (si no hay ruta, `/`).
   - cualquier otra cosa (tres partes que no encajan, `https://` en claro, puerto no numérico, host
     vacío) → `None`.
4. `lib.rs`: `pub mod netproxy;` y `pub use netproxy::{ProxyRequest, host_allowed, parse_request_line};`.
5. Tests en `netproxy.rs` (`mod tests`), todos con el prefijo `reglas_`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-sandbox/src/netproxy.rs
/// ¿Permite la lista conectar con `host:port`?
pub fn host_allowed(allow: &[String], host: &str, port: u16) -> bool;

/// Lo que pide la primera línea de una petición al proxy.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ProxyRequest {
    /// `CONNECT host:puerto` (túnel, para HTTPS).
    Connect { host: String, port: u16 },
    /// Petición HTTP en claro con URL absoluta; `rewritten` es la línea que se envía al servidor.
    Http { host: String, port: u16, rewritten: String },
}

/// Parsea la primera línea; `None` si no es una petición de proxy válida.
pub fn parse_request_line(line: &str) -> Option<ProxyRequest>;
```

## Ejemplo (entrada y resultado esperado)

```
host_allowed(&["*.github.com".into()], "api.github.com", 443)        → true
host_allowed(&["*.github.com".into()], "github.com", 443)            → false
host_allowed(&["github.com".into()], "github.com", 8080)             → false
host_allowed(&["127.0.0.1:30400".into()], "127.0.0.1", 30400)        → true
parse_request_line("CONNECT api.github.com:443 HTTP/1.1")
  → Some(Connect { host: "api.github.com", port: 443 })
parse_request_line("GET http://127.0.0.1:30400/v1/models HTTP/1.1")
  → Some(Http { host: "127.0.0.1", port: 30400, rewritten: "GET /v1/models HTTP/1.1" })
```

## Tests (con estos nombres)

- `reglas_dominio_exacto`: `github.com` permite github.com:443 y GitHub.com.:80, y no evil.com:443
- `reglas_comodin_solo_subdominios`: `*.github.com` permite api.github.com y a.b.github.com, no github.com ni xgithub.com
- `reglas_puerto`: sin puerto solo valen 80 y 443; `127.0.0.1:30400` permite solo el 30400
- `reglas_lista_vacia_no_permite_nada`: con `allow` vacío cualquier host da false
- `reglas_parsea_connect`: la línea CONNECT del ejemplo da `Connect` con host y puerto
- `reglas_parsea_http_absoluto`: la línea GET del ejemplo da `Http` con la línea reescrita; sin puerto usa 80 y sin ruta usa `/`
- `reglas_rechaza_lo_demas`: `GET /ruta HTTP/1.1`, `CONNECT host HTTP/1.1`, `GET https://a/ HTTP/1.1` y la cadena vacía dan None
