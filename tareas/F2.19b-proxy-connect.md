# F2.19b-proxy-connect — Proxy de salida: servidor en socket Unix con túnel CONNECT y aviso de cada decisión

## Objetivo

1. En `netproxy.rs` añade `ProxyDecision`, `OnDecision`, `NetProxy`, `NetProxy::new` y `NetProxy::serve`
   (firmas abajo). `serve` y sus funciones auxiliares van tras `#[cfg(unix)]`.
2. `serve`: borra `self.socket` si existe, `tokio::net::UnixListener::bind(&self.socket)` y, en bucle,
   acepta conexiones; cada una se atiende en `tokio::spawn`. Es un servidor: termina cuando quien lo
   lanzó aborta la tarea.
3. Cada conexión:
   a) lee hasta encontrar `\r\n\r\n` (máximo 8192 bytes y 10 s con `tokio::time::timeout`); si no llega,
      cierra sin responder.
   b) primera línea → `parse_request_line`. `None` → responde `HTTP/1.1 400 Bad Request\r\nContent-Length: 0\r\n\r\n`.
   c) decide con `host_allowed(&allow, host, port)` y llama a `on_decision` (si hay) con
      `ProxyDecision { host, port, allowed }`. Denegado → `HTTP/1.1 403 Forbidden\r\nContent-Length: 0\r\n\r\n`.
   d) `Connect` permitido: `tokio::net::TcpStream::connect((host, port))` con 10 s de máximo; si falla,
      `HTTP/1.1 502 Bad Gateway\r\nContent-Length: 0\r\n\r\n`. Si conecta: responde
      `HTTP/1.1 200 Connection established\r\n\r\n`, envía al servidor los bytes que ya se hubieran leído
      después de `\r\n\r\n` y une ambos extremos con `tokio::io::copy_bidirectional` dentro de
      `tokio::time::timeout(self.max_conn, …)`.
   e) `Http` permitido: por ahora responde `HTTP/1.1 501 Not Implemented\r\nContent-Length: 0\r\n\r\n`
      (lo implementa otra tarea).
4. `lib.rs`: añade `NetProxy`, `ProxyDecision` y `OnDecision` al `pub use netproxy::{…}`.
5. Tests con `#[tokio::test]`: socket en un `tempfile::tempdir()`, servidor de eco TCP falso en
   `127.0.0.1:0`, `tokio::spawn(proxy.serve())`, espera a que exista el archivo del socket (máximo 50
   intentos de 20 ms) y conecta con `tokio::net::UnixStream`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-sandbox/src/netproxy.rs
/// Una decisión del proxy (para el registro).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ProxyDecision { pub host: String, pub port: u16, pub allowed: bool }

/// Receptor de decisiones.
pub type OnDecision = std::sync::Arc<dyn Fn(&ProxyDecision) + Send + Sync>;

/// Proxy de salida que escucha en un socket Unix.
pub struct NetProxy {
    pub socket: std::path::PathBuf,
    pub allow: Vec<String>,
    pub on_decision: Option<OnDecision>,
    /// Duración máxima de una conexión.
    pub max_conn: std::time::Duration,
}
impl NetProxy {
    /// Proxy sin receptor y con 30 minutos por conexión.
    pub fn new(socket: std::path::PathBuf, allow: Vec<String>) -> NetProxy;
    /// Atiende conexiones hasta que se aborte la tarea.
    #[cfg(unix)]
    pub async fn serve(self) -> std::io::Result<()>;
}
```

## Ejemplo (entrada y resultado esperado)

```
cliente → "CONNECT 127.0.0.1:45123 HTTP/1.1\r\nHost: x\r\n\r\n"      (45123 = puerto del eco, permitido)
proxy   → "HTTP/1.1 200 Connection established\r\n\r\n"
cliente → "hola"        proxy → "hola"                               (lo devuelve el eco a través del túnel)

cliente → "CONNECT evil.example:443 HTTP/1.1\r\n\r\n"                 (no está en la lista)
proxy   → "HTTP/1.1 403 Forbidden\r\nContent-Length: 0\r\n\r\n"  y on_decision recibe allowed = false
```

## Tests (con estos nombres)

- `proxy_connect_permitido_hace_tunel`: con `127.0.0.1:<puerto del eco>` en la lista, tras el 200 lo que se escribe vuelve igual
- `proxy_connect_denegado_403`: un CONNECT a un host fuera de la lista recibe una respuesta que empieza por `HTTP/1.1 403`
- `proxy_connect_avisa_de_cada_decision`: tras un CONNECT permitido y otro denegado, el receptor guardó dos decisiones con `allowed` true y false
- `proxy_connect_peticion_rota_400`: la línea `HOLA\r\n\r\n` recibe una respuesta que empieza por `HTTP/1.1 400`
- `proxy_connect_destino_caido_502`: CONNECT a un puerto permitido donde no escucha nadie recibe `HTTP/1.1 502`

## No hagas

- No resuelvas ni conectes antes de comprobar la lista
- No dependas de `pcode-policy`: el registro se hace con el receptor `on_decision`
- No uses puertos fijos en los tests: siempre `127.0.0.1:0`
