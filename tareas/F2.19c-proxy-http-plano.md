# F2.19c-proxy-http-plano — Proxy de salida: reenvío de peticiones HTTP en claro (URL absoluta)

## Objetivo

1. En `netproxy.rs`, en la función que atiende cada conexión, sustituye la respuesta 501 de la rama
   `ProxyRequest::Http { host, port, rewritten }` (ya permitida por la lista) por el reenvío:
   a) conecta con `tokio::net::TcpStream::connect((host, port))` (10 s de máximo; si falla, responde
      `HTTP/1.1 502 Bad Gateway\r\nContent-Length: 0\r\n\r\n`);
   b) envía al servidor `rewritten` seguido de `\r\n`, después el resto de la cabecera tal como llegó
      (todo lo que hay tras la primera línea, incluido el `\r\n\r\n` final) y los bytes ya leídos del cuerpo;
   c) une ambos extremos con `tokio::io::copy_bidirectional` dentro de
      `tokio::time::timeout(self.max_conn, …)`, igual que en la rama `Connect`.
2. Sirve para llegar a un LiteLLM local (`http://127.0.0.1:30400`) desde dentro de la sandbox. No se
   interpreta el cuerpo ni se reutiliza la conexión para otro host: una conexión, un destino.
3. Añade los tests de la lista (prefijo `proxy_http_`) con un servidor HTTP falso: un
   `tokio::net::TcpListener` en `127.0.0.1:0` que lee hasta `\r\n\r\n`, guarda la primera línea recibida y
   responde `HTTP/1.1 200 OK\r\nContent-Length: 2\r\nConnection: close\r\n\r\nok`.

Sin firmas: no añade API: completa una rama de `NetProxy::serve`

## Ejemplo (entrada y resultado esperado)

```
cliente → "GET http://127.0.0.1:45200/hola HTTP/1.1\r\nHost: 127.0.0.1:45200\r\n\r\n"
servidor falso recibe → "GET /hola HTTP/1.1\r\nHost: 127.0.0.1:45200\r\n\r\n"
cliente recibe → "HTTP/1.1 200 OK\r\nContent-Length: 2\r\nConnection: close\r\n\r\nok"
```

## Tests (con estos nombres)

- `proxy_http_plano_reenvia`: con el destino en la lista, el servidor falso recibe la primera línea `GET /hola HTTP/1.1` y el cliente recibe una respuesta que termina en `ok`
- `proxy_http_plano_denegado_403`: la misma petición con la lista vacía recibe `HTTP/1.1 403` y el servidor falso no recibe ninguna conexión
- `proxy_http_plano_conserva_la_cabecera`: la cabecera `X-Prueba: 1` enviada por el cliente llega al servidor falso

## No hagas

- No añadas dependencias (ni `hyper` ni `httparse`)
