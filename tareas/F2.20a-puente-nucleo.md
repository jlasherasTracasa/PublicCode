## Objetivo

1. Crea `bridge.rs` con la función `bridge` (firma abajo), tras `#[cfg(unix)]`. Recibe un
   `tokio::net::TcpListener` YA enlazado (así quien llama conoce el puerto) y la ruta de un socket Unix.
2. En bucle: acepta una conexión TCP y, en un `tokio::spawn`, abre
   `tokio::net::UnixStream::connect(&socket)` y une ambos extremos con
   `tokio::io::copy_bidirectional`. Si no se puede abrir el socket Unix, cierra la conexión TCP sin más
   (y `tracing::warn!`). Un error en una conexión no detiene el puente.
3. El bucle solo termina si `accept` devuelve error (lo devuelve) o si quien lanzó la tarea la aborta.
4. `lib.rs`: `pub mod bridge;` y `#[cfg(unix)] pub use bridge::bridge;`.
5. Tests con `#[tokio::test]`: un servidor de eco falso en un socket Unix dentro de
   `tempfile::tempdir()` (`tokio::net::UnixListener`), el puente en `127.0.0.1:0` lanzado con
   `tokio::spawn`, y un cliente `tokio::net::TcpStream`. Toda espera lleva `tokio::time::timeout` de 5 s.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-sandbox/src/bridge.rs
/// Reenvía cada conexión que llega a `listener` al socket Unix `socket`, en ambos sentidos.
#[cfg(unix)]
pub async fn bridge(listener: tokio::net::TcpListener, socket: std::path::PathBuf) -> std::io::Result<()>;
```

## Ejemplo (entrada y resultado esperado)

```
eco Unix en /tmp/x/eco.sock · puente en 127.0.0.1:40123 → /tmp/x/eco.sock
cliente TCP a 127.0.0.1:40123 escribe "hola" → lee "hola"
```

## Tests (con estos nombres)

- `puente_reenvia`: lo que el cliente TCP escribe (`hola`) vuelve igual desde el eco del socket Unix
- `puente_dos_conexiones_a_la_vez`: dos clientes TCP abiertos a la vez reciben cada uno su propio eco
- `puente_sin_socket_cierra_la_conexion`: si la ruta del socket no existe, el cliente lee 0 bytes (conexión cerrada) y el puente sigue aceptando

## No hagas

- No enlaces el puerto dentro de `bridge`: el `TcpListener` llega ya creado
- No uses puertos fijos en los tests
