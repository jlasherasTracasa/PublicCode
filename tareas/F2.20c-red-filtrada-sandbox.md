## Objetivo

1. `run.rs`, struct `Sandbox`: campo nuevo `pub(crate) net_allow: Vec<String>` (ponlo a `vec![]` en
   `create_n1` y en `open_existing`) y el método `with_net_allow` (firma abajo).
2. `run.rs`, `run_with`: justo después del `if self.n0 { … }` inicial y ANTES de comprobar
   `userns_available()`: si `self.spec.network == Network::Filtered` y `exec_helper()` es `None`, devuelve
   `SandboxError::Invalid("la red filtrada necesita el ayudante de pcode (set_exec_helper)".into())`.
   Nunca se degrada a red abierta.
3. `run_with`, con `Filtered`: antes de construir `cmd`, crea `<estado>/proxy/`, añádelo a `writable` y
   lanza con `tokio::spawn` un `NetProxy` con socket `<estado>/proxy/proxy.sock`, `allow = self.net_allow.clone()`
   y un `on_decision` que añade una línea a `<estado>/red.jsonl`:
   `{"host":"<host>","port":<puerto>,"allowed":<true|false>}` (escríbela con `format!` y `{:?}` para el
   host; abre el archivo con `OpenOptions::new().create(true).append(true)`). Espera a que exista el
   socket (máximo 40 intentos de 50 ms con `tokio::time::sleep`); si no aparece,
   `SandboxError::Invalid("el proxy de salida no arrancó".into())`.
4. `run_with`: el argumento `--net` de `unshare` se pasa con `Network::None` Y con `Network::Filtered`.
   Con `Filtered` añade `cmd.env("PCODE_PUENTE", <ruta del socket>)`; en los demás casos
   `cmd.env_remove("PCODE_PUENTE")`. Al terminar la orden (después del `match` del tiempo máximo), aborta
   la tarea del proxy (`handle.abort()`).
5. `prepare.sh`: justo ANTES del bloque `if [ -n "$PCODE_BIN" ]; then` añade exactamente:
   ```
   if [ -n "$PCODE_PUENTE" ] && [ -n "$PCODE_BIN" ]; then
     "$PCODE_BIN" __puente --escucha 127.0.0.1:3128 --socket "$PCODE_PUENTE" --listo "$MS_TMP/puente.listo" &
     i=0; while [ ! -s "$MS_TMP/puente.listo" ] && [ "$i" -lt 50 ]; do sleep 0.1; i=$((i+1)); done
     export HTTP_PROXY=http://127.0.0.1:3128 HTTPS_PROXY=http://127.0.0.1:3128
     export http_proxy=http://127.0.0.1:3128 https_proxy=http://127.0.0.1:3128
   fi
   ```
6. Tests en `mod tests` de `run.rs`, con el prefijo `filtrada_`. No llames a `set_exec_helper`.

## Tests (con estos nombres)

- `filtrada_sin_ayudante_es_error`: `create_n1` con `Network::Filtered` y `run` de `["true"]` devuelve `SandboxError::Invalid` que menciona el ayudante (no necesita userns)
- `filtrada_with_net_allow_guarda_la_lista`: tras `with_net_allow(vec!["a.com".into()])` el campo `net_allow` vale `["a.com"]`
- `filtrada_prepare_lanza_el_puente`: `PREPARE` contiene `__puente`, `HTTPS_PROXY=http://127.0.0.1:3128` y la línea del puente va antes de `__sandbox-exec`
- `filtrada_prepare_es_sh_valido`: `sh -n -c PREPARE` termina con éxito

## No hagas

- No añadas campos a `SandboxSpec` ni datos a la variante `Network::Filtered`
- No cambies el comportamiento de `Network::None` ni de `Network::Open`
- No toques N0 (`run_worktree`): la copia de trabajo no aísla la red

## Notas

`iproute2` en el sistema). La prueba de extremo a extremo con el binario real la hace la tarea F2.20d.
