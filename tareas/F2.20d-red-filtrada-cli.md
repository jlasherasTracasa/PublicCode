## Objetivo

API de la sandbox que se usa: `Sandbox::create(spec)?.with_net_allow(Vec<String>)` y `Network::Filtered`.

1. `backend_run.rs`: añade la función pura `net_allow_list` (firma abajo): une las dos listas quitando
   vacíos y repetidos, conservando el orden (primero `needs`, luego `policy`).
2. `backend_run.rs`, función `network`: `"permitir"` → `Network::Open`; `"filtrar"` → `Network::Filtered`;
   cualquier otro valor → `Network::None`.
3. `run_with_backend`: el cálculo de `net` pasa a ser: si `cfg.sandbox.network == "filtrar"` →
   `Network::Filtered` (aunque el backend necesite red); si no, lo de hoy (red abierta si
   `be.caps().needs_network` no está vacío; si no, `network(cfg)`). Tras `Sandbox::create(…)?`, si `net`
   es `Filtered`, encadena
   `.with_net_allow(net_allow_list(&be.caps().needs_network, &crate::run::load_capabilities(std::path::Path::new("pcode.toml")).net_allow))`.
4. `SandboxCmd::Ejecutar`: opción nueva repetible
   `#[arg(long = "red-permitir", conflicts_with = "red")] red_permitir: Vec<String>` («Red filtrada:
   solo estos dominios (`dominio`, `*.dominio`, `host:puerto`)»). En `sandbox_cmd`: si no está vacía,
   `network: Network::Filtered` y `.with_net_allow(red_permitir)` tras `Sandbox::create`.
5. Tests unitarios `net_allow_…` en `backend_run.rs` (`#[cfg(test)] mod tests`).
6. Crea `tests/red_filtrada.rs` con las pruebas de extremo a extremo. Cada una empieza con
   `if !pcode_sandbox::userns_available() || pcode_tools::which("curl").is_none() { return; }`. Servidor
   HTTP falso: `std::net::TcpListener` en `127.0.0.1:0` atendido en un hilo que responde
   `HTTP/1.1 200 OK\r\nContent-Length: 2\r\nConnection: close\r\n\r\nok`. Lanza `pcode` con
   `.env_remove("no_proxy").env_remove("NO_PROXY")` (si no, curl se salta el proxy para 127.0.0.1),
   directorio de trabajo en un `tempdir` y `--estado` en OTRO `tempdir`.

## Ejemplo (entrada y resultado esperado)

```
net_allow_list(&["api.anthropic.com".into()], &["github.com".into(), "api.anthropic.com".into(), "".into()])
  → ["api.anthropic.com", "github.com"]

pcode sandbox ejecutar --estado E --red-permitir 127.0.0.1:P -- curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:P/
  → stdout «200»
pcode sandbox ejecutar --estado E --red-permitir 127.0.0.1:P -- curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:Q/
  → stdout «403»  (Q no está permitido)
```

## Tests (con estos nombres)

- `net_allow_une_sin_repetir`: el ejemplo de `net_allow_list` da las dos entradas en ese orden
- `net_allow_vacio`: dos listas vacías dan un vector vacío
- `filtrada_permite_dominio`: curl dentro de la sandbox llega al servidor falso permitido y devuelve 200 (se salta sin userns o sin curl)
- `filtrada_deniega_otro`: curl a otro puerto no permitido recibe 403 del proxy y `<estado>/red.jsonl` contiene `"allowed":false` (se salta sin userns o sin curl)
- `red_y_red_permitir_son_incompatibles`: `pcode sandbox ejecutar --estado E --red --red-permitir a.com -- true` termina con error de argumentos

## No hagas

- No cambies el valor por defecto de `[sandbox] red` (`denegar`)
- No abras conexiones a Internet en los tests: solo `127.0.0.1`
- No toques `crates/pcode-config`: `red` ya es una cadena libre
