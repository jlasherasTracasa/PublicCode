## Objetivo

`classify(run, jobs)` a partir del JSON de la API de Actions:
1. `success` → `Verde`.
2. `failure` o `timed_out` con al menos un paso fallido → `Roja{jobs, pasos}` (genera una tarea `CI-arreglo-<sha>`).
3. `cancelled`, o `failure` SIN ningún paso fallido → `NoAccionable` (no genera tarea).
4. `startup_failure` o error de infraestructura (runner perdido) → `Infra` (reintentar más tarde).
5. Run en curso → `EnCurso`.
Fixtures sacados de los casos reales del log de SO_IA (rojo real, cancelado, fantasma).
