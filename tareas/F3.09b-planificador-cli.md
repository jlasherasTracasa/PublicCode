## Objetivo

1. En `flow_cmd.rs`, variante `Planificar { goal: Vec<String>, tareas: PathBuf, min_ready: Option<usize>,
   model, provider, config }` («Pide al modelo las tareas que faltan para un objetivo y las deja como
   borrador.»): `goal` posicional (se une con espacios), `--tareas` (por defecto `tareas`), `--si-faltan N`,
   `--modelo`, `--proveedor`, `--config` (por defecto `pcode.toml`).
2. Rama: `load_flow`, `done_ids` y `board(...)`. Con `--si-faltan N`, si `should_plan(&rows, N)` es false,
   imprime `hay tareas listas de sobra: no hace falta planificar` y devuelve 0 sin llamar al modelo. Si el
   objetivo está vacío: `anyhow::bail!("falta el objetivo: pcode flow planificar \"…\"")`.
3. Pide el plan igual que `Desglosar`: una petición de chat por ronda, hasta 3 rondas (bucle `for`), con
   `planner_prompt(&goal, &rows, reparación)`, `pcode_flow::split::parse_blocks` y `check_plan`.
4. Con problemas tras 3 rondas: los imprime en stderr y devuelve 2 sin escribir nada.
5. Si vale: escribe cada tarea en `<tareas>/borradores/<id>.md`. Si alguno existe: stderr `ya existe <ruta>`
   y devuelve 2 sin escribir ninguno. Imprime `borrador: <ruta>` por archivo y al final
   `Revísalas y adóptalas con: pcode flow adoptar`.
6. Añade a `tests/flow.rs` los tests `planificar_*`.

Sin firmas: solo añade una variante de `FlowCmd` y su rama; la API está en `pcode_flow::planner`

## Ejemplo (entrada y resultado esperado)

```
Guion del modelo: una respuesta con content "<<<N1.md\n{valida N1}\n>>>\n<<<N2.md\n{valida N2 que depende de N1}\n>>>\n"
$ pcode flow planificar exportar a CSV   → código 0, existen tareas/borradores/N1.md y N2.md
$ pcode flow planificar --si-faltan 1 algo   (con una tarea lista en tareas/) → código 0, "no hace falta planificar", guion sin consumir
```

## Tests (con estos nombres)

- `planificar_escribe_borradores`: con el guion del ejemplo se crean los dos borradores
- `planificar_respuesta_mala_no_escribe`: tres respuestas sin bloques dan código 2 y no existe la carpeta de borradores
- `planificar_si_faltan_no_llama_al_modelo`: con una tarea lista y --si-faltan 1 sale con 0 aunque el guion esté vacío
- `planificar_no_pisa_borradores`: si tareas/borradores/N1.md ya existe sale con 2 y no lo cambia
