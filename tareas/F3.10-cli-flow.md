## Objetivo

1. `Runner::tick()`: un ciclo = recoger lo que ha terminado → aceptar → integrar → CI → `plan()` →
   lanzar → escribir `estado.md` → planificador si toca. Cada paso emite eventos.
2. `pcode flow run --tareas DIR [--paralelo N] [--una-vez]`: bucle de `tick` cada 30 s (o uno solo).
   Señal o archivo `.pcode/STOP` → parada limpia.
3. `pcode flow estado`: tabla de tareas, agentes en marcha y «Requiere coordinador».
4. Test con backend mock, 3 tareas y una dependencia: termina con las 3 integradas.
