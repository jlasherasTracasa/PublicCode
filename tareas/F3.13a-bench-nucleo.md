## Objetivo

1. Crea `bench.rs` con los tipos y funciones de abajo. Lógica pura.
2. `parse_cases`: una línea JSON por caso (se saltan las vacías); error `línea <k>: <error de serde>`.
3. `rows_to_jsonl` / `parse_rows`: una línea JSON por fila, ida y vuelta exacta.
4. `summarize`: `n` = filas; `first_pct` y `final_pct` = porcentaje (0–100, `f64`) de `ok_first` y `ok_final`;
   `tokens_per_accepted` y `millis_per_accepted` = suma de (entrada + salida) y de `millis` de las filas con
   `ok_final`, dividida entre cuántas son (0 si ninguna); `violations` = suma. Sin filas, todo a 0.
5. `report_markdown`: tabla con una columna por ejecución (su nombre) y estas filas, en este orden:
   `Tareas`, `Aceptación a la primera` (`75.0 %`), `Aceptación final`, `Tokens por tarea aceptada`,
   `Tiempo por tarea aceptada` (segundos con un decimal: `12.5 s`), `Violaciones de reglas`. Debajo, una
   sección `## Tareas que difieren` con una línea `- <id>: <nombre>=✓ <nombre>=✗` por cada id cuyo `ok_final`
   no coincide en todas las ejecuciones (o `ninguna`).
6. `lib.rs`: añade `pub mod bench;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-flow/src/bench.rs
/// Un caso del banco (una línea de `bench/<conjunto>.jsonl`).
#[derive(Debug, Clone, PartialEq, serde::Deserialize)]
pub struct BenchCase {
    pub id: String,
    #[serde(rename = "acepta")]
    pub accept: String,
    #[serde(rename = "tarea")]
    pub task: String,
    pub base: String,
    #[serde(rename = "aceptada_en")]
    pub accepted_at: String,
}

/// Resultado de un caso con un backend.
#[derive(Debug, Clone, PartialEq, serde::Serialize, serde::Deserialize)]
pub struct BenchRow {
    pub id: String, pub ok_first: bool, pub ok_final: bool, pub attempts: u32,
    pub tokens_in: u64, pub tokens_out: u64, pub millis: u64, pub violations: u32,
}

/// Métricas de una ejecución.
#[derive(Debug, Clone, PartialEq)]
pub struct Summary {
    pub n: usize, pub first_pct: f64, pub final_pct: f64,
    pub tokens_per_accepted: u64, pub millis_per_accepted: u64, pub violations: u32,
}

pub fn parse_cases(jsonl: &str) -> Result<Vec<BenchCase>, String>;
pub fn rows_to_jsonl(rows: &[BenchRow]) -> String;
pub fn parse_rows(jsonl: &str) -> Result<Vec<BenchRow>, String>;
pub fn summarize(rows: &[BenchRow]) -> Summary;
pub fn report_markdown(runs: &[(String, Vec<BenchRow>)]) -> String;
```
