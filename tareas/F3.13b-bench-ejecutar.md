## Objetivo

1. Crea `bench_run.rs` con `BenchCfg`, `worktree_args` y `run_case` (firmas abajo).
2. `worktree_args(dir, base)`: devuelve `["worktree", "add", "--detach", "--force", <dir>, <base>]`.
3. `run_case`:
   a) crea un worktree de `cfg.repo` en `base` dentro de
      `pcode_sandbox::tmp_base().join("pcode-bench").join(format!("{}-{}", std::process::id(), case.id))`
      con `git -C <repo> worktree add …` (`std::process::Command`); si falla, `Err` con el stderr;
   b) lee el texto de la tarea de `cfg.repo.join(&case.task)` (el archivo de tarea puede no existir en `base`);
      si no existe, `Err("no existe <ruta>")`; con `crate::task::parse_task(&case.id, &texto)` obtiene las rutas
      permitidas (`allowed_paths`); si no parsea, sin restricción;
   c) hasta `cfg.attempts.max(1)` intentos (bucle `for`): `Sandbox::create` con `root` = el worktree; `Job` con
      el texto, `accept = Some(case.accept)` y el relevo del intento anterior; `backend.run`; ejecuta
      `case.accept` con `sandbox.run_capture(&["sh", "-c", accept], &[])`; suma tokens de `res.usage`; cuenta
      `outside_scope(...)` sobre `sandbox.changes()` en `violations`; si el código es 0 termina; si no,
      construye el relevo con `crate::retry::build_handoff` (como en `Runner::execute`); descarta la sandbox
      siempre (`let _ = sandbox.discard();`): cada intento empieza de `base`;
   d) al acabar (bien o mal) quita el worktree: `git -C <repo> worktree remove --force <dir>`;
   e) devuelve `BenchRow` con `ok_first` (pasó en el intento 1), `ok_final`, `attempts`, tokens, `millis`
      (con `std::time::Instant`) y `violations`.
4. `lib.rs`: añade `pub mod bench_run;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-flow/src/bench_run.rs
use crate::bench::{BenchCase, BenchRow};
use pcode_backends::Backend;
use std::path::{Path, PathBuf};

/// Configuración de una ejecución del banco.
pub struct BenchCfg {
    /// Repo del que salen los commits `base`.
    pub repo: PathBuf,
    /// Intentos por caso (con relevo entre ellos).
    pub attempts: u32,
    /// Tiempo máximo por intento.
    pub task_timeout: std::time::Duration,
    /// Red de las sandboxes.
    pub network: pcode_sandbox::Network,
}

/// Argumentos de `git` para crear el worktree de un caso.
pub fn worktree_args(dir: &Path, base: &str) -> Vec<String>;
/// Ejecuta un caso con un backend y devuelve su fila de resultado.
pub async fn run_case(case: &BenchCase, backend: &dyn Backend, cfg: &BenchCfg) -> Result<BenchRow, String>;
```

## Ejemplo (entrada y resultado esperado)

```
worktree_args(Path::new("/tmp/w"), "abc123") → ["worktree", "add", "--detach", "--force", "/tmp/w", "abc123"]
Repo temporal con un commit (README y tareas/T1.md con `<!-- acepta: test -f out.txt -->`), caso T1 con base = HEAD:
  run_case con MockBackend que escribe out.txt → BenchRow { ok_first: true, ok_final: true, attempts: 1, .. }
  run_case con MockBackend que no escribe nada y attempts 2 → ok_final false, attempts 2
  tras cualquiera de las dos, `git worktree list` solo muestra el repo
```

## Tests (con estos nombres)

- `argumentos_del_worktree`: el primer caso del ejemplo
- `caso_aceptado_a_la_primera`: el MockBackend que escribe out.txt da ok_first y un intento (se salta sin namespaces de usuario)
- `caso_fallido_agota_intentos`: sin el archivo, attempts es 2 y ok_final false (se salta sin namespaces de usuario)
- `tarea_inexistente_es_error`: un caso cuya ruta de tarea no existe devuelve Err y no deja worktrees (no necesita sandbox)

## No hagas

- No integres nada en el repo: el banco solo mide
- No dejes worktrees sin quitar, tampoco cuando hay error
- No pongas bucles sin cota
