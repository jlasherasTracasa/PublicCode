## Objetivo

1. La tool `contexto` la intercepta el bucle (no está en `pcode-tools`): `{"op": "fijar"|"soltar"|"nota"|"estado", "ids": [int]?, "texto": str?}`.
   - Cada resultado de tool lleva un id corto visible (`[r12]`).
   - `soltar`: sustituye los resultados indicados por `"[r12 soltado: <primera línea>]"`.
   - `fijar`: marca resultados que la compactación no puede tocar.
   - `nota`: añade una decisión o restricción al **estado del proyecto** (`.pcode/estado-proyecto.md`).
   - `estado`: devuelve el estado del proyecto.
2. El estado del proyecto se reinyecta como mensaje de sistema adicional tras cada compactación (F4.02).
