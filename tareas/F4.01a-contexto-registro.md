## Objetivo

El id de un resultado vive en el propio texto del mensaje (prefijo `[r7] `), así que no hay índices que
se rompan al compactar. El registro solo guarda el último id dado y los ids fijados.
1. Crea `context.rs` con `result_id` y `ContextLedger` (firmas abajo). En `lib.rs` añade `pub mod context;`
   (orden alfabético, después de `pub mod compress;`) y `pub use context::ContextLedger;`.
2. `result_id(content)`: `Some(N)` si el texto empieza por `[r`, una o más cifras y después `]` o un
   espacio (vale para `[r7] hola` y para `[r7 soltado: hola]`); `None` en otro caso.
3. `tag(content)`: suma 1 a `last` y devuelve `format!("[r{last}] {content}")`. El primero es `[r1]`.
4. `sync(messages)`: `last` = el mayor entre `last` y los `result_id` de los mensajes con
   `role == Role::Tool` (sirve al retomar una conversación guardada).
5. `pin(ids)`: añade a `pinned` los ids entre 1 y `last` (los demás se ignoran) y devuelve cuántos son
   nuevos. `is_pinned(id)`: si está en `pinned`. `message_pinned(m)`: `true` solo si `m.role == Role::Tool`
   y su `result_id` está fijado.
6. `drop_results(ids, messages)`: para cada mensaje con rol `Tool` cuyo contenido empieza EXACTAMENTE por
   `[r{id}] ` con `id` en `ids` y no fijado, sustituye el contenido por `[r{id} soltado: {primera}]`, donde
   `primera` es la primera línea del texto que sigue al prefijo, sin espacios en los extremos y recortada
   a 80 caracteres (`chars().take(80)`, no bytes). Devuelve cuántos mensajes cambió. Los ya soltados no
   empiezan por `[r{id}] `, así que no se tocan.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/context.rs
use pcode_models::{Message, Role};

/// Id de un resultado de tool etiquetado (`[r7] …` o `[r7 soltado: …]`).
pub fn result_id(content: &str) -> Option<u32>;

/// Registro de resultados de tools: último id dado y resultados fijados.
#[derive(Debug, Clone, Default)]
pub struct ContextLedger { last: u32, pinned: std::collections::BTreeSet<u32> }

impl ContextLedger {
    /// Registro vacío (el primer id será 1).
    pub fn new() -> Self;
    /// Pone `last` al día con un historial ya etiquetado.
    pub fn sync(&mut self, messages: &[Message]);
    /// Etiqueta un resultado nuevo: `[rN] contenido`.
    pub fn tag(&mut self, content: &str) -> String;
    /// Fija resultados; devuelve cuántos son nuevos.
    pub fn pin(&mut self, ids: &[u32]) -> usize;
    /// Si el id está fijado.
    pub fn is_pinned(&self, id: u32) -> bool;
    /// Si el mensaje es un resultado de tool fijado.
    pub fn message_pinned(&self, m: &Message) -> bool;
    /// Sustituye por un marcador los resultados indicados que no estén fijados.
    pub fn drop_results(&self, ids: &[u32], messages: &mut [Message]) -> usize;
}
```

## Ejemplo (entrada y resultado esperado)

```
let mut l = ContextLedger::new();
let mut ms = vec![Message::tool_result("c1", l.tag("  linea uno\nlinea dos"))];
// ms[0].content == "[r1]   linea uno\nlinea dos"
l.drop_results(&[1], &mut ms) == 1
// ms[0].content == "[r1 soltado: linea uno]"
result_id("[r12] x") == Some(12);  result_id("[r12 soltado: x]") == Some(12);  result_id("r12") == None
```

## Tests (con estos nombres)

- `etiqueta_numera_desde_uno`: dos llamadas a tag dan los prefijos [r1] y [r2]
- `id_de_resultado`: los tres casos del ejemplo y la cadena vacía (None)
- `soltar_sustituye_por_marcador`: el ejemplo completo, con la primera línea recortada a 80 caracteres si es larga
- `soltar_no_toca_fijados_ni_repite`: con r1 fijado drop_results devuelve 0; soltar dos veces r2 devuelve 1 y luego 0
- `fijar_ignora_ids_desconocidos`: tras dos tag, pin(&[2, 9]) devuelve 1 y solo is_pinned(2) es true
- `sincroniza_con_el_historial`: sync con un mensaje Tool `[r5] x` hace que el siguiente tag sea [r6]
- `mensaje_fijado_solo_si_es_de_tool`: un mensaje de usuario con texto `[r1] x` no cuenta como fijado
