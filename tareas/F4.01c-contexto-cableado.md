# F4.01c-contexto-cableado — Bucle del agente: etiquetar resultados con `[rN]` e interceptar la tool `contexto`

## Contexto (lee esto y nada más)

- crates/pcode-core/src/agent.rs (método `run_messages`: el bloque `if call.name == REMEMBER_TOOL && self.memory` es el modelo de tool interceptada; `with_memory` es el modelo de activación)
- crates/pcode-core/src/context.rs (`ContextLedger::{sync, tag, handle}`, `CONTEXT_TOOL`, `context_spec`)
- crates/pcode-cli/src/chat.rs (función `prepare`: la cadena `.with_checkpoints().with_questions(…).with_memory().with_verify_reminder()`)

## Objetivo

1. `agent.rs`, struct `Agent`: campo nuevo `context: Option<crate::context::ContextLedger>`; en
   `Agent::new` vale `None`. Añade `with_context_tool` (firma abajo) junto a `with_memory`.
2. `run_messages`, antes del `loop`: `if let Some(l) = self.context.as_mut() { l.sync(&messages); }`.
3. `run_messages`, donde se construye `specs`, después del bloque que añade `remember_spec()`:
   si `self.context.is_some() && self.policy.tool_visible(CONTEXT_TOOL, &[])`, haz
   `specs.push(crate::context::context_spec())`.
4. `run_messages`, dentro de `for call in calls`, justo después del bloque
   `if call.name == REMEMBER_TOOL && self.memory { … }`: si `call.name == CONTEXT_TOOL` y hay registro,
   calcula `let content = l.handle(&call.arguments, &mut messages);` (con `l = self.context.as_mut()`),
   después `self.audit(&call, "allow")`, emite `AgentEvent::ToolResult { name, is_error: false, content }`,
   añade `Message::tool_result(call.id.clone(), content)` y `continue`. Este resultado NO se etiqueta.
5. Al final del `for`, la última línea `messages.push(Message::tool_result(call.id.clone(), out.content));`
   pasa a etiquetar: si hay registro, el contenido es `l.tag(&out.content)`; si no, `out.content`. El
   `self.emit(AgentEvent::ToolResult { … })` de justo antes no cambia (la interfaz no ve la etiqueta).
6. `chat.rs`, función `prepare`: añade `.with_context_tool()` después de `.with_memory()`.

## Ejemplo (entrada y resultado esperado)

```
// Test en `mod tests` de agent.rs (usa los ayudantes `tool`, `text` y `agent` que ya existen):
std::fs::write(d.path().join("a.txt"), "hola").unwrap();
let script = vec![
    tool("leer", json!({"path": "a.txt"})),
    tool("contexto", json!({"op": "soltar", "ids": [1]})),
    text("fin"),
];
let (a, p) = agent(&d, script, Capabilities::default(), None);
let mut a = a.with_context_tool();
let r = a.run("lee").await;
// r.transcript: sistema, usuario, asistente, Tool "[r1 soltado: …]", asistente, Tool "soltados 1 de 1 …", asistente
// p.requests()[0].tools contiene una spec con name == "contexto"
```
