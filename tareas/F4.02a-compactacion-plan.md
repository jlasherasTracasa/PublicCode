## Objetivo

1. Crea `compact.rs` con las constantes y funciones de abajo. En `lib.rs` añade `pub mod compact;`
   (después de `pub mod checkpoint;`). No hay E/S ni llamadas al modelo en esta tarea.
2. `estimate_tokens`: suma, para cada mensaje, `content.chars().count()` y, por cada llamada de
   `tool_calls`, `name.chars().count() + arguments.to_string().chars().count()`; devuelve el total
   dividido entre 4 hacia arriba (`div_ceil(4)`).
3. `prefix_len`: cuántos mensajes seguidos con `Role::System` hay al principio (es el prefijo estable:
   nunca se modifica, para no invalidar la caché del proveedor).
4. `segments(messages, prefix_len)`: rangos consecutivos que cubren `prefix_len..messages.len()`. Empieza
   un segmento nuevo cada mensaje cuyo rol NO es `Tool`; los mensajes `Tool` se quedan en el segmento
   abierto (si el primero tras el prefijo es `Tool`, abre segmento él). Así una llamada y sus resultados
   nunca se separan.
5. `plan(messages, prefix_len, keep_recent, pinned)`:
   a) `segs = segments(…)`; si `segs.len() <= keep_recent`, `None`.
   b) Los antiguos son todos menos los `keep_recent` últimos. Un segmento antiguo en el que algún mensaje
      cumple `pinned(m)` se conserva entero; los índices de los demás van, en orden, a `summarize`.
   c) Si `summarize.len() < MIN_SUMMARIZED`, `None`. Si no, `Some(CompactPlan { prefix_len, summarize })`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/compact.rs
use pcode_models::{Message, Role};

/// Segmentos recientes que nunca se resumen.
pub const KEEP_RECENT_SEGMENTS: usize = 3;
/// Mensajes mínimos que tiene que haber para que merezca la pena resumir.
pub const MIN_SUMMARIZED: usize = 3;

/// Tokens aproximados de un historial (4 caracteres por token).
pub fn estimate_tokens(messages: &[Message]) -> u64;
/// Longitud del prefijo estable (mensajes de sistema iniciales).
pub fn prefix_len(messages: &[Message]) -> usize;
/// Segmentos del historial tras el prefijo (un turno y sus resultados de tools).
pub fn segments(messages: &[Message], prefix_len: usize) -> Vec<std::ops::Range<usize>>;

/// Qué mensajes se sustituyen por un resumen.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CompactPlan { pub prefix_len: usize, pub summarize: Vec<usize> }

/// Plan de compactación, o `None` si no hay bastante que resumir.
pub fn plan(messages: &[Message], prefix_len: usize, keep_recent: usize,
            pinned: &dyn Fn(&Message) -> bool) -> Option<CompactPlan>;
```

## Ejemplo (entrada y resultado esperado)

```
roles:    [S, U, A, T, A, T, T, U, A]      (S sistema, U usuario, A asistente, T tool)
prefix_len -> 1
segments(.., 1) -> [1..2, 2..4, 4..7, 7..8, 8..9]
plan(.., 1, 3, &|_| false)            -> Some(CompactPlan { prefix_len: 1, summarize: vec![1, 2, 3] })
plan(.., 1, 3, &|m| es el mensaje 3)  -> None   (el segmento 2..4 se conserva; queda 1 mensaje < 3)
estimate_tokens([usuario "abcde"])    -> 2
```
