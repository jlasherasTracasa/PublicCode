## Objetivo

1. Tabla SQLite `file_facets(path, sha256, api, invariants, pitfalls, updated_ms, source_task)`.
2. `get(path, current_sha)`: devuelve las facetas solo si el hash coincide (si el archivo cambió,
   la memoria está caducada y no se usa).
3. `put`: guarda las facetas que escribe el agente (tool `memoria_archivo` en F4.05) o el destilador.
4. `for_task(paths)`: texto compacto con las facetas válidas de esos archivos, para el contexto.
