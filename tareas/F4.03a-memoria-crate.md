## Objetivo

1. Crea `crates/pcode-memory/Cargo.toml` EXACTAMENTE con el contenido del ejemplo. Todas las
   dependencias están ya en el workspace; se declaran ahora las que usarán las tareas siguientes para
   que nadie más tenga que tocar este archivo.
2. Crea `lib.rs` con la línea de documentación
   `//! Memoria del agente: facetas de archivos, búsqueda en el código y episodios de tareas anteriores.`,
   `pub mod hash;` y `pub use hash::{sha256_file, sha256_hex};`.
3. Crea `hash.rs` con las dos funciones de las firmas. `sha256_hex` usa
   `use sha2::{Digest, Sha256};` y `hex::encode(Sha256::digest(bytes))` (64 caracteres en minúsculas).
   `sha256_file` lee el archivo entero con `std::fs::read` y llama a `sha256_hex`.
4. `Cargo.lock` cambia solo al compilar: inclúyelo en el commit.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/hash.rs
/// SHA-256 de unos bytes, en hexadecimal.
pub fn sha256_hex(bytes: &[u8]) -> String;
/// SHA-256 del contenido de un archivo, en hexadecimal.
pub fn sha256_file(path: &std::path::Path) -> std::io::Result<String>;
```
