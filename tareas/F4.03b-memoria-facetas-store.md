## Objetivo

Una faceta es lo que el agente aprendió de un archivo (su API, sus invariantes y sus trampas). Si el
archivo cambia, su hash cambia y la memoria deja de valer: nunca se usa memoria caducada.
1. Crea `facets.rs` con `Facets`, `FacetStore` y `render_facets` (firmas abajo). En `lib.rs` añade
   `pub mod facets;` y `pub use facets::{FacetStore, Facets, render_facets};`.
2. Esquema (en `open` y `open_in_memory`, con `execute_batch`):
   `CREATE TABLE IF NOT EXISTS file_facets (path TEXT PRIMARY KEY, sha256 TEXT NOT NULL, api TEXT NOT NULL, invariants TEXT NOT NULL, pitfalls TEXT NOT NULL, source_task TEXT NOT NULL);`
   `open(path)` crea antes la carpeta padre con `std::fs::create_dir_all` (ignora su error).
3. `put`: `INSERT INTO file_facets VALUES (?1, ?2, ?3, ?4, ?5, ?6) ON CONFLICT(path) DO UPDATE SET
   sha256 = excluded.sha256, api = excluded.api, invariants = excluded.invariants,
   pitfalls = excluded.pitfalls, source_task = excluded.source_task` (una fila por archivo).
4. `get(path, sha256)`: `SELECT api, invariants, pitfalls FROM file_facets WHERE path = ?1 AND sha256 = ?2`
   con `query_row(…).optional()` (necesita `use rusqlite::OptionalExtension;`). Si el hash no coincide,
   `Ok(None)`.
5. `render_facets(path, f)`: `## {path}\n` y una línea por faceta NO vacía, en este orden:
   `- API: …\n`, `- Invariantes: …\n`, `- Trampas: …\n`. Cada valor en una sola línea
   (`split_whitespace` y unir con un espacio).
6. `for_task(root, paths)`: para cada ruta, en orden, calcula `sha256_file(&root.join(ruta))` (si falla,
   la salta), llama a `get` y, si hay facetas, añade su `render_facets`. Deja de añadir cuando el texto
   pasaría de 4000 caracteres. Sin facetas válidas devuelve la cadena vacía.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/facets.rs
/// Lo aprendido de un archivo.
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Facets { pub api: String, pub invariants: String, pub pitfalls: String }

/// Facetas por archivo, guardadas en SQLite.
pub struct FacetStore { conn: rusqlite::Connection }

impl FacetStore {
    /// Abre (o crea) la base de datos.
    pub fn open(path: &std::path::Path) -> rusqlite::Result<Self>;
    /// Base de datos en memoria (tests).
    pub fn open_in_memory() -> rusqlite::Result<Self>;
    /// Facetas de `path` si se escribieron con ese mismo hash.
    pub fn get(&self, path: &str, sha256: &str) -> rusqlite::Result<Option<Facets>>;
    /// Guarda (o sustituye) las facetas de `path`.
    pub fn put(&self, path: &str, sha256: &str, f: &Facets, source_task: &str) -> rusqlite::Result<()>;
    /// Texto compacto con las facetas vigentes de estos archivos.
    pub fn for_task(&self, root: &std::path::Path, paths: &[String]) -> rusqlite::Result<String>;
}

/// Facetas de un archivo como texto para el contexto.
pub fn render_facets(path: &str, f: &Facets) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
render_facets("src/a.rs", &Facets { api: "fn a() -> u32".into(), invariants: String::new(), pitfalls: "no llamar\n dos veces".into() })
  == "## src/a.rs\n- API: fn a() -> u32\n- Trampas: no llamar dos veces\n"
s.put("src/a.rs", "h1", &f, "F9.01");
s.get("src/a.rs", "h1") == Ok(Some(f));   s.get("src/a.rs", "h2") == Ok(None)
```

## Tests (con estos nombres)

- `facetas_validas_con_mismo_hash`: put y get con el mismo hash devuelven las mismas facetas
- `facetas_caducan_si_cambia`: get con otro hash devuelve None
- `put_sustituye_la_fila_del_archivo`: dos put del mismo path dejan solo las segundas facetas
- `render_omite_facetas_vacias`: el caso del ejemplo, carácter a carácter
- `for_task_omite_caducadas`: dos archivos en un tempdir con facetas guardadas; se modifica uno y for_task solo devuelve el otro
- `for_task_sin_nada_es_vacio`: rutas sin facetas o que no existen dan la cadena vacía
- `open_crea_la_carpeta`: open sobre `<tempdir>/.pcode/memoria.db` crea el archivo
