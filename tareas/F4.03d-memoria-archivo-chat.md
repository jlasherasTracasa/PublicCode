1. `crates/pcode-cli/Cargo.toml`, sección `[dependencies]`: añade
   `pcode-memory = { path = "../pcode-memory" }` después de la línea de `pcode-lsp`.
2. `chat.rs`, función `prepare`, justo después de `let mut tools = pcode_tools::native_registry();`:
   `tools.register(std::sync::Arc::new(pcode_memory::FacetTool)).expect("nombre único");`
   (`prepare` la usan el chat y la TUI, así que vale para los dos).
3. `tests/chat.rs`: añade el test `memoria_archivo_en_chat` del ejemplo.
4. `Cargo.lock` cambia solo al compilar: inclúyelo en el commit.

## Ejemplo (entrada y resultado esperado)

```
#[test]
fn memoria_archivo_en_chat() {
    let d = tempfile::tempdir().unwrap();
    std::fs::write(d.path().join("a.rs"), "fn a() {}").unwrap();
    pcode(
        d.path(),
        json!([
            resp("", json!([{"id":"1","name":"memoria_archivo","arguments":{"op":"guardar","path":"a.rs","api":"fn a()"}}])),
            resp("anotado", json!([])),
        ]),
    )
    .arg("chat")
    .write_stdin("anota a.rs\n/salir\n")
    .assert()
    .success()
    .stdout(predicate::str::contains("⏺ memoria_archivo"))
    .stdout(predicate::str::contains("notas de a.rs guardadas"));
    assert!(d.path().join(".pcode/memoria.db").exists());
}
```
