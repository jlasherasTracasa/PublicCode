## Objetivo

1. Dependencias nuevas permitidas: `tree-sitter`, `tree-sitter-rust` y `tree-sitter-python`.
2. `symbols(path, source)`: lista de `Symbol {kind, name, qualified, start_line, end_line}` para fn,
   struct, enum, trait, impl (con el tipo) y mod en Rust; def y class en Python.
3. `repo_map(root, max_lines)`: por archivo, sus símbolos con la firma (primera línea), recortado a
   `max_lines`.
4. Tool `editar_simbolo` (`[Write]`): `{"path", "symbol": "Tipo::metodo"|"funcion", "new_source"}`
   reemplaza el rango completo del símbolo. Si el nombre es ambiguo o no existe → error con la lista
   de candidatos.
