## Objetivo

1. Crea `edit_symbol.rs` con `replace_symbol` y la tool `EditSymbol` (firmas abajo).
2. `replace_symbol(text, lang, symbol, line, new_source)`:
   a) Si `lang` es `""` o `"markdown"`: `Err("lenguaje sin símbolos: usa `editar`")`.
   b) `ranges = symbol_ranges(text, lang)`; `r = find_symbol(&ranges, symbol, line)?`.
   c) Salvaguarda: si `lang != "python"` y en las líneas `r.start_line..=r.end_line` el número de `{`
      no es igual al de `}`: `Err("no se pudo delimitar «{symbol}» con seguridad; usa `editar`")`.
   d) Resultado: las líneas anteriores a `start_line`, después `new_source` sin los saltos de línea
      finales (`trim_end_matches('\n')`), después las líneas posteriores a `end_line`; todo unido con
      `\n`, y con `\n` final si `text` acababa en `\n`. `new_source` se inserta tal cual: quien llama
      pone la sangría. Los comentarios de documentación y atributos de encima del símbolo no forman
      parte del rango y se conservan.
   e) Devuelve `(texto nuevo, format!("{} (líneas {}-{} → {} líneas)", r.qualified, r.start_line, r.end_line, n))`
      con `n` = líneas de `new_source`.
3. `EditSymbol`: nombre `editar_simbolo`; descripción EXACTA: «Reemplaza entero un símbolo (función,
   método, struct, clase…) por `new_source`. `symbol` es su nombre o `Tipo::metodo`; `line` (opcional)
   desambigua. Más seguro que `editar` para cambiar una función completa: no hace falta copiar el texto
   antiguo.»; parámetros: `path`, `symbol`, `new_source` (string) y `line` (integer);
   `required: ["path", "symbol", "new_source"]`; efectos `&[Effect::Write]`.
   `call`: valida los tres argumentos (`faltan `path`, `symbol` o `new_source``), resuelve la ruta con
   `resolve_in_root`, lee el archivo (`no se pudo leer {p}: {e}`), llama a `replace_symbol` con
   `crate::outline::language_of(p)`, escribe y devuelve `ToolOutput::ok(format!("editado {p}: {resumen}"))`.
4. `lib.rs`: `pub mod edit_symbol;`, `pub use edit_symbol::EditSymbol;` y, en `native_registry`, añade
   `std::sync::Arc::new(EditSymbol),` justo después de `std::sync::Arc::new(EditFile),`.

## Ejemplo (entrada y resultado esperado)

```
text = "/// Suma.\npub fn suma(a: u32, b: u32) -> u32 {\n    a + b\n}\n\npub fn resta() {}\n"
replace_symbol(text, "rust", "suma", None, "pub fn suma(a: u32, b: u32) -> u32 {\n    a.wrapping_add(b)\n}\n")
 -> Ok(("/// Suma.\npub fn suma(a: u32, b: u32) -> u32 {\n    a.wrapping_add(b)\n}\n\npub fn resta() {}\n",
        "suma (líneas 2-4 → 3 líneas)"))
tool: {"path":"src/a.rs","symbol":"suma","new_source":"…"} -> "editado src/a.rs: suma (líneas 2-4 → 3 líneas)"
```

## Tests (con estos nombres)

- `editar_simbolo_reemplaza`: el caso del ejemplo, texto y resumen exactos
- `editar_simbolo_metodo_cualificado`: con dos impl que tienen `nuevo`, `Caja::nuevo` cambia solo el de Caja
- `editar_simbolo_ambiguo_lista_candidatos`: `nuevo` sin cualificar da Err que nombra los dos candidatos y el archivo no cambia
- `editar_simbolo_llaves_descuadradas_no_edita`: en JavaScript (lang js), `function a() {` con un `if (x) {` dentro y una cadena de plantilla que tiene una línea `}` sin sangría da el Err de «no se pudo delimitar» (el rango por sangría se corta ahí y las llaves no cuadran)
- `editar_simbolo_python`: reemplaza un método de una clase y conserva el resto
- `tool_editar_simbolo_escribe_el_archivo`: call sobre un tempdir cambia el archivo y devuelve `editado a.rs: …`; con una ruta `../x` es error
- `tool_registrada_en_las_nativas`: native_registry().get("editar_simbolo") es Some
