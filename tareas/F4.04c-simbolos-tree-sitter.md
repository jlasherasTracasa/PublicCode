## Objetivo

Los rangos por sangría fallan cuando dentro de una función hay texto sin sangría (cadenas multilínea).
Con tree-sitter el rango es exacto.
1. `crates/pcode-tools/Cargo.toml`: añade `tree-sitter = "0.24"`, `tree-sitter-rust = "0.23"` y
   `tree-sitter-python = "0.23"` (permitidas por AGENTS.md §7 para esta tarea). Si no resuelven juntas,
   usa las últimas compatibles entre sí y anótalo en Decisiones.
2. Crea `symbols_ts.rs` con `symbol_ranges_ts` (firma abajo); `lib.rs`: `pub mod symbols_ts;`.
   - Solo `lang == "rust"` y `lang == "python"`; otro lenguaje → `None`. Si el parser no se puede crear
     o `tree.root_node().has_error()` → `None` (se usará el método por sangría).
   - Recorre los hijos de la raíz en orden. Nodos Rust que son símbolos y su `kind` de salida:
     `function_item` y `function_signature_item` → `fn`; `struct_item` y `union_item` → `struct`;
     `enum_item` → `enum`; `trait_item` → `trait`; `type_item` → `type`; `mod_item` → `mod`;
     `impl_item` → `impl`; `macro_definition` → `macro`; `const_item` y `static_item` → `const`.
     Python: `function_definition` → `fn`; `class_definition` → `class`; un `decorated_definition` se
     sustituye por su hijo del campo `definition`.
   - Nombre: el texto del campo `name`. Para `impl_item`: `{trait} for {type}` si tiene campo `trait`, y
     si no `{type}`, con los espacios en blanco colapsados.
   - `start_line = node.start_position().row + 1`, `end_line = node.end_position().row + 1`.
   - Entra SOLO en el cuerpo (campo `body`) de `impl_item`, `trait_item`, `mod_item` y
     `class_definition`, con profundidad + 1. Un `fn` con profundidad > 0 sale con kind `method`.
   - `qualified`: la misma regla que en `symbols.rs` (dueño = tipo del impl, o nombre del contenedor).
3. `symbols.rs`, primera línea de `symbol_ranges`:
   `if let Some(v) = crate::symbols_ts::symbol_ranges_ts(text, lang) { return v; }`.
   Los tests que ya hay en `symbols.rs` deben seguir pasando sin cambiarlos.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tools/src/symbols_ts.rs
use crate::symbols::SymbolRange;

/// Rangos exactos con tree-sitter; `None` si el lenguaje no está soportado o el texto no se puede analizar.
pub fn symbol_ranges_ts(text: &str, lang: &str) -> Option<Vec<SymbolRange>>;
```

## Ejemplo (entrada y resultado esperado)

```
// API de tree-sitter que hace falta:
let mut parser = tree_sitter::Parser::new();
parser.set_language(&tree_sitter_rust::LANGUAGE.into()).ok()?;      // o tree_sitter_python::LANGUAGE
let tree = parser.parse(text, None)?;
let root = tree.root_node();
let mut cursor = root.walk();
for child in root.named_children(&mut cursor) {
    child.kind();                                   // "function_item", "impl_item"…
    child.child_by_field_name("name");              // Option<Node>
    child.child_by_field_name("body");              // Option<Node>: sus hijos son los miembros
    child.utf8_text(text.as_bytes()).ok();          // texto del nodo
    child.start_position().row;                     // fila desde 0
}

// Caso que solo acierta tree-sitter (la línea 3 es una llave sin sangría dentro de una cadena):
"fn a() {\n    let s = r#\"\n}\nfn falso() {}\n\"#;\n}\nfn b() {}\n"
 -> ("a", "fn", 1, 6) · ("b", "fn", 7, 7)        (no existe ningún símbolo `falso`)
```

## Tests (con estos nombres)

- `ts_rust_cadena_con_llave_sin_sangria`: el caso del ejemplo da solo `a` (1-6) y `b` (7-7)
- `ts_rust_impl_y_metodos`: `impl fmt::Display for Punto { fn fmt… }` da el impl con nombre `fmt::Display for Punto` y el método Punto::fmt con kind method
- `ts_python_clase_decorada`: una clase con un método decorado con @staticmethod da A y A::f, y el rango de f empieza en la línea del `def`
- `ts_lenguaje_no_soportado_es_none`: lang js y lang vacío devuelven None
- `ts_texto_con_errores_de_sintaxis_es_none`: `fn a( {` devuelve None y symbol_ranges sigue devolviendo lo del método por sangría
