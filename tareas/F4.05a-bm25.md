## Objetivo

Lo usan la búsqueda de tools (F4.10), la búsqueda en el código (F4.05) y la memoria episódica (F4.09).
1. Crea `bm25.rs` con `tokenize` y `Bm25` (firmas abajo). En `lib.rs` añade `pub mod bm25;` (después
   de `pub mod bash;`).
2. `tokenize(text)`:
   a) Parte el texto en trozos por cualquier carácter que no sea alfanumérico (`char::is_alphanumeric`):
      espacios, `_`, `-`, `.`, `:`, paréntesis…
   b) Cada trozo se parte en palabras por los cambios de caja: hay corte ANTES de una mayúscula si el
      carácter anterior es minúscula o cifra, o si el anterior es mayúscula y el siguiente es minúscula
      (`HTTPServer` → `HTTP`, `Server`).
   c) Emite las palabras en minúsculas y, si el trozo dio más de una palabra, también el trozo entero en
      minúsculas (después de sus palabras). Se descartan los tokens de menos de 2 caracteres.
3. `Bm25::new(docs)`: tokeniza cada documento y guarda, por documento, la frecuencia de cada término y
   su longitud en tokens; además cuántos documentos contienen cada término y la longitud media.
4. `search(query, k)`: términos = tokens únicos de la consulta. Puntuación de un documento = suma, por
   término, de `idf * tf * (K1 + 1) / (tf + K1 * (1 - B + B * dl / avgdl))`, con
   `idf = ln(1 + (N - n + 0.5) / (n + 0.5))` (`N` documentos, `n` los que contienen el término, `tf` su
   frecuencia en el documento, `dl` la longitud del documento). Devuelve los de puntuación > 0, de mayor
   a menor (a igualdad, índice menor primero), como mucho `k`. Con `avgdl == 0` o sin documentos, vacío.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tools/src/bm25.rs
/// Parámetros estándar de BM25.
pub const K1: f32 = 1.2;
pub const B: f32 = 0.75;

/// Tokens de un texto con código: separa snake_case y camelCase, en minúsculas.
pub fn tokenize(text: &str) -> Vec<String>;

/// Índice BM25 en memoria sobre una lista de documentos.
#[derive(Debug, Clone, Default)]
pub struct Bm25 { /* frecuencias por documento, longitudes, documentos por término, longitud media */ }

impl Bm25 {
    /// Indexa los documentos (el índice de cada uno es su posición en `docs`).
    pub fn new(docs: &[String]) -> Self;
    /// Número de documentos.
    pub fn len(&self) -> usize;
    /// Si no hay documentos.
    pub fn is_empty(&self) -> bool;
    /// Los `k` documentos más relevantes: (índice, puntuación), de mayor a menor.
    pub fn search(&self, query: &str, k: usize) -> Vec<(usize, f32)>;
}
```

## Ejemplo (entrada y resultado esperado)

```
tokenize("parseBlame_v2 fooBar.rs")  -> ["parse", "blame", "parseblame", "v2", "foo", "bar", "foobar", "rs"]
tokenize("HTTPServer x")             -> ["http", "server", "httpserver"]
let i = Bm25::new(&["alfa beta".into(), "beta gamma gamma delta".into()]);
i.search("gamma", 5)  -> [(1, p)] con p > 0
i.search("beta", 5)   -> [(0, p0), (1, p1)] con p0 > p1   (el documento corto puntúa más)
i.search("zeta", 5)   -> []
```

## Tests (con estos nombres)

- `tokeniza_snake_y_camel`: el primer caso del ejemplo, en ese orden exacto
- `tokeniza_siglas_y_descarta_cortos`: el segundo caso del ejemplo (la `x` suelta se descarta)
- `bm25_encuentra_por_contenido`: la consulta gamma devuelve solo el documento 1
- `bm25_documento_corto_puntua_mas`: la consulta beta devuelve [0, 1] en ese orden
- `bm25_sin_coincidencias_o_vacio`: la consulta zeta y un índice sin documentos devuelven vacío
- `bm25_respeta_k`: con tres documentos que contienen el término y k = 2 devuelve dos
