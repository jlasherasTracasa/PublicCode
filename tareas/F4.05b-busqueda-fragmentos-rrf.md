## Objetivo

1. Crea `search.rs` con `Chunk`, `chunks` y `rrf` (firmas abajo). En `lib.rs` añade `pub mod search;`.
2. `chunks(path, text)`:
   a) `lang = pcode_tools::outline::language_of(path)`;
      `ranges = pcode_tools::symbols::symbol_ranges(text, lang)`.
   b) Descarta los contenedores (`kind` igual a `impl`, `mod`, `trait` o `class`): sus miembros ya son
      fragmentos por sí mismos.
   c) Por cada rango que queda, un `Chunk` con `symbol = Some(qualified)`, sus líneas inicial y final y
      `text` = esas líneas del archivo unidas con `\n`.
   d) Si no queda ninguno (lenguaje sin símbolos, Markdown, archivo de configuración…): ventanas de
      `WINDOW_LINES` líneas (1-60, 61-120…), con `symbol = None`. Un texto vacío da vector vacío.
3. `rrf(lists, k)`: fusión por rango recíproco. La puntuación de un id es la suma, por cada lista en la
   que aparece, de `1.0 / (k + posición)` con la posición desde 1 (si un id se repite en una lista,
   cuenta solo su primera aparición). Devuelve (id, puntuación) de mayor a menor; a igualdad, por id
   en orden alfabético.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/search.rs
/// Líneas de cada ventana cuando un archivo no tiene símbolos.
pub const WINDOW_LINES: usize = 60;

/// Un fragmento indexable de un archivo.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Chunk {
    pub path: String,
    /// Nombre cualificado del símbolo, o `None` si es una ventana de líneas.
    pub symbol: Option<String>,
    pub start_line: u32,
    pub end_line: u32,
    pub text: String,
}

/// Fragmentos de un archivo: un símbolo por fragmento, o ventanas de líneas.
pub fn chunks(path: &str, text: &str) -> Vec<Chunk>;

/// Fusión por rango recíproco de varias listas ordenadas de ids.
pub fn rrf(lists: &[Vec<String>], k: f32) -> Vec<(String, f32)>;
```

## Ejemplo (entrada y resultado esperado)

```
chunks("a.rs", "pub struct Caja;\n\nimpl Caja {\n    pub fn abre(&self) {}\n}\n")
 -> [Chunk { symbol: Some("Caja"), start_line: 1, end_line: 1, text: "pub struct Caja;" },
     Chunk { symbol: Some("Caja::abre"), start_line: 4, end_line: 4, text: "    pub fn abre(&self) {}" }]   (path "a.rs" en los dos)
chunks("notas.txt", <130 líneas>) -> tres fragmentos sin símbolo: 1-60, 61-120, 121-130
rrf(&[vec!["a".into(), "b".into()], vec!["b".into(), "c".into()]], 60.0)
 -> [("b", 1.0/62.0 + 1.0/61.0), ("a", 1.0/61.0), ("c", 1.0/62.0)]
```
