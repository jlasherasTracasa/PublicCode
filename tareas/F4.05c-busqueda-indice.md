## Objetivo

1. Crea `index.rs` con `Hit` y `RepoIndex` (firmas abajo). En `lib.rs` añade `pub mod index;` y
   `pub use index::{Hit, RepoIndex};`.
2. Estado de `RepoIndex`: `files: BTreeMap<String, (String, Vec<Chunk>)>` (ruta → hash y fragmentos),
   `flat: Vec<Chunk>` (todos los fragmentos, en orden de ruta) y `bm25: pcode_tools::bm25::Bm25`.
3. `refresh_files(root, files)`: para cada ruta lee `root.join(ruta)` con `std::fs::read`; se salta los
   que no se pueden leer, los de más de 512 KB y los que no son UTF-8. Calcula `sha256_hex` de los
   bytes: si coincide con el guardado, conserva sus fragmentos; si no, recalcula `chunks(ruta, texto)`.
   Quita del índice las rutas que ya no están en `files`. Después reconstruye `flat` y
   `bm25 = Bm25::new(…)` con un documento por fragmento: `"{path} {símbolo o vacío} {text}"`.
   Devuelve cuántos archivos se recalcularon o se quitaron.
4. `build(root)` = índice vacío + `refresh(root)`; `refresh(root)` =
   `refresh_files(root, &pcode_tools::outline::project_files(root))`.
5. `search(query, k)`:
   a) Lista A: `bm25.search(query, 50)`, como ids de texto (`índice.to_string()`).
   b) Lista B (por nombre): fragmentos con símbolo cuyo último segmento (tras el último `::`) en
      minúsculas es IGUAL a la consulta en minúsculas y sin espacios en los extremos; después, los que
      contienen alguna palabra de la consulta (separada por espacios, en minúsculas, de 3 caracteres o
      más); sin repetir, en orden de índice dentro de cada grupo, como mucho 50.
   c) `rrf(&[A, B], 60.0)`, los `k` primeros, convertidos en `Hit` con su puntuación.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/index.rs
/// Un resultado de la búsqueda en el código.
#[derive(Debug, Clone, PartialEq)]
pub struct Hit { pub path: String, pub symbol: Option<String>, pub start_line: u32, pub score: f32 }

/// Índice en memoria de los fragmentos del repositorio.
#[derive(Default)]
pub struct RepoIndex { /* files, flat, bm25 */ }

impl RepoIndex {
    /// Indexa los archivos del proyecto.
    pub fn build(root: &std::path::Path) -> std::io::Result<RepoIndex>;
    /// Reindexa solo lo que cambió; devuelve cuántos archivos se recalcularon o quitaron.
    pub fn refresh(&mut self, root: &std::path::Path) -> std::io::Result<usize>;
    /// Igual que `refresh`, con la lista de archivos dada (rutas relativas a `root`).
    pub fn refresh_files(&mut self, root: &std::path::Path, files: &[String]) -> std::io::Result<usize>;
    /// Número de fragmentos indexados.
    pub fn len(&self) -> usize;
    /// Si no hay fragmentos.
    pub fn is_empty(&self) -> bool;
    /// Los `k` fragmentos más relevantes.
    pub fn search(&self, query: &str, k: usize) -> Vec<Hit>;
}
```

## Ejemplo (entrada y resultado esperado)

```
tempdir con  a.rs: "pub fn parse_blame() {}\n"
             b.rs: "pub fn otra() {\n    // parse_blame parse_blame parse_blame\n    parse_blame();\n}\n"
let mut i = RepoIndex::default();
i.refresh_files(root, &["a.rs".into(), "b.rs".into()])  -> Ok(2)
i.refresh_files(root, &["a.rs".into(), "b.rs".into()])  -> Ok(0)      (nada cambió)
i.search("parse_blame", 5)[0]  -> Hit { path: "a.rs", symbol: Some("parse_blame"), start_line: 1, .. }
   (a.rs está en las dos listas; b.rs solo en la de BM25)
```

## Tests (con estos nombres)

- `bm25_encuentra_por_contenido`: buscar una palabra que solo está en el cuerpo de `otra` devuelve b.rs
- `simbolo_por_nombre_gana`: el caso del ejemplo; el primer resultado es a.rs con el símbolo parse_blame
- `refresh_solo_cambiados`: el segundo refresh devuelve 0; tras reescribir b.rs devuelve 1; tras quitar b.rs de la lista devuelve 1 y ya no sale en las búsquedas
- `salta_binarios_y_enormes`: un archivo con bytes que no son UTF-8 no rompe el refresh ni entra en el índice
- `indice_vacio_no_encuentra_nada`: RepoIndex::default().search devuelve vacío

## No hagas

- No guardes el índice en disco: es en memoria y se reconstruye por hash
- No uses `project_files` en los tests: usa `refresh_files` con un tempdir
