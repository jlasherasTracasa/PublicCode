# F4.05d-comprimir-codigo — `compress_code`: conservar firmas y cuerpos relevantes, omitir el resto (lógica pura)

## Objetivo

1. Crea `compress_code.rs` con `compress_code` (firma abajo). En `lib.rs` añade `pub mod compress_code;`
   y `pub use compress_code::compress_code;`.
2. Si el fragmento ya cabe (`fragment.chars().count().div_ceil(4) <= budget_tokens`), devuélvelo igual.
3. Si no: `ranges = pcode_tools::symbols::symbol_ranges(fragment, lang)`. Candidatos a comprimir: los
   rangos de más de 2 líneas cuyo `kind` no es `impl`, `mod`, `trait` ni `class`.
4. Un candidato es RELEVANTE si algún token de `pcode_tools::bm25::tokenize(query)` está en
   `tokenize(name)`. Los relevantes se dejan enteros.
5. De cada candidato no relevante se conserva la firma y se omite el cuerpo:
   - La firma son las líneas desde `start_line` hasta la primera (como mucho 10 líneas después) que,
     sin espacios finales, acaba en `{` (o en `:` si `lang == "python"`), incluida. Si no hay ninguna,
     la firma es solo `start_line`.
   - El cuerpo (de la línea siguiente a la firma hasta `end_line`) se sustituye por UNA línea:
     `{sangría de start_line}    // … {n} líneas omitidas` (en Python: `{sangría}    ...  # {n} líneas omitidas`),
     donde `n` cuenta las líneas quitadas. Si la última línea del rango, sin sangría, empieza por `}`,
     se conserva (y no cuenta en `n`). Si no hay ninguna línea que quitar, no se toca.
6. Todo lo que está fuera de los candidatos (comentarios `///`, `use`, atributos, contenedores) se
   conserva tal cual. Conserva el `\n` final si lo había. No se recorta más aunque siga sin caber.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/compress_code.rs
/// Comprime un fragmento de código para el contexto: deja las firmas y los cuerpos de los símbolos
/// relacionados con `query`, y sustituye los demás cuerpos por una línea.
pub fn compress_code(fragment: &str, lang: &str, query: &str, budget_tokens: usize) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
fragment (rust):
/// Suma.
pub fn suma(a: u32, b: u32) -> u32 {
    let c = a + b;
    c
}

pub fn resta(a: u32, b: u32) -> u32 {
    let c = a - b;
    c
}

compress_code(fragment, "rust", "resta", 10) ->
/// Suma.
pub fn suma(a: u32, b: u32) -> u32 {
    // … 2 líneas omitidas
}

pub fn resta(a: u32, b: u32) -> u32 {
    let c = a - b;
    c
}
```

## Tests (con estos nombres)

- `compress_code_conserva_firmas_y_cuerpo_relevante`: el caso del ejemplo, carácter a carácter
- `si_cabe_no_cambia`: con un presupuesto de 1000 tokens devuelve el fragmento igual
- `firma_en_varias_lineas_se_conserva`: una función con los parámetros en tres líneas conserva hasta la línea que acaba en `{`
- `python_usa_puntos_suspensivos`: un `def` de cuatro líneas no relevante queda en su cabecera y `    ...  # 3 líneas omitidas`
- `funciones_de_una_o_dos_lineas_no_se_tocan`: `fn a() {}` y una función de dos líneas quedan igual aunque no quepan
- `lenguaje_sin_simbolos_no_cambia`: con lang vacío devuelve el fragmento igual
