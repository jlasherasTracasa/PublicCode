## Objetivo

Compartir todo entre agentes en paralelo sale caro («The Collaboration Tax»): el tablero está acotado
en entradas y en caracteres, y cada ronda se inyecta como UN mensaje corto.
1. Crea `board.rs` con `Board` (firmas abajo) sobre un `BTreeMap<String, String>`. En `lib.rs` añade
   `pub mod board;` (después de `pub mod ask;`) y `pub use board::Board;`.
2. `set(key, value)`: la clave y el valor se guardan en una línea (`split_whitespace` y unir con un
   espacio). Con clave vacía devuelve `false`. Calcula cómo quedaría el tablero: si es una clave nueva y
   ya hay `max_entries`, o si `render()` del resultado pasaría de `max_chars` caracteres, NO cambia nada
   y devuelve `false`. Si cabe, guarda (sustituyendo el valor anterior de esa clave) y devuelve `true`.
3. `remove(key)`: quita la clave; `true` si existía.
4. `render()`: cadena vacía si no hay entradas; si no, `# Tablero compartido\n` y una línea
   `- {clave}: {valor}\n` por entrada, en orden alfabético de clave.
5. `message()`: `None` si está vacío; si no, `Some(Message::user(self.render()))`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/board.rs
/// Tablero compartido y acotado entre subagentes.
#[derive(Debug, Clone)]
pub struct Board { max_entries: usize, max_chars: usize, entries: std::collections::BTreeMap<String, String> }

impl Board {
    /// Tablero vacío con sus límites.
    pub fn new(max_entries: usize, max_chars: usize) -> Self;
    /// Guarda una entrada si cabe; `false` si no cabe (y no cambia nada).
    pub fn set(&mut self, key: &str, value: &str) -> bool;
    /// Quita una entrada.
    pub fn remove(&mut self, key: &str) -> bool;
    /// Número de entradas.
    pub fn len(&self) -> usize;
    /// Si está vacío.
    pub fn is_empty(&self) -> bool;
    /// Texto compacto del tablero.
    pub fn render(&self) -> String;
    /// El tablero como mensaje para el inicio de una ronda.
    pub fn message(&self) -> Option<pcode_models::Message>;
}
```

## Ejemplo (entrada y resultado esperado)

```
let mut b = Board::new(2, 80);
b.set("api", "usar  parse_blame\n de blame.rs") == true
b.set("ci", "verde") == true
b.render() == "# Tablero compartido\n- api: usar parse_blame de blame.rs\n- ci: verde\n"
b.set("otra", "x") == false          // ya hay 2 entradas
b.set("ci", "rojo") == true          // sustituir no cuenta como entrada nueva
b.set("ci", &"x".repeat(100)) == false   // pasaría de 80 caracteres; `ci` sigue valiendo "rojo"
```

## Tests (con estos nombres)

- `tablero_respeta_limites`: la secuencia del ejemplo, paso a paso
- `tablero_render_ordenado_y_en_una_linea`: el render del ejemplo, carácter a carácter
- `tablero_vacio_sin_mensaje`: un tablero nuevo da render vacío y message None
- `tablero_quita_entradas`: remove devuelve true la primera vez y false la segunda, y libera sitio para otra clave
- `tablero_rechaza_clave_vacia`: set con clave de solo espacios devuelve false
