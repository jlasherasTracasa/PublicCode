## Objetivo

1. Crea `router.rs` con las firmas de abajo. Lógica pura.
2. `feature(task)`: `<modo>:<directorio>`; modo = `kernel`, `aislado` o `coordinador`; directorio = los dos
   primeros tramos de la primera ruta de `allowed_paths(task)` (`crates/pcode-flow/src/a.rs` →
   `crates/pcode-flow`; una ruta con un solo tramo → ese tramo), o `-` si no hay rutas.
3. `RouterStats` guarda por `(backend, rasgo)`: aciertos a la primera, muestras y tokens (entrada + salida).
   `add` suma una fila. `samples` devuelve las muestras. `success_rate` usa suavizado de Laplace:
   `(aciertos + 1) / (muestras + 2)` (sin muestras: 0.5). `mean_tokens`: tokens / muestras (0.0 sin muestras).
4. `stats_from_runs(runs, tasks)`: por cada `(backend, filas)` y cada fila cuyo `id` sea el de una tarea de
   `tasks`, `add(backend, &feature(tarea), fila)`. Las filas de tareas desconocidas se ignoran.
5. `choose`: candidatos con al menos `MIN_SAMPLES` muestras para ese rasgo; si no hay ninguno → `default`.
   Puntuación = `success_rate − lambda × (mean_tokens / mayor mean_tokens entre esos candidatos)` (si el mayor
   es 0, el término de coste es 0). Gana la mayor; a igualdad, el que va antes en `candidates`.
6. `needs_critic`: true si hay al menos `MIN_SAMPLES` muestras y `success_rate < 0.5`.
7. `allow_subagents`: true solo si la tarea toca más de 2 archivos (`allowed_paths(task).len() > 2`).
8. `lib.rs`: añade `pub mod router;`.

```rust
// crates/pcode-flow/src/router.rs
use crate::bench::BenchRow;
use crate::task::TaskDef;

/// Muestras mínimas para fiarse del histórico.
pub const MIN_SAMPLES: u32 = 3;

/// Rasgo de una tarea para el router.
pub fn feature(task: &TaskDef) -> String;

/// Histórico por (backend, rasgo).
#[derive(Debug, Clone, Default)]
pub struct RouterStats { /* BTreeMap<(String, String), (u32, u32, u64)> */ }

impl RouterStats {
    pub fn add(&mut self, backend: &str, feature: &str, row: &BenchRow);
    pub fn samples(&self, backend: &str, feature: &str) -> u32;
    pub fn success_rate(&self, backend: &str, feature: &str) -> f64;
    pub fn mean_tokens(&self, backend: &str, feature: &str) -> f64;
}

pub fn stats_from_runs(runs: &[(String, Vec<BenchRow>)], tasks: &[TaskDef]) -> RouterStats;
pub fn choose(stats: &RouterStats, feature: &str, candidates: &[String], lambda: f64, default: &str) -> String;
pub fn needs_critic(stats: &RouterStats, feature: &str, backend: &str) -> bool;
pub fn allow_subagents(task: &TaskDef) -> bool;
```

## Ejemplo (entrada y resultado esperado)

```
rasgo "aislado:crates/pcode-flow"; glm: 4 muestras, 1 acierto, 1000 tokens de media; claude: 4 muestras, 4 aciertos, 4000 de media
success_rate(glm) = 2/6 = 0.333…   success_rate(claude) = 5/6 = 0.833…
choose(stats, rasgo, ["glm","claude"], 0.0, "glm") → "claude"
choose(stats, rasgo, ["glm","claude"], 1.0, "glm") → "glm"      (0.333 − 0.25 = 0.083 frente a 0.833 − 1.0 = −0.167)
choose(stats, "otro:rasgo", ["glm","claude"], 0.0, "glm") → "glm"   (sin muestras)
needs_critic(stats, rasgo, "glm") → true      needs_critic(stats, rasgo, "claude") → false
```

## Tests (con estos nombres)

- `rasgo_de_la_tarea`: una tarea aislada que toca crates/pcode-flow/src/a.rs da `aislado:crates/pcode-flow` y una sin rutas `aislado:-`
