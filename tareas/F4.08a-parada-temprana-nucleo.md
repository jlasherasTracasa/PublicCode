## Objetivo

1. Crea `early_stop.rs` con las firmas de abajo. Lógica pura.
2. `Experience::from_samples`: mediana de los pasos que necesitaron tareas parecidas ya aceptadas (ordena; con
   número par, la media entera de las dos centrales). Sin muestras → `None`.
3. `should_stop_early`: true solo si hay experiencia, `steps > 2 * median_steps` y `steps_since_write >= 5`
   (lleva el doble de lo normal y los últimos 5 pasos no ha escrito nada). Sin experiencia, siempre false.
4. `uncertainty_gate`: true si `had_repaired_call` es true o si el texto del asistente, en minúsculas,
   contiene alguno de `DOUBT_MARKERS`.
5. `lib.rs`: añade `pub mod early_stop;` y `pub use early_stop::Experience;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/early_stop.rs
/// Lo que se sabe de tareas parecidas.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Experience {
    /// Mediana de pasos hasta aceptar.
    pub median_steps: u32,
}

/// Expresiones de duda que activan la puerta (en minúsculas).
pub const DOUBT_MARKERS: [&str; 6] = ["no estoy seguro", "no estoy segura", "quizá", "quizás", "probablemente", "not sure"];

impl Experience {
    /// Experiencia a partir de los pasos de tareas parecidas ya aceptadas.
    pub fn from_samples(steps: &[u32]) -> Option<Experience>;
}

/// ¿Conviene parar ya? (lleva el doble de la mediana y no escribe)
pub fn should_stop_early(steps: u32, steps_since_write: u32, exp: Option<&Experience>) -> bool;
/// ¿Hay que pedir confirmación antes de una acción irreversible?
pub fn uncertainty_gate(assistant_text: &str, had_repaired_call: bool) -> bool;
```

## Ejemplo (entrada y resultado esperado)

```
Experience::from_samples(&[10, 4, 6]) → Some(Experience { median_steps: 6 })     from_samples(&[4, 8]) → Some(6)     from_samples(&[]) → None
should_stop_early(13, 5, Some(&Experience { median_steps: 6 })) → true
should_stop_early(13, 2, Some(..6)) → false      should_stop_early(12, 9, Some(..6)) → false      should_stop_early(99, 99, None) → false
uncertainty_gate("Quizá convenga borrar la carpeta", false) → true      uncertainty_gate("Borro la carpeta", false) → false      uncertainty_gate("", true) → true
```

## Tests (con estos nombres)

- `mediana_de_las_muestras`: los tres casos de from_samples del ejemplo
- `para_si_dobla_mediana_sin_escribir`: 13 pasos, 5 sin escribir y mediana 6 da true
- `no_para_si_escribe`: con 2 pasos desde la última escritura da false
- `no_para_en_el_doble_exacto`: 12 pasos con mediana 6 da false
- `sin_experiencia_no_para`: sin Experience da false con cualquier número
- `puerta_por_duda`: un texto con «Quizá» (con mayúscula) da true y uno sin marcadores false
- `puerta_por_reparacion`: had_repaired_call a true da true aunque el texto esté vacío
