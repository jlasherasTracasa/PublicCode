# F4.09b-memoria-episodica-recall — `EpisodicMemory`: cargar los informes y recordar solo episodios verificados (BM25)

## Objetivo

La experiencia de una tarea que no pasó su aceptación no se usa como ejemplo a seguir (seguir malas
experiencias empeora al agente): los episodios no verificados solo salen en `recall_failures`, para
avisar de lo que ya se intentó.
1. En `episodic.rs` añade `EpisodicMemory` (firmas abajo). En `lib.rs` añade
   `pub use episodic::{Episode, EpisodicMemory};`. No cambies `parse_report` ni `render`.
2. `from_episodes(eps)`: guarda los episodios y construye DOS índices `pcode_tools::bm25::Bm25`: uno con
   los verificados y otro con los no verificados. El documento de un episodio es
   `"{task} {summary} {files unidos con espacio} {lessons unidas con espacio}"`. Guarda también, para
   cada índice, la posición de cada documento en la lista de episodios.
3. `load_reports(dir, verified)`: lee los archivos `*.md` de `dir` (sin subcarpetas), en orden
   alfabético de nombre; para cada uno, `parse_report(nombre sin extensión, texto, verified.contains(&task))`,
   donde `task` es lo que va antes del primer `-` del nombre. Los archivos que no se pueden leer como
   texto se saltan. Si `dir` no existe, devuelve el error de E/S.
4. `recall(task_text, k)`: los `k` episodios VERIFICADOS más relevantes según BM25, de mayor a menor.
   `recall_failures(task_text, k)`: lo mismo sobre los NO verificados.
5. `len()` e `is_empty()` cuentan todos los episodios.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-memory/src/episodic.rs (añadir)
/// Episodios de tareas anteriores con búsqueda por texto.
pub struct EpisodicMemory { /* episodios, índice de verificados, índice de fallidos */ }

impl EpisodicMemory {
    /// Memoria a partir de episodios ya construidos.
    pub fn from_episodes(eps: Vec<Episode>) -> Self;
    /// Carga los informes de una carpeta; `verified` son los ids de tarea que pasaron su aceptación.
    pub fn load_reports(dir: &std::path::Path, verified: &std::collections::HashSet<String>) -> std::io::Result<Self>;
    /// Número de episodios.
    pub fn len(&self) -> usize;
    /// Si no hay episodios.
    pub fn is_empty(&self) -> bool;
    /// Episodios verificados más parecidos a la tarea.
    pub fn recall(&self, task_text: &str, k: usize) -> Vec<&Episode>;
    /// Episodios NO verificados más parecidos (para avisar de lo ya intentado).
    pub fn recall_failures(&self, task_text: &str, k: usize) -> Vec<&Episode>;
}
```

## Ejemplo (entrada y resultado esperado)

```
tempdir con tres informes: F9.01-blame.md (habla de "blame"), F9.02-diff.md (habla de "diff"),
F9.03-blame-ui.md (habla de "blame" y no pasó la aceptación).
let ok: HashSet<String> = ["F9.01".to_string(), "F9.02".to_string()].into();
let m = EpisodicMemory::load_reports(dir, &ok)?;      // m.len() == 3
m.recall("parsear git blame", 5)          -> [episodio F9.01]            (F9.03 no sale: no está verificado)
m.recall_failures("parsear git blame", 5) -> [episodio F9.03]
m.recall("algo sin relación zzz", 5)      -> []
```

## Tests (con estos nombres)

- `memoria_recall_solo_verificados`: el caso del ejemplo; recall de blame devuelve solo F9.01
- `memoria_fallidos_aparte`: recall_failures de blame devuelve solo F9.03
- `memoria_carga_informes_reales`: load_reports sobre un tempdir con los tres informes da len 3 y los episodios en orden alfabético de archivo
- `memoria_carpeta_inexistente_es_error`: load_reports sobre una ruta que no existe devuelve Err
- `memoria_sin_coincidencias_es_vacio`: una consulta sin palabras en común devuelve vector vacío
