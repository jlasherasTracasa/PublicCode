## Objetivo

1. `agent.rs`, struct `Agent`: campo nuevo `catalog: Option<pcode_tools::catalog::ToolCatalog>` (`None`
   en `Agent::new`) y el método `with_tool_search` (firma abajo), junto a `with_context_tool`.
2. `run_messages`, justo después de `let mut specs = self.tools.specs_filtered(…);` y ANTES de añadir
   `preguntar`, `recordar` y `contexto`:
   `if let Some(c) = &self.catalog { specs = c.visible(pcode_tools::catalog::dedupe(specs)); }`
3. `run_messages`, dentro de `for call in calls`, junto a las otras tools interceptadas (después del
   bloque de `CONTEXT_TOOL`): si `call.name == SEARCH_TOOL` y hay catálogo:
   a) vuelve a calcular la lista completa:
      `let all = pcode_tools::catalog::dedupe(self.tools.specs_filtered(|n, e| self.policy.tool_visible(n, e) && !(ro && writes(e))));`
      (`ro` es `self.read_only`; calcula `all` antes de pedir `self.catalog.as_mut()`);
   b) `let q = call.arguments.get("consulta").and_then(|v| v.as_str()).unwrap_or("");`
   c) `let content = catalog.search(&all, q, 5);`
   d) `self.audit(&call, "allow")`, emite `AgentEvent::ToolResult { name, is_error: false, content }`,
      añade `Message::tool_result(call.id.clone(), content)` (sin etiqueta `[rN]`) y `continue`.
4. Una tool sin anunciar se puede llamar igual (el registro la sigue teniendo): no cambies `run_call`.
5. `chat.rs`, función `prepare`: añade `.with_tool_search(pcode_tools::catalog::DEFAULT_MAX_VISIBLE)`
   después de `.with_context_tool()`.

        pcode_models::ToolSpec { name: "clima_hoy".into(), description: "[MCP clima] Tiempo de hoy en una ciudad".into(),
                                 parameters: json!({"type": "object"}) }
    }
    fn effects(&self) -> &'static [Effect] { &[Effect::Read] }
    async fn call(&self, _: serde_json::Value, _: &ToolContext) -> ToolOutput { ToolOutput::ok("sol") }
}
let script = vec![tool("buscar_tools", json!({"consulta": "tiempo ciudad"})), text("fin")];
let (mut a, p) = agent(&d, script, Capabilities::default(), None);
a.tools.register(Arc::new(Falsa)).unwrap();
let mut a = a.with_tool_search(3);
a.run("qué tiempo hace").await;
// p.requests()[0].tools: contiene "buscar_tools" y "leer", NO contiene "clima_hoy"
