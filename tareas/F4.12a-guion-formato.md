## Objetivo

1. Crea `script.rs` con lo de las firmas. En `lib.rs` añade `pub mod script;` (después de
   `pub mod memory;`). En esta tarea no se ejecuta nada.
2. `script_spec()`: nombre `guion`; descripción EXACTA: «Ejecuta varias órdenes de shell seguidas en
   una sola llamada y devuelve el resultado de cada una. Úsala para secuencias fijas (formatear, lint,
   tests). Por defecto se para en la primera que falla.»; parámetros
   `{"type":"object","properties":{"pasos":{"type":"array","items":{"type":"string"}},"parar_en_error":{"type":"boolean"}},"required":["pasos"]}`.
3. `parse_steps(args)`: `pasos` tiene que ser una lista de textos; se quitan los espacios de los
   extremos y los vacíos. Errores (texto EXACTO): sin `pasos` o sin ningún paso válido →
   `falta `pasos` (lista de órdenes)`; más de `MAX_STEPS` → `demasiados pasos (máximo 20)`.
   `parar_en_error` vale `true` si falta.
4. `exit_code(output)`: si la primera línea es `exit=<entero>`, ese entero; si no, `-1`.
5. `render(results, total)`: por cada resultado, una cabecera y debajo su `output` (si no está vacío):
   - correcto (`code == 0` y sin `denied`): `[{i}/{total}] ✓ {command}`
   - fallido: `[{i}/{total}] ✗ {command} (código {code})`
   - denegado: `[{i}/{total}] ⛔ {command}: {motivo}`
   (`i` desde 1). Si `results.len() < total`, una línea `no ejecutados: {n} pasos`. Última línea
   siempre: `guion: {ok} de {total} pasos correctos`. Las partes se unen con `\n`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/script.rs
/// Nombre de la tool.
pub const SCRIPT_TOOL: &str = "guion";
/// Pasos máximos de un guion.
pub const MAX_STEPS: usize = 20;

/// Resultado de un paso del guion.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct StepResult { pub command: String, pub code: i32, pub output: String, pub denied: Option<String> }

/// Especificación de la tool `guion`.
pub fn script_spec() -> pcode_models::ToolSpec;
/// Pasos y `parar_en_error` de los argumentos de una llamada.
pub fn parse_steps(args: &serde_json::Value) -> Result<(Vec<String>, bool), String>;
/// Código de salida que informa la tool `bash` en su primera línea (`exit=N`), o -1.
pub fn exit_code(output: &str) -> i32;
/// Resumen del guion para el modelo.
pub fn render(results: &[StepResult], total: usize) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
parse_steps(&json!({"pasos": [" cargo fmt --all ", "", "cargo test"]})) -> Ok((vec!["cargo fmt --all", "cargo test"], true))
exit_code("exit=101\n--- stdout ---\n") -> 101;   exit_code("tiempo agotado tras 5 s") -> -1
render(&[StepResult { command: "cargo fmt --all".into(), code: 0, output: String::new(), denied: None },
         StepResult { command: "cargo test".into(), code: 101, output: "test a ... FAILED".into(), denied: None }], 3) ->
"[1/3] ✓ cargo fmt --all\n[2/3] ✗ cargo test (código 101)\ntest a ... FAILED\nno ejecutados: 1 pasos\nguion: 1 de 3 pasos correctos"
```
