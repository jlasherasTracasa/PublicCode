## Objetivo

1. En `script.rs` añade `run_script` (firma abajo). No cambies lo que ya hay. Hace falta
   `use pcode_tools::Tool;` para poder llamar a `Bash.call`.
2. Para cada paso, en orden:
   a) `policy.check_command(paso)`:
      - `Decision::Deny(why)`: añade `StepResult { command, code: -1, output: String::new(), denied: Some(why) }`
        y TERMINA el guion (una denegación siempre lo para, aunque `stop_on_error` sea `false`).
      - `Decision::Ask(why)`: igual, con `denied: Some(format!("requiere aprobación ({why}): ejecútala sola con `bash`"))`.
        Dentro de un guion no se piden aprobaciones.
      - `Decision::Allow`: sigue.
   b) `let out = pcode_tools::Bash.call(serde_json::json!({"command": paso}), ctx).await;`
   c) `code = exit_code(&out.content)`;
      `output = crate::compress::compress_tool_output(paso, &out.content)`.
   d) Añade el `StepResult` (con `denied: None`). Si `code != 0 && stop_on_error`, termina.
3. Devuelve los resultados de los pasos que se llegaron a tratar. El tiempo máximo de cada paso es el
   de `ctx.timeout` (lo aplica `Bash`): no hay esperas sin cota.

## Ejemplo (entrada y resultado esperado)

```
let ctx = ToolContext { root: d.path().to_path_buf(), timeout: std::time::Duration::from_secs(10) };
let libre = Policy::new(Capabilities::default());
run_script(&["echo uno".into(), "echo dos".into()], true, &libre, &ctx).await
  -> 2 resultados con code 0; el output del primero contiene "uno"
run_script(&["exit 3".into(), "echo no".into()], true, &libre, &ctx).await   -> 1 resultado, code 3
run_script(&["exit 3".into(), "echo si".into()], false, &libre, &ctx).await  -> 2 resultados, codes 3 y 0
let sin_push = Policy::new(Capabilities { deny_commands: vec!["git push*".into()], ..Default::default() });
run_script(&["echo a".into(), "git push origin x".into(), "echo b".into()], false, &sin_push, &ctx).await
  -> 2 resultados; el segundo tiene denied Some(..) y code -1; "echo b" no se ejecuta
```
