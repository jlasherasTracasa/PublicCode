## Objetivo

La intercepta el bucle (no está en el registro) porque cada paso tiene que pasar por la política.
1. `agent.rs`, struct `Agent`: campo nuevo `script: bool` (`false` en `Agent::new`) y el método
   `with_script_tool` (firma abajo), junto a `with_tool_search`.
2. `run_messages`, donde se construye `specs`, después del bloque que añade `context_spec()`: si
   `self.script && self.can_exec() && self.policy.tool_visible(SCRIPT_TOOL, &[Effect::Exec])`, haz
   `specs.push(crate::script::script_spec())`. (`can_exec` ya es `false` en modo plan.)
3. `run_messages`, dentro de `for call in calls`, junto a las otras tools interceptadas: si
   `call.name == SCRIPT_TOOL && self.script`:
   a) Si `self.read_only`: contenido `modo plan: solo lectura (vuelve al modo normal para aplicarlo)`.
   b) Si `self.policy.check_effects(&[Effect::Exec])` es `Decision::Deny(why)`: contenido
      `denegado por la política: {why}`.
   c) Si `parse_steps(&call.arguments)` da `Err(e)`: contenido `e`.
   d) Si no: `let results = crate::script::run_script(&steps, stop, &self.policy, &self.ctx).await;`,
      pon `ran_check = true`, y por cada resultado audita el paso como una llamada a `bash`:
      `self.audit(&ToolCall { id: call.id.clone(), name: "bash".into(), arguments: serde_json::json!({"command": r.command}) }, if r.denied.is_some() { "deny" } else { "allow" })`.
      Contenido: `crate::script::render(&results, steps.len())`.
   e) En todos los casos: emite `AgentEvent::ToolResult { name: call.name.clone(), is_error: false, content: content.clone() }`,
      añade el resultado etiquetado igual que los de las tools normales (si `self.context` existe,
      `l.tag(&content)`; si no, `content`) con `Message::tool_result(call.id.clone(), …)`, y `continue`.
4. `chat.rs`, función `prepare`: añade `.with_script_tool()` al final de la cadena de `.with_…()`.

## Ejemplo (entrada y resultado esperado)

```
// En `mod tests` de agent.rs (ayudantes `tool`, `text`, `agent`):
let script = vec![tool("guion", json!({"pasos": ["echo uno", "echo dos"]})), text("fin")];
let (a, p) = agent(&d, script, Capabilities::default(), None);
let mut a = a.with_script_tool();
```
