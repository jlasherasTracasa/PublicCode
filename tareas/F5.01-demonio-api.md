## Objetivo

1. Dependencia permitida: `axum`. Socket Unix `.pcode/pcoded.sock` por defecto; `--tcp 127.0.0.1:PORT`
   opcional con token en la cabecera.
2. Métodos JSON-RPC: `run.start`, `run.status`, `flow.status`, `flow.stop`, `sandbox.changes`,
   `approvals.list` y `approvals.decide{id, permitir}`.
3. `GET /eventos`: SSE con los eventos de sesión y de flujo.
4. `ApprovalBroker`: las decisiones `Ask` de la política se convierten en aprobaciones pendientes; el
   bucle espera (con tiempo máximo) la decisión en lugar de denegar.
5. `pcode daemon` lo arranca.

## Firmas (cópialas tal cual)

pub struct Approval { pub id: u64, pub session: i64, pub action: String, pub reason: String }
pub struct ApprovalBroker { /* pendientes + oneshot */ }

    pub fn pending(&self) -> Vec<Approval>;
    pub fn decide(&self, id: u64, allow: bool) -> bool;
}
