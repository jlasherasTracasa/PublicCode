## Objetivo

1. Crea `output.rs` con `RunFormat`, `event_json` y `summary_json` (firmas abajo). Sin E/S: solo construyen
   valores.
2. `RunFormat::parse`: `"texto"` → `Text`, `"json"` → `Json`, `"stream-json"` → `StreamJson`; cualquier otra
   cosa → `Err("formato desconocido «<s>»: usa texto, json o stream-json")`.
3. `event_json(e)`: misma forma que `agent_json` de `chat.rs`:
   `TextDelta` → `{"tipo":"delta","texto":…}`; `Text` → `{"tipo":"texto","texto":…}`; `Info` →
   `{"tipo":"info","texto":…}`; `ToolCall` → `{"tipo":"tool","nombre":…,"argumentos":…}`; `ToolResult` →
   `{"tipo":"resultado","nombre":…,"error":bool,"contenido":…}` con el contenido recortado a 8000 caracteres.
4. `summary_json(label, code, text, report, changes)` devuelve el objeto del ejemplo: `uso` con `entrada`,
   `salida` y `cache` (de `report.usage`), `pasos` = `report.steps`, `salida_acepta` =
   `report.acceptance_output` (o `null`) y `cambios` = una entrada por `FileChange` con las claves `ruta`,
   `mas`, `menos`, `creado`, `borrado`.
5. `main.rs`: añade `mod output;` junto a los demás `mod`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/output.rs
use pcode_core::{AgentEvent, FileChange, RunReport};

/// Formato de salida de `pcode run`.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RunFormat { Text, Json, StreamJson }

impl RunFormat {
    /// `texto`, `json` o `stream-json`.
    pub fn parse(s: &str) -> Result<RunFormat, String>;
}

/// Un evento del agente como objeto JSON (una línea de `stream-json`).
pub fn event_json(e: &AgentEvent) -> serde_json::Value;

/// Objeto final de `pcode run --formato json` (y última línea de `stream-json`).
pub fn summary_json(label: &str, code: i32, text: &str, report: &RunReport, changes: &[FileChange]) -> serde_json::Value;
```

## Ejemplo (entrada y resultado esperado)

```
summary_json("hecho", 0, "listo", &report, &[]) ==
  {"tipo":"fin","resultado":"hecho","codigo":0,"texto":"listo","pasos":2,
   "uso":{"entrada":3,"salida":2,"cache":0},"cambios":[],"salida_acepta":null}
event_json(&AgentEvent::ToolCall{name:"bash".into(), arguments: json!({"command":"ls"})}) ==
  {"tipo":"tool","nombre":"bash","argumentos":{"command":"ls"}}
```
