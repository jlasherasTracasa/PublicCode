## Objetivo

1. `run.rs`, `RunArgs`: añade el campo `format` (firma abajo).
2. `run.rs`, `run`: al principio, `let format = crate::output::RunFormat::parse(&a.format).map_err(anyhow::Error::msg)?;`.
   Si `a.backend` es `Some` y `format` no es `Text`, termina con
   `anyhow::bail!("--formato json y stream-json no están disponibles con --backend")`.
3. Con `StreamJson`: antes de `agent.run`, engancha un observador al agente con
   `agent = agent.with_observer(std::sync::Arc::new(|e| println!("{}", crate::output::event_json(e))));`
   (`agent` ya es `let mut`; `with_observer` consume y devuelve el agente).
4. Al final, sustituye la impresión actual por: con `Text`, lo de ahora (texto en stdout y la línea
   `resultado: …` en stderr); con `Json` o `StreamJson`, una sola línea en stdout con
   `crate::output::summary_json(label, code, &text, &report, &agent.turn_changes())` y nada en stderr.
5. `output.rs`: quita el `#![allow(dead_code)]` que dejó F5.06a.
6. Crea `tests/formato.rs` copiando los ayudantes `script`, `resp` y `pcode` de `tests/run.rs` y escribe los
   tests de la lista. Cada línea de stdout se parsea con `serde_json::from_str::<serde_json::Value>`.

## Ejemplo (entrada y resultado esperado)

```

$ pcode run "haz algo" --formato stream-json     (mock: llama a `escribir` y luego «listo»)

{"tipo":"texto","texto":"listo"}
{"tipo":"fin","resultado":"hecho","codigo":0,…}
```

## Tests (con estos nombres)

- `formato_json_tiene_campos`: con el mock «listo», stdout es una sola línea JSON con `tipo == "fin"`, `resultado == "hecho"`, `texto == "listo"` y las claves `pasos`, `uso`, `cambios` y `salida_acepta`
- `stream_json_una_linea_por_evento`: todas las líneas de stdout son JSON, hay una con `tipo == "tool"` y la última tiene `tipo == "fin"`
- `formato_texto_no_cambia`: sin `--formato`, stdout contiene `listo` y no empieza por `{`
- `formato_desconocido_falla`: `--formato xml` sale con código distinto de 0 y stderr contiene `formato desconocido`
- `json_con_acepta_que_falla_sale_con_2`: con `--acepta false` y `--formato json` el código es 2 y `resultado == "fallo"`
