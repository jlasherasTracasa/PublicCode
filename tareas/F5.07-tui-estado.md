## Objetivo

1. `App` guarda TODO el estado de la TUI; `update(Event) -> Vec<Command>` es puro (sin E/S) y
   `render(&App, &mut Frame)` dibuja la maqueta de docs/interfaces.md: árbol de sesiones a la
   izquierda, transcripción en el centro, panel lateral (cambios, aprobaciones, tareas o agentes) a
   la derecha, entrada y barra de estado abajo.
2. A menos de 100 columnas el panel lateral se pliega; a menos de 70, también el árbol (se abre con atajo).
3. `i18n`: `t(lang, clave) -> &'static str` con tablas `es` y `en`; ningún literal visible fuera de las tablas.
4. Tests con `TestBackend` a 80×24 y 120×40 comparando el buffer con un texto esperado.

## Firmas (cópialas tal cual)

```rust
pub enum Lang { Es, En }
pub enum Focus { Tree, Chat, Side, Input }
pub enum SidePanel { Changes, Approvals, Tasks, Agents }
pub enum Event { Key(crossterm::event::KeyEvent), Server(pcode_protocol::Event), Resize(u16, u16), Tick }
pub enum Command { Rpc { method: String, params: serde_json::Value }, Quit, OpenEditor(String) }
pub struct App {
    pub lang: Lang, pub focus: Focus, pub side: SidePanel,
    pub sessions: Vec<pcode_protocol::SessionInfo>, pub current: Option<i64>,
    pub transcripts: std::collections::BTreeMap<i64, Vec<pcode_protocol::TranscriptEntry>>,
    pub approvals: Vec<pcode_protocol::ApprovalDto>, pub changes: Vec<pcode_protocol::ChangeDto>,
    pub input: String, pub status: String,
}
impl App { pub fn new(lang: Lang) -> Self; pub fn update(&mut self, ev: Event) -> Vec<Command>; }
pub fn render(app: &App, f: &mut ratatui::Frame);
pub fn t(lang: Lang, key: &str) -> &'static str;
```
