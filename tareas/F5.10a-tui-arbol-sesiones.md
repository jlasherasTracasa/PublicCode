## Objetivo

La TUI ejecuta un solo agente en proceso. El «árbol» son las conversaciones guardadas del proyecto y, bajo la
actual, los subagentes: llamadas a tools cuyo nombre está en `SUBAGENT_TOOLS`.
1. Crea `tree.rs` con `SessionItem`, `SubagentItem`, `SUBAGENT_TOOLS`, `subagents_of` y `tree_rows` (firmas abajo).
2. `subagents_of(entries)`: una entrada por cada `Entry::Tool` cuyo `name` esté en `SUBAGENT_TOOLS`, en
   orden, con su `brief` y su `state`.
3. `tree_rows(sessions, subagents, width)`: una fila de texto por sesión, en el orden recibido:
   `" ● <título> (<n>)"` si `current`, `" ○ <título> (<n>)"` si no (`n` = `messages`). Justo debajo de la
   sesión actual, una fila por subagente: `"   ⏳ <brief>"` si `Running`, `"   ✓ <brief>"` si `Ok`,
   `"   ✗ <brief>"` si `Err`. Cada fila se recorta a `width` caracteres; si se recorta, el último carácter
   es `…`. Un título vacío se muestra como `—`.
4. Si ninguna sesión es `current` y hay subagentes, los subagentes van al final.
5. `lib.rs`: añade `pub mod tree;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/tree.rs
use crate::app::{Entry, ToolState};

/// Una conversación guardada del proyecto.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SessionItem {
    /// Identificador en la base de sesiones.
    pub id: i64,
    /// Título (el primer mensaje, recortado).
    pub title: String,
    /// Mensajes guardados.
    pub messages: usize,
    /// Es la conversación abierta.
    pub current: bool,
}

/// Un subagente lanzado en la conversación actual.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SubagentItem {
    /// Qué se le encargó (resumen de los argumentos).
    pub brief: String,
    /// Estado.
    pub state: ToolState,
}

/// Tools que lanzan un subagente.
pub const SUBAGENT_TOOLS: [&str; 3] = ["subagente", "agente", "task"];

/// Subagentes de la transcripción, en orden.
pub fn subagents_of(entries: &[Entry]) -> Vec<SubagentItem>;
/// Filas del árbol, de `width` caracteres como mucho.
pub fn tree_rows(sessions: &[SessionItem], subagents: &[SubagentItem], width: u16) -> Vec<String>;
```

## Ejemplo (entrada y resultado esperado)

```
sessions = [ {id:2, title:"arregla el test", messages:6, current:true}, {id:1, title:"añade login", messages:12, current:false} ]
subagents = [ {brief:"busca usos de foo", state:Ok}, {brief:"revisa el diff", state:Running} ]
tree_rows(&sessions, &subagents, 29) ==
  [" ● arregla el test (6)", "   ✓ busca usos de foo", "   ⏳ revisa el diff", " ○ añade login (12)"]
tree_rows(&[{id:1, title:"un título larguísimo que no cabe", messages:3, current:false}], &[], 12) == [" ○ un títul…"]
```
