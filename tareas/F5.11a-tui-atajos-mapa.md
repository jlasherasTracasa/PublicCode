## Objetivo

1. `Cargo.toml` de `pcode-tui`: añade `toml.workspace = true` en `[dependencies]`.
2. Crea `keys.rs` con `Action`, `KeyCombo`, `KeyMap` y `load_keymap` (firmas abajo).
3. Nombre de cada acción en el archivo (`Action::name`) y atajo por defecto:
   `interrumpir` ctrl+c · `salir` ctrl+d · `salidas` ctrl+o · `borrar` ctrl+u · `plan` backtab ·
   `subir` pageup · `bajar` pagedown · `nueva_linea` alt+enter · `lider` ctrl+x · `lateral` ctrl+b · `ayuda` f1.
   `Action::ALL` las lista en ese orden.
4. `KeyCombo::parse("ctrl+shift+k")`: partes separadas por `+`, en minúsculas; todas menos la última son
   modificadores (`ctrl`, `alt`, `shift`); la última es la tecla: un solo carácter, o `enter`, `tab`,
   `backtab`, `esc`, `space`, `up`, `down`, `left`, `right`, `home`, `end`, `pageup`, `pagedown`, `delete`,
   `f1` … `f12`. Otra cosa → `Err("atajo no válido «<texto>»")`. `space` es `KeyCode::Char(' ')`.
5. `KeyCombo::from_event(ev)`: para `KeyCode::Char(c)` guarda `c` en minúsculas y quita `SHIFT` de los
   modificadores; para `KeyCode::BackTab` quita `SHIFT`. De los modificadores solo cuentan CONTROL, ALT y SHIFT.
6. `KeyMap::from_toml(s)`: parte de `default_map()`. Lee la tabla `[atajos]` con
   `toml::from_str::<BTreeMap<String, BTreeMap<String, String>>>(s)` (error de sintaxis →
   `Err("keybindings.toml: <error>")`). Cada clave es un nombre de acción (desconocida →
   `Err("acción desconocida «<nombre>»")`) y su valor un atajo. Sustituye el atajo de esa acción. Al final, si
   dos acciones comparten atajo → `Err("atajo repetido «<atajo>»: <acción1> y <acción2>")` (nombres en el
   orden de `Action::ALL`). Sin tabla `[atajos]`, el mapa por defecto.
7. `KeyMap::action(ev)`: la acción cuyo atajo es `KeyCombo::from_event(ev)`. `KeyMap::bindings()`: pares
   `(acción, texto del atajo)` en el orden de `Action::ALL`; el texto es el que `parse` aceptaría
   (`"ctrl+c"`, `"backtab"`, `"f1"`).
8. `load_keymap(paths)`: lee el primer archivo de `paths` que exista y devuelve `from_toml` de su contenido;
   si no existe ninguno, `Ok(default_map())`.
9. `lib.rs`: `pub mod keys;` y `pub use keys::{Action, KeyMap};`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/keys.rs
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};
use std::collections::BTreeMap;

/// Acción de la TUI que se puede asignar a una tecla.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Action { Interrupt, Quit, ToggleOutputs, ClearInput, TogglePlan, ScrollUp, ScrollDown, NewLine, Leader, ToggleSide, Help }

impl Action {
    /// Todas, en el orden en que se listan.
    pub const ALL: [Action; 11];
    /// Nombre en `keybindings.toml` (`interrumpir`, `salir`…).
    pub fn name(self) -> &'static str;
}

/// Una combinación de teclas normalizada.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct KeyCombo { pub code: KeyCode, pub mods: KeyModifiers }

impl KeyCombo {
    /// De texto: `"ctrl+k"`, `"alt+enter"`, `"f1"`.
    pub fn parse(s: &str) -> Result<KeyCombo, String>;
    /// De una pulsación.
    pub fn from_event(ev: &KeyEvent) -> KeyCombo;
    /// A texto (lo inverso de `parse`).
    pub fn text(&self) -> String;
}

/// Qué tecla dispara cada acción.
#[derive(Debug, Clone, PartialEq)]
pub struct KeyMap { /* BTreeMap<Action, KeyCombo> */ }

impl KeyMap {
    pub fn default_map() -> KeyMap;
    pub fn from_toml(s: &str) -> Result<KeyMap, String>;
    pub fn action(&self, ev: &KeyEvent) -> Option<Action>;
    pub fn bindings(&self) -> Vec<(Action, String)>;
}

/// Mapa del primer archivo que exista; el de por defecto si no hay ninguno.
pub fn load_keymap(paths: &[std::path::PathBuf]) -> Result<KeyMap, String>;
```

## Ejemplo (entrada y resultado esperado)

```
keybindings.toml:
  [atajos]
  salir = "ctrl+q"
  ayuda = "f2"
-> action(Ctrl+Q) == Some(Action::Quit); action(Ctrl+D) == None; action(F2) == Some(Action::Help)

  [atajos]
  salidas = "ctrl+b"
-> Err("atajo repetido «ctrl+b»: salidas y lateral")

KeyCombo::from_event(BackTab con SHIFT) == KeyCombo::parse("backtab").unwrap()
```

## Tests (con estos nombres)

- `atajos_por_defecto`: `default_map().action` da `Interrupt` para Ctrl+C, `TogglePlan` para BackTab con SHIFT, `Help` para F1 y None para la letra `a`
- `toml_sobrescribe`: el primer caso del ejemplo
- `conflicto_es_error`: el segundo caso del ejemplo, con el mensaje exacto
- `accion_o_atajo_desconocidos_son_error`: `volar = "f3"` da `acción desconocida «volar»` y `salir = "ctrl+"` da un Err que contiene `atajo no válido`
- `texto_y_parse_son_inversos`: para cada atajo de `default_map().bindings()`, `KeyCombo::parse(texto).unwrap().text() == texto`
- `load_usa_el_primer_archivo_que_existe`: con rutas `[no-existe, archivo]` se lee `archivo`; con una lista vacía, el mapa por defecto
