## Objetivo

1. `app.rs`: añade a `App` el campo `pub help_open: bool` (doc: «Ventana de ayuda de atajos abierta»), a
   `false` en `App::new`. En `act`, `Action::Help` pasa a `self.help_open = true; Some(vec![])`.
2. `app.rs`, `key`: después del bloque de la aprobación pendiente, si `self.help_open`: ponlo a `false` y
   devuelve `vec![]` (cualquier tecla cierra la ventana y no hace nada más).
3. `i18n.rs`: añade al final de `ES` y `EN` (mismo orden) `help_title` = `" Atajos · cualquier tecla cierra "`
   / `" Shortcuts · any key closes "` y una clave por acción, `act_<nombre>` con el nombre de
   `Action::name()`: `act_interrumpir` = «interrumpe al agente, borra la entrada o sale» / «interrupt, clear
   or quit», `act_salir` = «sale» / «quit», `act_salidas` = «despliega las salidas de las tools» / «expand
   tool outputs», `act_borrar` = «borra la entrada» / «clear the input», `act_plan` = «modo plan o normal» /
   «plan or build mode», `act_subir` = «sube en la conversación» / «scroll up», `act_bajar` = «baja en la
   conversación» / «scroll down», `act_nueva_linea` = «nueva línea» / «new line», `act_lider` = «tecla líder»
   / «leader key», `act_lateral` = «barra lateral» / «sidebar», `act_ayuda` = «esta ayuda» / «this help».
4. `render.rs`: al final de `render`, si `app.help_open`, dibuja una ventana centrada sobre `body` (ancho
   `min(60, body.width - 2)`, alto = filas + 2) con `Clear`, borde redondeado, título `help_title` y una fila
   por elemento de `app.keymap.bindings()`:
   `format!("{:<12} {}", atajo, t(app.lang, &format!("act_{}", accion.name())))`.

Sin firmas: Solo añade el campo `help_open` a App; el resto es estado privado, textos y dibujo

## Ejemplo (entrada y resultado esperado)

```
F1                         -> app.help_open == true, sin órdenes
(otra tecla, p. ej. `x`)   -> app.help_open == false, la entrada sigue vacía, sin órdenes
pantalla 80×24 con help_open: hay una fila con "Atajos · cualquier tecla cierra" y otra con "ctrl+c       interrumpe al agente"
con salir = "ctrl+q" en el mapa: hay una fila con "ctrl+q       sale"
```

## Tests (con estos nombres)

- `ayuda_f1_abre_y_cualquier_tecla_cierra`: F1 pone `help_open` a true; después la tecla `x` lo pone a false sin escribir `x` en la entrada
- `ayuda_f1_render_80x24_lista_los_atajos`: con `help_open = true` la pantalla contiene `Atajos · cualquier tecla cierra` y `ctrl+c       interrumpe al agente`
- `ayuda_f1_muestra_el_atajo_remapeado`: con `salir = "ctrl+q"` la pantalla contiene `ctrl+q       sale`
- `ayuda_f1_cabe_en_120x40`: a 120×40 la pantalla contiene las 11 acciones (comprueba `f1` y `esta ayuda`)
