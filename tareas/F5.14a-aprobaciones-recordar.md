# F5.14a-aprobaciones-recordar — Aprobaciones: «permitir y recordar» en `ApprovalBroker`

## Objetivo

Todo en `approvals.rs`. Una decisión recordada vale solo para la MISMA sesión y el MISMO texto de acción, y solo mientras viva
el demonio (no se guarda en disco). Nunca se recuerda una denegación.
1. Añade a `ApprovalBroker` el campo `remembered: Mutex<std::collections::HashSet<(i64, String)>>` e inicialízalo vacío en `new`.
2. `decide_with(id, allow, remember)`: como `decide`, pero si `allow && remember`, antes de enviar la decisión inserta
   `(dto.session, dto.action.clone())` en `remembered` (el `dto` es el `ApprovalDto` guardado en `pending` con ese id).
   Devuelve `false` si el id no existe.
3. `decide(id, allow)` pasa a ser `self.decide_with(id, allow, false)` (misma firma, mismo comportamiento).
4. `request(...)`: al principio, si `remembered` contiene `(session, action.to_string())`, devuelve `true` inmediatamente, sin
   crear una aprobación pendiente ni emitir eventos.
5. `remembered(session)`: acciones recordadas de esa sesión, ordenadas alfabéticamente. `forget(session)`: borra las de esa sesión.
6. Añade los tests de la lista al `mod tests` existente (usa `broker(5000)` y el patrón de `aprobacion_permitida`:
   `tokio::spawn` de `request`, esperar a que `pending()` no esté vacío con `tokio::task::yield_now()` como mucho 10000 vueltas, decidir).

```rust
/// Decide una aprobación; con `allow` y `remember`, la misma acción de esa sesión ya no se vuelve a preguntar.
pub fn decide_with(&self, id: u64, allow: bool, remember: bool) -> bool;

pub fn decide(&self, id: u64, allow: bool) -> bool;

/// Olvida lo recordado para una sesión.

```

## Ejemplo (entrada y resultado esperado)

```
request(1, "bash git push", …) → pendiente id 1;  decide_with(1, true, true) → true  (la petición devuelve true)
request(1, "bash git push", …) → true al momento, sin pendiente
request(2, "bash git push", …) → vuelve a quedar pendiente (otra sesión)
request(1, "bash git push --force", …) → vuelve a quedar pendiente (otra acción)
remembered(1) == ["bash git push"];  forget(1);  remembered(1) == []
```

## Tests (con estos nombres)

- `recordar_permite_la_misma_accion_sin_preguntar`: tras `decide_with(id, true, true)`, otra `request` igual devuelve `true` sin dejar nada en `pending()`
- `recordar_no_vale_para_otra_sesion_ni_otra_accion`: la misma acción en la sesión 2, o una acción distinta en la 1, vuelve a quedar pendiente
- `denegar_con_recordar_no_recuerda`: `decide_with(id, false, true)` deniega y `remembered(1)` queda vacío
- `olvidar_vuelve_a_preguntar`: tras `forget(1)` la misma acción vuelve a quedar pendiente
