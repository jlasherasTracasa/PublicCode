## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`: cambia el comentario de `APPROVALS_DECIDE` por
   `/// Decidir una aprobación: `{id, allowed, remember?}` → `true` si existía. Con `remember`, no se vuelve a preguntar por esa misma acción en esa sesión.`
   (la constante no cambia).
2. `server.rs`, función `rpc`, brazo `methods::APPROVALS_DECIDE`: lee además
   `let remember = p.get("remember").and_then(|v| v.as_bool()).unwrap_or(false);` y sustituye `st.approvals.decide(a, ok)` por
   `st.approvals.decide_with(a, ok, remember)`. El error `"se esperaba {id, allowed}"` no cambia.
3. En `mod tests` de `server.rs` añade `rpc_aprobacion_recordada_no_vuelve_a_preguntar`, copiando `aprobaciones_por_rpc`: lanza
   `b.request(1, "git push", "irreversible", "agente:s-1")` en un `tokio::spawn`, espera el id con el bucle de `approvals.list`,
   decide con `{"id": id, "allowed": true, "remember": true}` y comprueba que la petición devuelve `true`. Después llama otra vez a
   `s.approvals.request(1, "git push", "irreversible", "agente:s-1")` dentro de
   `tokio::time::timeout(Duration::from_secs(2), …)` y comprueba que devuelve `Ok(true)` y que `approvals.list` está vacío.

Sin firmas: no añade API de Rust: solo un parámetro opcional (`remember`) en un método JSON-RPC que ya existe

## Ejemplo (entrada y resultado esperado)

```
{"method": "approvals.decide", "params": {"id": 3, "allowed": true, "remember": true}} → {"result": true}
```
