## Objetivo

1. Crea `diff.js`: módulo ES sin imports ni DOM, con las dos funciones de abajo exportadas.
2. `parseUnifiedDiff(text)`: devuelve un array de archivos `{ meta, hunks }`. Recorre las líneas de `text.split("\n")` (ignora
   una última línea vacía). Una línea que empieza por `diff --git ` abre un archivo nuevo; si el texto no trae esa línea (por
   ejemplo el diff de un archivo nuevo que empieza por `--- /dev/null`), todo va en un único archivo. Hasta el primer `@@`, las
   líneas van a `meta` (array de strings). Una línea `@@ -a,b +c,d @@ …` abre un trozo `{ header, lines }` (`header` = la línea
   entera) y fija los contadores `oldNo = a`, `newNo = c` (si falta `,b` o `,d` da igual). Dentro del trozo:
   - empieza por `+` → `{ kind: "add", oldNo: null, newNo, text }` y suma 1 a `newNo`;
   - empieza por `-` → `{ kind: "del", oldNo, newNo: null, text }` y suma 1 a `oldNo`;
   - empieza por `\` (`\ No newline at end of file`) → se ignora;
   - otra → `{ kind: "ctx", oldNo, newNo, text }` y suma 1 a los dos.
   `text` es la línea SIN su primer carácter (`+`, `-` o espacio).
3. `sideBySide(hunk)`: filas `{ left, right }` para pintar dos columnas. Una línea `ctx` va en las dos (`left === right`).
   Un grupo seguido de líneas `del` y las `add` que van justo después se emparejan por orden: la primera borrada con la
   primera añadida, etc.; si sobran de un lado, el otro es `null`.
4. Crea `diff.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const d = "diff --git a/a.txt b/a.txt\n--- a/a.txt\n+++ b/a.txt\n@@ -1,3 +1,3 @@\n uno\n-dos\n+DOS\n tres\n";
parseUnifiedDiff(d)[0].meta  → ["diff --git a/a.txt b/a.txt", "--- a/a.txt", "+++ b/a.txt"]
parseUnifiedDiff(d)[0].hunks[0].lines →
  [{ kind: "ctx", oldNo: 1, newNo: 1, text: "uno" }, { kind: "del", oldNo: 2, newNo: null, text: "dos" },
   { kind: "add", oldNo: null, newNo: 2, text: "DOS" }, { kind: "ctx", oldNo: 3, newNo: 3, text: "tres" }]
sideBySide(parseUnifiedDiff(d)[0].hunks[0]) → 3 filas: (uno | uno), (dos | DOS), (tres | tres)
```

## Tests (con estos nombres)

- `parse_diff_numeros_de_linea`: el ejemplo da las cuatro líneas con sus números antiguos y nuevos
- `parse_diff_de_dos_archivos`: un texto con dos `diff --git` da dos archivos, cada uno con su `meta` y sus trozos
- `parse_diff_de_archivo_nuevo_sin_cabecera_git`: un diff que empieza por `--- /dev/null` da un archivo con todas las líneas `add`
- `ignora_la_marca_de_sin_salto_final`: la línea que empieza por barra invertida no aparece ni cambia los números
- `split_empareja_lineas`: el ejemplo da tres filas y la del medio empareja `dos` con `DOS`
- `split_con_mas_borradas_que_anadidas`: dos `del` y una `add` dan dos filas y en la segunda `right` es `null`
- `diff_vacio`: cadena vacía da un array vacío
- `diff_no_interpreta_html`: una línea `+<b>x</b>` conserva el texto `<b>x</b>` tal cual (el módulo no genera HTML)
