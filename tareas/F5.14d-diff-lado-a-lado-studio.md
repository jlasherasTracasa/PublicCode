## Objetivo

1. `web_assets.rs`: añade a `ASSETS` la línea `("diff.js", include_str!("../web/studio/diff.js")),`. `index.html`: en el bloque
   `<script type="module">` final, antes de `inicio();`: `import * as diff from "/studio/diff.js"; Studio.diff = diff;`.
2. Preferencia: `modoDiff()` devuelve `"lado"` si `localStorage["pcode.diffModo"] === "lado"` (try/catch) y la ventana mide más
   de 900 px (`innerWidth > 900`); si no, `"unificado"`.
3. En `pintaDiff(t)`: después de vaciar la caja, añade una barra `div` de clase `diff-barra` con un botón (`aria-pressed`) cuyo
   texto es `⇄ Lado a lado` o `≡ Unificado` según el modo al que se cambia; al pulsarlo, guarda el modo contrario en
   `localStorage["pcode.diffModo"]` (`"lado"` o `"unificado"`) y llama a `pintaDiff(t)`.
4. Si `modoDiff() === "unificado"`: deja la pintura actual como está (y lo que otras tareas hayan añadido a `pintaDiff`).
5. Si `modoDiff() === "lado"`: `for (const f of Studio.diff.parseUnifiedDiff(t.text))`: un `div.meta` por línea de `f.meta`; por cada
   trozo, un `div.hunk` con `h.header` y un `div` de clase `lado` (rejilla de 2 columnas) con dos celdas por cada fila de
   `Studio.diff.sideBySide(h)`. Cada celda es un `div` de clase `celda` + (`add`, `del` o nada) con tres `span`: número de línea
   (`oldNo` a la izquierda, `newNo` a la derecha), el prefijo `+`, `-` o espacio (el color no basta) y el texto. Una celda `null`
   es un `div.celda.vacia`. Todo con `el(...)`/`textContent`.
6. CSS: `.diff-barra { position: sticky; top: 0; display: flex; justify-content: flex-end; padding: 4px 12px; background: var(--superficie-3); }`,
   `.diff .lado { display: grid; grid-template-columns: 1fr 1fr; }`, `.diff .celda { display: flex; gap: 8px; padding: 0 8px; overflow: hidden; }`,
   `.diff .celda .num { min-width: 36px; text-align: right; color: var(--texto-2); user-select: none; }`,
   `.diff .celda.vacia { background: var(--superficie-3); }`. Las clases `add` y `del` reutilizan los colores de `.diff .add` y `.diff .del`.
7. `ORDENES`: `["Diff: cambiar entre unificado y lado a lado", "", () => { … }]` (invierte la preferencia y, si la pestaña activa
   es un diff, la repinta).
