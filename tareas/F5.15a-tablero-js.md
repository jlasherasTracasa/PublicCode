## Objetivo

1. Crea `tablero.js`: módulo ES sin imports ni DOM. Una tarea es `{ id, state, attempts }` (`TaskDto`); una sesión es
   `{ id, title, backend, state, parent }` (`SessionInfo`, `parent` puede ser `null`).
2. `COLUMNS`: `[["pending", "Pendiente"], ["running", "En marcha"], ["accepted", "Aceptada"], ["integrated", "Integrada"], ["blocked", "Bloqueada"]]`.
3. `columnOf(state)`: pasa `state` a minúsculas y devuelve la clave de columna: empieza por `run` o `en marcha` → `running`;
   por `accept` o `acept` → `accepted`; por `integr` → `integrated`; por `block` o `bloq` → `blocked`; cualquier otro
   (incluido `pending`, `pendiente` o vacío) → `pending`.
4. `board(tasks)`: objeto con las cinco claves de `COLUMNS`, cada una con sus tareas ordenadas por `id` (orden de texto).
5. `upsertTask(tasks, task)`: array NUEVO: sustituye la tarea con el mismo `id` o la añade al final.
6. `agentTree(sessions)`: `[{ session, children }]` anidado por `parent`. Son raíces las sesiones con `parent` nulo o cuyo
   `parent` no está en la lista. Raíces e hijos ordenados por `id` numérico ascendente.
7. `moveFocus(b, col, row, key)`: `b` es el resultado de `board`; `col` es el índice de columna (0–4) y `row` el de la tarjeta.
   `ArrowLeft`/`ArrowRight` cambian de columna sin salirse (0–4) y ajustan `row` a `min(row, tarjetas de la nueva columna - 1)`
   (0 si está vacía); `ArrowUp`/`ArrowDown` cambian `row` dentro de `[0, tarjetas - 1]`; `Home`/`End` van a la primera o
   última tarjeta de la columna. Otra tecla devuelve la misma posición. Devuelve `{ col, row }`.
8. Crea `tablero.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
columnOf("Running(2)") → "running";  columnOf("Blocked: sin red") → "blocked";  columnOf("lo que sea") → "pending"
board([{ id: "F1.02", state: "accepted", attempts: 1 }, { id: "F1.01", state: "running", attempts: 2 }])
  → { pending: [], running: [{ id: "F1.01", … }], accepted: [{ id: "F1.02", … }], integrated: [], blocked: [] }
agentTree([{ id: 3, parent: 1 }, { id: 1, parent: null }, { id: 2, parent: 9 }])
  → [{ session: { id: 1, … }, children: [{ session: { id: 3, … }, children: [] }] }, { session: { id: 2, … }, children: [] }]
moveFocus(b, 1, 0, "ArrowRight") → { col: 2, row: 0 };   moveFocus(b, 0, 0, "ArrowLeft") → { col: 0, row: 0 }
```

## Tests (con estos nombres)

- `tablero_coloca_por_estado`: el ejemplo de `board` deja cada tarea en su columna y las cinco claves existen
- `columna_por_estado`: los tres casos del ejemplo de `columnOf`, más `Integrated` e `Aceptada`
- `task_updated_mueve_tarjeta`: `upsertTask` con un id existente y otro estado hace que `board` la cambie de columna, sin duplicarla
- `upsert_no_muta`: el array original conserva su longitud y su contenido
- `arbol_anida`: el ejemplo de `agentTree` da dos raíces y la sesión 3 como hija de la 1
- `teclado_entre_columnas`: `ArrowRight` y `ArrowLeft` cambian de columna sin salirse y ajustan la fila; `ArrowDown` no pasa de la última tarjeta
