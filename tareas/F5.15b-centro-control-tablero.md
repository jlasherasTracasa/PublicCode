## Objetivo

API de F5.04 (compárala con los comentarios de las constantes `FLOW_…` del protocolo; si la forma difiere, manda el protocolo y
anótalo en *Decisiones*): `flow.status {}` → `{ tasks: [{id, state, attempts}], needsCoordinator: [ids] }`; evento SSE
`taskUpdated { task: {id, state, attempts} }`.
1. `web_assets.rs`: añade a `ASSETS` la línea `("tablero.js", include_str!("../web/studio/tablero.js")),`. `index.html`: en el bloque
   `<script type="module">` final, antes de `inicio();`: `import * as tablero from "/studio/tablero.js"; Studio.tablero = tablero;`.
2. Junto a `<div id="ajustes" …>` añade `<div id="vista-flujo" class="ajustes oculto" aria-label="Centro de control"></div>`.
   En `muestra()`: `$("vista-flujo").classList.toggle("oculto", !t || t.kind !== "flujo"); if (t && t.kind === "flujo") pintaFlujo();`.
   En `pintaPestanas`, el texto de esa pestaña es `"▦ Centro de control"`.
3. Estado `S.flujo = { tasks: [], needs: [], foco: { col: 0, row: 0 } }`. `abreFlujo()` (imita `abreAjustes`): crea o activa la
   pestaña `{ id: "flujo", kind: "flujo", path: "Centro de control" }` y llama a `cargaFlujo()`. `cargaFlujo()`:
   `r = await rpc("flow.status")`; `S.flujo.tasks = r.tasks || []`; `S.flujo.needs = r.needsCoordinator || []`; `pintaFlujo()`.
   Si falla, pinta `el("div", "vacio", "No hay ningún flujo en marcha: " + e.message)`.
4. `pintaFlujo()`: título «Centro de control» y un `div` de clase `tablero` con `role="grid"` y una columna por elemento de
   `Studio.tablero.COLUMNS` (`div.columna` con cabecera `Etiqueta · n`). Cada tarea es un `button` de clase `tarjeta` con el `id`
   en negrita, el estado en texto y `intento N` (`attempts`); `tabIndex = 0` solo en la tarjeta del foco (`S.flujo.foco`), `-1` en
   las demás; `aria-label = id + ", " + etiqueta de la columna`. Tras pintar, si la vista ya tenía el foco, vuelve a enfocar la
   tarjeta del foco. Sin tareas: `el("div", "vacio", "El flujo no tiene tareas todavía.")`.
5. Teclado: `$("vista-flujo").addEventListener("keydown", …)`: para las flechas, `Home` y `End`,
   `S.flujo.foco = Studio.tablero.moveFocus(Studio.tablero.board(S.flujo.tasks), foco.col, foco.row, e.key)`, `e.preventDefault()` y `pintaFlujo()`.
6. `conecta()`: añade `case "taskUpdated": S.flujo.tasks = Studio.tablero.upsertTask(S.flujo.tasks, e.task); if (tabActiva()?.kind === "flujo") pintaFlujo(); break;`.
7. CSS: `.tablero { display: grid; grid-template-columns: repeat(5, minmax(150px, 1fr)); gap: 10px; overflow-x: auto; }`,
   `.columna { background: var(--superficie-3); border-radius: 10px; padding: 8px; min-height: 120px; }`,
   `.tarjeta { display: block; width: 100%; text-align: left; margin: 6px 0; padding: 8px; border-radius: 8px; }`,
   `.tarjeta:focus-visible { outline: 2px solid var(--primario); }`.
   `ORDENES`: `["Flujo: centro de control", "", () => abreFlujo()]`.
