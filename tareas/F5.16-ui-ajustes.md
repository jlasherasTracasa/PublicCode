## Objetivo

1. Demonio: `backends.detect` → `BackendDto` por cada backend de la configuración y por cada CLI
   conocida en el PATH (`claude`, `copilot`, `gemini`, `opencode`): instalado, versión y, si la CLI
   lo permite sin efectos, si la sesión está iniciada. Cada comprobación con tiempo máximo de 5 s.
2. UI: tabla de backends con su estado y botón «iniciar sesión» (en escritorio abre una terminal con
   la orden de login; en web muestra la orden para copiar); rol por defecto de cada backend; URL de
   LiteLLM; tema (sistema, claro, oscuro); idioma.
3. Las credenciales NO se editan aquí en modo web (ver F5.20).
