## Objetivo

1. `Cargo.toml` de `pcode-server`: añade en `[dependencies]` la línea `pcode-skills = { path = "../pcode-skills" }` (crate del
   propio workspace).
2. Crea `skills_api.rs` con las firmas de abajo y tests (con `tempfile::tempdir()`) en el mismo archivo.
3. `list(root)`: para cada pareja (directorio, estado) de `[(ACTIVE_DIR, "activa"), (QUARANTINE_DIR, "cuarentena"), (RETIRED_DIR, "retirada")]`:
   `pcode_skills::Registry::load(&[root.join(dir)])` (error → `Err(e.to_string())`; un directorio que no existe da un registro
   vacío) y por cada skill de `reg.all()` un `SkillView` con `name`, `description`, `state`, `body`,
   `path` = el directorio de la skill relativo a `root` (`dir.strip_prefix(root)`, y `\` cambiado por `/`) y `evidence` = contenido de `<dir de la skill>/EVIDENCIA.md` si
   existe (`None` si no). Orden: activas, cuarentena, retiradas; dentro, por nombre (como las da `all()`).
4. `parse_target(s)`: `"claude"` → `Target::Claude`, `"agents"` → `Target::AgentsMd`, `"copilot"` → `Target::Copilot`,
   `"gemini"` → `Target::Gemini`, `"opencode"` → `Target::Opencode`; otro → `Err(format!("destino desconocido: {s}"))`.
5. `export(root, target)`: `parse_target`, carga SOLO las activas (`Registry::load(&[root.join(ACTIVE_DIR)])`), llama a
   `pcode_skills::export(&reg, target, root)` y devuelve las rutas escritas relativas a `root` con `/`. Errores como texto.
6. `lib.rs`: añade `pub mod skills_api;` debajo de `pub mod settings;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/skills_api.rs
use crate::workspace::WsResult;
use std::path::Path;

/// Dónde viven las skills según su estado (relativo a la raíz del proyecto).
pub const ACTIVE_DIR: &str = ".claude/skills";
pub const QUARANTINE_DIR: &str = ".pcode/skills/cuarentena";
pub const RETIRED_DIR: &str = ".pcode/skills/retiradas";

/// Una skill para la interfaz.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "camelCase")]
pub struct SkillView { pub name: String, pub description: String, pub state: String, pub path: String, pub body: String, pub evidence: Option<String> }

pub fn list(root: &Path) -> WsResult<Vec<SkillView>>;
pub fn parse_target(s: &str) -> WsResult<pcode_skills::Target>;
/// Exporta las skills activas al formato de un agente; devuelve los archivos escritos.
pub fn export(root: &Path, target: &str) -> WsResult<Vec<String>>;
```

## Ejemplo (entrada y resultado esperado)

```
<raíz>/.claude/skills/adr/SKILL.md                      (frontmatter con `name: adr` y `description: Registra decisiones`)
<raíz>/.pcode/skills/cuarentena/nueva/SKILL.md + EVIDENCIA.md ("pasa 3 de 5 evals")
list(raíz) → [SkillView { name: "adr", state: "activa", path: ".claude/skills/adr", evidence: None, … },
              SkillView { name: "nueva", state: "cuarentena", path: ".pcode/skills/cuarentena/nueva", evidence: Some("pasa 3 de 5 evals"), … }]
export(raíz, "gemini") → ["GEMINI.md"]      export(raíz, "x") → Err("destino desconocido: x")
```

## Tests (con estos nombres)

- `skills_list_tres_estados`: con una skill en cada uno de los tres directorios salen tres vistas con `state` activa, cuarentena y retirada, en ese orden
- `evidencia_solo_si_existe`: la skill en cuarentena con `EVIDENCIA.md` trae su texto y la activa trae `None`
- `sin_directorios_lista_vacia`: en un directorio temporal vacío `list` da `Ok` con vector vacío
- `destino_desconocido`: `parse_target("x")` da `Err` que contiene `destino desconocido`
- `exporta_solo_las_activas`: `export(root, "gemini")` crea `GEMINI.md` con el nombre de la skill activa y sin el de la que está en cuarentena
