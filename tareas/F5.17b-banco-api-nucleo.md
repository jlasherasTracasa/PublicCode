## Objetivo

1. Crea `bench_api.rs` con las firmas de abajo y tests en el mismo archivo.
2. `backend_of(file_name)`: quita la extensión `.jsonl`; si el nombre empieza por una fecha `AAAA-MM-DD-` (4 dígitos, guion, 2
   dígitos, guion, 2 dígitos, guion), devuelve lo que sigue; si no, el nombre sin extensión.
3. `summarize(file_name, jsonl)`: cada línea no vacía es un objeto JSON con los campos `ok_primera` (bool), `ok_final` (bool),
   `tokens` (número) y `ms` (número); los que falten cuentan `false` o 0. Las líneas que no son JSON válido se ignoran.
   `tasks` = líneas válidas; `ok_first` y `ok_final` = cuántas tienen ese campo en `true`; `tokens` y `ms` = sumas.
   `backend = backend_of(file_name)` y `file = file_name`.
4. `summary(root)`: lee los archivos `*.jsonl` de `root/bench/resultados` (si el directorio no existe → `Ok(vec![])`), ordenados
   por nombre, y devuelve un `summarize` por archivo. Error de lectura → `Err` con el texto.
5. `lib.rs`: añade `pub mod bench_api;` debajo de `pub mod assist;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/bench_api.rs
use crate::workspace::WsResult;
use std::path::Path;

/// Resumen de una ejecución del banco.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "camelCase")]
pub struct BackendSummary { pub backend: String, pub file: String, pub tasks: u32, pub ok_first: u32, pub ok_final: u32, pub tokens: u64, pub ms: u64 }

pub fn backend_of(file_name: &str) -> String;
pub fn summarize(file_name: &str, jsonl: &str) -> BackendSummary;
/// Un resumen por archivo de `bench/resultados/*.jsonl`.
pub fn summary(root: &Path) -> WsResult<Vec<BackendSummary>>;
```

## Ejemplo (entrada y resultado esperado)

```
backend_of("2026-11-01-claude-code.jsonl") == "claude-code";   backend_of("prueba.jsonl") == "prueba"
summarize("2026-11-01-glm.jsonl", "{\"id\":\"F1.01\",\"ok_primera\":true,\"ok_final\":true,\"tokens\":1200,\"ms\":900}\n{\"id\":\"F1.02\",\"ok_primera\":false,\"ok_final\":true,\"tokens\":800,\"ms\":100}\nno es json\n")
  == BackendSummary { backend: "glm", file: "2026-11-01-glm.jsonl", tasks: 2, ok_first: 1, ok_final: 2, tokens: 2000, ms: 1000 }
```

## Tests (con estos nombres)

- `backend_del_nombre_del_archivo`: con fecha delante da lo que sigue a la fecha y sin fecha el nombre sin extensión
- `resume_un_archivo`: el ejemplo da 2 tareas, 1 a la primera, 2 al final, 2000 tokens y 1000 ms
- `ignora_lineas_que_no_son_json`: la línea `no es json` no cuenta como tarea
- `sin_directorio_de_resultados`: en un directorio temporal vacío `summary` da `Ok` con vector vacío
- `un_resumen_por_archivo_ordenado`: con dos archivos en `bench/resultados` salen dos resúmenes en orden de nombre
