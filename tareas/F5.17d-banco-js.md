## Objetivo

1. Crea `banco.js`: módulo ES sin imports ni DOM, con las tres funciones de abajo exportadas. Un resumen es
   `{ backend, file, tasks, okFirst, okFinal, tokens, ms }` (lo que devuelve `bench.summary`).
2. `rate(part, total)`: porcentaje entero redondeado (`Math.round(100 * part / total)`); con `total` 0 devuelve 0.
3. `formatTokens(n)`: menos de 1000 → el número tal cual (`"999"`); menos de 1 000 000 → miles con un decimal y `k` (`"12.3k"`);
   si no, millones con un decimal y `M` (`"1.2M"`). Un decimal `.0` se conserva (`"2.0k"`).
4. `bars(summaries, width, barHeight, gap)`: una barra horizontal por resumen para el porcentaje de aceptación a la primera:
   `{ label: backend, value: rate(okFirst, tasks), x: 0, y: i * (barHeight + gap), width: Math.round(width * value / 100), height: barHeight }`.
   Devuelve `{ bars, height }` con `height` = alto total (`n * barHeight + (n - 1) * gap`, 0 si no hay resúmenes).
5. Crea `banco.test.js` con los tests de la lista.
