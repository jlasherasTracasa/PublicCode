## Objetivo

Todo en `index.html`. API: `skills.list {}` → `[{ name, description, state, path, body, evidence }]` con `state` `activa`, `cuarentena`
o `retirada`; `skills.export { target }` → rutas escritas, con `target` `claude`, `agents`, `copilot`, `gemini` u `opencode`.
1. Junto a `<div id="ajustes" …>` añade `<div id="vista-skills" class="ajustes oculto" aria-label="Skills"></div>`. En `muestra()`:
   `$("vista-skills").classList.toggle("oculto", !t || t.kind !== "skills"); if (t && t.kind === "skills") pintaSkills();`.
   En `pintaPestanas`, el texto de la pestaña es `"✧ Skills"`.
2. `abreSkills()` (imita `abreAjustes`): crea o activa la pestaña `{ id: "skills", kind: "skills", path: "Skills" }`, carga
   `S.skills = { lista: await rpc("skills.list"), estado: "activa", abierta: null }` (si falla, `fallo(e)` y lista vacía) y pinta.
3. `pintaSkills()`: título «Skills»; tres botones `role="tab"` con `aria-selected`: `Activas (n)`, `En cuarentena (n)`,
   `Retiradas (n)`, que cambian `S.skills.estado` y repintan. Debajo, la lista de skills de ese estado: un `button` de clase
   `problema` por skill con el nombre en negrita y la descripción; al pulsarlo, `S.skills.abierta = s.name` y repinta.
   Lista vacía: `No hay skills en este estado.`.
4. Si hay una skill abierta, debajo se muestra: su ruta (`s.path + "/SKILL.md"`), el cuerpo con `md(s.body)` dentro de un
   `div` de clase `documento-skill` y, si `s.evidence`, un apartado «Evidencia» con `md(s.evidence)`.
5. Exportar (solo en la pestaña de activas): una fila «Exportar a:» con cinco botones — `Claude Code` (`claude`), `AGENTS.md`
   (`agents`), `GitHub Copilot` (`copilot`), `Gemini` (`gemini`) y `opencode` (`opencode`). Al pulsar:
   `confirm("Se escribirán las skills activas en el formato de " + nombre + ". ¿Exportar?")`; si acepta,
   `rutas = await rpc("skills.export", { target })` y `aviso(rutas.length ? "Exportado: " + rutas.join(", ") : "Ya estaba al día", "ok")`;
   errores con `fallo(e)`.
6. `ORDENES`: `["Skills: ver y exportar", "", () => abreSkills()]`.
