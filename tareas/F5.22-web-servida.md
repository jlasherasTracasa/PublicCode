## Objetivo

1. `pcode web [--puerto P] [--ui-dir D]`: el demonio sirve la UI compilada desde `D` (por defecto
   `apps/ui/dist`) en `127.0.0.1`.
2. Imprime una URL con un token de un solo uso (`/?t=<token>`) que se canjea por una cookie de sesión
   `HttpOnly`, `SameSite=Strict`; después, la cookie autoriza `/rpc` y `/eventos`.
3. Cabeceras: CSP `default-src 'self'`, `X-Content-Type-Options: nosniff` y `Referrer-Policy: no-referrer`.
4. Documenta el acceso por túnel SSH (`ssh -L`) en la ayuda de la orden.
