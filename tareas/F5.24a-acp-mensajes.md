## Objetivo

ACP es JSON-RPC 2.0 por stdio, un mensaje por línea. El editor (cliente) llama a `initialize`, `session/new`,
`session/prompt` y `session/cancel`; el agente le envía notificaciones `session/update` y le pide permiso con la
petición `session/request_permission`. Aquí solo se leen y se construyen mensajes; no hay E/S.
1. `Cargo.toml`: `name = "pcode-acp"`, `version/edition/license.workspace = true`; dependencias `serde_json` y
   `pcode-core` (`{ path = "../pcode-core" }`). El workspace ya incluye `crates/*`.
2. `lib.rs` con lo de *Firmas*. `parse(msg)`: con `method` e `id` → petición del editor según el método
   (`initialize` → `Initialize`; `session/new` → `NewSession { cwd: params.cwd o "." }`; `session/prompt` →
   `Prompt { session_id: params.sessionId, text }` donde `text` es la unión con `\n` de los `text` de los bloques
   `{"type":"text"}` de `params.prompt`; otro → `Unknown`); con `method` sin `id`: `session/cancel` →
   `Cancel { session_id }`, otro → `Ignored`; sin `method` pero con `id` → `Response { id, result }` (`result` o
   `Value::Null` si trae `error`).
3. Respuestas: `response(id, result)` → `{"jsonrpc":"2.0","id":id,"result":result}`; `error(id, code, msg)`;
   `initialize_result()` → `{"protocolVersion":1,"agentCapabilities":{"loadSession":false,"promptCapabilities":{"image":false}}}`;
   `new_session_result(sid)` → `{"sessionId":sid}`; `prompt_result(stop)` → `{"stopReason":stop}` (`end_turn`,
   `cancelled`, `max_tokens`, `refusal`).
4. `update(sid, ev)` traduce un `AgentEvent` a la notificación `{"jsonrpc":"2.0","method":"session/update","params":{"sessionId":sid,"update":U}}`:
   `TextDelta(t)` → U = `{"sessionUpdate":"agent_message_chunk","content":{"type":"text","text":t}}`;
   `ToolCall{name,arguments}` → `{"sessionUpdate":"tool_call","toolCallId":<id>,"title":<name>,"status":"in_progress","rawInput":arguments}`;
   `ToolResult{name,is_error,content}` → `{"sessionUpdate":"tool_call_update","toolCallId":<id>,"status":"failed"|"completed","content":[{"type":"content","content":{"type":"text","text":<content recortado a 4000 caracteres>}}]}`;
   `Info` y `Text` → `None` (el texto ya llegó en trozos). `<id>` lo pone quien llama (parámetro `call_id`).
5. `permission_request(id, sid, call_id, title)` → petición `session/request_permission` con
   `params = {"sessionId","toolCall":{"toolCallId":call_id,"title":title},"options":[{"optionId":"allow","name":"Permitir","kind":"allow_once"},{"optionId":"reject","name":"Rechazar","kind":"reject_once"}]}`.
   `permission_granted(result)` → `true` solo si `result.outcome.outcome == "selected"` y `result.outcome.optionId == "allow"`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-acp/src/lib.rs
//! Mensajes del Agent Client Protocol (ACP): lo que envía el editor y lo que responde PublicCode.
use pcode_core::AgentEvent;
use serde_json::{Value, json};

/// Un mensaje del editor.
#[derive(Debug, Clone, PartialEq)]
pub enum ClientMsg {
    Initialize { id: Value },
    NewSession { id: Value, cwd: String },
    Prompt { id: Value, session_id: String, text: String },
    Cancel { session_id: String },
    Response { id: Value, result: Value },
    Unknown { id: Value, method: String },
    Ignored,
}

pub fn parse(msg: &Value) -> ClientMsg;
pub fn response(id: &Value, result: Value) -> Value;
pub fn error(id: &Value, code: i64, message: &str) -> Value;
pub fn initialize_result() -> Value;
pub fn new_session_result(session_id: &str) -> Value;
pub fn prompt_result(stop_reason: &str) -> Value;
pub fn update(session_id: &str, call_id: &str, ev: &AgentEvent) -> Option<Value>;
pub fn permission_request(id: u64, session_id: &str, call_id: &str, title: &str) -> Value;
pub fn permission_granted(result: &Value) -> bool;
```

## Tests (con estos nombres)

- `acp_parse_prompt_une_bloques_de_texto`: prompt con dos bloques text `a` y `b` y uno image → `Prompt { text: "a\nb", .. }`
- `acp_parse_respuesta_y_cancel`: `{id:7,result:{}}` → `Response`; `session/cancel` sin id → `Cancel`
- `acp_inicializa`: `initialize_result()` → `protocolVersion == 1`
- `acp_texto_es_agent_message_chunk`: `update` de `TextDelta("hola")` → `params.update.sessionUpdate == "agent_message_chunk"` y texto `hola`
- `acp_tool_result_fallido`: `ToolResult { is_error: true, .. }` → `status == "failed"`
- `acp_permiso_mapea_a_aprobacion`: `permission_granted` de `{outcome:{outcome:"selected",optionId:"allow"}}` → true; `reject` o `cancelled` → false
