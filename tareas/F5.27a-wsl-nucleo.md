## Objetivo

Todo lo que se puede probar en Linux, sin ejecutar `wsl.exe`.
1. Crea `wsl.rs` con lo de *Firmas* y sus tests; en `main.rs` solo añade `mod wsl;` junto a los demás `mod`.
   Mientras F5.27b no use las funciones, pon `#![allow(dead_code)] // lo usa F5.27b` al principio de `wsl.rs`.
2. `decode_output(bytes)`: si hay al menos 2 bytes y el segundo es 0 (UTF-16LE, como sale en Windows), decodifica
   con `String::from_utf16_lossy` de los pares `u16::from_le_bytes`; si no, `String::from_utf8_lossy`. Quita los `\0`
   y los `\u{feff}` que queden.
3. `parse_list(out)`: salta la primera línea (cabecera `NAME STATE VERSION`) y las vacías. En cada línea: si empieza
   (tras recortar) por `*`, es la predeterminada; las columnas separadas por espacios son nombre, estado y versión.
   Las que no tengan 3 columnas o cuya versión no sea un número se saltan.
4. `windows_to_wsl_path(p)`: `C:\x\y` o `C:/x/y` → `/mnt/c/x/y` (letra en minúscula; `C:\` → `/mnt/c`); rutas UNC
   (`\\servidor\…`) o relativas → `None`.
5. `wsl_command(distro, cwd_wsl, args)`: `["wsl.exe", "-d", distro, "--cd", cwd_wsl, "--", "pcode", args…]`.
6. `pick_distro(list, wanted)`: con `wanted` → la de ese nombre si es versión 2; sin él → la predeterminada si es
   versión 2, o la primera de versión 2. `None` si no hay ninguna.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/wsl.rs
//! WSL2 en Windows: distribuciones, rutas y la orden para ejecutar `pcode` dentro.

/// Una distribución de WSL.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct WslDistro { pub name: String, pub state: String, pub version: u8, pub default: bool }

pub fn decode_output(bytes: &[u8]) -> String;
pub fn parse_list(out: &str) -> Vec<WslDistro>;
pub fn windows_to_wsl_path(p: &str) -> Option<String>;
pub fn wsl_command(distro: &str, cwd_wsl: &str, args: &[String]) -> Vec<String>;
pub fn pick_distro<'a>(list: &'a [WslDistro], wanted: Option<&str>) -> Option<&'a WslDistro>;
```

## Tests (con estos nombres)

- `wsl_decodifica_utf16`: los bytes UTF-16LE de `  NAME\r\n* Ubuntu` → texto que contiene `* Ubuntu` sin `\0`
- `wsl_parse_lista`: `  NAME STATE VERSION\n* Ubuntu Running 2\n  Debian Stopped 1\n` → Ubuntu (2, default) y Debian (1)
- `wsl_ruta_windows`: `C:\\Users\\a\\p` → `/mnt/c/Users/a/p`; `D:/x` → `/mnt/d/x`
- `wsl_ruta_unc_none`: `\\\\srv\\x` y `rel\\x` → None
- `wsl_orden`: `wsl_command("Ubuntu", "/mnt/c/p", &["tui".into()])` → `[wsl.exe, -d, Ubuntu, --cd, /mnt/c/p, --, pcode, tui]`
- `wsl_elige_version_2`: lista con Debian v1 predeterminada y Ubuntu v2 → sin `wanted` elige Ubuntu; `wanted = Debian` → None
