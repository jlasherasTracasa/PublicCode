## Objetivo

En Windows, la sandbox N1 solo existe dentro de WSL2. `pcode wsl` ejecuta `pcode` allí, en la misma carpeta.
1. `wsl.rs`: quita el `#![allow(dead_code)]`. Añade `WslArgs` y `run` de *Firmas*. `run` en Windows
   (`#[cfg(windows)]`): ejecuta `wsl.exe -l -v`, `decode_output`, `parse_list`, `pick_distro(&l, args.distro.as_deref())`
   (sin distribución → mensaje «No hay ninguna distribución de WSL2: instala una con `wsl --install`» y código 2),
   traduce `std::env::current_dir()` con `windows_to_wsl_path` (None → mensaje «Esta carpeta no está en una unidad
   local» y 2) y lanza `wsl_command(...)` heredando la terminal; devuelve su código. En el resto
   (`#[cfg(not(windows))]`): imprime «`pcode wsl` solo tiene sentido en Windows» y devuelve 2.
2. `doctor_line(list)` (pura): sin versión 2 → `"✗ WSL2 no hay distribuciones (sandbox N1 no disponible; se usa N0)"`;
   con alguna → `"✓ WSL2 <nombre> (sandbox N1 con `pcode wsl`)"` con la que elegiría `pick_distro(list, None)`.
3. `main.rs`: orden `Wsl(wsl::WslArgs)` con doc «Ejecuta pcode dentro de WSL2 (Windows)» y su brazo
   `Some(Cmd::Wsl(a)) => std::process::exit(wsl::run(a).await?)`.
4. `doctor.rs`: solo en Windows (`#[cfg(windows)]`), tras la línea de la sandbox, ejecuta `wsl.exe -l -v` y escribe
   `doctor_line`; si `wsl.exe` no existe, nada.

```rust
// crates/pcode-cli/src/wsl.rs (además de lo de F5.27a)
/// Argumentos de `pcode wsl`.
#[derive(Debug, clap::Args)]
pub struct WslArgs {
    /// Distribución (por defecto, la predeterminada si es WSL2).
    #[arg(long = "distro")]
    pub distro: Option<String>,
    /// Argumentos para `pcode` dentro de WSL (tras `--`).
    #[arg(last = true)]
    pub args: Vec<String>,
}

/// Ejecuta `pcode` dentro de WSL2; devuelve el código de salida.
pub async fn run(a: WslArgs) -> anyhow::Result<i32>;

/// Línea de `pcode doctor` sobre WSL2.
pub fn doctor_line(list: &[WslDistro]) -> String;
```

## Tests (con estos nombres)
