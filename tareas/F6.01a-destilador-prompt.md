## Objetivo

1. Crea `distill.rs` con `AttemptPair`, `distill_prompt` y `extract_skill_md` (firmas abajo). Funciones
   puras: no llaman a ningún modelo.
2. `distill_prompt(pairs, existing_index)` devuelve, en este orden:
   a) el párrafo fijo: «Eres el destilador de skills de PublicCode. A partir de parejas (intento
      fallido, intento aceptado) de la misma tarea, escribe UNA skill reutilizable que recoja la
      decisión crítica que separa el fallo del acierto. No copies el diff: generaliza.»
   b) `## Formato de salida` con la plantilla exacta de un SKILL.md: frontmatter entre líneas `---` con
      `name:` (minúsculas y guiones), `description:` (máx. 300 caracteres), `no_usar_cuando:` y
      `procedencia: destilada de <ids separados por coma>`; después `# Título`, `## Procedimiento`,
      `## Decisión crítica` y `## Contrato` con `### Entradas`, `### Salidas` y `### Ejemplo`. Añade la
      frase: «Responde SOLO con el SKILL.md.»
   c) `## Skills existentes` + `existing_index` (o `(ninguna)` si está vacío) y la frase «Si una ya
      cubre el caso, devuelve esa skill REVISADA con el mismo `name`.»
   d) por cada pareja: `## Pareja <task_id>`, `### Intento fallido` + `failed_handoff` recortado a 1500
      caracteres, `### Resumen del intento aceptado` + `success_summary`, y `### Diff aceptado` + un
      bloque de código con `success_diff` recortado a 4000 caracteres. Al recortar, corta por carácter
      (no por byte) y añade `…`.
   La línea `procedencia` de la plantilla lleva los `task_id` reales de `pairs`.
3. `extract_skill_md(reply)`: devuelve el texto desde la primera línea que es exactamente `---` hasta el
   final, quitando una última línea que sea solo una valla de código (tres acentos graves) y los
   espacios finales, y terminado en `\n`. `None` si no hay ninguna línea `---`.
4. `lib.rs`: `pub mod distill;` y `pub use distill::{AttemptPair, distill_prompt, extract_skill_md};`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-skills/src/distill.rs
/// Un intento fallido y el intento aceptado de la misma tarea.
#[derive(Debug, Clone, PartialEq)]
pub struct AttemptPair { pub task_id: String, pub failed_handoff: String, pub success_diff: String, pub success_summary: String }

/// Prompt para el rol `destilador` (modelo fuerte).
pub fn distill_prompt(pairs: &[AttemptPair], existing_index: &str) -> String;

/// El SKILL.md contenido en la respuesta del modelo (aunque venga dentro de una valla de código).
pub fn extract_skill_md(reply: &str) -> Option<String>;
```

## Ejemplo (entrada y resultado esperado)

```
extract_skill_md("Aquí va:\n```markdown\n---\nname: x\ndescription: d\n---\n# X\n```\n")
  → Some("---\nname: x\ndescription: d\n---\n# X\n")
extract_skill_md("no puedo")  → None
```

## Tests (con estos nombres)

- `prompt_incluye_parejas_y_formato`: con dos parejas `F1.01` y `F1.02`, el prompt contiene `## Pareja F1.01`, `## Pareja F1.02`, `no_usar_cuando:` y `procedencia: destilada de F1.01, F1.02`
- `prompt_recorta_diffs_largos`: un `success_diff` de 10000 caracteres aparece recortado (el prompt mide menos de 8000 caracteres más el resto) y contiene `…`
- `prompt_sin_skills_existentes`: con `existing_index` vacío aparece `(ninguna)`
- `extrae_de_una_valla`: el primer ejemplo devuelve exactamente esa cadena
- `extrae_sin_valla`: una respuesta que empieza directamente por `---` se devuelve entera terminada en un salto de línea
- `sin_frontmatter_es_none`: `no puedo` devuelve None
