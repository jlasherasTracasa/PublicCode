## Objetivo

1. En `bench_cmd.rs`, variante nueva `Comparar { anterior: PathBuf, actual: PathBuf, umbral: f64, issue:
   Option<PathBuf> }` («Compara dos ejecuciones y avisa si la actual empeora.»): dos posicionales, `--umbral`
   (puntos porcentuales, por defecto 3.0) y `--issue <archivo>`.
2. Rama: lee los dos archivos con `parse_rows` (error de lectura o de formato → stderr y devuelve 2; mismo
   tratamiento que en `Informe`), llama a `pcode_flow::regress::compare` y genera el texto con
   `issue_markdown` (los nombres son los de los archivos sin extensión).
3. Imprime siempre el texto en stdout. Si `regressed`: con `--issue`, además lo escribe en ese archivo; imprime
   en stderr `regresión: <n> tareas empeoraron` y devuelve 2. Si no: imprime en stderr `sin regresión` y
   devuelve 0 (y no escribe el archivo de `--issue`).
4. Añade a `tests/bench.rs` los tests `comparar_*`.

Sin firmas: solo añade una variante de `BenchCmd` y su rama; la API está en `pcode_flow::regress`

## Ejemplo (entrada y resultado esperado)

```
anterior.jsonl: T1 y T2 aceptadas a la primera.   actual.jsonl: T1 aceptada, T2 fallida.
$ pcode bench comparar anterior.jsonl actual.jsonl --issue aviso.md
→ código 2; stdout contiene "# Regresión en PublicBench" y "- T2"; existe aviso.md con el mismo texto
$ pcode bench comparar anterior.jsonl anterior.jsonl --issue aviso2.md → código 0, stderr "sin regresión", no existe aviso2.md
```

## Tests (con estos nombres)

- `comparar_regresion_sale_con_2`: el primer caso del ejemplo da código 2, el texto y el archivo del aviso
- `comparar_sin_regresion_sale_con_0`: el segundo caso da código 0 y no crea el archivo
- `comparar_archivo_inexistente`: un archivo que no existe da código 2 y un error en stderr
