## Objetivo

1. En `trajectory.rs` añade `EXPORT_VERSION` y `export_jsonl` (firmas abajo).
2. `export_jsonl(sessions, out)`: por cada sesión `(id, transcripción)` escribe UNA línea JSON (con
   `serde_json::json!` y `writeln!`) con las claves, en español y estables:
   `{"version":1,"id":"<id>","tqs":<total con 3 decimales>,"elementos":[…]}`. Cada elemento es:
   - `Text(t)` → `{"tipo":"texto","texto":t}`
   - `ToolCall{name,input}` → `{"tipo":"llamada","tool":name,"entrada":input}`
   - `ToolResult{output,is_error}` → `{"tipo":"resultado","salida":output,"error":is_error}`
   `tqs` es el total de `tqs(transcripción)` redondeado a 3 decimales
   (`(x * 1000.0).round() / 1000.0`).
3. Las sesiones se escriben en el orden recibido; una lista vacía no escribe nada. Los errores de
   escritura se propagan.
4. `lib.rs`: añade `EXPORT_VERSION` y `export_jsonl` al `pub use trajectory::{…}`.
5. Tests con el prefijo `export_` escribiendo en un `Vec<u8>` y volviendo a leer cada línea con
   `serde_json::from_str::<serde_json::Value>`.

## Ejemplo (entrada y resultado esperado)

```
sesión ("s1", [Text("hola"), ToolCall{name:"leer", input:{"path":"a"}}, ToolResult{output:"x", is_error:false}])
→ una línea cuyo JSON tiene: version 1 · id "s1" · tqs entre 0 y 1 ·
  elementos[0] = {"tipo":"texto","texto":"hola"} ·
  elementos[1] = {"tipo":"llamada","tool":"leer","entrada":{"path":"a"}} ·
  elementos[2] = {"tipo":"resultado","salida":"x","error":false}
```

## Tests (con estos nombres)

- `export_formato_estable`: la sesión del ejemplo produce una línea con `version` 1, `id` s1 y los tres elementos con esas claves exactas
- `export_una_linea_por_sesion`: dos sesiones producen dos líneas, en el orden recibido, cada una JSON válido
- `export_vacio_no_escribe`: una lista vacía deja el `Vec<u8>` vacío
- `export_incluye_tqs_redondeado`: el campo `tqs` tiene como mucho 3 decimales y coincide con `tqs()` redondeado
- `export_salida_con_saltos_de_linea`: un `output` con saltos de línea sigue ocupando una sola línea del archivo
