## Objetivo

1. Crea `web_assets.rs` con la tabla `ASSETS` (vacía por ahora) y las funciones `find` y `asset` (firmas
   abajo). Un nombre es válido solo si acaba en `.js` y todo lo anterior son letras minúsculas, cifras o
   `_` (nada de `/`, `..`, mayúsculas ni cadena vacía). `find` busca el nombre en la tabla que recibe y
   devuelve `(JS_MIME, contenido)`; `asset(name)` es `find(ASSETS, name)`.
2. `lib.rs`: añade `pub mod web_assets;` (en orden alfabético, después de `pub mod settings;`).
3. `server.rs`: añade el manejador `studio_asset` justo debajo de `index` y su ruta en `router`:
   `.route("/studio/{name}", get(studio_asset))`. Si `!authorized(&st, &headers)` responde 401; si
   `crate::web_assets::asset(&name)` es `None`, 404; si no, 200 con el contenido y las cabeceras
   `content-type` (el mime devuelto), `x-content-type-options: nosniff` y `cache-control: no-cache`.
   La CSP de `index` ya permite `script-src 'self'`: no la cambies.
4. `index.html`: borra la última línea `inicio();` del `<script>` grande (la que va justo antes de
   `</script>`) y, después de ese `</script>`, añade el bloque del ejemplo. Los módulos se ejecutan
   después del script clásico, así que `inicio()` arranca ya con `window.Studio` creado.
5. Tests en `web_assets.rs` (`#[cfg(test)] mod tests`) y en el módulo `tests` de `server.rs`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/web_assets.rs
/// Tipo MIME de los módulos de Studio.
pub const JS_MIME: &str = "text/javascript; charset=utf-8";

/// Módulos de Studio embebidos en el binario: (nombre, contenido). Una línea por módulo:
/// `("difusa.js", include_str!("../web/studio/difusa.js")),`
pub const ASSETS: &[(&str, &str)] = &[];

/// Busca `name` en `table`. `None` si el nombre no es válido o no está.
pub fn find(table: &[(&'static str, &'static str)], name: &str) -> Option<(&'static str, &'static str)>;

/// Módulo de Studio por su nombre (lo que va detrás de `/studio/`): (mime, contenido).
pub fn asset(name: &str) -> Option<(&'static str, &'static str)>;

// crates/pcode-server/src/server.rs
async fn studio_asset(
    State(st): State<Arc<AppState>>,
    headers: HeaderMap,
    axum::extract::Path(name): axum::extract::Path<String>,
) -> Response;
```

## Ejemplo (entrada y resultado esperado)

```
<!-- index.html, justo después del </script> del script grande y antes de </body> -->
<script type="module">
// Módulos de Studio (crates/pcode-server/web/studio/<x>.js, servidos en /studio/<x>.js).
// Una línea por módulo, antes de inicio():  import * as x from "/studio/x.js"; Studio.x = x;
window.Studio = {};
inicio();
</script>

find(&[("a_b.js", "export const X = 1;")], "a_b.js")   -> Some((JS_MIME, "export const X = 1;"))
find(&[("a_b.js", "…")], "../a_b.js")                  -> None
find(&[("a_b.js", "…")], "otro.js")                    -> None
```

## Tests (con estos nombres)

- `find_devuelve_mime_y_contenido`: con la tabla del ejemplo, `a_b.js` da `JS_MIME` y su contenido
- `find_rechaza_nombres_no_validos`: `../a_b.js`, `a/b.js`, `A.js`, `a.css`, `.js` y la cadena vacía dan `None` aunque estén en la tabla
- `find_desconocido_es_none`: un nombre válido que no está en la tabla da `None`
- `index_solo_importa_modulos_registrados`: cada `"/studio/<nombre>"` que aparece en `include_str!("../web/index.html")` existe según `asset`
- `web_modulo_desconocido_404`: en `server.rs`, GET `/studio/no_existe.js` sin token configurado responde 404
- `web_modulo_sin_token_401`: en `server.rs`, con `app(Some("tk"), …)`, GET `/studio/no_existe.js` sin cabeceras responde 401

## Notas

`index_solo_importa_modulos_registrados` pasa hoy porque `index.html` aún no importa nada; protege a
las tareas siguientes: si alguien importa `/studio/x.js` sin registrarlo en `ASSETS`, el test falla.
Clippy acepta la tabla vacía; si se queja de `find` sin usar, no lo marques con `#[allow]`: `asset` la usa.
