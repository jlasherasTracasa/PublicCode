## Objetivo

1. Crea `package.json` en `crates/pcode-server/web/studio/` con exactamente `{ "private": true, "type": "module" }`
   (no es un paquete npm: solo dice a Node que los `.js` de esa carpeta son módulos ES; sin dependencias).
2. Crea `test.sh` en `tools/studio/` (ejecutable, `chmod +x`) con el contenido del ejemplo. Ojo: en Node 22
   `node --test <carpeta>/` falla; hay que pasar el patrón entre comillas `"…/test/*.test.js"`.
3. Crea `arnes.test.js` con tres tests (`node:test`, `node:assert/strict`, `node:fs`, `node:path`). La
   carpeta de módulos es `path.join(import.meta.dirname, "..")`; los módulos son sus archivos `*.js`
   (sin entrar en `test/`).
4. `ci.yml`: añade al final de `jobs:` el job `studio` del ejemplo.

Sin firmas: arnés de tests y CI: no añade API; el contenido exacto está en el ejemplo

## Ejemplo (entrada y resultado esperado)

```
#!/bin/sh
# tools/studio/test.sh: tests de los módulos de Studio con el runner nativo de Node (sin npm).
set -eu
cd "$(dirname "$0")/../.."
command -v node >/dev/null 2>&1 || { echo "falta node (>= 22)" >&2; exit 1; }
node -e 'process.exit(Number(process.versions.node.split(".")[0]) >= 22 ? 0 : 1)' || { echo "hace falta node >= 22" >&2; exit 1; }
exec node --test "crates/pcode-server/web/studio/test/*.test.js"

# .github/workflows/ci.yml
  studio:
    name: Studio (módulos JS con node --test)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: tools/studio/test.sh
```

## Tests (con estos nombres)

- `cada_modulo_tiene_su_test`: para cada `<x>.js` de la carpeta de módulos existe `test/<x>.test.js`; con cero módulos pasa
- `los_modulos_no_importan_nada`: ningún `<x>.js` de la carpeta contiene `import ` al principio de una línea ni `require(`
- `package_json_declara_modulos_es`: `package.json` tiene `type` igual a `module` y no tiene `dependencies` ni `devDependencies`

## No hagas

- No ejecutes `npm` ni añadas dependencias
- No toques `tools/studio/e2e.js`
- No cambies los demás jobs de `ci.yml`
