## Objetivo

1. Crea `plegado.js` con las cinco funciones de las firmas. Las líneas se numeran desde 0 y salen de
   `text.split("\n")`. La sangría de una línea es su ancho en columnas: un espacio suma 1 y un tabulador
   lleva a la siguiente columna múltiplo de `tabSize`. Una línea en blanco (vacía o solo espacios) no
   tiene sangría: nunca empieza un rango y no corta un bloque.
2. `foldRanges`: la línea `i` (no en blanco) empieza un rango si la siguiente línea no en blanco tiene
   más sangría que ella. `end` es la última línea no en blanco anterior a la primera línea no en blanco
   con sangría menor o igual que la de `i` (o la última no en blanco del texto). Devuelve los rangos
   ordenados por `start`.
3. `project(text, ranges, folded)`: `folded` es una lista de `start`. Quita las líneas `start+1..=end` de
   cada rango plegado (los `start` que no correspondan a ningún rango se ignoran; los rangos anidados no
   quitan dos veces). Devuelve `{ shown, lines }`: `shown` es el texto que queda y `lines[i]` es el número
   de línea real de la línea `i` de `shown`.
4. `toRealOffset` y `toShownOffset` convierten posiciones (índices de carácter) entre `shown` y `text`
   usando `lines`. Si la posición real cae en una línea oculta, `toShownOffset` devuelve el final de la
   línea visible anterior (la cabecera del pliegue). `rangeAt` devuelve el rango más interno (el de
   `start` mayor) que contiene la línea, o `null`.
5. Crea `plegado.test.js` con los tests de la lista (importa de `../plegado.js`).

## Ejemplo (entrada y resultado esperado)

```
const T = "fn a() {\n    if x {\n        y();\n    }\n}\n\nfn b() {}\n";   // 8 líneas (la última, vacía)
foldRanges(T)                         -> [{ start: 0, end: 3 }, { start: 1, end: 2 }]
project(T, foldRanges(T), [1])        -> { shown: "fn a() {\n    if x {\n    }\n}\n\nfn b() {}\n", lines: [0, 1, 3, 4, 5, 6, 7] }
project(T, foldRanges(T), [0, 1])     -> { shown: "fn a() {\n}\n\nfn b() {}\n", lines: [0, 4, 5, 6, 7] }
toRealOffset(T, [0, 1, 3, 4, 5, 6, 7], 20)   -> 33    (inicio de la línea real 3)
toShownOffset(T, [0, 1, 3, 4, 5, 6, 7], 33)  -> 20
toShownOffset(T, [0, 1, 3, 4, 5, 6, 7], 25)  -> 19    (línea 2 oculta: final de la línea 1)
rangeAt(foldRanges(T), 2)             -> { start: 1, end: 2 }
```

## Tests (con estos nombres)

- `rangos_por_sangria`: el texto `T` del ejemplo da los dos rangos del ejemplo
- `rangos_de_python`: `def f():\n    a\n\n    b\nc\n` da un solo rango `{ start: 0, end: 3 }` (la línea en blanco no corta el bloque)
- `tabuladores_cuentan_como_sangria`: `a\n\tb\nc` da `{ start: 0, end: 1 }`
- `sin_bloques_no_hay_rangos`: `a\nb\nc` y la cadena vacía dan `[]`
- `proyectar_oculta_lineas_y_numeracion_sigue`: `project(T, r, [1])` da el `shown` y `lines` del ejemplo
- `plegados_anidados_no_quitan_dos_veces`: `project(T, r, [0, 1])` da el resultado del ejemplo
- `sin_plegados_es_identidad`: `project(T, r, [])` devuelve `shown === T` y `lines` de 0 a 7
- `offsets_ida_y_vuelta`: los tres casos de `toRealOffset` y `toShownOffset` del ejemplo
- `rango_mas_interno`: `rangeAt(r, 2)` es el rango de `start` 1 y `rangeAt(r, 6)` es `null`
