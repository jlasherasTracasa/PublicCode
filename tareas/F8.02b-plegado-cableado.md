## Objetivo

El editor es un `<textarea id="ta">` y todo el código usa `ta.value` como texto real. Por eso el plegado
es una **vista de solo lectura**: con algo plegado, `ta` muestra la proyección y `ta.readOnly = true`; el
texto real sigue en `t.content`. En cuanto el usuario teclea o una función necesita posiciones reales,
se despliega todo.
1. `web_assets.rs`: añade `("plegado.js", include_str!("../web/studio/plegado.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as plegado from "/studio/plegado.js"; Studio.plegado = plegado;`.
2. HTML y CSS: dentro de `#gutter`, tras `<div id="capa-git"></div>`, añade `<div id="capa-pliegue"></div>`.
   CSS: `#capa-pliegue .pl { position: absolute; left: 2px; height: 21px; cursor: pointer; }` y
   `.editor.plegado .capa-diag, .editor.plegado #capa-git { display: none; }`.
3. Debajo de `repinta` añade (estado: `t.plegadas`, lista de `start` por pestaña; `S.pliegue`, la
   proyección activa o `null`):
   - `aplicaPlegado()`: con `t = tabActiva()` de tipo `file`; si `t.plegadas?.length`, calcula
     `r = Studio.plegado.foldRanges(t.content)` y `S.pliegue = Studio.plegado.project(t.content, r, t.plegadas)`,
     pone `ta.value = S.pliegue.shown` y `ta.readOnly = true`; si no, `S.pliegue = null`,
     `ta.readOnly = false` y `ta.value = t.content`. Después: `$("editor").classList.toggle("plegado", !!S.pliegue)`,
     `gutter.dataset.n = ""`, `repinta()`, `sincroniza()`, `pintaPliegues()`.
   - `despliegaTodo()`: si `!S.pliegue`, no hace nada; si no, guarda
     `pos = Studio.plegado.toRealOffset(t.content, S.pliegue.lines, ta.selectionStart)`, vacía `t.plegadas`,
     llama a `aplicaPlegado()` y hace `ta.setSelectionRange(pos, pos)`.
   - `alternaPliegue(start)`: oculta `#buscador`, añade o quita `start` de `t.plegadas` (créala si falta) y
     llama a `aplicaPlegado()`.
   - `pintaPliegues()`: vacía `#capa-pliegue`; si el texto pasa de 300000 caracteres, sale. Para cada rango
     de `foldRanges(t.content)` cuyo `start` sea visible (`fila = S.pliegue ? S.pliegue.lines.indexOf(start) : start`,
     `fila >= 0`) añade `el("div", "pl", plegado ? "▸" : "▾")` con `style.top = fila * 21 + "px"` y
     `onclick = () => alternaPliegue(start)`.
4. Cambios en funciones existentes:
   - `muestra`: justo después de `ta.value = t.content;` añade `aplicaPlegado();`.
   - `repinta`: si `S.pliegue`, `#numeros` muestra `S.pliegue.lines.map((l) => l + 1).join("\n")`; al final
     llama a `pintaPliegues()` solo cuando cambie el número de líneas (dentro del `if` que ya existe).
   - `posicion`: la línea que se muestra es `S.pliegue ? S.pliegue.lines[antes.length - 1] + 1 : antes.length`.
   - Primera línea de `irALinea`, `selecciona`, `posCursor`, `selLineas`, `preguntaSeleccion` y de
     `buscador` (solo si `abrir`): `despliegaTodo();`. En `posRaton`: `if (S.pliegue) return null;`.
   - Primer `ta.addEventListener("keydown"` (el de Tab e Intro), al principio:
     `if (S.pliegue && !e.ctrlKey && !e.metaKey && !e.altKey && (e.key.length === 1 || ["Enter", "Backspace", "Delete", "Tab"].includes(e.key))) despliegaTodo();`.
5. Atajos, en el `document.addEventListener("keydown"` final, antes de la rama de `k === "s"`:
   Ctrl+Mayús+`[` (`e.code === "BracketLeft"`) pliega el rango de la línea del cursor
   (`Studio.plegado.rangeAt(rangos, lineaReal)`), Ctrl+Mayús+`]` (`e.code === "BracketRight"`) llama a
   `despliegaTodo()`. Añade a `ORDENES`: `["Plegar el bloque del cursor", "Ctrl Mayús [", …]` y
   `["Desplegar todo", "Ctrl Mayús ]", () => despliegaTodo()]`.

futura que edite `ta.value` debe llamar antes a `despliegaTodo()`.
