## Objetivo

1. Crea `minimapa.js` con las cuatro funciones de las firmas (sin DOM: solo números y cadenas).
2. `rows(text, maxRows)`: las líneas salen de `text.split("\n")`. Si hay `maxRows` líneas o menos, una
   fila por línea; si hay más, exactamente `maxRows` filas y la fila `i` describe la línea
   `Math.floor(i * total / maxRows)`. Cada fila es `{ indent, length }` en columnas (tabulador = hasta el
   siguiente múltiplo de 4): `indent` es el ancho de los espacios iniciales y `length` el ancho de la
   línea sin los espacios finales (0 para una línea en blanco, con `indent` 0).
3. `usedHeight(totalLines, mapHeight)` = `Math.min(mapHeight, totalLines * 3)` (3 px por línea como mucho).
   `viewport(scrollTop, clientHeight, totalLines, lineHeight, used)` devuelve `{ top, height }` en píxeles
   del minimapa: `top = used * scrollTop / (totalLines * lineHeight)` y
   `height = Math.max(8, used * clientHeight / (totalLines * lineHeight))`, recortados para que
   `0 <= top` y `top + height <= used` (si `height > used`, `height = used` y `top = 0`).
4. `lineAt(y, used, totalLines)` = `Math.floor(y / used * totalLines) + 1`, recortado a `1..=totalLines`.
5. Crea `minimapa.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
rows("a\n    bb  \n", 10)            -> [{ indent: 0, length: 1 }, { indent: 4, length: 6 }, { indent: 0, length: 0 }]
rows("0\n1\n2\n3\n4\n5\n6\n7", 4)      -> 4 filas: las de las líneas 0, 2, 4 y 6
usedHeight(50, 300) -> 150           usedHeight(1000, 300) -> 300
viewport(0, 420, 100, 21, 300)       -> { top: 0, height: 60 }

viewport(0, 420, 10, 21, 30)         -> { top: 0, height: 30 }
lineAt(150, 300, 100) -> 51          lineAt(-5, 300, 100) -> 1          lineAt(999, 300, 100) -> 100
```
