## Objetivo

1. `web_assets.rs`: añade `("minimapa.js", include_str!("../web/studio/minimapa.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as minimapa from "/studio/minimapa.js"; Studio.minimapa = minimapa;`.
2. HTML: dentro de `<div class="codigo">`, después del `<textarea id="ta">`, añade
   `<canvas id="minimapa" class="minimapa" width="80" aria-hidden="true"></canvas>`.
   CSS: `.minimapa { position: absolute; top: 0; right: 0; width: 80px; height: 100%; cursor: pointer; }`,
   `.codigo pre, .codigo textarea { padding-right: 96px; }` (añade solo esa propiedad, después de la regla
   existente) y `@media (max-width: 1100px) { .minimapa { display: none; } }`.
3. Debajo de `sincroniza` añade `let filasMapa = [];` y `function pintaMinimapa()`: toma `c = $("minimapa")`;
   si `c.clientHeight === 0`, sale; ajusta `c.height = c.clientHeight` si difiere; borra con `clearRect`;
   `total = ta.value.split("\n").length`, `used = Studio.minimapa.usedHeight(total, c.height)`,
   `alto = used / filasMapa.length`. Para cada fila `i` con `length > indent` dibuja
   `fillRect(4 + indent * 0.6, i * alto, Math.min(72 - indent * 0.6, (length - indent) * 0.6), Math.max(1, alto - 1))`
   con el color de la variable CSS `--ed-gutter`
   (`getComputedStyle(document.documentElement).getPropertyValue("--ed-gutter")`). Después dibuja la zona
   visible: `v = Studio.minimapa.viewport(ta.scrollTop, ta.clientHeight, total, 21, used)` como
   `fillRect(0, v.top, 80, v.height)` con `--ed-sel` y `globalAlpha = 0.5`.
4. Enganches: al final de `repinta`, `filasMapa = Studio.minimapa.rows(ta.value, 400); pintaMinimapa();`;
   al final de `sincroniza`, `pintaMinimapa();`. Clic:
   `$("minimapa").addEventListener("mousedown", (e) => { … })` calcula
   `n = Studio.minimapa.lineAt(e.offsetY, used, total)` y hace `ta.scrollTop = Math.max(0, (n - 8) * 21)`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
