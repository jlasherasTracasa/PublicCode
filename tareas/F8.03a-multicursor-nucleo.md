## Objetivo

Una selección es `{ a, b }` con `a <= b` (índices de carácter; `a === b` es un cursor).
1. Crea `multicursor.js` con las funciones de las firmas.
2. `normalize(sels)`: copia ordenada por `a`; quita las repetidas y las que solapan con una anterior
   (`a` menor que el `b` de la anterior; dos cursores en el mismo punto son repetidos).
3. `wordAt(text, offset)`: rango de la palabra (`[A-Za-z0-9_]`) que toca `offset` por la izquierda o la
   derecha; sin palabra, `{ a: offset, b: offset }`.
4. `nextOccurrence(text, sels)`: busca el texto de la **última** selección de `sels` (exacto, distingue
   mayúsculas) a partir de su `b`, y al llegar al final sigue desde 0. Devuelve la primera aparición que no
   esté ya en `sels`, o `null` (también `null` si la última selección está vacía).
   `allOccurrences(text, a, b)`: todas las apariciones sin solape de `text.slice(a, b)`, en orden; `[]` si `a === b`.
5. `applyEdit(text, sels, edit)`: aplica a `normalize(sels)` de izquierda a derecha acumulando el
   desplazamiento. `{ type: "insert", text }` sustituye cada selección por el texto; `{ type: "backspace" }`
   borra la selección o, si es un cursor, el carácter anterior (nada en la posición 0);
   `{ type: "delete" }` borra la selección o el carácter siguiente (nada al final). Devuelve
   `{ text, sels }` con un cursor por selección en su posición final.
6. `caretVertical(text, sels, dir)`: con `dir = 1` parte de la selección de mayor `b`; con `dir = -1`, de la
   de menor `a`. Devuelve un cursor en la línea siguiente (o anterior) en la misma columna, recortada al
   largo de esa línea; `null` si no hay línea. `toggleCaret(sels, offset)`: si ya hay un cursor en
   `offset` lo quita; si no, lo añade; devuelve una lista nueva.
7. Crea `multicursor.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const T = "foo bar foo baz foo";
wordAt(T, 5)                                               -> { a: 4, b: 7 }
nextOccurrence(T, [{ a: 0, b: 3 }])                        -> { a: 8, b: 11 }
nextOccurrence(T, [{ a: 0, b: 3 }, { a: 8, b: 11 }])       -> { a: 16, b: 19 }
nextOccurrence(T, [{ a: 8, b: 11 }, { a: 16, b: 19 }])     -> { a: 0, b: 3 }      (da la vuelta)
nextOccurrence(T, [{ a: 0, b: 3 }, { a: 8, b: 11 }, { a: 16, b: 19 }]) -> null
allOccurrences(T, 0, 3)                                    -> [{ a: 0, b: 3 }, { a: 8, b: 11 }, { a: 16, b: 19 }]
applyEdit("foo bar foo", [{ a: 8, b: 11 }, { a: 0, b: 3 }], { type: "insert", text: "x" })
                                                           -> { text: "x bar x", sels: [{ a: 1, b: 1 }, { a: 7, b: 7 }] }
applyEdit("foo bar foo", [{ a: 3, b: 3 }, { a: 11, b: 11 }], { type: "backspace" })
                                                           -> { text: "fo bar fo", sels: [{ a: 2, b: 2 }, { a: 9, b: 9 }] }
applyEdit("ab", [{ a: 0, b: 0 }, { a: 2, b: 2 }], { type: "delete" }) -> { text: "b", sels: [{ a: 0, b: 0 }, { a: 1, b: 1 }] }
caretVertical("abcd\nxy\nabcdef", [{ a: 3, b: 3 }], 1)     -> { a: 7, b: 7 }       (línea 1, columna recortada a 2)
caretVertical("abcd\nxy", [{ a: 6, b: 6 }], 1)             -> null
```

## Tests (con estos nombres)

- `normaliza_ordena_y_quita_solapes`: `[{a:5,b:8},{a:0,b:3},{a:2,b:6},{a:0,b:3}]` da `[{a:0,b:3},{a:5,b:8}]`
- `palabra_bajo_el_cursor`: `wordAt(T, 5)` y `wordAt(T, 7)` dan `{a:4,b:7}`; en `"a  b"`, posición 2, da `{a:2,b:2}`
- `ctrl_d_añade_siguiente_aparicion`: los cuatro casos de `nextOccurrence` del ejemplo
- `todas_las_apariciones`: el caso de `allOccurrences` del ejemplo y `[]` con `a === b`
- `escribir_en_tres_cursores`: insertar `x` en las tres apariciones de `foo` en `T` da `x bar x baz x` y cursores en 1, 7 y 13
- `borrar_hacia_atras_en_varios_cursores`: el caso de `backspace` del ejemplo; un cursor en 0 no borra nada
- `suprimir_en_varios_cursores`: el caso de `delete` del ejemplo
- `columna_de_cuatro_lineas`: en `"aaaa\nbbbb\ncccc\ndddd"`, tres llamadas seguidas a `caretVertical(…, 1)` desde `{a:2,b:2}` (añadiendo cada resultado a `sels`) dan cursores en 7, 12 y 17
- `alt_clic_añade_y_quita`: `toggleCaret([], 4)` da `[{a:4,b:4}]` y `toggleCaret([{a:4,b:4}], 4)` da `[]`
