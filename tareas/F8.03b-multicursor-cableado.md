## Objetivo

La selección nativa del `<textarea id="ta">` es la principal; las demás van en `S.multi` (lista de
`{ a, b }`, en el orden en que se añaden).
1. `web_assets.rs`: añade `("multicursor.js", include_str!("../web/studio/multicursor.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as multicursor from "/studio/multicursor.js"; Studio.multicursor = multicursor;`.
2. HTML y CSS: dentro de `<div class="codigo">`, después de `#capa-diag`, añade
   `<div id="capa-multi" class="capa-diag" aria-hidden="true"></div>`. CSS:
   `.mc { position: absolute; height: 21px; background: var(--ed-sel); border-right: 2px solid var(--primario); }`.
   En `sincroniza`, aplica a `$("capa-multi")` el mismo `transform` que a `$("capa-diag")`.
3. Justo antes del primer `ta.addEventListener("keydown"` añade `S.multi = [];` y las funciones:
   - `pintaMulti()`: vacía `#capa-multi`; para cada selección de `S.multi` calcula línea y columnas de
     `a` y `b` (`ta.value.slice(0, a).split("\n")`) y añade `el("div", "mc")` con
     `top = 10 + linea * 21`, `left = 16 + colVisual(l, colA) * cw` y
     `width = Math.max(2, (colVisual(l, colB) - colVisual(l, colA)) * cw)` (`cw = medirCaracter()`; si la
     selección ocupa varias líneas, dibuja solo un cursor de 2 px en `b`). Termina con `sincroniza()`.
   - `limpiaMulti()`: si `S.multi.length`, la vacía y llama a `pintaMulti()`.
   - `editaMulti(edit)`: `r = Studio.multicursor.applyEdit(ta.value, [{ a: ta.selectionStart, b: ta.selectionEnd }, ...S.multi], edit)`;
     `ta.value = r.text`; la primera de `r.sels` pasa a ser la selección nativa (`setSelectionRange`) y el
     resto, `S.multi`; después `ta.dispatchEvent(new Event("input"))` y `pintaMulti()`.
4. En ese primer manejador de `keydown`, al principio y antes de las ramas de Tab e Intro:
   - Ctrl+D (o Cmd+D): `e.preventDefault()`. Si no hay selección, selecciona la palabra con `wordAt`. Si la
     hay, `n = Studio.multicursor.nextOccurrence(ta.value, [{ a, b }, ...S.multi])` y, si no es `null`,
     `S.multi.push(n); pintaMulti();`.
   - Ctrl+Mayús+L: `S.multi = allOccurrences(v, a, b)` sin la selección nativa; `pintaMulti()`.
   - Con `S.multi.length`: Tab → `editaMulti({ type: "insert", text: "    " })`; Intro →
     `editaMulti({ type: "insert", text: "\n" })` (ambas con `preventDefault` y `return`); Escape, flechas,
     Inicio, Fin, RePág y AvPág → `limpiaMulti()` sin `preventDefault`.
5. Añade `ta.addEventListener("beforeinput", (e) => { … })`: si `!S.multi.length`, sale. Según
   `e.inputType`: `insertText`, `insertFromPaste` e `insertReplacementText` →
   `{ type: "insert", text: e.data ?? e.dataTransfer?.getData("text/plain") ?? "" }`; `insertLineBreak` →
   insertar `"\n"`; `deleteContentBackward` → `backspace`; `deleteContentForward` → `delete`; cualquier
   otro → `limpiaMulti()` y sale. En los casos tratados: `e.preventDefault(); editaMulti(edit);`.
6. `ta.addEventListener("mousedown", (e) => { if (!e.altKey) limpiaMulti(); });` y, en `activa`, `S.multi = [];`
   antes de `pintaPestanas()`. Añade a `ORDENES`:
   `["Añadir la siguiente aparición a la selección", "Ctrl D", …]` y `["Seleccionar todas las apariciones", "Ctrl Mayús L", …]`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
