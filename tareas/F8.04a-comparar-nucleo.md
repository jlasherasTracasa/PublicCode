## Objetivo

1. Crea `comparar.js` con las tres funciones de las firmas.
2. `diffLines(a, b)`: parte cada texto con `split("\n")` y, si el texto acaba en salto de línea, descarta
   el último elemento vacío. Quita el prefijo y el sufijo comunes (filas `same`). Para el tramo central usa
   la subsecuencia común más larga (tabla de programación dinámica en un `Uint32Array` de
   `(n + 1) * (m + 1)`); si `n * m > 4000000`, no calcules la tabla: todas las líneas centrales de `a` son
   `del` y todas las de `b` son `add`. Dentro de un bloque de cambios van primero las `del` y luego las `add`.
   Cada fila es `{ kind, left, right, text }` con números de línea desde 1 (`null` en el lado que no existe).
3. `sideBySide(rows)`: devuelve pares `{ left, right }` donde cada lado es `{ n, text, kind }` o `null`.
   Una fila `same` da un par con los dos lados. En un bloque de cambios, la `del` número `k` se empareja
   con la `add` número `k`; las que sobran van con el otro lado a `null`.
4. `stats(rows)` devuelve `{ added, removed }` (número de filas `add` y `del`).
5. Crea `comparar.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
diffLines("uno\ndos\ntres\n", "uno\n2\ntres\ncuatro\n") ->
  [ { kind: "same", left: 1, right: 1, text: "uno" },
    { kind: "del",  left: 2, right: null, text: "dos" },
    { kind: "add",  left: null, right: 2, text: "2" },
    { kind: "same", left: 3, right: 3, text: "tres" },
    { kind: "add",  left: null, right: 4, text: "cuatro" } ]
sideBySide(esas filas) ->
  [ { left: { n: 1, text: "uno", kind: "same" },  right: { n: 1, text: "uno", kind: "same" } },
    { left: { n: 2, text: "dos", kind: "del" },   right: { n: 2, text: "2", kind: "add" } },
    { left: { n: 3, text: "tres", kind: "same" }, right: { n: 3, text: "tres", kind: "same" } },
    { left: null,                                 right: { n: 4, text: "cuatro", kind: "add" } } ]
stats(esas filas) -> { added: 2, removed: 1 }
```

## Tests (con estos nombres)

- `textos_iguales_son_todo_same`: `diffLines("a\nb\n", "a\nb\n")` da dos filas `same` y `stats` da ceros
- `cambio_añadido_y_quitado`: el caso del ejemplo da exactamente esas cinco filas
- `texto_vacio_contra_texto`: `diffLines("", "a\nb")` da dos filas `add` con `right` 1 y 2
- `lcs_conserva_lineas_comunes_en_medio`: `diffLines("a\nb\nc\nd", "x\nb\nc\ny")` deja `b` y `c` como `same`
- `dos_columnas_emparejan_cambios`: `sideBySide` del ejemplo da los cuatro pares
- `sobrantes_van_con_null`: tres `del` seguidas de una `add` dan tres pares; solo el primero tiene `right`
- `entrada_enorme_no_calcula_tabla`: dos textos de 2100 líneas todas distintas terminan en menos de 2 s y dan 2100 `del` y 2100 `add`
