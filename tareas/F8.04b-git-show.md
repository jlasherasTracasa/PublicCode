## Objetivo

1. `workspace.rs`: añade `git_show` debajo de `git_diff` (firma abajo). Valida la ruta con
   `safe_path(root, rel)?`. `rev` solo puede tener letras, cifras y `. _ / ~ ^ -`, no puede estar vacía ni
   empezar por `-`; si no cumple, `Err(format!("revisión no válida: {rev}"))`. Quita de `rel` las barras
   iniciales y ejecuta `git(root, &["show", &format!("{rev}:./{rel}")])` (el `./` hace la ruta relativa a
   `root` aunque `root` sea una subcarpeta del repositorio).
2. `lib.rs` de `pcode-protocol`: en `pub mod methods`, después de `GIT_DIFF`, añade
   `/// Contenido de un archivo en una revisión: `{path, rev?}` → `string` (`rev` por defecto `HEAD`).`
   y `pub const GIT_SHOW: &str = "git.show";`.
3. `server.rs`: en el `match` de `rpc`, después de la rama `methods::GIT_DIFF`, añade la rama
   `methods::GIT_SHOW`: `root = st.repo.clone()`, `rel = str_param(&p, "path")`, `rev = str_param(&p, "rev")`
   (si está vacía, `"HEAD"`), y responde con
   `ws_reply(id, blocking(move || crate::workspace::git_show(&root, &rel, &rev)).await)`.
4. Tests en el módulo `tests` de `workspace.rs`, usando `repo()` (ya tiene `src/main.rs` confirmado).

## Firmas (cópialas tal cual)

## Ejemplo (entrada y resultado esperado)

```
// repo() confirma src/main.rs con "fn main() {\n    println!(\"hola\");\n}\n"
std::fs::write(d.path().join("src/main.rs"), "fn main() {}\n").unwrap();
git_show(d.path(), "src/main.rs", "HEAD")        -> Ok("fn main() {\n    println!(\"hola\");\n}\n")
git_show(d.path(), "src/main.rs", "--output=x")  -> Err("revisión no válida: --output=x")
git_show(d.path(), "../fuera.txt", "HEAD")       -> Err(…)   // lo rechaza safe_path
```

## Tests (con estos nombres)

- `git_show_devuelve_la_version_de_head`: tras cambiar el archivo en disco, `git_show(…, "HEAD")` devuelve el contenido confirmado

- `git_show_archivo_que_no_esta_en_head`: un archivo nuevo sin confirmar da `Err`
