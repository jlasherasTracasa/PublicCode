## Objetivo

1. `web_assets.rs`: añade `("comparar.js", include_str!("../web/studio/comparar.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as comparar from "/studio/comparar.js"; Studio.comparar = comparar;`.
2. HTML y CSS: después de `<div id="vista-diff" …></div>` añade
   `<div id="vista-cmp" class="cmp oculto" aria-label="Comparación"></div>`. CSS:
   `.cmp { position: absolute; inset: 0; overflow: auto; font: 13px/20px var(--mono); color: var(--ed-texto); background: var(--ed-fondo); }`,
   `.cmp .fila { display: grid; grid-template-columns: 1fr 1fr; }`,
   `.cmp .c { white-space: pre; overflow: hidden; padding: 0 8px; border-right: 1px solid var(--linea); }`,
   `.cmp .c.add { background: var(--ok-fondo); }`, `.cmp .c.del { background: var(--error-fondo); }`,
   `.cmp .c.hueco { background: var(--superficie-3); }`, `.cmp .n { display: inline-block; width: 4ch; color: var(--ed-gutter); }`.
3. Debajo de `pintaDiff` añade:
   - `abreComparacion(titulo, izq, der)`: crea o reutiliza la pestaña `{ id: "c:" + titulo, kind: "cmp", path: titulo, filas }`
     con `filas = Studio.comparar.sideBySide(Studio.comparar.diffLines(izq, der))` y la activa con `activa(id)`.
   - `pintaComparacion(t)`: vacía `#vista-cmp`; si ninguna fila tiene cambios, muestra
     `el("div", "meta", "Los dos archivos son iguales.")`; si no, por cada par añade `el("div", "fila")` con
     dos celdas: `el("div", "c " + kind)` con `el("span", "n", n)` y el texto como nodo de texto, o
     `el("div", "c hueco", " ")` si el lado es `null`. Nunca uses `innerHTML`.
   - `async comparaCon(path)`: con `t = tabActiva()`; si no es de tipo `file`,
     `aviso("Abre primero el archivo con el que quieres comparar")`. Si lo es: izquierda `t.content`,
     derecha `(await rpc("fs.read", { path })).content`, título `base(t.path) + " ↔ " + base(path)`.
   - `async comparaHead(path)`: izquierda `await rpc("git.show", { path, rev: "HEAD" })`; derecha, el
     `content` de la pestaña abierta de ese archivo o, si no está abierta, `fs.read`; título
     `base(path) + " (HEAD ↔ actual)"`. Los errores van a `fallo(e)`.
4. `cargaDir`: en la lista de `menu(…)` de `fila.oncontextmenu`, solo para archivos (`!it.dir`), añade
   antes de la entrada de borrar: `["Comparar con el archivo abierto", () => comparaCon(it.path)]` y
   `["Comparar con HEAD", () => comparaHead(it.path)]`.
5. `muestra`: añade `$("vista-cmp").classList.toggle("oculto", !t || t.kind !== "cmp");` junto a la línea de
   `vista-diff`, y antes de `if (t.kind === "diff") pintaDiff(t);` añade
   `if (t.kind === "cmp") { pintaComparacion(t); marcaArbol(); return; }`. `pintaPestanas`: el texto de una
   pestaña `cmp` es `"⇄ " + t.path`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
