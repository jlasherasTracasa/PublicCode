## Objetivo

El estado es `{ tabs, active, right }`: `tabs` es la lista de ids de pestañas en orden, `active` el id de
la pestaña del editor (o `null`) y `right` el id de la pestaña que se ve en el panel derecho (o `null` si
el editor no está dividido). Las funciones devuelven un estado nuevo y no modifican el que reciben.
1. Crea `division.js` con las tres funciones de las firmas.
2. `split(state)`: si `right` no es `null`, lo pone a `null` (cierra la división). Si es `null` y hay
   `active`, `right = active` (el mismo archivo en los dos lados). Sin `active`, devuelve el estado igual.
3. `close(state, id)`: quita `id` de `tabs`. Si `id` era `right`, `right = null`. Si `id` era `active`, el
   nuevo `active` es la pestaña que queda en la misma posición, o la anterior, o `null`. Si después de
   cerrar `right` es igual a `active` y solo queda esa pestaña, `right = null` (los grupos se unen). Un `id`
   que no está en `tabs` deja el estado igual.
4. `swap(state)`: si `right` no es `null` y es distinto de `active`, intercambia `active` y `right`; si no,
   devuelve el estado igual.
5. Crea `division.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
split({ tabs: ["a", "b"], active: "a", right: null })   -> { tabs: ["a", "b"], active: "a", right: "a" }
split({ tabs: ["a", "b"], active: "a", right: "b" })    -> { tabs: ["a", "b"], active: "a", right: null }
close({ tabs: ["a", "b", "c"], active: "b", right: "a" }, "b") -> { tabs: ["a", "c"], active: "c", right: "a" }
close({ tabs: ["a", "b"], active: "a", right: "b" }, "b")      -> { tabs: ["a"], active: "a", right: null }
close({ tabs: ["a", "b"], active: "b", right: "a" }, "b")      -> { tabs: ["a"], active: "a", right: null }
swap({ tabs: ["a", "b"], active: "a", right: "b" })     -> { tabs: ["a", "b"], active: "b", right: "a" }
```

## Tests (con estos nombres)

- `dividir_crea_dos_grupos`: el primer caso de `split` del ejemplo
- `dividir_otra_vez_cierra_la_division`: el segundo caso de `split`; sin `active` el estado no cambia
- `cerrar_la_activa_elige_la_siguiente`: el primer caso de `close` del ejemplo; cerrando la última de la lista se elige la anterior
- `cerrar_la_derecha_quita_la_division`: el segundo caso de `close` del ejemplo
- `cerrar_ultima_pestaña_une_grupos`: el tercer caso de `close` del ejemplo
- `cerrar_un_id_desconocido_no_cambia_nada`: `close(estado, "zz")` devuelve un estado igual al de entrada
- `intercambiar_paneles`: el caso de `swap` del ejemplo; con `right` `null` no cambia
- `no_modifica_la_entrada`: tras llamar a `close`, el array `tabs` original conserva sus elementos
