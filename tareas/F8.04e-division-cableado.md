## Objetivo

1. `web_assets.rs`: añade `("division.js", include_str!("../web/studio/division.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as division from "/studio/division.js"; Studio.division = division;`.
2. HTML: dentro de `<div id="area" class="area">`, al final, añade
   `<div id="ref" class="ref oculto" aria-label="Vista de referencia"><header><span id="ref-titulo"></span><button id="ref-cambiar" title="Intercambiar con el editor">⇄</button><button id="ref-cerrar" title="Cerrar la vista dividida">✕</button></header><pre id="ref-code"></pre></div>`.
   CSS: `.area.dividida > div:not(.ref) { right: 50%; }`,
   `.ref { position: absolute; top: 0; bottom: 0; right: 0; width: 50%; display: flex; flex-direction: column; border-left: 1px solid var(--linea); background: var(--ed-fondo); }`,
   `.ref header { display: flex; gap: 6px; align-items: center; padding: 4px 8px; font-size: 12px; color: var(--texto-2); }`,
   `.ref header span { flex: 1; }`,
   `.ref pre { flex: 1; margin: 0; padding: 10px 16px; overflow: auto; font: 13.5px/21px var(--mono); white-space: pre; color: var(--ed-texto); tab-size: 4; }`.
3. Debajo de `cierra` añade `S.derecha = null;` y:
   - `estadoDivision()`: `({ tabs: S.tabs.map((x) => x.id), active: S.activa, right: S.derecha })`.
   - `pintaRef()`: `t = S.tabs.find((x) => x.id === S.derecha)`; alterna `oculto` en `#ref` y `dividida` en
     `#area`; si hay `t`, `$("ref-titulo").textContent = t.path` y
     `$("ref-code").innerHTML = resalta(t.content, t.lang)` (`resalta` ya escapa el texto).
   - `divide()`: si `S.derecha === null` y la pestaña activa no es un archivo de texto (`kind === "file"` y
     no `binary`), `aviso("Abre un archivo para dividir el editor")`; si no,
     `S.derecha = Studio.division.split(estadoDivision()).right; pintaRef();`.
4. `cierra`: sustituye el cálculo manual de `S.activa` por
   `const st = Studio.division.close(estadoDivision(), id);` (llámala antes del `splice`) y, tras el
   `splice`, `S.activa = st.active; S.derecha = st.right;`. Al final de `muestra` llama a `pintaRef()`.
   En el `ta.addEventListener("input"`, dentro del `requestAnimationFrame`, añade
   `if (S.derecha === t.id) pintaRef();`.
5. Botones y atajo: `$("ref-cerrar").onclick = () => { S.derecha = null; pintaRef(); };`
   `$("ref-cambiar").onclick = () => { const st = Studio.division.swap(estadoDivision()); S.derecha = st.right; activa(st.active); };`.
   En el `keydown` final, rama nueva `k === "\\"` → `divide()`. En `ORDENES`:
   `["Dividir el editor (vista de referencia a la derecha)", "Ctrl \\", () => divide()]`.
