## Objetivo

El módulo convierte Markdown en datos (bloques y tramos); nunca genera HTML. Lo que parezca HTML
(`<script>`, `<b>`) se queda como texto.
1. Crea `markdown.js` con `safeUrl`, `inline` y `parse`.
2. `safeUrl(url)`: recorta espacios. Devuelve la URL si empieza por `http://`, `https://` o `mailto:` (sin
   distinguir mayúsculas), por `#`, o si es relativa (no casa con `/^[a-zA-Z][a-zA-Z0-9+.-]*:/` y no empieza
   por `//`). En otro caso (`javascript:`, `data:`, vacía) devuelve `null`.
3. `inline(text)`: recorre el texto con una sola expresión regular con estas alternativas, en este orden:
   código `` `…` ``, imagen `![alt](src)`, enlace `[texto](href)`, negrita `**…**`, cursiva `*…*`. Sin
   anidar: el contenido de cada tramo es texto. Tramos: `{ type: "text" | "code" | "strong" | "em", text }`,
   `{ type: "link", text, href }`, `{ type: "image", alt, src }`. Un enlace o imagen cuya URL no pasa
   `safeUrl` se deja como texto literal. Los tramos `text` contiguos se unen en uno.
4. `parse(text)`: línea a línea, en este orden de prioridad: bloque de código entre líneas que empiezan
   por ``` (el resto de la línea de apertura es `lang`); título `#`–`######`; regla (`---`, `***` o `___`
   solos en la línea); cita (líneas seguidas que empiezan por `>`, unidas con un espacio); tabla (línea
   que empieza por `|` seguida de una línea separadora de `|`, `-` y `:`; las siguientes líneas que
   empiezan por `|` son filas; las celdas se recortan); lista (líneas seguidas que casan con
   `/^\s*([-*+]|\d+[.)])\s+(.*)$/`; `ordered` según la primera); línea en blanco (cierra el párrafo);
   párrafo (líneas seguidas unidas con un espacio). Los tipos de bloque están en las firmas.
5. Crea `markdown.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
safeUrl(" https://a.b/c ") -> "https://a.b/c"     safeUrl("docs/x.md") -> "docs/x.md"     safeUrl("#uso") -> "#uso"
safeUrl("JaVaScRiPt:alert(1)") -> null            safeUrl("data:text/html,x") -> null     safeUrl("//evil.com") -> null
inline("Un **texto** con `code` y [enlace](https://x.y).") ->
  [ { type: "text", text: "Un " }, { type: "strong", text: "texto" }, { type: "text", text: " con " },
    { type: "code", text: "code" }, { type: "text", text: " y " },
    { type: "link", text: "enlace", href: "https://x.y" }, { type: "text", text: "." } ]
inline("<b>x</b> [m](javascript:alert(1))") -> [ { type: "text", text: "<b>x</b> [m](javascript:alert(1))" } ]
parse("# Hola\n\nuno\ndos\n\n- a\n- b\n\n```rust\nfn x() {}\n```\n") ->
  [ { type: "heading", level: 1, spans: [{ type: "text", text: "Hola" }] },
    { type: "paragraph", spans: [{ type: "text", text: "uno dos" }] },
    { type: "list", ordered: false, items: [[{ type: "text", text: "a" }], [{ type: "text", text: "b" }]] },
    { type: "code", lang: "rust", text: "fn x() {}" } ]
```

## Tests (con estos nombres)

- `url_segura_y_peligrosa`: los seis casos de `safeUrl` del ejemplo y la cadena vacía (`null`)
- `tramos_en_linea`: el primer caso de `inline` del ejemplo
- `markdown_no_ejecuta_html`: `inline("<script>alert(1)</script>")` da un solo tramo `text` con ese mismo texto
- `enlace_javascript_se_queda_en_texto`: el segundo caso de `inline` del ejemplo
- `imagen_relativa`: `inline("![logo](docs/img/logo.png)")` da `[{ type: "image", alt: "logo", src: "docs/img/logo.png" }]`
- `bloques_basicos`: el caso de `parse` del ejemplo da exactamente esos cuatro bloques
- `lista_numerada_y_cita`: `1. a\n2. b` da una lista con `ordered` `true`; `> x\n> y` da una cita con el texto `x y`
- `tabla_sencilla`: `| a | b |\n|---|---|\n| 1 | 2 |` da una tabla con cabecera de dos celdas y una fila de dos celdas
- `codigo_no_se_interpreta`: dentro de un bloque de código, `**x**` y `# y` quedan tal cual en `text`
- `regla_horizontal`: `---` solo en una línea da `{ type: "rule" }`

## No hagas

- No generes cadenas de HTML ni uses `innerHTML`: el módulo devuelve datos
- No añadas cursiva con `_`: rompe los nombres con guion bajo
- No uses `document`, `window` ni imports en `markdown.js`
