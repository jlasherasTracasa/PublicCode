## Objetivo

1. `web_assets.rs`: añade `("markdown.js", include_str!("../web/studio/markdown.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as markdown from "/studio/markdown.js"; Studio.markdown = markdown;`.
2. Debajo de `pintaDocumento` añade:
   - `nodoTramos(padre, spans)`: por cada tramo añade a `padre`: `text` → nodo de texto; `code` →
     `el("code", "", text)`; `strong` → `el("strong", "", text)`; `em` → `el("em", "", text)`; `link` →
     `a = el("a", "", text)` con `a.href = href`, `a.target = "_blank"`, `a.rel = "noopener noreferrer"`;
     `image` → `el("span", "img-md", "🖼 " + alt)` con `dataset.src = src`.
   - `nodoBloque(b)`: `heading` → `el("h" + Math.min(b.level, 6))`; `paragraph` → `p`; `quote` →
     `blockquote`; `rule` → `hr`; `code` → `el("pre", "", b.text)`; `list` → `ol` o `ul` con un `li` por
     elemento; `table` → `table` con `thead` y `tbody` (`th` y `td`). Los tramos se añaden con `nodoTramos`.
   - `pintaPrevia(t)`: vacía `#documento`; busca la pestaña del archivo
     (`S.tabs.find((x) => x.kind === "file" && x.path === t.path)`) y usa su `content` (si se cerró, muestra
     `el("div", "meta", "El archivo ya no está abierto.")`). Crea `el("article")` con un `el("div", "md")`
     al que añade `nodoBloque(b)` por cada bloque de `Studio.markdown.parse(texto)`.
   - `abrePrevia()`: con `t = tabActiva()`; si es una pestaña `previa`, activa la del archivo (`"f:" + t.path`);
     si no es un archivo con `t.lang === "md"`, `aviso("La vista previa es para archivos Markdown")`; si lo
     es, crea o reutiliza `{ id: "p:" + t.path, kind: "previa", path: t.path }` y la activa.
3. `muestra`: `#documento` se ve también con `t.kind === "previa"` (cambia la condición de su línea) y,
   antes de `if (t.kind === "diff") pintaDiff(t);`, añade
   `if (t.kind === "previa") { pintaPrevia(t); marcaArbol(); return; }`. `pintaPestanas`: el texto de una
   pestaña `previa` es `"◉ " + base(t.path)`.
4. Atajo en el `keydown` final: Ctrl+Mayús+V (`k === "v" && e.shiftKey`) → `abrePrevia()`. En `ORDENES`:
   `["Markdown: vista previa", "Ctrl Mayús V", () => abrePrevia()]`. CSS: `.md table { border-collapse: collapse; }`,
   `.md th, .md td { border: 1px solid var(--linea); padding: 4px 8px; }`, `.md hr { border: 0; border-top: 1px solid var(--linea); }`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
