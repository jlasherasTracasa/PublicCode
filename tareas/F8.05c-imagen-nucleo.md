## Objetivo

1. Crea `image.rs` con lo que indican las firmas. `image_mime` mira solo la extensión (sin distinguir
   mayúsculas): `png` → `image/png`, `jpg` y `jpeg` → `image/jpeg`, `gif` → `image/gif`, `webp` →
   `image/webp`, `svg` → `image/svg+xml`; cualquier otra, `None`.
2. `base64_encode`: base64 estándar (alfabeto `A–Z a–z 0–9 + /`, relleno con `=`), escrito a mano: no hay
   dependencia de base64 permitida.
3. `read_image_with_limit(root, rel, max)`: si `image_mime(rel)` es `None`,
   `Err(format!("{rel} no es una imagen que se pueda mostrar"))`. Resuelve la ruta con
   `crate::workspace::safe_path(root, rel)?`. Si el tamaño pasa de `max`,
   `Err(format!("{rel} ocupa {size} bytes: demasiado para verla aquí"))`. Si no se puede leer,
   `Err(format!("no se puede leer {rel}: {e}"))`. `read_image` llama a la anterior con `MAX_IMAGE`.
4. `lib.rs`: añade `pub mod image;` (después de `pub mod assist;`).
5. Tests en `image.rs` con `tempfile::tempdir()`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/image.rs
use crate::workspace::WsResult;
use std::path::Path;

/// Tamaño máximo de una imagen que se muestra en Studio.
pub const MAX_IMAGE: u64 = 8 * 1024 * 1024;

/// Imagen lista para un `data:` URL.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct ImageContent { pub mime: String, pub base64: String, pub size: u64 }

/// Tipo MIME según la extensión, o `None` si no es una imagen admitida.
pub fn image_mime(rel: &str) -> Option<&'static str>;
/// Base64 estándar con relleno.
pub fn base64_encode(bytes: &[u8]) -> String;
/// Lee una imagen de como mucho `max` bytes.
pub fn read_image_with_limit(root: &Path, rel: &str, max: u64) -> WsResult<ImageContent>;
/// Lee una imagen del proyecto (como mucho [`MAX_IMAGE`] bytes).
pub fn read_image(root: &Path, rel: &str) -> WsResult<ImageContent>;
```

## Ejemplo (entrada y resultado esperado)

```
base64_encode(b"")       -> ""          base64_encode(b"f")      -> "Zg=="
base64_encode(b"fo")     -> "Zm8="      base64_encode(b"foo")    -> "Zm9v"
base64_encode(b"foobar") -> "Zm9vYmFy"
image_mime("docs/Logo.PNG") -> Some("image/png")      image_mime("a.svg") -> Some("image/svg+xml")
image_mime("a.txt") -> None
// con un archivo "a.png" de 3 bytes b"foo":
read_image(dir, "a.png") -> Ok(ImageContent { mime: "image/png", base64: "Zm9v", size: 3 })
```

## Tests (con estos nombres)

- `base64_de_los_vectores_del_rfc`: los cinco casos de `base64_encode` del ejemplo
- `mime_por_extension`: `png`, `JPG`, `jpeg`, `gif`, `webp` y `svg` dan su tipo; `txt` y un nombre sin extensión dan `None`
- `lee_una_imagen_pequeña`: el caso de `read_image` del ejemplo
- `imagen_grande_se_rechaza`: `read_image_with_limit(dir, "a.png", 2)` con un archivo de 3 bytes da `Err` que contiene `demasiado`
- `no_imagen_se_rechaza`: `read_image(dir, "a.txt")` da `Err` que contiene `no es una imagen`
- `ruta_fuera_de_la_raiz_se_rechaza`: `read_image(dir, "../x.png")` da `Err`
