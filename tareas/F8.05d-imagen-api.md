## Objetivo

1. `lib.rs` de `pcode-protocol`: en `pub mod methods`, después de `FS_READ`, añade
   `/// Lee una imagen del proyecto: `{path}` → `{mime, base64, size}`.` y
   `pub const FS_READ_IMAGE: &str = "fs.readImage";`.
2. `server.rs`, `match` de `rpc`: después de la rama `methods::FS_READ` añade la rama
   `methods::FS_READ_IMAGE`, igual que aquella pero llamando a `crate::image::read_image(&root, &rel)`.
3. `server.rs`, función `index`: en la cadena de la CSP añade `; img-src 'self' data:` al final (hace
   falta para mostrar imágenes como `data:` URL; el resto de la política no cambia).
4. Tests en el módulo `tests` de `server.rs`. Para el de RPC crea un directorio con `tempfile::tempdir()`,
   escribe `a.png` con los bytes `b"foo"` y construye el estado con
   `AppState::new(d.path().to_path_buf(), "/bin/true".into(), None)` y `router(st)`; llama con `call`.

## Ejemplo (entrada y resultado esperado)

```
call(&a, "fs.readImage", json!({"path": "a.png"}), None)
  -> (200, {"jsonrpc":"2.0","id":1,"result":{"mime":"image/png","base64":"Zm9v","size":3}})
call(&a, "fs.readImage", json!({"path": "a.txt"}), None)
  -> (200, {"jsonrpc":"2.0","id":1,"error":{"code":-32000,"message":"a.txt no es una imagen que se pueda mostrar"}})
```

## Tests (con estos nombres)

- `imagen_por_rpc_en_base64`: `fs.readImage` de `a.png` (bytes `foo`) devuelve `mime` `image/png`, `base64` `Zm9v` y `size` 3
- `imagen_por_rpc_rechaza_lo_que_no_es_imagen`: `fs.readImage` de `a.txt` devuelve un error con código -32000
- `imagen_csp_permite_data`: la cabecera `content-security-policy` de GET `/` contiene `img-src 'self' data:` y sigue conteniendo `default-src 'self'`
