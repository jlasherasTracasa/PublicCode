## Objetivo

1. Crea `edits.rs` con las firmas de abajo y tests en `#[cfg(test)] mod tests` del mismo archivo.
2. `parse_text_edits`: la entrada es el resultado JSON de `textDocument/formatting`: un array de
   `{"range": {"start": {"line", "character"}, "end": {"line", "character"}}, "newText": "…"}`. `null` o
   cualquier cosa que no sea un array da `vec![]`. Un elemento al que le falte algún campo se ignora.
3. `offset_of`: convierte (línea desde 0, columna en unidades UTF-16) en desplazamiento en BYTES dentro de
   `text`. Las líneas se separan por `\n`. Recorre los `char` de la línea sumando `c.len_utf16()` hasta
   llegar a `character`. Si `character` pasa del final de la línea, devuelve el final de esa línea (antes del
   `\n`). Si `line` pasa de la última línea, devuelve `text.len()`.
4. `apply_edits`: calcula (inicio, fin) en bytes de cada edición con `offset_of`; ordénalas por inicio; si
   alguna tiene `fin < inicio` o empieza antes de que acabe la anterior, devuelve
   `Err("ediciones solapadas".to_string())`. Aplica de la última a la primera con `String::replace_range`.
   Sin ediciones devuelve el texto igual.
5. `lib.rs`: añade `pub mod edits;` debajo del comentario `//!` inicial (antes de los `use`).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-lsp/src/edits.rs
use serde::{Deserialize, Serialize};
use serde_json::Value;

/// Una edición de texto del LSP (posiciones desde 0, columnas en UTF-16).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TextEdit { pub line: u32, pub character: u32, pub end_line: u32, pub end_character: u32, pub new_text: String }

/// Lee el array de `TextEdit` que devuelve el servidor.
pub fn parse_text_edits(v: &Value) -> Vec<TextEdit>;
/// Desplazamiento en bytes de una posición LSP.
pub fn offset_of(text: &str, line: u32, character: u32) -> usize;
/// Aplica las ediciones; error si se solapan.
pub fn apply_edits(text: &str, edits: &[TextEdit]) -> Result<String, String>;
```

## Ejemplo (entrada y resultado esperado)

```
apply_edits("let a=1;\nlet  b=2;\n", &[TextEdit { line: 1, character: 3, end_line: 1, end_character: 5, new_text: " ".into() }])
  == Ok("let a=1;\nlet b=2;\n")
offset_of("ñ😀x", 0, 3) == 6      // ñ = 1 unidad UTF-16 y 2 bytes; 😀 = 2 unidades y 4 bytes
offset_of("ab\ncd", 5, 0) == 5    // línea que no existe → final del texto
```

## Tests (con estos nombres)

- `parsea_ediciones_del_servidor`: un array con una edición válida y otra sin `newText` da un solo `TextEdit`
- `parsea_null_como_vacio`: `Value::Null` da vector vacío
- `desplazamiento_utf16_con_emoji`: `offset_of("ñ😀x", 0, 3)` da 6
- `columna_mas_alla_del_final_se_recorta`: columna 99 en la línea `ab` de `ab\ncd` da 2
- `aplica_varias_ediciones_en_cualquier_orden`: dos ediciones dadas en orden inverso producen el texto esperado
- `ediciones_solapadas_se_rechazan`: dos ediciones que se pisan dan `Err` con el texto `ediciones solapadas`
