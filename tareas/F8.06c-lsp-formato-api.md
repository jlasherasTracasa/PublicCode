## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`, debajo de `LSP_STATUS`, añade
   `/// Formatea un documento: `{path, content}` → `{content, changed}`.` y
   `pub const LSP_FORMAT: &str = "lsp.format";`.
2. `server.rs`, en la función `rpc`, dentro de `match req.method.as_str()`, añade un brazo
   `methods::LSP_FORMAT` justo después del brazo `methods::LSP_STATUS`. Pasos del brazo:
   a) `let (rel, content) = (str_param(&p, "path"), str_param(&p, "content"));`
   b) si `crate::workspace::safe_path(&st.repo, &rel)` da `Err(e)`: `return rpc_err(id, -32000, e).into_response();`
   c) `st.lsp.client_for(&rel).await` (error → se devuelve tal cual); con el cliente `c`: `c.sync(&rel, &content).await`,
      luego `c.formatting(&rel).await` y `pcode_lsp::edits::apply_edits(&content, &eds)`.
   d) responde con `ws_reply(id, r.map(|t| serde_json::json!({"changed": t != content, "content": t})))`,
      donde `r: Result<String, String>`.
3. Añade en `mod tests` de `server.rs` los dos tests de la lista. Usa
   `AppState::new(d.path().to_path_buf(), "/bin/true".into(), None)` con `tempfile::tempdir()` y `call(&a, "lsp.format", …, None)`.

## Ejemplo (entrada y resultado esperado)

```
petición:  {"method": "lsp.format", "params": {"path": "src/main.rs", "content": "fn  main() {}\n"}}
respuesta: {"result": {"changed": true, "content": "fn main() {}\n"}}
petición con "path": "../x.rs" → {"error": {"code": -32000, "message": "… fuera …"}}
```

## Tests (con estos nombres)

- `rpc_formato_ruta_fuera_de_la_raiz`: `lsp.format` con `path` `../x.rs` devuelve un error cuyo mensaje contiene `fuera`
- `rpc_formato_sin_servidor_de_lenguaje`: `lsp.format` con `path` `datos.xyz` devuelve un error que contiene `sin servidor de lenguaje`
