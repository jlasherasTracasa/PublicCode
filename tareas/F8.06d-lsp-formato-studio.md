## Objetivo

Todo en `index.html`, en el `<script>` principal. El método `lsp.format {path, content}` devuelve `{content, changed}`.
1. Debajo de la función `referencias` añade `formatoAlGuardar()` y `formatea(silencioso)` (firmas abajo).
   `formatea`: `const t = tabActiva()`; si no hay pestaña, `t.kind !== "file"`, `!LSP_EXT.test(t.path)` o
   `S.lspError[grupoLsp(t.path)]`, devuelve `false`. Llama `await rpc("lsp.format", { path: t.path, content: t.content })`.
   Si `r.changed`: guarda `const pos = ta.selectionStart`, pon `ta.value = r.content`,
   `ta.setSelectionRange(Math.min(pos, r.content.length), Math.min(pos, r.content.length))` y
   `ta.dispatchEvent(new Event("input"))` (así se actualizan `t.content`, el resaltado y el LSP); devuelve `true`.
   Si falla: `if (!silencioso) fallo(e)`; devuelve `false`.
2. En el `ta.addEventListener("keydown", …)` que empieza por `ocultaHover();` (el de `F12`), añade
   `else if (e.shiftKey && e.altKey && e.key.toLowerCase() === "f") { e.preventDefault(); formatea(); }`.
3. En `guarda()`, justo antes del `try`, añade `if (formatoAlGuardar()) await formatea(true);`.
4. En `ORDENES` añade `["Formatear el documento", "Mayús Alt F", () => formatea()]` y
   `["Formatear al guardar: activar o desactivar", "", () => { … }]`: invierte el valor de
   `localStorage["pcode.formatoAlGuardar"]` (`"1"` activado, se borra la clave al desactivar) dentro de try/catch y
   muestra `aviso("Formatear al guardar: activado")` o `"…: desactivado"`.
5. En la lista de atajos de la bienvenida (`<div class="atajos2">`) añade `<kbd>⇧ Alt F</kbd><span>Formatear el documento</span>`.
