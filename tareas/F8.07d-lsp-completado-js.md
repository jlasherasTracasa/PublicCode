## Objetivo

1. Crea `completado.js`: módulo ES sin dependencias, sin `document` ni `window`, con las cuatro funciones de
   abajo exportadas.
2. `prefix(text, pos)`: la palabra que hay justo antes de `pos` (caracteres `[A-Za-z0-9_$]` y letras
   acentuadas). Devuelve `{ text: "do", start: 8 }` (`start` = índice donde empieza). Sin palabra: `{ text: "", start: pos }`.
3. `filter(items, pref)`: los items cuyo `label` empieza por `pref` sin distinguir mayúsculas, primero los que
   coinciden respetando mayúsculas; si `pref` es `""` devuelve todos. Como mucho 50. No modifica `items`.
4. `apply(text, pos, item)`: devuelve `{ text, cursor }`. Si el item trae `replaceStart` y `replaceEnd`
   (columnas de la línea del cursor), sustituye ese tramo de la línea por `item.insertText`; si no, sustituye
   desde `prefix(text, pos).start` hasta `pos`. `cursor` queda justo después de lo insertado.
5. `inComment(lineToCursor, lang)`: `true` si en el texto de la línea hasta el cursor ya empezó un
   comentario de línea: `//` para `rust`, `js`, `go`, `java`, `c`; `#` para `py`, `sh`, `toml`. Otros lenguajes: `false`.
6. Crea `completado.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
prefix("let x = do", 10)                        → { text: "do", start: 8 }
filter([{label:"Doble"},{label:"doble"},{label:"otro"}], "do") → [{label:"doble"},{label:"Doble"}]
apply("let x = do", 10, { insertText: "doble()" }) → { text: "let x = doble()", cursor: 15 }
apply("a\n  foo.ba", 10, { insertText: "bar", replaceStart: 6, replaceEnd: 8 }) → { text: "a\n  foo.bar", cursor: 11 }
inComment("let a = 1; // do", "rust")           → true
```

## Tests (con estos nombres)

- `prefijo_de_la_palabra_actual`: `let x = do` con el cursor al final da `do` y `start` 8
- `prefijo_vacio_tras_espacio`: con el cursor después de un espacio el prefijo es cadena vacía
- `filtra_al_escribir`: con `do` quedan solo los que empiezan por do y primero el que respeta mayúsculas
- `aplica_sustituye_el_prefijo`: insertar `doble()` sobre `do` deja el cursor tras el paréntesis
- `aplica_respeta_text_edit`: con `replaceStart` y `replaceEnd` se sustituye ese tramo de la línea del cursor
- `no_abre_dentro_de_comentarios`: una línea con `//` antes del cursor en rust da `true` y sin él `false`
