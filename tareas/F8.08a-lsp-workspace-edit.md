# F8.08a-lsp-workspace-edit — LSP: leer un `WorkspaceEdit` y rechazar lo que cae fuera del proyecto (lógica pura)

## Objetivo

1. Crea `workspace_edit.rs` con las firmas de abajo y tests en el mismo archivo.
2. `parse_workspace_edit(root, v)`: `v` es un `WorkspaceEdit` del LSP con una de estas dos formas (pueden venir las dos; usa
   `documentChanges` si existe y no está vacío, si no `changes`):
   - `{"changes": {"<uri>": [TextEdit, …], …}}`
   - `{"documentChanges": [{"textDocument": {"uri": "<uri>"}, "edits": [TextEdit, …]}, …]}` (los elementos sin `textDocument`,
     como crear o renombrar archivos, se ignoran).
   Por cada URI: `crate::uri_to_path(uri)` (si da `None`, error `"URI no válida: <uri>"`), luego
   `crate::rel_path(root, &ruta)`. Si la ruta relativa resultante es absoluta
   (`std::path::Path::new(&rel).is_absolute()`), empieza por `..` o contiene `:`, devuelve
   `Err(format!("el cambio toca un archivo fuera del proyecto: {rel}"))`.
   Las ediciones se leen con `crate::edits::parse_text_edits`. Un archivo sin ediciones no se incluye.
   Devuelve los archivos ordenados por `path`. `v` nulo → `Ok(vec![])`.
3. `lib.rs`: añade `pub mod workspace_edit;` debajo del comentario `//!` inicial.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-lsp/src/workspace_edit.rs
use crate::edits::TextEdit;
use serde::{Deserialize, Serialize};
use serde_json::Value;
use std::path::Path;

/// Ediciones de un archivo del proyecto (ruta relativa con `/`).
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct FileEdits { pub path: String, pub edits: Vec<TextEdit> }

/// Lee un `WorkspaceEdit`; error si toca algo fuera de `root`.
pub fn parse_workspace_edit(root: &Path, v: &Value) -> Result<Vec<FileEdits>, String>;
```

## Ejemplo (entrada y resultado esperado)

```
root = /tmp/p  (usa `tempfile::tempdir()` y `canonicalize()`; las URIs se construyen con `crate::path_to_uri(&root.join("src/a.rs"))`)
v = {"changes": {"file:///tmp/p/src/a.rs": [{"range": {"start": {"line": 0, "character": 3}, "end": {"line": 0, "character": 6}}, "newText": "suma"}]}}
→ Ok([FileEdits { path: "src/a.rs", edits: [TextEdit { line: 0, character: 3, end_line: 0, end_character: 6, new_text: "suma" }] }])
```

## Tests (con estos nombres)

- `lee_changes_de_dos_archivos`: un `changes` con dos URIs da dos `FileEdits` ordenados por ruta
- `lee_document_changes`: la forma `documentChanges` da el mismo resultado que `changes`
- `fuera_de_la_raiz_se_rechaza`: una URI de otro directorio temporal da `Err` que contiene `fuera del proyecto`
- `null_da_vacio`: `Value::Null` da `Ok` con vector vacío
