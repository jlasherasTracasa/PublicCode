## Objetivo

1. En `lib.rs`, encima de `impl LspClient`, añade el struct `CodeAction` (firma abajo).
2. Dentro de `impl LspClient`, después de `hover`, añade `rename`: parte de `self.position(rel, line, character)`,
   le añade `p["newName"] = json!(new_name)`, pide `"textDocument/rename"` con `REQUEST_TIMEOUT` y devuelve
   `crate::workspace_edit::parse_workspace_edit(&self.root, &v)`. Si `new_name` está vacío o tiene espacios,
   devuelve `Err("el nombre nuevo no es válido".to_string())` sin llamar al servidor.
3. Añade `code_actions`: pide `"textDocument/codeAction"` con
   `json!({"textDocument": {"uri": path_to_uri(&self.abs(rel))}, "range": {"start": {"line": line, "character": 0}, "end": {"line": line + 1, "character": 0}}, "context": {"diagnostics": []}})`.
   La respuesta es un array (o `null` → vacío). Por cada elemento con `title` y con `edit`:
   `CodeAction { title, kind: elemento["kind"] o "", edits: parse_workspace_edit(&self.root, &elemento["edit"])? }`.
   Los elementos sin `edit` (solo `command`) se ignoran.
4. En `LspClient::initialize`, en `"textDocument": {…}` añade `"rename": {}` y
   `"codeAction": {"codeActionLiteralSupport": {"codeActionKind": {"valueSet": ["quickfix", "refactor", "source"]}}}`.
5. En `fake` (tests) añade al `match m.as_str()`, antes del brazo `_ if v.get("id")…`:
   - `"textDocument/rename"` → `reply(json!({"changes": {format!("{root_uri}/src/lib.rs"): [{"range":{"start":{"line":7,"character":3},"end":{"line":7,"character":8}},"newText": v["params"]["newName"]}]}}))`
   - `"textDocument/codeAction"` → `reply(json!([{"title":"Importar HashMap","kind":"quickfix","edit":{"changes":{format!("{root_uri}/src/main.rs"):[{"range":{"start":{"line":0,"character":0},"end":{"line":0,"character":0}},"newText":"use std::collections::HashMap;\n"}]}}},{"title":"Solo orden","command":{"command":"x"}}]))`
   (para usar `format!` como clave construye el mapa con `serde_json::Map` o un `json!` con variable).
6. Añade los tests de la lista imitando `lsp_definicion_referencias_hover_y_diagnosticos`.

```rust
/// Una acción de código con las ediciones que aplica.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct CodeAction { pub title: String, pub kind: String, pub edits: Vec<workspace_edit::FileEdits> }

// dentro de `impl LspClient`
/// Renombra el símbolo de la posición: devuelve las ediciones por archivo (no las aplica).
pub async fn rename(&self, rel: &str, line: u32, character: u32, new_name: &str) -> Result<Vec<workspace_edit::FileEdits>, String>;
/// Acciones de código (arreglos rápidos y refactorizaciones) de una línea.
pub async fn code_actions(&self, rel: &str, line: u32) -> Result<Vec<CodeAction>, String>;
```

## Tests (con estos nombres)

- `lsp_renombrar_devuelve_ediciones_por_archivo`: `rename("src/main.rs", 1, 6, "triple")` da un `FileEdits` de `src/lib.rs` con `new_text` `triple`
