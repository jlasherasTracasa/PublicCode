## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`, debajo de `LSP_STATUS`, añade tres constantes con su comentario `///`:
   `LSP_RENAME = "lsp.rename"` (`{path, line, character, newName, dryRun?}` → `{files: {path, edits}[], applied}`),
   `LSP_CODE_ACTIONS = "lsp.codeActions"` (`{path, line}` → `{title, kind, edits}[]`) y
   `LSP_APPLY_EDITS = "lsp.applyEdits"` (`{edits: {path, edits}[]}` → `{path, edits}[]`).
2. `server.rs`, función `rpc`, `match req.method.as_str()`, después del brazo de `LSP_STATUS`:
   - `methods::LSP_RENAME`: lee `rel`, `line`, `ch` como el brazo de `LSP_HOVER`, `new_name = str_param(&p, "newName")` y
     `dry = p.get("dryRun").and_then(|v| v.as_bool()).unwrap_or(false)`. Con `st.lsp.client_for(&rel).await` y
     `c.rename(&rel, line, ch, &new_name).await` obtiene `files`; después
     `blocking(move || crate::lsp_apply::apply_file_edits(&root, &files, dry)).await`. Si no es simulacro y fue bien,
     `st.emit(Event::FilesChanged {})`. Respuesta: `json!({"files": resumen, "applied": !dry})`.
   - `methods::LSP_CODE_ACTIONS`: `c.code_actions(&rel, line).await` → `ws_reply(id, r)`.
   - `methods::LSP_APPLY_EDITS`: `serde_json::from_value::<Vec<pcode_lsp::workspace_edit::FileEdits>>(p["edits"].clone())`
     (si falla: `rpc_err(id, -32602, "se esperaba {edits}")`), aplica con `apply_file_edits(&root, &files, false)` dentro de
     `blocking`, emite `Event::FilesChanged {}` y responde con el resumen.
3. Tests en `mod tests` de `server.rs` (lista de abajo), con `tempfile::tempdir()` como raíz.

## Ejemplo (entrada y resultado esperado)

```
{"method": "lsp.applyEdits", "params": {"edits": [{"path": "a.rs", "edits": [{"line": 0, "character": 3, "endLine": 0, "endCharacter": 8, "newText": "triple"}]}]}}
→ {"result": [{"path": "a.rs", "edits": 1}]}  y a.rs pasa de "fn doble() {}\n" a "fn triple() {}\n"
```

## Tests (con estos nombres)

- `rpc_renombrar_sin_servidor_de_lenguaje`: `lsp.rename` sobre `datos.xyz` devuelve un error que contiene `sin servidor de lenguaje`
- `rpc_aplicar_ediciones_escribe_el_archivo`: `lsp.applyEdits` con una edición sobre `a.rs` cambia el archivo y devuelve el resumen
- `rpc_aplicar_ediciones_fuera_de_la_raiz`: `lsp.applyEdits` con `path` `../x.rs` devuelve un error que contiene `fuera`
