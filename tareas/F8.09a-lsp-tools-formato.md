## Objetivo

El modelo no sabe contar columnas: las tools recibirán una línea (desde 1) y el nombre del símbolo, y
este módulo calcula la posición que pide el LSP.
1. `crates/pcode-tools/Cargo.toml`, en `[dependencies]`: añade `pcode-lsp = { path = "../pcode-lsp" }`
   (`pcode-lsp` no depende de `pcode-tools`: no hay ciclo). `Cargo.lock` cambia solo: inclúyelo en el commit.
2. Crea `lsp_tools.rs` con lo de las firmas; en `lib.rs` añade `pub mod lsp_tools;` (después de
   `pub mod edit;`).
3. `find_position(text, line, symbol)`: `line` va desde 1. Errores (texto EXACTO):
   línea fuera de rango → `la línea {line} no existe (el archivo tiene {n} líneas)`; el símbolo no está
   en esa línea → `«{symbol}» no aparece en la línea {line}: {texto de la línea sin espacios en los extremos, recortado a 100 caracteres}`.
   Si está: `Ok((line - 1, columna))`, con la columna de su primera aparición en unidades UTF-16:
   `linea[..indice_en_bytes].encode_utf16().count() as u32`.
4. `render_locations(root, locs)`: sin resultados, `sin resultados`. Si no, una línea por posición (como
   mucho 50): `{path}:{line + 1}:{character + 1}  {texto}`, donde `texto` es esa línea del archivo
   `root.join(path)` sin espacios en los extremos y recortada a 120 caracteres (si no se puede leer,
   la línea acaba tras la columna). Si hay más de 50, una última línea `… y {n} más`.
5. `render_diagnostics(path, diags)`: sin diagnósticos, `{path}: sin diagnósticos`. Si no, primera línea
   `{path}: {e} errores, {a} avisos` (severidad 1 = error, 2 = aviso) y después, ordenados por
   severidad y luego por línea (como mucho 50):
   `{path}:{line + 1}:{character + 1} {sev} {primera línea del mensaje}{fuente}`, con `sev` = `error`,
   `aviso`, `info` o `pista` (1, 2, 3, otro) y `fuente` = ` [{source}]` si `source` no está vacío.
6. `DiagStore`: un `Arc<Mutex<HashMap<String, Vec<Diagnostic>>>>` (de `std::sync`). `sink()` devuelve un
   `pcode_lsp::DiagnosticsSink` (`Arc::new(move |path, diags| …)`) que guarda la última lista de cada
   ruta; `take(path)` saca y devuelve la lista (`None` si no ha llegado nada); `clear(path)` la borra.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tools/src/lsp_tools.rs
use pcode_lsp::{Diagnostic, DiagnosticsSink, Location};
use std::path::Path;

/// Posición LSP (línea desde 0, columna UTF-16) de `symbol` en la línea `line` (desde 1) de `text`.
pub fn find_position(text: &str, line: u32, symbol: &str) -> Result<(u32, u32), String>;
/// Posiciones como texto `ruta:línea:columna  código`.
pub fn render_locations(root: &Path, locs: &[Location]) -> String;
/// Diagnósticos de un archivo como texto, los errores primero.
pub fn render_diagnostics(path: &str, diags: &[Diagnostic]) -> String;

/// Últimos diagnósticos publicados por los servidores, por ruta.
#[derive(Clone, Default)]
pub struct DiagStore(std::sync::Arc<std::sync::Mutex<std::collections::HashMap<String, Vec<Diagnostic>>>>);

impl DiagStore {
    /// Almacén vacío.
    pub fn new() -> Self;
    /// Sumidero para `LspManager::new` que guarda lo que llega.
    pub fn sink(&self) -> DiagnosticsSink;
    /// Saca los diagnósticos de una ruta, si han llegado.
    pub fn take(&self, path: &str) -> Option<Vec<Diagnostic>>;
    /// Olvida los diagnósticos de una ruta.
    pub fn clear(&self, path: &str);
}
```

## Ejemplo (entrada y resultado esperado)

```
find_position("fn main() {\n    let año = doble(1);\n}\n", 2, "doble") -> Ok((1, 14))
find_position("fn main() {}\n", 1, "doble") -> Err("«doble» no aparece en la línea 1: fn main() {}")
find_position("fn main() {}\n", 9, "main")  -> Err("la línea 9 no existe (el archivo tiene 1 líneas)")
render_locations(root, &[Location { path: "src/lib.rs".into(), line: 0, character: 7 }])   (src/lib.rs: "pub fn doble() {}")
  -> "src/lib.rs:1:8  pub fn doble() {}"
render_diagnostics("a.rs", &[aviso en (4, 0) "sin usar" de "rustc", error en (1, 4) "tipo incorrecto\nmás" sin fuente])
  -> "a.rs: 1 errores, 1 avisos\na.rs:2:5 error tipo incorrecto\na.rs:5:1 aviso sin usar [rustc]"
```

## Tests (con estos nombres)

- `formato_posicion_en_utf16`: los tres casos de find_position del ejemplo (la `ñ` cuenta una unidad)
- `formato_posiciones_con_el_codigo`: el caso de render_locations en un tempdir; con un archivo que no existe la línea es `x.rs:1:1`; sin posiciones, `sin resultados`
- `formato_diagnosticos_errores_primero`: el caso de render_diagnostics, carácter a carácter; sin diagnósticos, `a.rs: sin diagnósticos`
- `formato_almacen_guarda_lo_ultimo`: llamar dos veces al sink con la misma ruta deja la segunda lista; take la devuelve una vez y después None; clear la borra
