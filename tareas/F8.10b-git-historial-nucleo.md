## Objetivo

1. Crea `history.rs` con las firmas de abajo y tests en el mismo archivo (cada test crea su repo temporal; copia la
   función `repo()` de los tests de `workspace.rs`).
2. `parse_log(raw)`: cada línea es `sha40<US>autor<US>segundos<US>asunto`, donde `<US>` es el carácter `\u{1f}`.
   Las líneas con menos de 4 campos se ignoran. `short` = 8 primeros caracteres del sha.
3. `valid_rev(s)`: `true` si `s` tiene entre 4 y 40 caracteres y todos son hexadecimales (`0-9a-fA-F`).
4. `git_log(root, rel, limit)`: si `rel` es `Some`, valida con `crate::workspace::safe_path(root, r)?`. Si el repo no tiene
   commits (`git(root, &["rev-parse", "--verify", "HEAD"])` falla), devuelve `Ok(vec![])`. Lanza
   `git log -n <limit> --format=<LOG_FORMAT> [-- rel]` con `crate::workspace::git` y pasa la salida por `parse_log`.
5. `git_blame(root, rel)`: `safe_path`; si el archivo no está versionado (`git(root, &["ls-files", "--error-unmatch", "--", rel])`
   falla) devuelve `Ok(vec![])`; si no, `git blame --porcelain -- rel` y `crate::blame::parse_blame`.
6. `git_show(root, rev, rel)`: si `!valid_rev(rev)` → `Err("revisión no válida".into())`; valida `rel` con `safe_path`; lanza
   `git show --no-color --no-ext-diff --format= <rev> [-- rel]` (con `--format=` vacío solo sale el diff).
7. `lib.rs`: añade `pub mod history;` debajo de `pub mod blame;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/history.rs
use crate::workspace::WsResult;
use std::path::Path;

/// Formato de `git log` que entiende `parse_log` (campos separados por U+001F).
pub const LOG_FORMAT: &str = "%H%x1f%an%x1f%at%x1f%s";

/// Un commit del historial.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct Commit { pub sha: String, pub short: String, pub author: String, pub time: i64, pub subject: String }

pub fn parse_log(raw: &str) -> Vec<Commit>;
pub fn valid_rev(s: &str) -> bool;
/// Últimos `limit` commits (de un archivo si `rel` es `Some`).
pub fn git_log(root: &Path, rel: Option<&str>, limit: usize) -> WsResult<Vec<Commit>>;
/// Autor y commit de cada línea de un archivo.
pub fn git_blame(root: &Path, rel: &str) -> WsResult<Vec<crate::blame::BlameLine>>;
/// Diff de un commit (de un archivo si `rel` es `Some`).
pub fn git_show(root: &Path, rev: &str, rel: Option<&str>) -> WsResult<String>;

// Ya existe: pub(crate) fn crate::workspace::git(root: &Path, args: &[&str]) -> WsResult<String>
```

## Ejemplo (entrada y resultado esperado)

```
parse_log("a1b2c3d4e5f6a7b8c9d0a1b2c3d4e5f6a7b8c9d0\u{1f}Ana\u{1f}1700000000\u{1f}arregla x\n")
  == [Commit { sha: "a1b2…c9d0", short: "a1b2c3d4", author: "Ana", time: 1700000000, subject: "arregla x" }]
valid_rev("a1b2") == true;  valid_rev("HEAD; rm") == false;  valid_rev("abc") == false
```

## Tests (con estos nombres)

- `parsea_el_log`: dos líneas con el separador U+001F dan dos commits con `short` de 8 caracteres
- `revision_valida_solo_hexadecimal`: `a1b2c3d4` vale; `--help`, `abc` y un texto de 41 caracteres no
- `log_de_un_archivo`: en un repo con dos commits, uno que toca `a.txt` y otro `b.txt`, `git_log(Some("a.txt"))` da un commit
- `blame_por_linea`: en un repo con un commit, `git_blame` de un archivo de dos líneas da dos entradas con el mismo sha
- `archivo_sin_commits`: `git_blame` de un archivo nuevo sin versionar da vector vacío
- `show_rechaza_revision_rara`: `git_show(root, "--output=x", None)` da `Err` con `revisión no válida`
