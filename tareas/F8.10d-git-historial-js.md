## Objetivo

1. Crea `historial.js`: módulo ES sin dependencias ni DOM, con las tres funciones de abajo exportadas.
2. `ago(sec, nowSec)`: tiempo transcurrido en español a partir de dos marcas en segundos. Con `d = nowSec - sec`:
   `d < 60` → `"ahora"`; `< 3600` → `"hace N min"`; `< 86400` → `"hace N h"`; `< 30 días` → `"hace N días"` (`"hace 1 día"`
   en singular); `< 365 días` → `"hace N meses"` (`"hace 1 mes"`); si no `"hace N años"` (`"hace 1 año"`). N es la parte entera.
3. `blameLine(blame, line)`: de la lista `[{line, sha, author, time, summary}]` devuelve el elemento cuyo campo `line` es igual al parámetro `line`
   (línea desde 1) o `null`.
4. `annotation(b, nowSec)`: texto que se pinta al final de la línea: `"<autor>, <ago> · <resumen>"`. Si `b.author === ""`
   devuelve `"Sin confirmar todavía"`. El resumen se corta a 60 caracteres y entonces termina en `…`. Si `b` es `null`, `""`.
5. Crea `historial.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
ago(1000, 1000 + 3 * 86400)   → "hace 3 días"
annotation({ line: 1, sha: "a1b2c3d4", author: "Ana", time: 1000, summary: "arregla x" }, 1000 + 7200) → "Ana, hace 2 h · arregla x"
annotation({ line: 2, sha: "00000000", author: "", time: 0, summary: "" }, 5) → "Sin confirmar todavía"
```

## Tests (con estos nombres)

- `hace_en_minutos_horas_y_dias`: 90 s da `hace 1 min`, 7200 s `hace 2 h` y 3 días `hace 3 días`
- `hace_en_singular`: 1 día, 1 mes y 1 año salen en singular
- `anotacion_con_autor_y_resumen`: el ejemplo da `Ana, hace 2 h · arregla x`
- `anotacion_corta_resumenes_largos`: un resumen de 80 caracteres queda en 60 más `…`
- `anotacion_sin_confirmar`: autor vacío da `Sin confirmar todavía` y `null` da cadena vacía
- `linea_blame_busca_por_numero`: devuelve el elemento de esa línea y `null` si no existe

## No hagas

- No uses `Date.now()` dentro del módulo: la hora actual llega por parámetro
- No uses `document` ni `window`
