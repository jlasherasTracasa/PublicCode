## Objetivo

API: `git.blame {path}` → `[{line, sha, author, time, summary}]`; `git.log {path, limit}` → `[{sha, short, author, time, subject}]`;
`git.show {sha, path}` → texto del diff.
1. `web_assets.rs`: añade a la tabla `ASSETS` la línea `("historial.js", include_str!("../web/studio/historial.js")),`.
2. `index.html`: en el bloque `<script type="module">` final, antes de `inicio();`, añade
   `import * as historial from "/studio/historial.js"; Studio.historial = historial;`.
3. Blame: en `<div class="codigo">`, después de `<div id="capa-diag" …>`, añade
   `<div id="capa-blame" class="capa-diag" aria-hidden="true"></div>`; en `sincroniza()` aplícale el mismo `transform` que a
   `capa-diag`. Estado `S.blame = {}` (por ruta) y `S.verBlame` (leído de `localStorage["pcode.blame"] === "1"` con try/catch).
   `cargaBlame(t)`: si `S.verBlame` y `t` es un archivo no binario, `S.blame[t.path] = await rpc("git.blame", { path: t.path })`
   (si falla, `[]`) y llama a `pintaBlame()`. `pintaBlame()`: vacía `#capa-blame`; si `!S.verBlame`, no hay pestaña de archivo
   o `t.dirty`, termina; busca `b = Studio.historial.blameLine(S.blame[t.path] || [], posCursor().line + 1)`; si hay, añade
   un `div` con clase `blame` y texto `Studio.historial.annotation(b, Date.now() / 1000)`, con `top = 10 + línea0 * 21` px y
   `left = 16 + (colVisual(textoLinea, textoLinea.length) + 4) * medirCaracter()` px. CSS `.blame`: `position: absolute;
   white-space: nowrap; color: var(--texto-2); opacity: .7; font: 12px/21px var(--mono)`.
   Llama a `cargaBlame(t)` al final de `abre` (pestaña nueva) y de `guarda`, y a `pintaBlame()` al final de `posicion()`.
4. Panel: añade `<section id="p-historial" class="panel oculto"><header>Historial <span id="historial-archivo"></span></header><div id="historial" class="scroll"></div></section>`
   junto a `p-actividad`; en `panel()` añade `"historial"` al array de nombres y `if (nombre === "historial") pintaHistorial();`.
   `pintaHistorial()`: sin pestaña de archivo → `el("div", "vacio", "Abre un archivo para ver su historial.")`; si no,
   `rpc("git.log", { path: t.path, limit: 50 })` y un `button` de clase `problema` por commit con `c.short`, `c.subject` y
   `c.author + ", " + Studio.historial.ago(c.time, Date.now() / 1000)`; al pulsarlo, `abreCommitArchivo(c, t.path)`. Sin commits:
   `"Este archivo no tiene commits."`.
5. `abreCommitArchivo(c, path)`: `text = await rpc("git.show", { sha: c.sha, path })`; añade (o activa si ya existe) la pestaña
   `{ id: "c:" + c.sha + ":" + path, kind: "diff", path: c.short + " " + base(path), text, fijo: true }`. En
   `alCambiarArchivos`, cambia `else if (t.kind === "diff")` por `else if (t.kind === "diff" && !t.fijo)`.
6. `ORDENES`: `["Git: historial del archivo", "", () => panel("historial")]` y
   `["Git: mostrar u ocultar el blame en línea", "", () => { … }]` (invierte `S.verBlame`, lo guarda en `localStorage` y llama a
   `cargaBlame(tabActiva())` o `pintaBlame()`). Usa `Studio.historial` solo dentro de funciones.
