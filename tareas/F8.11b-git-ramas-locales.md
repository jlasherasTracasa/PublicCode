## Objetivo

1. En `branches.rs` añade las dos funciones de abajo y un módulo de tests `#[cfg(test)] mod locales` (copia en él la
   función `repo()` de los tests de `workspace.rs`, pero con `g(&["init", "-q", "-b", "main"])` para fijar el nombre de la rama).
2. `git_branches(root)`: `crate::workspace::git(root, &["branch", &format!("--format={BRANCH_FORMAT}")])` y `parse_branches`.
3. `git_checkout(root, name, create)`:
   a) `valid_branch_name(name)?`;
   b) si `create`: `git(root, &["checkout", "-b", name])` (los cambios sin confirmar se conservan);
   c) si no: comprueba primero `git(root, &["status", "--porcelain", "--untracked-files=no"])`; si su salida no está vacía
      devuelve `Err("hay cambios sin confirmar: haz commit o guárdalos (stash) antes de cambiar de rama".into())`; si está
      vacía, `git(root, &["checkout", name])`.
   Devuelve `Ok(())`.

## Tests (con estos nombres)

- `crear_y_cambiar_de_rama`: tras `git_checkout(root, "feature/x", true)` la rama actual de `git_branches` es `feature/x`, y `git_checkout(root, "main", false)` vuelve a `main`
- `checkout_con_cambios_avisa`: con un archivo versionado modificado, cambiar de rama da `Err` que contiene `cambios sin confirmar`
- `nombre_no_valido_no_llega_a_git`: `git_checkout(root, "-f", true)` da `Err` con `nombre de rama no válido`

## No hagas

- Nunca uses `--force`, `-f`, `reset` ni `stash` en el código
- Los tests usan siempre un repo temporal, nunca el de PublicCode
- No cambies las funciones puras de F8.11a
