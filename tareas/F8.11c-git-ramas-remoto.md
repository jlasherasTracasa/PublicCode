## Objetivo

1. En `branches.rs` añade las funciones de abajo y un módulo de tests `#[cfg(test)] mod remoto` con tests `#[tokio::test]`.
2. `run_git(root, args, timeout)`: `tokio::process::Command::new("git")` con `.arg("-C").arg(root).args(args)`,
   `.env("GIT_TERMINAL_PROMPT", "0")` (así git falla en vez de pedir usuario o contraseña), `.stdin(Stdio::null())`,
   `.kill_on_drop(true)`; espera con `tokio::time::timeout(timeout, cmd.output())`. Vencido el tiempo:
   `Err(format!("git tardó más de {} s", timeout.as_secs()))`. Si sale bien devuelve stdout + stderr juntos (git escribe el
   progreso en stderr), recortados con `trim()`; si sale mal, `Err` con stderr recortado.
3. `git_pull(root)`: busca la rama actual en `git_branches(root)?`. Si no hay rama actual → `Err("no hay rama actual".into())`.
   Si su `upstream` es `None` → `Err("la rama no sigue a ninguna rama remota: haz push primero".into())`. Si no,
   `run_git(root, &["pull".into(), "--ff-only".into()], SYNC_TIMEOUT).await`.
4. `git_push(root)`: si `crate::workspace::git(root, &["remote"])` devuelve vacío →
   `Err("este repositorio no tiene remoto: añade uno con `git remote add origin <url>`".into())`. Si no,
   `run_git(root, &push_args(&rama.name, rama.upstream.as_deref()), SYNC_TIMEOUT).await` con la rama actual.
5. Tests sin red: el «remoto» es un repo desnudo local creado con `git init -q --bare <dir>/remoto.git` y añadido con
   `git remote add origin <ruta>`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/branches.rs
use std::time::Duration;

/// Tiempo máximo de `pull` y `push`.
pub const SYNC_TIMEOUT: Duration = Duration::from_secs(120);

/// Lanza git sin terminal y con tiempo máximo; devuelve su salida.
pub async fn run_git(root: &Path, args: &[String], timeout: Duration) -> WsResult<String>;
/// `git pull --ff-only` de la rama actual.
pub async fn git_pull(root: &Path) -> WsResult<String>;
/// `git push` de la rama actual (configura `origin` como remota si no la tenía). Nunca fuerza.
pub async fn git_push(root: &Path) -> WsResult<String>;
```

## Tests (con estos nombres)

- `push_sin_remoto_da_error_claro`: en un repo sin remotos `git_push` da `Err` que contiene `no tiene remoto`
- `push_y_pull_con_remoto_local`: con un repo desnudo local como `origin`, `git_push` va bien, la rama pasa a tener upstream y `git_pull` devuelve `Ok`
- `pull_sin_rama_remota_avisa`: en un repo con remoto pero sin haber hecho push, `git_pull` da `Err` que contiene `no sigue a ninguna rama remota`
- `git_con_tiempo_maximo`: `run_git` con un tiempo de 1 ms sobre `git log` de un repo temporal devuelve `Ok` o el error `git tardó más de`, nunca se cuelga

## No hagas

- Nunca añadas `--force` ni `-f`
- No uses la red en los tests: el remoto es un directorio local
- No bloquees el hilo async con `std::process::Command` para pull o push: usa `tokio::process`
