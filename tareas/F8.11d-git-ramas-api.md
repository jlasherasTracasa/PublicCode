## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`, debajo de `GIT_COMMIT`, añade con su comentario `///`:
   `GIT_BRANCHES = "git.branches"` (`{}` → `{name, current, upstream}[]`), `GIT_CHECKOUT = "git.checkout"`
   (`{branch, create?}` → `true`), `GIT_PULL = "git.pull"` y `GIT_PUSH = "git.push"` (`{}` → texto de git; piden aprobación).
2. `server.rs`, función `rpc`, `match req.method.as_str()`, después del brazo `methods::GIT_COMMIT`:
   - `GIT_BRANCHES`: `ws_reply(id, blocking(move || crate::branches::git_branches(&root)).await)`.
   - `GIT_CHECKOUT`: `branch = str_param(&p, "branch")`, `create = p.get("create").and_then(|v| v.as_bool()).unwrap_or(false)`;
     `blocking(move || crate::branches::git_checkout(&root, &branch, create))`; emite `Event::FilesChanged {}`; responde `true`.
   - `GIT_PULL | GIT_PUSH`: `let push = req.method == methods::GIT_PUSH;` Pide aprobación con
     `st.approvals.request(0, if push { "git push" } else { "git pull" }, if push { "envía tus commits al remoto" } else { "trae y aplica los cambios del remoto" }, "Studio").await`.
     Si devuelve `false`: `rpc_err(id, -32000, "denegado: no se ha ejecutado git")`. Si `true`: `crate::branches::git_push(&st.repo).await`
     o `git_pull`, emite `Event::FilesChanged {}` y responde con `ws_reply(id, r)`.
3. Tests en `mod tests` de `server.rs` (lista de abajo). Para el de la aprobación: lanza la llamada `git.push` en un
   `tokio::spawn` (clona el `Router`), espera la aprobación pendiente con el bucle de `aprobaciones_por_rpc`
   (`approvals.list` hasta 100 veces con pausa de 10 ms), decide con `approvals.decide {id, allowed: false}` y comprueba
   que la respuesta de `git.push` es un error que contiene `denegado`.
