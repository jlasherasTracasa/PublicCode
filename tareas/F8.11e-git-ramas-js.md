## Objetivo

1. Crea `ramas.js`: módulo ES sin dependencias ni DOM, con las dos funciones de abajo exportadas.
2. `options(branches)`: recibe `[{ name, current, upstream }]` (lo que devuelve `git.branches`) y devuelve
   `[{ value, label, current }]`: primero la rama actual y después el resto por orden alfabético de `name`.
   `label` = el nombre, más `" ↑ " + upstream` si tiene rama remota, más `" (sin publicar)"` si `upstream` es `null`.
   `current` se copia tal cual. No modifica el array de entrada.
3. `syncSummary(text)`: de la salida de `git pull` o `git push` devuelve la última línea no vacía, recortada a 120
   caracteres (si se corta termina en `…`). Texto vacío → `"Hecho"`.
4. Crea `ramas.test.js` con los tests de la lista.

## Firmas (cópialas tal cual)

```javascript
export function options(branches) {}   // → [{ value: string, label: string, current: boolean }]

```

## Ejemplo (entrada y resultado esperado)

```
options([{ name: "zeta", current: false, upstream: null }, { name: "main", current: true, upstream: "origin/main" }])
  → [{ value: "main", label: "main ↑ origin/main", current: true }, { value: "zeta", label: "zeta (sin publicar)", current: false }]
syncSummary("remote: ok\nTo /tmp/r.git\n   a1b2..c3d4  main -> main\n") → "a1b2..c3d4  main -> main"
```

## Tests (con estos nombres)

- `la_rama_actual_va_primero`: con `zeta` y `main` (actual) el orden es `main`, `zeta`
- `etiqueta_con_remota_o_sin_publicar`: `main` muestra `↑ origin/main` y `zeta` muestra `(sin publicar)`
- `no_modifica_la_entrada`: el array original conserva su orden tras llamar a `options`
- `resumen_es_la_ultima_linea`: el ejemplo da la línea `a1b2..c3d4  main -> main` sin espacios al principio
- `resumen_vacio`: cadena vacía da `Hecho`
