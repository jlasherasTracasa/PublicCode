## Objetivo

API: `git.branches {}` → `[{name, current, upstream}]`; `git.checkout {branch, create?}` → `true`; `git.pull {}` y `git.push {}` →
texto (el demonio pide antes una aprobación, que aparece en el panel del agente con «Permitir»/«Denegar»).
1. `web_assets.rs`: añade a la tabla `ASSETS` la línea `("ramas.js", include_str!("../web/studio/ramas.js")),`.
2. `index.html`: en el bloque `<script type="module">` final, antes de `inicio();`, añade
   `import * as ramas from "/studio/ramas.js"; Studio.ramas = ramas;`.
3. En `<section id="p-git">`, entre el `<header>` y `<div class="commit">`, añade
   `<div class="fila ramas"><select id="sel-rama" aria-label="Rama"></select><button id="b-rama-nueva" title="Rama nueva">＋</button><button id="b-pull" title="Traer cambios del remoto (pull)">↓ Pull</button><button id="b-push" title="Enviar commits al remoto (push)">↑ Push</button></div>`
   y una regla CSS `.ramas { display: flex; gap: 6px; padding: 6px 14px; } .ramas select { flex: 1; min-width: 0; }`.
4. `refrescaRamas()`: `rpc("git.branches")`, vacía `#sel-rama` y añade un `<option>` por cada elemento de
   `Studio.ramas.options(lista)` (`value`, `textContent = label`, `selected = current`). Si falla (no es un repo git),
   deja el selector vacío. Llámala en `panel()` cuando `nombre === "git"` y después de cada cambio de rama.
5. `$("sel-rama").onchange`: `rpc("git.checkout", { branch: valor })` → `aviso("Rama: " + valor, "ok")`; si falla, `fallo(e)` y
   `refrescaRamas()` (para volver a marcar la rama real).
6. `$("b-rama-nueva").onclick`: `prompt("Nombre de la rama nueva")`; si hay texto, `rpc("git.checkout", { branch, create: true })`,
   `aviso` y `refrescaRamas()`; errores con `fallo(e)`.
7. `sincroniza_remoto(metodo)` para `b-pull` (`"git.pull"`) y `b-push` (`"git.push"`): abre el panel del agente con `agente(true)`,
   muestra `aviso("Aprueba la operación en el panel del agente")`, espera `await rpc(metodo)` y al terminar
   `aviso(Studio.ramas.syncSummary(texto), "ok")` y `refrescaRamas()`; errores con `fallo(e)`. Mientras espera, desactiva
   los dos botones (`disabled = true`) y reactívalos en `finally`.
8. `ORDENES`: `["Git: pull", "", () => sincroniza_remoto("git.pull")]`, `["Git: push", "", () => sincroniza_remoto("git.push")]` y
   `["Git: rama nueva", "", () => { panel("git"); $("b-rama-nueva").click(); }]`.
