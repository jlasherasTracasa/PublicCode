## Objetivo

1. Crea `conflicts.rs` con las firmas de abajo y tests en el mismo archivo.
2. `parse_conflicts(text)`: recorre el texto línea a línea CONSERVANDO el salto de línea de cada una
   (`text.split_inclusive('\n')`). Un conflicto empieza en una línea que empieza por `<<<<<<< ` (lo que sigue es
   `ours_label`); sigue el texto «nuestro» hasta una línea que empieza por `=======`; si antes aparece una línea que empieza
   por `||||||| `, lo que va entre ella y `=======` es `base` (estilo diff3); después va el texto «suyo» hasta la línea que
   empieza por `>>>>>>> ` (lo que sigue es `theirs_label`). Las líneas de marcador no forman parte de ningún texto. Todo lo
   que queda fuera de conflictos va en segmentos `Text` (no generes segmentos `Text` vacíos). Si un conflicto no se cierra
   (falta `>>>>>>>`), todo desde su `<<<<<<<` hasta el final se devuelve como `Text` tal cual.
3. `count_conflicts(segments)`: cuántos segmentos son `Conflict`.
4. `resolve(text, choices)`: vuelve a parsear y sustituye el conflicto número i por: `"ours"` → nuestro; `"theirs"` → suyo;
   `"both"` → nuestro seguido de suyo; `"none"` → nada. Si `choices.len()` no coincide con el número de conflictos:
   `Err(format!("se esperaban {n} elecciones y llegaron {m}"))`. Elección desconocida: `Err(format!("elección desconocida: {c}"))`.
5. `is_conflicted(index, worktree)`: `true` si alguna de las dos letras de `git status` es `U`, o si son `A`+`A` o `D`+`D`.
6. `lib.rs`: añade `pub mod conflicts;` debajo de `pub mod assist;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/conflicts.rs
/// Un trozo de un archivo con marcas de conflicto.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
#[serde(tag = "kind", rename_all = "camelCase")]
pub enum Segment {
    /// Texto sin conflicto.
    Text { text: String },
    /// Un conflicto: nuestra versión, la suya y, si git la dio, la base común.
    #[serde(rename_all = "camelCase")]
    Conflict { ours: String, theirs: String, base: Option<String>, ours_label: String, theirs_label: String },
}
pub fn parse_conflicts(text: &str) -> Vec<Segment>;
pub fn count_conflicts(segments: &[Segment]) -> usize;
/// Texto final tras elegir en cada conflicto `ours`, `theirs`, `both` o `none`.
pub fn resolve(text: &str, choices: &[String]) -> Result<String, String>;
/// Si un archivo de `git status` está en conflicto.
pub fn is_conflicted(index: &str, worktree: &str) -> bool;
```

## Ejemplo (entrada y resultado esperado)

```
text = "a\n<<<<<<< HEAD\nuno\n=======\ndos\n>>>>>>> rama\nz\n"
parse_conflicts(text) == [Text { text: "a\n" }, Conflict { ours: "uno\n", theirs: "dos\n", base: None, ours_label: "HEAD", theirs_label: "rama" }, Text { text: "z\n" }]
resolve(text, &["both".into()]) == Ok("a\nuno\ndos\nz\n")
resolve(text, &[]) == Err("se esperaban 1 elecciones y llegaron 0")
```

## Tests (con estos nombres)

- `parsea_tres_bloques`: un texto con tres conflictos separados por texto da tres `Conflict` y el texto intermedio intacto
- `parsea_base_diff3`: un conflicto con `||||||| base` rellena `base` con el texto entre esa marca y `=======`
- `aceptar_ambos_conserva_orden`: `both` deja primero lo nuestro y después lo suyo, como en el ejemplo
- `aceptar_nuestro_o_suyo`: `ours` da `a\nuno\nz\n` y `theirs` da `a\ndos\nz\n`
- `conflicto_sin_cerrar_se_deja_como_texto`: sin la marca `>>>>>>>` no hay ningún `Conflict` y el texto se conserva entero
- `numero_de_elecciones_incorrecto`: cero elecciones para un conflicto da el `Err` del ejemplo
- `estado_en_conflicto`: `UU`, `AA`, `DU` dan `true`; `M` con espacio y `A` con espacio dan `false`
