## Objetivo

1. Crea `conflictos.js`: módulo ES sin dependencias ni DOM, con las cuatro funciones de abajo exportadas. Los segmentos
   tienen la forma `{ kind: "text", text }` o `{ kind: "conflict", ours, theirs, base, oursLabel, theirsLabel }`.
2. `isConflicted(f)`: recibe un archivo de `git.status` `{ path, index, worktree }`; `true` si `index` o `worktree` es `"U"`, o
   si los dos son `"A"`, o los dos `"D"`.
3. `blockResult(seg, choice)`: texto que deja ese conflicto: `"ours"` → `seg.ours`; `"theirs"` → `seg.theirs`;
   `"both"` → `seg.ours + seg.theirs`; `"none"` → `""`; `undefined` o `null` → `null` (sin decidir).
4. `complete(segments, choices)`: `true` si hay una elección válida (`ours`, `theirs`, `both`, `none`) para cada
   segmento de conflicto. `choices` es un array indexado por número de conflicto (0, 1, 2…), no por número de segmento.
5. `preview(segments, choices)`: texto completo del archivo resultante; los conflictos sin decidir se sustituyen por
   la línea `"⟪ conflicto N sin resolver ⟫\n"` (N desde 1).
6. Crea `conflictos.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const segs = [{ kind: "text", text: "a\n" }, { kind: "conflict", ours: "uno\n", theirs: "dos\n", base: null, oursLabel: "HEAD", theirsLabel: "rama" }, { kind: "text", text: "z\n" }];
preview(segs, ["both"]) → "a\nuno\ndos\nz\n"
preview(segs, [])       → "a\n⟪ conflicto 1 sin resolver ⟫\nz\n"
complete(segs, ["ours"])   → true;   complete(segs, []) → false
```

## Tests (con estos nombres)

- `en_conflicto_por_letras`: `UU`, `AA` y `DU` dan `true`; `M` con espacio da `false`
- `resultado_de_cada_eleccion`: `ours`, `theirs`, `both` y `none` dan el texto esperado y sin elección da `null`
- `aceptar_ambos_conserva_orden`: `preview` con `both` deja primero lo nuestro y después lo suyo
- `vista_previa_marca_lo_pendiente`: sin elecciones aparece la línea `⟪ conflicto 1 sin resolver ⟫`
- `completas_exige_una_eleccion_por_conflicto`: con dos conflictos y una sola elección da `false`
