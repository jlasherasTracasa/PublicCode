## Objetivo

API: `git.conflict {path}` → `{conflicts, segments}`; `git.resolveConflict {path, choices}` → `true` (escribe y hace `git add`).
1. `web_assets.rs`: añade a la tabla `ASSETS` la línea `("conflictos.js", include_str!("../web/studio/conflictos.js")),`.
2. `index.html`: en el bloque `<script type="module">` final, antes de `inicio();`, añade
   `import * as conflictos from "/studio/conflictos.js"; Studio.conflictos = conflictos;`.
3. Junto a `<div id="vista-diff" …>` añade `<div id="vista-conflicto" class="conflicto oculto" aria-label="Conflictos de merge"></div>`.
   CSS: `.conflicto { position: absolute; inset: 0; overflow: auto; padding: 12px 16px 40px; }`,
   `.conflicto .bloque { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 8px; margin: 8px 0; }` y
   `.conflicto pre { margin: 0; padding: 8px; overflow: auto; font: 13px/20px var(--mono); background: var(--superficie-3); border-radius: 8px; }`.
   A 900 px o menos (`@media (max-width: 900px)`), `grid-template-columns: 1fr`.
4. `muestra()`: `$("vista-conflicto").classList.toggle("oculto", !t || t.kind !== "conflicto");` y
   `if (t && t.kind === "conflicto") pintaConflicto(t);` (y que la rama final `else if (!t.binary)` no se ejecute para este tipo:
   añade `else if (t.kind === "conflicto") { /* ya pintado */ }` antes). En `pintaPestanas`, el texto de la pestaña es `"⚠ " + base(t.path)`.
5. `abreConflicto(path)`: `rpc("git.conflict", { path })`; si `conflicts === 0`, `abre(path)`; si no, añade o activa la pestaña
   `{ id: "x:" + path, kind: "conflicto", path, segments, elecciones: [] }`.
6. `pintaConflicto(t)`: barra superior con el título `N conflictos en <ruta>`, botón «✓ Marcar resuelto» (desactivado mientras
   `!Studio.conflictos.complete(t.segments, t.elecciones)`) y botón «✦ Pedir al agente que lo resuelva». Por cada segmento de conflicto, un
   `div.bloque` con tres columnas, cada una con un rótulo y un `<pre>` (`textContent`): «Nuestro (<oursLabel>)» con `seg.ours`,
   «Suyo (<theirsLabel>)» con `seg.theirs` y «Resultado» con `Studio.conflictos.blockResult(seg, t.elecciones[i])` o `"(sin decidir)"`. Debajo, cuatro
   botones: «Aceptar nuestro», «Aceptar suyo», «Aceptar ambos», «Quitar ambos», que guardan `"ours"`, `"theirs"`, `"both"` o
   `"none"` en `t.elecciones[i]` y vuelven a llamar a `pintaConflicto(t)`. El texto sin conflicto no se muestra entero: solo
   una línea tenue `… N líneas sin conflicto …`.
7. «Marcar resuelto»: `rpc("git.resolveConflict", { path: t.path, choices: t.elecciones })` → `aviso("Conflicto resuelto y preparado", "ok")`,
   cierra la pestaña (quítala de `S.tabs`, activa otra) y `abre(t.path)`. «Pedir al agente»:
   `alAgente("Resuelve los conflictos de merge de @" + t.path + " conservando la intención de las dos versiones y explica qué has elegido en cada bloque.")`.
8. En `refrescaGit`, dentro de `grupo`, si `Studio.conflictos.isConflicted(f)`: la letra mostrada es `"!"` y
   `c.onclick = () => abreConflicto(f.path)`.
