## Objetivo

1. Crea `depurador.js`: módulo ES sin imports ni DOM, con las cinco funciones de abajo exportadas. Ninguna modifica
   sus argumentos: devuelven objetos nuevos.
2. `toggleBreakpoint(bps, path, line)`: `bps` es `{ "<ruta>": [líneas desde 1, ordenadas] }`. Si `line` ya está en la lista
   de `path`, la quita; si no, la añade y ordena de menor a mayor. Si la lista queda vacía, borra la clave.
3. `linesOf(bps, path)`: la lista de líneas de esa ruta o `[]`.
4. `initialState()`: `{ status: "idle", reason: "", frames: [], variables: [], output: "", exitCode: null }`.
5. `reduce(state, ev)`: estado nuevo según `ev.tipo`:
   - `"started"` → `initialState()` con `status: "running"`;
   - `"debugStopped"` → `status: "stopped"`, `reason: ev.reason || ""`, `frames: ev.frames || []`, `variables: []`;
   - `"continued"` → `status: "running"`, `reason: ""`, `frames: []`, `variables: []`;
   - `"variables"` → `variables: ev.items`;
   - `"debugOutput"` → `output` = lo anterior + `ev.text`, quedándose solo con los últimos 20000 caracteres;
   - `"debugExited"` → `status: "idle"`, `reason: ""`, `frames: []`, `variables: []`, `exitCode: ev.code` (puede ser `null`);
   - cualquier otro → el mismo `state`.
6. `currentLocation(state)`: `{ path, line }` del primer marco (`state.frames[0]`) si `status === "stopped"` y hay marcos; si no, `null`.
7. Crea `depurador.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
toggleBreakpoint({}, "a.py", 7)                    → { "a.py": [7] }
toggleBreakpoint({ "a.py": [3, 7] }, "a.py", 5)    → { "a.py": [3, 5, 7] }
toggleBreakpoint({ "a.py": [7] }, "a.py", 7)       → {}
reduce(initialState(), { tipo: "debugStopped", reason: "breakpoint", frames: [{ id: 4, name: "main", path: "a.py", line: 7 }] })
  → { status: "stopped", reason: "breakpoint", frames: [{ id: 4, name: "main", path: "a.py", line: 7 }], variables: [], output: "", exitCode: null }
```

## Tests (con estos nombres)

- `alterna_un_punto_de_ruptura`: añadir la línea 7, añadir la 5 (queda ordenado) y quitar la 7
- `quitar_el_ultimo_borra_la_ruta`: al quitar la única línea de `a.py` la clave desaparece
- `no_modifica_la_entrada`: el objeto `bps` original queda igual tras `toggleBreakpoint`
- `parado_guarda_motivo_y_pila`: `debugStopped` deja `status` `stopped`, el `reason` y los marcos, como en el ejemplo
- `salida_se_acumula_y_se_recorta`: dos `debugOutput` se concatenan y con más de 20000 caracteres se conservan los últimos
- `al_terminar_vuelve_a_reposo`: `debugExited` con `code` 1 deja `status` `idle`, sin marcos y `exitCode` 1
- `posicion_actual_solo_si_esta_parado`: `currentLocation` da el primer marco cuando está parado y `null` en marcha
