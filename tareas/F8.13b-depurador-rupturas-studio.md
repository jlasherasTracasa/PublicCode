## Objetivo

Métodos del demonio que se usan (de F9.21; hoy solo depura Python). Antes de escribir, compara con las constantes `DEBUG_…` de
`pub mod methods`; si un nombre o un parámetro difiere, manda el protocolo y anótalo en *Decisiones*:
`debug.start {program, breakpoints: {"<ruta>": [líneas]}}` → `true`; `debug.setBreakpoints {path, lines}` (líneas desde 1) →
líneas verificadas; `debug.stop {}`.
1. `web_assets.rs`: añade a la tabla `ASSETS` la línea `("depurador.js", include_str!("../web/studio/depurador.js")),`.
2. `index.html`: en el bloque `<script type="module">` final, antes de `inicio();`, añade
   `import * as depurador from "/studio/depurador.js"; Studio.depurador = depurador;`.
3. En `<div id="gutter" …>`, después de `<div id="capa-git"></div>`, añade `<div id="capa-rupturas"></div>`. CSS:
   `#capa-rupturas { position: absolute; top: 10px; left: 8px; width: 10px; }` y
   `.ruptura { position: absolute; width: 9px; height: 9px; margin-top: 6px; border-radius: 50%; background: var(--error); }`.
4. Estado: `S.rupturas = {}` y `S.dep = null` (se rellena con `Studio.depurador.initialState()` al iniciar).
   `pintaRupturas()`: vacía `#capa-rupturas` y, para cada línea de `Studio.depurador.linesOf(S.rupturas, t.path)` de la pestaña
   activa, añade un `div.ruptura` con `top = (línea - 1) * 21` px (igual que `pintaMarcas`). Llámala al final de `muestra()` en
   la rama de archivos (junto a `pintaMarcas()`).
5. `alternaRuptura(linea)`: `S.rupturas = Studio.depurador.toggleBreakpoint(S.rupturas, t.path, linea)`, `pintaRupturas()` y, si
   hay sesión (`S.dep && S.dep.status !== "idle"`), `rpc("debug.setBreakpoints", { path: t.path, lines: linesOf(…) })` (errores con `fallo`).
   Se llama: a) al hacer clic en `#gutter` (`$("gutter").addEventListener("click", …)`: la línea es
   `Math.floor((e.clientY - ta.getBoundingClientRect().top + ta.scrollTop - 10) / 21) + 1`; ignora el clic si el objetivo
   tiene la clase `gm`, que son las marcas de git); b) con `F9` sobre la línea del cursor (`posCursor().line + 1`).
6. `iniciaDepuracion()`: pestaña de archivo; si está sucia, `await guarda()`. `S.dep = Studio.depurador.reduce(Studio.depurador.initialState(), { tipo: "started" })`.
   Después `rpc("debug.start", { program: t.path, breakpoints: S.rupturas })` (`S.rupturas` ya tiene la forma que pide el
   demonio). Si falla: `S.dep = null` y `fallo(e)`. `detieneDepuracion()`: `rpc("debug.stop")` y `S.dep = null`.
7. Teclado, en el `document.addEventListener("keydown", …)` global, ANTES de la línea `const c = e.ctrlKey || e.metaKey; if (!c) return;`:
   `F5` sin sesión → `iniciaDepuracion()`; `Mayús+F5` → `detieneDepuracion()`; `F9` → `alternaRuptura(…)`; siempre con `e.preventDefault()`.
8. `ORDENES`: `["Depurar: iniciar con el archivo abierto", "F5", …]`, `["Depurar: detener", "Mayús F5", …]` y
   `["Depurar: poner o quitar punto de ruptura", "F9", …]`.
