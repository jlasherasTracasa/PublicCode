## Objetivo

1. Crea `test_discovery.rs` con las firmas de abajo y tests en el mismo archivo. Solo se parsea texto.
2. `parse_cargo_list(out)`: salida de `cargo test -- --list --format terse`. Valen solo las líneas que terminan en `: test`.
   `id` = lo anterior a `: test`; `name` = lo que va tras el último `::` del id; `group` = lo anterior a ese `::` (o `""`).
   Se ignoran las líneas `: benchmark`, las vacías, los resúmenes (`12 tests, 0 benchmarks`) y los doc-tests (id con espacios).
3. `parse_pytest_collect(out)`: salida de `python3 -m pytest --collect-only -q`. Valen las líneas que contienen `::` y no
   tienen espacios. `id` = la línea entera; `group` = lo anterior al primer `::` (el archivo); `name` = lo posterior.
4. `parse_go_list(out)`: salida de `go test -list . ./...`. Valen las líneas que empiezan por `Test` y no tienen espacios.
   `id` = `name` = la línea; `group` = `""`. Las líneas `ok  paquete 0.01s` se ignoran.
5. `parse_list(runner, out)`: reparte según `runner` (`"cargo"`, `"pytest"`, `"go"`); otro → `Err(format!("no se pueden listar tests con {runner}"))`.
   En todos, `runner` se copia al campo `runner`, se quitan duplicados de `id` (queda el primero) y se respeta el orden de llegada.
6. `lib.rs`: añade `pub mod test_discovery;` debajo de `pub mod settings;`.

```rust
/// Un test descubierto.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct TestItem { pub id: String, pub name: String, pub group: String, pub runner: String }

pub fn parse_cargo_list(out: &str) -> Vec<TestItem>;
pub fn parse_pytest_collect(out: &str) -> Vec<TestItem>;
pub fn parse_go_list(out: &str) -> Vec<TestItem>;

pub fn parse_list(runner: &str, out: &str) -> Result<Vec<TestItem>, String>;
```

## Ejemplo (entrada y resultado esperado)

```
parse_cargo_list("workspace::tests::lista_lee_y_escribe: test\nrapido: test\n\n2 tests, 0 benchmarks\n")
  == [TestItem { id: "workspace::tests::lista_lee_y_escribe", name: "lista_lee_y_escribe", group: "workspace::tests", runner: "cargo" },
      TestItem { id: "rapido", name: "rapido", group: "", runner: "cargo" }]
parse_pytest_collect("tests/test_a.py::TestX::test_y\n\n1 test collected in 0.01s\n")
  == [TestItem { id: "tests/test_a.py::TestX::test_y", name: "TestX::test_y", group: "tests/test_a.py", runner: "pytest" }]
parse_go_list("TestSuma\nok  \tejemplo/x\t0.003s\n") == [TestItem { id: "TestSuma", name: "TestSuma", group: "", runner: "go" }]
```

## Tests (con estos nombres)

- `lista_de_cargo`: el ejemplo de cargo da dos tests y no incluye el resumen ni líneas vacías
- `cargo_ignora_benchmarks_y_doctests`: una línea `x: benchmark` y otra `src/lib.rs - foo (line 3): test` no aparecen
- `lista_de_pytest`: el ejemplo de pytest da un test con el archivo como grupo
- `lista_de_go`: el ejemplo de go da solo `TestSuma`
- `sin_duplicados`: la misma línea dos veces da un solo test
- `ejecutor_desconocido`: `parse_list("npm", "")` da `Err` que contiene `no se pueden listar`
