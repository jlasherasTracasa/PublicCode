## Objetivo

1. Crea `test_runners.rs` con las firmas de abajo y tests en el mismo archivo (con `tempfile::tempdir()`).
2. `detect_runners(root)`, en este orden y solo los que correspondan:
   - `cargo` si existe `Cargo.toml`: `label "Rust (cargo)"`, `list Some("cargo test -- --list --format terse")`, `run_all "cargo test"`;
   - `pytest` si existe `pyproject.toml`, `pytest.ini`, `setup.py` o el directorio `tests`: `label "Python (pytest)"`,
     `list Some("python3 -m pytest --collect-only -q")`, `run_all "python3 -m pytest -v"`;
   - `go` si existe `go.mod`: `label "Go"`, `list Some("go test -list . ./...")`, `run_all "go test -v ./..."`;
   - `npm` si existe `package.json` y su texto contiene `"test"`: `label "npm test"`, `list None`, `run_all "npm test"`.
3. `valid_test_id(id)`: `true` si no está vacío, tiene como mucho 300 caracteres y solo usa `A-Z a-z 0-9 _ : . / -`.
4. `run_command(runner, test)`: con `test == None` devuelve el `run_all` de ese ejecutor. Con `Some(id)`: si
   `!valid_test_id(id)` → `Err("nombre de test no admitido".into())`; `cargo` → `cargo test -- --exact <id>`;
   `pytest` → `python3 -m pytest -v <id>`; `go` → `go test -v -run '^<id>$' ./...` (con las comillas simples);
   `npm` → `Err("npm test no permite ejecutar un solo test".into())`. Ejecutor desconocido →
   `Err(format!("ejecutor de tests desconocido: {runner}"))`.
5. `lib.rs`: añade `pub mod test_runners;` debajo de `pub mod settings;`.

## Firmas (cópialas tal cual)

```rust
use std::path::Path;

/// Un ejecutor de tests detectado en el proyecto.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Runner { pub id: String, pub label: String, pub list: Option<String>, pub run_all: String }

pub fn detect_runners(root: &Path) -> Vec<Runner>;
pub fn valid_test_id(id: &str) -> bool;
/// Orden de shell para ejecutar todos los tests (`None`) o uno.
pub fn run_command(runner: &str, test: Option<&str>) -> Result<String, String>;
```
