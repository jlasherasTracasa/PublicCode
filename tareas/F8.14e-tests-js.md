## Objetivo

1. Crea `pruebas.js`: módulo ES sin imports ni DOM, con las cuatro funciones de abajo exportadas. Un test es
   `{ id, name, group, runner }`; el estado es un objeto `{ "<id>": "ok" | "fail" }` (sin clave = sin ejecutar).
2. `groupTests(items)`: devuelve `[{ group, items }]` ordenado por `group` (alfabético; el grupo `""` va el primero y se
   llama `"(raíz)"` en el campo `group` del resultado) y, dentro, los tests por `name`. No modifica la entrada.
3. `applyResults(state, results)`: `results` es `[{ id, ok }]`. Devuelve un estado NUEVO con `"ok"` o `"fail"` para cada id
   recibido y el resto igual.
4. `counts(items, state)`: `{ total, ok, fail, pending }` contando solo los ids de `items`.
5. `mark(status)`: `"ok"` → `"✓"`, `"fail"` → `"✗"`, cualquier otro (incluido `undefined`) → `"·"`.
6. Crea `pruebas.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const items = [{ id: "b::dos", name: "dos", group: "b", runner: "cargo" }, { id: "uno", name: "uno", group: "", runner: "cargo" }];
groupTests(items) → [{ group: "(raíz)", items: [items[1]] }, { group: "b", items: [items[0]] }]
applyResults({ uno: "ok" }, [{ id: "b::dos", ok: false }]) → { uno: "ok", "b::dos": "fail" }
counts(items, { uno: "ok" }) → { total: 2, ok: 1, fail: 0, pending: 1 }
```

## Tests (con estos nombres)

- `agrupa_y_ordena`: el ejemplo da primero `(raíz)` y después `b`, con los tests por nombre
- `aplica_resultados_sin_mutar`: el estado original no cambia y el nuevo tiene `fail` para el id recibido
- `cuenta_ok_fallidos_y_pendientes`: el ejemplo de `counts` da total 2, ok 1, fail 0, pending 1
- `ignora_resultados_de_tests_que_no_estan`: `counts` no cuenta un id del estado que no está en `items`
- `marca_por_estado`: `ok` da ✓, `fail` da ✗ y sin estado da ·

## No hagas

- No uses `document`, `window` ni imports
- No dependas solo del color en ningún sitio: por eso existe `mark`
