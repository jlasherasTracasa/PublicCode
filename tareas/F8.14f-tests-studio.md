## Objetivo

API: `tests.runners {}` → `[{id, label, list?, runAll}]`; `tests.command {runner, test?}` → orden; `tests.parse {runner, mode, output}` →
tests `[{id, name, group, runner}]` (modo `list`) o resultados `[{id, ok}]` (modo `run`); `terminal.run {command}` → `{id}` con eventos
`terminalOutput {id, text}` y `terminalExit {id, code}`.
1. `web_assets.rs`: añade a `ASSETS` la línea `("pruebas.js", include_str!("../web/studio/pruebas.js")),`. `index.html`: en el bloque
   `<script type="module">` final, antes de `inicio();`: `import * as pruebas from "/studio/pruebas.js"; Studio.pruebas = pruebas;`.
2. Panel: sección `<section id="p-pruebas" class="panel oculto"><header>Tests <span id="pruebas-cuenta"></span><div class="acciones"><button id="b-pruebas-todo" title="Ejecutar todos">▶</button><button id="b-pruebas" title="Volver a descubrir">⟳</button></div></header><div id="pruebas" class="scroll"></div></section>`
   junto a `p-actividad`; botón `<button data-panel="pruebas" aria-pressed="false" title="Tests">✓</button>` en `<nav class="actividad">`
   antes de `b-ajustes`; en `panel()`, `"pruebas"` en el array y `if (nombre === "pruebas" && !S.pruebas) descubrePruebas();`.
3. `capturaOrden(cmd)`: devuelve una promesa de `{ code, output }`. Hace `rpc("terminal.run", { command: cmd })`, guarda
   `S.capturas[id] = { salida: "", resolve }` (`S.capturas = {}` al principio) y abre la terminal con `terminal(true)`. En `conecta()`:
   en `terminalOutput`, si `S.capturas[e.id]`, acumula `e.text` en `salida` (máx. 400000 caracteres) y escríbelo también con
   `escribeSalida(document.createTextNode(e.text))`; en `terminalExit`, si `S.capturas[e.id]`, llama a
   `resolve({ code: e.code, output: salida })` y borra la entrada. No toques el manejo de `S.terminal`.
4. `descubrePruebas()`: `S.pruebas = { runners: await rpc("tests.runners"), items: [], estado: {}, salida: {} }`. Para cada ejecutor con
   `list`: `capturaOrden(r.list)` y `rpc("tests.parse", { runner: r.id, mode: "list", output })`; junta los tests en `items`. Los
   ejecutores sin `list` se muestran solo con su botón «▶ Ejecutar todos (<label>)». Al final, `pintaPruebas()`.
5. `ejecutaPruebas(runner, test)`: `cmd = await rpc("tests.command", { runner, test })`; `r = await capturaOrden(cmd)`;
   `res = await rpc("tests.parse", { runner, mode: "run", output: r.output })`;
   `S.pruebas.estado = Studio.pruebas.applyResults(S.pruebas.estado, res)`; guarda `S.pruebas.ultima = { cmd, code: r.code, output: r.output }` y `pintaPruebas()`.
6. `pintaPruebas()`: `#pruebas-cuenta` = `· ✓ n  ✗ m  · k` con `Studio.pruebas.counts`. Por cada grupo de `groupTests(items)`, un
   título `grupo-titulo` y una fila `button.problema` por test con `mark(estado[id])` + nombre (clases `e` para ✗ y `ok` para ✓,
   además del símbolo); al pulsar, `ejecutaPruebas(t.runner, t.id)`. Si hay algún `fail`, al final un botón
   `chispa mini` «✦ Pedir al agente que arregle los tests» que hace
   `alAgente(await rpc("assist.prompt", { kind: "orden", command: ultima.cmd, code: ultima.code, output: ultima.output.slice(-60000) }))`.
   Sin ejecutores: `el("div", "vacio", "No se han encontrado tests (cargo, pytest, go o npm test).")`.
7. `b-pruebas` → `descubrePruebas()`; `b-pruebas-todo` → `ejecutaPruebas(r.id)` para cada ejecutor, uno detrás de otro.
   `ORDENES`: `["Tests: abrir el explorador", "", () => panel("pruebas")]` y `["Tests: ejecutar todos", "", () => $("b-pruebas-todo").click()]`.
