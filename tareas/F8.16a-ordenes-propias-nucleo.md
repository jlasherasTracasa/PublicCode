## Objetivo

Una orden propia es un archivo Markdown: el nombre del archivo sin `.md` es la orden (`/revisar` ← `revisar.md`) y
el cuerpo es la plantilla del mensaje. El frontmatter es opcional.
1. Crea `custom_commands.rs` con lo de *Firmas* y sus tests; en `lib.rs`, `pub mod custom_commands;` y
   `pub use custom_commands::{CustomCommand, load_commands};`.
2. `split_frontmatter(text)`: quita el CRLF; si empieza por `---\n` y hay un `\n---` después, devuelve las líneas
   `clave: valor` del frontmatter (clave y valor recortados, sin comillas alrededor del valor) y el cuerpo sin los
   saltos de línea iniciales; si no, `(vacío, texto entero)`. Lo usarán también los agentes propios (F8.17a).
3. `parse_command(name, text)`: claves `descripcion` (si falta, la primera línea no vacía del cuerpo, recortada a 80
   caracteres), `modelo` (opcional) y `plan` (`true` → modo plan). Cuerpo vacío → `Err("la orden <name> está vacía")`.
4. `expand(args)`: sustituye cada `$ARGUMENTOS` por `args` recortado; si la plantilla no tiene `$ARGUMENTOS` y `args`
   no está vacío, añade `"\n\n"` y los argumentos al final.
5. `load_commands(dirs)`: lee cada carpeta en orden (las que no existen se saltan); solo archivos `.md` con nombre en
   minúsculas, cifras y guiones; una carpeta posterior sustituye las órdenes con el mismo nombre (pásale la global
   primero y la del proyecto después). Las que no se pueden leer o dan error se saltan. Resultado ordenado por nombre.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-skills/src/custom_commands.rs
//! Órdenes propias: `.pcode/ordenes/<nombre>.md` → `/nombre`.
use std::collections::BTreeMap;
use std::path::PathBuf;

/// Una orden propia.
#[derive(Debug, Clone, PartialEq)]
pub struct CustomCommand {
    pub name: String,
    pub description: String,
    pub model: Option<String>,
    pub plan: bool,
    pub template: String,
}

/// Frontmatter `clave: valor` y cuerpo de un Markdown.
pub fn split_frontmatter(text: &str) -> (BTreeMap<String, String>, String);

/// Lee una orden a partir de su nombre y su texto.
pub fn parse_command(name: &str, text: &str) -> Result<CustomCommand, String>;

impl CustomCommand {
    /// El mensaje para el agente con estos argumentos.
    pub fn expand(&self, args: &str) -> String;
}

/// Órdenes de varias carpetas; las posteriores mandan.
pub fn load_commands(dirs: &[PathBuf]) -> Vec<CustomCommand>;
```

## Tests (con estos nombres)

- `custom_commands_plantilla_con_argumentos`: plantilla `Revisa $ARGUMENTOS` y args ` src/a.rs ` → `Revisa src/a.rs`
- `custom_commands_sin_marcador_anade_al_final`: plantilla `Explica` y args `x` → `Explica\n\nx`
- `custom_commands_frontmatter_activa_modo_plan`: frontmatter con `plan: true` y `modelo: m1` → `plan` y `model == Some("m1")`
- `custom_commands_descripcion_por_defecto`: sin frontmatter y cuerpo `Haz X\nmás` → descripción `Haz X`
- `custom_commands_proyecto_manda_sobre_global`: `a.md` en las dos carpetas → gana la segunda; `B.md` y `c.txt` se ignoran
