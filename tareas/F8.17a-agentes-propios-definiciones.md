## Objetivo

Un agente propio es `.pcode/agentes/<nombre>.md`: frontmatter con `descripcion` (obligatoria), `modelo`, `tools`
(lista separada por comas; vacía = todas) y `solo_lectura` (`true`/`false`, por defecto `false`); el cuerpo es su
prompt de sistema.
1. Crea `agent_defs.rs` con lo de *Firmas* y sus tests; en `lib.rs`, `pub mod agent_defs;` y
   `pub use agent_defs::{AgentDef, load_agents};`.
2. `parse_agent(name, text)` usa `custom_commands::split_frontmatter`. Sin `descripcion` →
   `Err("el agente <name> no tiene descripcion")`; cuerpo vacío → `Err("el agente <name> no tiene prompt")`.
   `tools`: separa por comas, recorta y quita vacíos (admite también `[a, b]`: quita los corchetes).
3. `load_agents(dirs)`: igual que `load_commands` (solo `.md` con nombre en minúsculas, cifras y guiones; la carpeta
   posterior manda; los que dan error se saltan; ordenados por nombre).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-skills/src/agent_defs.rs
//! Agentes propios: `.pcode/agentes/<nombre>.md`.
use std::path::PathBuf;

/// Un agente propio.
#[derive(Debug, Clone, PartialEq)]
pub struct AgentDef {
    pub name: String,
    pub description: String,
    pub model: Option<String>,
    pub tools: Vec<String>,
    pub read_only: bool,
    pub prompt: String,
}

/// Lee un agente a partir de su nombre y su texto.
pub fn parse_agent(name: &str, text: &str) -> Result<AgentDef, String>;

/// Agentes de varias carpetas; las posteriores mandan.
pub fn load_agents(dirs: &[PathBuf]) -> Vec<AgentDef>;
```
