## Objetivo

`pcode-core` no depende de `pcode-skills`: la definición que recibe es `SubagentSpec` (la CLI convierte cada
`AgentDef` en uno). El subagente usa el mismo proveedor, la misma política que el padre (nunca más), solo las tools
de su lista y su propio prompt; no tiene aprobador (lo que pida aprobación se deniega).
1. Crea `subagent.rs` con lo de *Firmas* y sus tests; en `lib.rs`, `pub mod subagent;` y
   `pub use subagent::{DelegateTool, SubagentSpec};`.
2. `DelegateTool::new`: guarda las tools del registro (con `specs_filtered(|_, _| true)` + `get`) y el resto.
3. `spec()`: nombre `delegar`; descripción «Encarga una tarea a un agente especializado y devuelve su informe.
   Agentes: <nombre>: <descripción>; …»; parámetros `{"type":"object","properties":{"agente":{"type":"string"},
   "tarea":{"type":"string"}},"required":["agente","tarea"]}`. `effects()`: `&[Effect::Write]` (así el modo plan del
   padre no puede delegar en un agente que escribe).
4. `call(args, ctx)`: agente desconocido → `ToolOutput::error("agente desconocido: <x>; hay: <lista>")`. Si no:
   registro nuevo solo con las tools de `spec.tools` (todas si está vacía; nunca `delegar`, para que no haya
   recursión); `Agent::new(provider, registro, policy.clone(), None, AgentConfig { agent_id: "sub:<nombre>",
   model: spec.model o el modelo por defecto, system_prompt: spec.prompt, budget: Budget { max_steps: 20, ..Default::default() },
   stop_hook: None }, ctx.clone())`; `set_read_only(spec.read_only)`; `run(tarea)`. `Done { final_message }` →
   `ToolOutput::ok("Informe de <nombre>:\n<final_message>")`; cualquier otro resultado → `ToolOutput::error` con
   `"<nombre> no terminó: <outcome:?>"`.

## Tests (con estos nombres)

- `subagent_informe_vuelve_al_padre`: guion del proveedor con una respuesta de texto `listo` → `call` da `is_error == false` y contiene `listo`
- `subagent_no_amplia_capacidades`: política con `deny_write = ["**"]` y guion que llama a `escribir` y luego responde → el archivo no existe
- `subagent_agente_de_solo_lectura`: spec con `read_only: true` y guion que llama a `escribir` → el archivo no existe
- `subagent_solo_sus_tools`: spec con `tools = ["leer"]` → la primera petición al MockProvider solo anuncia `leer`
- `subagent_desconocido`: `agente: "x"` → error que contiene `agente desconocido`
