## Objetivo

1. Crea `pricing.rs` con lo de *Firmas* y sus tests; en `lib.rs`, `pub mod pricing;` y `pub use pricing::{Price, cost_usd};`.
2. `cost_usd(usage, price)`: precios en dólares por MILLÓN de tokens. Entrada sin caché =
   `input_tokens - cached_input_tokens` (con `saturating_sub`); la cacheada se cobra a `price.cache_read` si es
   `Some`, o a `price.input` si es `None`. Resultado: `(sin_caché * input + cacheada * cache + output_tokens * output) / 1e6`.
3. `budget_state(spent, limit)`: `limit <= 0` → `Ok`; `spent >= limit` → `Stop`; `spent >= 0.8 * limit` → `Warn`;
   si no, `Ok`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-models/src/pricing.rs
//! Precios por millón de tokens y presupuesto en dólares.
use crate::types::Usage;

/// Precio de un modelo en dólares por millón de tokens.
#[derive(Debug, Clone, Copy, PartialEq, Default)]
pub struct Price { pub input: f64, pub output: f64, pub cache_read: Option<f64> }

/// Estado del presupuesto.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BudgetState { Ok, Warn, Stop }

/// Coste en dólares de un uso.
pub fn cost_usd(usage: &Usage, price: &Price) -> f64;

/// Avisa al 80 % y para al 100 %.
pub fn budget_state(spent: f64, limit: f64) -> BudgetState;
```
