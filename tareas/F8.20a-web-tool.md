## Objetivo

1. `Cargo.toml` de pcode-tools: `reqwest.workspace = true` en `[dependencies]`.
2. `web.rs` con lo de *Firmas*; en `lib.rs`, `pub mod web;`. NO la añadas a `native_registry` (la registra el chat
   en F8.20b).
3. `html_to_text(html)`: quita los bloques `<script…>…</script>`, `<style…>…</style>` y los comentarios `<!-- -->`
   (sin distinguir mayúsculas), cambia `<br>`, `</p>`, `</div>`, `</li>` y `</h1>`…`</h6>` por saltos de línea, quita
   el resto de etiquetas, decodifica `&amp; &lt; &gt; &quot; &#39; &nbsp;`, recorta cada línea, junta espacios
   seguidos y deja como mucho una línea vacía seguida. Con `regex` (ya es dependencia).
4. `host_of(url)`: el host de una URL `http://` o `https://` (sin usuario, puerto ni ruta), en minúsculas; otro
   esquema → `None`.
5. `WebTool`: `spec()` nombre `web`, descripción «Lee una página web (GET) y devuelve su texto», parámetros
   `{"url": string}` obligatorio. `effects()` → `&[Effect::Network]`. `call`: `host_of` None → error «solo URLs
   http(s)»; GET con `timeout = ctx.timeout.min(30 s)` (sin proxy si el host es `127.0.0.1` o `localhost`); estado
   no 2xx → error `HTTP <código>`; lee el cuerpo por trozos (`chunk()`) y para al pasar de `self.max_bytes`,
   añadiendo `\n[… recortado a <max_bytes> bytes]`; si el `content-type` contiene `html`, `html_to_text`; si es
   `text/` o `json`, el texto tal cual; otro tipo → error «tipo no admitido: <tipo>».
6. Tests de integración `tests/web.rs` con un servidor HTTP falso en 127.0.0.1 (copia el de `discover.rs`).

#[async_trait::async_trait]

## Tests (con estos nombres)

- `html_a_texto_sin_scripts`: `<p>Hola &amp; adiós</p><script>x()</script><style>p{}</style>` → `Hola & adiós` sin `x()` ni `p{}`
- `host_de_la_url`: `https://User@Ejemplo.com:8080/a?b` → `ejemplo.com`; `ftp://x` → None
