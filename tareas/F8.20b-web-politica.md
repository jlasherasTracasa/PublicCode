## Objetivo

1. `agent.rs`: tras las comprobaciones de `Write` y `Exec`, añade: si la decisión sigue en `Allow`, la tool tiene
   `Effect::Network` y `arg("url")` es `Some(u)`: con `pcode_tools::web::host_of(&u)` → `None` →
   `Decision::Deny("URL no válida")`; `Some(h)` → `self.policy.check_domain(&h)`, y si da `Deny(_)` se convierte en
   `Decision::Ask(format!("dominio fuera de red_permitir: {h}"))` (el usuario puede aprobarlo; sin aprobador se
   deniega, como cualquier `Ask`).
2. `chat.rs`, `prepare`: tras `native_registry()`, registra `pcode_tools::web::WebTool::default()`.
3. Tests en `agent.rs` con una tool falsa `web` de efecto `Network` (como las tools de prueba del módulo) que
   devuelve `ok`.

Sin firmas: no añade API pública: cambia una decisión dentro de `Agent` y registra una tool

## Tests (con estos nombres)

- `web_domain_permitido_se_ejecuta`: `net_allow = ["ejemplo.com"]` y llamada con `url` `https://ejemplo.com/x` → la tool se ejecuta
- `web_domain_no_permitido_pide_aprobacion`: sin `net_allow` y sin aprobador → el resultado contiene `requiere aprobación humana`; con el aprobador `Yes` → se ejecuta
- `web_domain_url_invalida`: `url` `file:///etc/passwd` → `denegado por la política`
