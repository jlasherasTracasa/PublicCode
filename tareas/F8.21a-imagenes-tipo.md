## Objetivo

1. Crea `image.rs` con lo de *Firmas*; en `lib.rs`, `pub mod image;` y `pub use image::ImagePart;`.
2. `base64_encode`: alfabeto estándar con `=` de relleno (no hay crate de base64 permitido: escríbelo, son ~20 líneas).
3. `media_type_for(path)`: por la extensión en minúsculas: `png` → `image/png`, `jpg`/`jpeg` → `image/jpeg`, `gif` →
   `image/gif`, `webp` → `image/webp`; otra → `None`.
4. `ImagePart::from_bytes(media_type, bytes)`: más de `MAX_IMAGE_BYTES` → `Err("imagen demasiado grande (<n> bytes, máximo 5 MB)")`.
5. `types.rs`: añade a `Message` el campo `images` de *Firmas* (con `#[serde(default, skip_serializing_if = "Vec::is_empty")]`),
   `images: vec![]` en `Message::new` y el constructor `Message::user_with_images`.
6. `anthropic.rs`, `Role::User`: sin imágenes, igual que ahora; con imágenes, `content` es una lista: primero un
   bloque por imagen `{"type":"image","source":{"type":"base64","media_type":…,"data":…}}` y después
   `{"type":"text","text":…}`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-models/src/image.rs
//! Imágenes en los mensajes (para modelos con visión).
use serde::{Deserialize, Serialize};

/// Tamaño máximo de una imagen: 5 MB.
pub const MAX_IMAGE_BYTES: usize = 5 * 1024 * 1024;

/// Una imagen adjunta.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct ImagePart { pub media_type: String, pub data_base64: String }

impl ImagePart {
    pub fn from_bytes(media_type: &str, bytes: &[u8]) -> Result<ImagePart, String>;
}

pub fn base64_encode(bytes: &[u8]) -> String;
pub fn media_type_for(path: &std::path::Path) -> Option<&'static str>;

// crates/pcode-models/src/types.rs, en `pub struct Message`
    /// Imágenes adjuntas (solo en mensajes de usuario).
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub images: Vec<crate::image::ImagePart>,

impl Message {
    /// Mensaje de usuario con imágenes.
    pub fn user_with_images(text: impl Into<String>, images: Vec<crate::image::ImagePart>) -> Self;
}
```

## Tests (con estos nombres)

- `image_base64_vectores`: ``, `f`, `fo`, `foo`, `foob` → ``, `Zg==`, `Zm8=`, `Zm9v`, `Zm9vYg==`
- `image_tipo_por_extension`: `a.PNG` → image/png; `b.jpeg` → image/jpeg; `c.txt` → None
- `image_demasiado_grande`: 5 MB + 1 byte → Err con `demasiado grande`
- `image_anthropic_con_imagen`: usuario con una imagen → `content[0].type == "image"`, `source.data` y el texto en `content[1]`
- `image_mensaje_sin_imagenes_no_cambia`: `Message::user("a")` serializado no contiene `images`
