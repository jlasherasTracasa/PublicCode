## Objetivo

Solo cambia el mensaje de usuario con imágenes; sin imágenes, el cuerpo es idéntico al de ahora.
1. `gemini.rs`: `parts` = un `{"inline_data":{"mime_type":…,"data":…}}` por imagen y después `{"text":…}`.
2. `openai.rs`: `content` pasa a ser una lista: `{"type":"text","text":…}` y después un
   `{"type":"image_url","image_url":{"url":"data:<media_type>;base64,<data>"}}` por imagen.
3. Tests en los módulos de tests de cada archivo.

Sin firmas: solo cambia dos conversiones existentes

## Tests (con estos nombres)

- `image_gemini_inline_data`: usuario con imagen → `contents[0].parts[0].inline_data.mime_type` es el tipo y el texto va después
- `image_openai_image_url_base64`: usuario con imagen → `messages[0].content[1].image_url.url` empieza por `data:image/png;base64,`
- `image_openai_sin_imagen_sigue_siendo_texto`: `Message::user("a")` → `content` es la cadena `a`
