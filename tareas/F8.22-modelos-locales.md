## Objetivo

Detectar Ollama, LM Studio y vLLM ya existe (`pcode config proveedores --detectar`) y `/modelos` en la TUI es F8.24.
Falta lo más útil para empezar sin cuenta: si no hay ningún modelo configurado ni clave, usar uno local.
1. `provider.rs`: añade `local_provider_cfg` (*Firmas*): el primer servidor con algún modelo →
   `(name, ProviderCfg { kind: "openai-compatible", url, model: Some(primer modelo), ..Default })`; ninguno → `None`.
2. `provider.rs`: añade `build_provider_or_local` y su variante con candidatos: llama a `build_provider`; si da
   error, `name` es `None` y `cfg.providers` está vacío, prueba `detect_local(candidates, 300 ms)`; con
   `local_provider_cfg` `Some((n, p))` → escribe por stderr «Sin clave de API: uso <modelo> de <n> en este equipo» y
   devuelve `from_cfg(&n, &p)`; si no, devuelve el error original.
3. En `chat.rs` (`prepare`), `ask.rs` y `run.rs` cambia `build_provider(…)?` por
   `build_provider_or_local(…).await?` (las tres funciones ya son `async`).
4. Tests unitarios en `provider.rs` con un servidor falso en 127.0.0.1 (copia el de `discover.rs`) y candidatos
   `[("ollama", "Ollama", "<url del falso>/v1")]`. Aísla el entorno: quita `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`,
   `GOOGLE_API_KEY`, `OPENAI_API_KEY` y `PCODE_MOCK_SCRIPT` con `unsafe { std::env::remove_var(..) }` y un comentario
   `// SAFETY de la prueba:`; si alguna estaba definida al empezar, el test termina sin comprobar (la CI no las tiene).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/provider.rs
/// Proveedor para el primer servidor local que ofrece algún modelo.
pub fn local_provider_cfg(servers: &[pcode_models::discover::LocalServer]) -> Option<(String, ProviderCfg)>;

/// `build_provider` y, si no hay ningún modelo configurado, un servidor local.
pub async fn build_provider_or_local(cfg: &Config, name: Option<&str>) -> anyhow::Result<Selected>;

/// Igual, con los servidores candidatos y el tiempo máximo de cada sonda (para las pruebas).
pub async fn build_provider_or_local_with(cfg: &Config, name: Option<&str>, candidates: &[(&str, &str, &str)], timeout: std::time::Duration) -> anyhow::Result<Selected>;
```

## Tests (con estos nombres)

- `local_elige_el_primero_con_modelos`: servidores `a` sin modelos y `b` con `["q"]` → `("b", url de b, modelo q)`
- `local_ninguno_es_none`: lista vacía → None
- `local_detecta_ollama_falso`: config vacía, sin claves y servidor falso con `{"data":[{"id":"qwen3"}]}` → `Selected` con `default_model == Some("qwen3")`
- `local_sin_servidor_no_espera`: config vacía, sin claves y candidato en un puerto cerrado → Err en menos de 2 s
