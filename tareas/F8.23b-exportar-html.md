# F8.23b-exportar-html — Exportar: conversación a HTML autocontenido (lógica pura)

## Objetivo

1. Añade a `exportar.rs` las funciones `escape_html` y `to_html` (firmas abajo).
2. `escape_html`: `&` → `&amp;`, `<` → `&lt;`, `>` → `&gt;`, `"` → `&quot;` (el `&` primero).
3. `to_html` devuelve un documento completo: `<!doctype html>`, `<html lang="es">`, `<head>` con
   `<meta charset="utf-8">`, `<title>` (título escapado) y un único `<style>` en línea; `<body>` con `<h1>`
   (título), `<p class="meta">Modelo: … · n mensajes</p>` y, por cada mensaje (mismo recorrido que
   `to_markdown`):
   - usuario: `<section class="msg user"><h2>Usuario</h2><pre>contenido escapado</pre></section>`
   - asistente: `<section class="msg assistant"><h2>Asistente</h2>` + `<pre>contenido</pre>` si no está vacío +
     por cada tool `<details class="tool"><summary>🔧 nombre</summary><pre>argumentos</pre><pre>salida</pre></details>`
     + `</section>`.
   Todo el texto que venga de los mensajes pasa por `escape_html`.
4. El `<style>` usa estos colores: fondo `#0b1220`, texto `#d3e3fd`, acento `#8ab4f8`, fondo de `pre`
   `#182b46`; con `@media (prefers-color-scheme: light)`: fondo `#ffffff`, texto `#041e49`, acento `#0b57d0`,
   fondo de `pre` `#eaf2fd`. `pre { white-space: pre-wrap; }`. Fuente: `system-ui, sans-serif` (ninguna
   fuente remota).
5. El documento no contiene ninguna URL ni recurso externo: ni `http://` ni `https://` propios, ni `<link`,
   ni `<script`, ni `<img`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/exportar.rs
/// Escapa texto para meterlo en HTML.
pub fn escape_html(s: &str) -> String;

/// La conversación como una página HTML que no carga nada de fuera.
pub fn to_html(title: &str, model: &str, messages: &[Message]) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
escape_html("a < b && \"c\"") == "a &lt; b &amp;&amp; &quot;c&quot;"
to_html("t", "m", &[Message::user("<script>alert(1)</script>")]) contiene
  "<pre>&lt;script&gt;alert(1)&lt;/script&gt;</pre>"  y no contiene "<script"
```

## Tests (con estos nombres)

- `html_escapa_el_contenido`: el segundo caso del ejemplo (contiene el `<pre>` escapado y no contiene `<script`)
- `html_sin_recursos_externos`: con la conversación de 5 mensajes de `markdown_con_tools`, el resultado no contiene `<link`, `<script`, `<img` ni `http`
- `html_es_un_documento_completo`: empieza por `<!doctype html>`, contiene `<meta charset="utf-8">`, un solo `<style>` y acaba en `</html>` (con o sin salto de línea final)
- `html_tools_plegadas`: la conversación con una tool contiene `<details class="tool"><summary>🔧 escribir</summary>` y la salida `escrito`
