## Objetivo

1. `exportar.rs`: quita el `#![allow(dead_code)]`. Añade `ExportArgs` (firma abajo) y
   `pub fn export(a: ExportArgs) -> anyhow::Result<i32>`.
2. `export`: abre `Store::open(&cwd.join(".pcode/pcode.db"))`. Lista `store.sessions(u32::MAX)`. Elige la
   sesión con `id == a.session` o, si no se da, la primera (la más reciente). Si no hay sesiones o no existe
   ese id: escribe en stderr `no hay ninguna sesión guardada en este proyecto` (o `no existe la sesión <id>`)
   y devuelve `Ok(2)`.
3. Mensajes: los eventos con `kind == "mensaje"`, cada `payload` con `serde_json::from_value::<Message>`
   (los que no se puedan leer se saltan).
4. Texto: `to_markdown(&row.task, &row.model, &msgs)` si `a.format == "md"`; `to_html(…)` si es `"html"`;
   otro valor → `anyhow::bail!("formato desconocido «{}»: usa md o html", a.format)`.
5. Enmascara el texto final con
   `mask(&texto, std::env::var("HOME").ok().as_deref(), &env_secrets(std::env::vars()))`.
6. Salida: si `a.output` es `Some(ruta)`, escribe el archivo e imprime en stderr `exportado a <ruta>`; si no,
   imprime el texto en stdout. Devuelve `Ok(0)`.
7. `main.rs`: variante `Exportar(exportar::ExportArgs)` en `Cmd` con el doc
   `/// Exporta una conversación guardada a Markdown o a una página HTML autocontenida.` y el brazo
   `Some(Cmd::Exportar(a)) => std::process::exit(exportar::export(a)?),`.
8. Crea `tests/exportar.rs` (copia los ayudantes `resp` y `pcode` de `tests/chat.rs`).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/exportar.rs
/// Argumentos de `pcode exportar`.
#[derive(Debug, clap::Args)]
pub struct ExportArgs {
    /// Número de sesión (por defecto, la última de este proyecto).
    pub session: Option<i64>,
    /// `md` (por defecto) o `html`.
    #[arg(long = "formato", default_value = "md")]
    pub format: String,
    /// Archivo de salida (por defecto, la salida estándar).
    #[arg(long = "salida")]
    pub output: Option<std::path::PathBuf>,
}

/// Ejecuta `pcode exportar` y devuelve el código de salida.
pub fn export(a: ExportArgs) -> anyhow::Result<i32>;
```

## Tests (con estos nombres)

- `exportar_markdown_de_la_ultima_sesion`: tras un `pcode chat di hola` con el mock, `pcode exportar` sale con 0 y stdout contiene `## Usuario`, `di hola` y `hola desde el mock`
- `exportar_html_a_un_archivo`: `--formato html --salida s.html` crea el archivo, que empieza por `<!doctype html>` y no contiene `<script`
- `exportar_oculta_claves_del_entorno`: con `MI_API_KEY=sk-secreto-12345678` en el entorno y un mock que responde con ese texto, stdout no contiene `sk-secreto-12345678` y sí `•••`
- `exportar_sin_sesiones_sale_con_2`: en un directorio vacío, código 2 y stderr contiene `no hay ninguna sesión`
- `exportar_sesion_inexistente_sale_con_2`: tras crear una sesión, `pcode exportar 99` sale con 2 y stderr contiene `no existe la sesión 99`
