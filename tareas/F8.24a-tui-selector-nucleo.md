# F8.24a-tui-selector-nucleo — TUI: lista seleccionable con búsqueda difusa (lógica pura)

## Objetivo

1. Crea `picker.rs` con `PickItem`, `Picker` y `PickerOutcome` (firmas abajo). Sin E/S ni dibujo.
2. `filtered()`: con `query` vacío, todos los elementos en su orden. Si no, los que tienen
   `crate::app::fuzzy_score(&self.query, &item.label)` distinto de `None`, de mayor a menor puntuación; a
   igual puntuación, el orden original (usa `sort_by` estable).
3. `key(k)`:
   - `Up` / `Down`: mueve `selected` dentro de `filtered()` sin salirse (0 … len-1). → `Pending`.
   - `Char(c)` sin CONTROL: añade `c` a `query` y pone `selected = 0`. → `Pending`.
   - `Backspace`: quita el último carácter de `query` y pone `selected = 0`. → `Pending`.
   - `Enter`: si `filtered()` tiene elemento en `selected` → `Chosen(id de ese elemento)`; si no → `Pending`.
   - `Esc` → `Closed`. Cualquier otra tecla → `Pending`.
4. `rows(width, max)`: como mucho `max` filas de `filtered()`, empezando en un desplazamiento tal que la
   seleccionada sea visible (`inicio = selected.saturating_sub(max - 1)`). Cada fila es
   `("› <label>  <detail>", true)` para la seleccionada y `("  <label>  <detail>", false)` para el resto,
   recortada a `width` caracteres. Si `detail` está vacío no se añaden los dos espacios.
5. `lib.rs`: añade `pub mod picker;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/picker.rs
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

/// Un elemento de la lista.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PickItem {
    /// Lo que se devuelve al elegirlo.
    pub id: String,
    /// Texto principal (sobre el que se busca).
    pub label: String,
    /// Texto secundario.
    pub detail: String,
}

/// Lista con búsqueda.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Picker {
    /// Título de la ventana.
    pub title: String,
    /// Elementos.
    pub items: Vec<PickItem>,
    /// Lo escrito para filtrar.
    pub query: String,
    /// Índice elegido dentro de `filtered()`.
    pub selected: usize,
}

/// Qué pasó con una tecla.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PickerOutcome { Pending, Chosen(String), Closed }

impl Picker {
    pub fn new(title: impl Into<String>, items: Vec<PickItem>) -> Picker;
    pub fn filtered(&self) -> Vec<&PickItem>;
    pub fn key(&mut self, k: KeyEvent) -> PickerOutcome;
    pub fn rows(&self, width: u16, max: usize) -> Vec<(String, bool)>;
}
```

## Ejemplo (entrada y resultado esperado)

```
items: [ {id:"1", label:"claude-sonnet", detail:""}, {id:"2", label:"gpt-mini", detail:"openai"}, {id:"3", label:"glm-4", detail:""} ]
sin query: rows(40, 10) == [("› claude-sonnet", true), ("  gpt-mini  openai", false), ("  glm-4", false)]
teclear "g", "p"         -> filtered() == [gpt-mini]; selected == 0
Down, Down (sin query)   -> selected == 2; otro Down -> sigue en 2
Enter con selected == 1  -> Chosen("2")
Esc                      -> Closed
```

## Tests (con estos nombres)

- `selector_filtra_y_elige`: tras teclear `gp`, `filtered()` solo tiene `gpt-mini` e Intro devuelve `Chosen("2")`
- `selector_flechas_no_se_salen`: tres Down dejan `selected == 2` y cuatro Up lo dejan en 0
- `selector_esc_cierra_sin_elegir`: Esc devuelve `Closed`
- `selector_intro_sin_resultados_no_elige`: con la búsqueda `zzz` no hay filas e Intro devuelve `Pending`
- `selector_filas_con_detalle_y_recorte`: el caso `rows(40, 10)` del ejemplo y `rows(8, 10)[0].0` mide 8 caracteres
- `selector_ventana_sigue_a_la_seleccion`: con 20 elementos, `selected = 15` y `max = 5`, la última fila devuelta es la seleccionada
