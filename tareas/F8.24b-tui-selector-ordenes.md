## Objetivo

1. `app.rs`: añade `pub enum PickerKind { Sessions, Models }` (Debug, Clone, Copy, PartialEq, Eq), la
   variante `Command::Resume(i64)` (doc: «Retomar la conversación guardada con ese id») y a `App` los campos
   `pub picker: Option<(PickerKind, crate::picker::Picker)>` y `pub models: Vec<String>` (doc: «Modelos que
   se ofrecen en `/modelos`»); `None` y `vec![]` en `App::new`.
2. `commands.rs`: añade al final de `COMMANDS` `sesiones`/`sessions` («retoma una conversación anterior» /
   «resume an earlier conversation») y `modelos`/`models` («elige el modelo de una lista» / «pick the model
   from a list»), con `external: false`.
3. `i18n.rs`: añade al final de `ES` y `EN`: `pick_sessions` = `" Sesiones · escribe para filtrar "` /
   `" Sessions · type to filter "`, `pick_models` = `" Modelos · escribe para filtrar "` /
   `" Models · type to filter "`, `no_sessions` = `"No hay conversaciones guardadas en este proyecto."` /
   `"There are no saved conversations in this project."`, `no_models` =
   `"No hay modelos configurados: usa /modelo <nombre>."` / `"No models configured: use /model <name>."`,
   `messages` = `"mensajes"` / `"messages"`.
4. `app.rs`, `submit`, nuevos brazos del `match name`:
   - `"sesiones" | "sessions"`: si `self.sessions` está vacío, `Entry::Info(no_sessions)`; si no, abre el
     selector con un `PickItem { id: <id en texto>, label: <title>, detail: "<n> <messages>" }` por sesión y
     título `pick_sessions`. Devuelve `vec![]`.
   - `"modelos" | "models"`: igual con `self.models` (`id` y `label` = nombre, `detail` vacío), título
     `pick_models`, o `Entry::Info(no_models)` si está vacío.
5. `app.rs`, `key`: después de los bloques de aprobación y de ayuda, si `self.picker` es `Some`, pasa la
   tecla a `Picker::key` y devuelve: `Pending` → `vec![]`; `Closed` → cierra (`picker = None`) y `vec![]`;
   `Chosen(id)` → cierra y, si era `Models`, `self.model = id.clone()` y `vec![Command::SetModel(id)]`; si
   era `Sessions`, `vec![Command::Resume(id.parse().unwrap_or(0))]`.
6. `app.rs`, `leader_key`: `Char('l')` ejecuta `/sesiones`; `Char('m')` ejecuta `/modelos` si `self.models`
   no está vacío (si lo está, sigue dejando `/modelo ` en la entrada como ahora).
7. `render.rs`: al final de `render`, si hay selector, una ventana centrada sobre `body` (ancho
   `min(70, body.width - 2)`, alto `min(filas + 3, body.height)`) con `Clear`, borde redondeado y el título
   del selector; primera línea `"> <query>"`; después `picker.rows(ancho - 2, alto - 3)`, la seleccionada con
   `th.bubble()` y el resto con `th.text()`.

## Ejemplo (entrada y resultado esperado)

```
app.models = ["m1", "m2"]; teclear "/modelos" + Intro -> app.picker es Some((Models, _)); Down, Intro ->
  [Command::SetModel("m2")], app.model == "m2", app.picker == None
app.sessions = [{id:7, title:"arregla el test", messages:6, current:false}]; "/sesiones" + Intro, Intro ->
  [Command::Resume(7)]
"/sesiones" con app.sessions vacío -> Entry::Info("No hay conversaciones guardadas en este proyecto.")
pantalla 80×24 con el selector de sesiones: contiene "Sesiones · escribe para filtrar" y "› arregla el test  6 mensajes"
```

## Tests (con estos nombres)

- `selector_de_modelos_elige_y_cambia`: el primer caso del ejemplo
- `selector_de_sesiones_pide_retomar`: el segundo caso del ejemplo (`Command::Resume(7)`)
- `selector_esc_cierra_sin_cambiar`: con el selector de modelos abierto, Esc deja `picker == None`, `model` sin cambiar y no devuelve órdenes
- `selector_sin_datos_avisa`: `/sesiones` sin sesiones y `/modelos` sin modelos añaden un `Entry::Info` y no abren nada
- `selector_teclas_no_llegan_a_la_entrada`: con el selector abierto, teclear `x` deja `input` vacío y `query == "x"`
- `selector_render_80x24_y_120x40`: la pantalla contiene el título `Sesiones · escribe para filtrar` y la fila `› arregla el test  6 mensajes` en los dos tamaños
- `selector_lider_l_abre_sesiones`: Ctrl+X y `l` con una sesión abren el selector de sesiones
