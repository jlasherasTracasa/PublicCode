## Objetivo

1. `run.rs`: saca el bucle que convierte el historial en entradas a una función pública
   `entries_of(history: &[Message]) -> Vec<Entry>` (mensajes de usuario → `Entry::User`; de asistente con
   texto → `Entry::Assistant { done: true }`; el resto se salta) y úsala en `run_tui`
   (`app.entries.extend(entries_of(&history))` dentro del mismo `if history.len() > 1`).
2. `run.rs`, `TuiOptions`: añade `pub models: Vec<String>` (doc: «Modelos para `/modelos`») y
   `pub load_session: LoadSession` (firma abajo). En `run_tui`: `app.models = …` tras crear `app`, y guarda
   `let mut load_session = opts.load_session;`.
3. `run.rs`, `match cmd`: añade `Command::Resume(id)`: si `turn.is_some()`, añade
   `Entry::Info(t(lang, "wait").into())`; si no, llama a `load_session(id)`: con `Some(msgs)`,
   `history = msgs; app.entries = entries_of(&history); app.title.clear();` y marca
   `s.current = s.id == id` en cada elemento de `app.sessions`; con `None`, `Entry::Info(t(lang, "unknown").into())`.
4. `chat.rs`: añade `fn load_session(store: &Store, id: i64) -> Option<Vec<Message>>` (los eventos `mensaje`
   de esa sesión, como en `load_last`; `None` si no hay ninguno) y haz que `load_last` la use.
5. `chat.rs`: añade `fn model_choices(cfg: &Config, current: &str) -> Vec<String>`: `current`, el
   `preferences.model` y el `model` de cada proveedor, sin vacíos ni repetidos, con `current` primero y el
   resto en orden alfabético.
6. `chat.rs`, función `tui`: carga `let (cfg, _) = Config::load_layered(&a.config)?;` para `model_choices`.
   Comparte `persist` entre los dos cierres con `Arc<Mutex<Persist>>` (`std::sync`): `on_turn` hace lo de
   ahora tras `lock()`; `load_session` es
   `Box::new(move |id| { let mut p = persist2.lock().unwrap(); let msgs = load_session(&p.store, id)?; p.session = Some(id); p.saved = msgs.len(); Some(msgs) })`.

## Ejemplo (entrada y resultado esperado)

```
entries_of(&[system("s"), user("hola"), assistant(""), assistant("qué tal")]) ==
  [Entry::User("hola"), Entry::Assistant { text: "qué tal", done: true }]
cfg de: [preferencias]\nmodelo = "p"\n[proveedores.a]\ntipo = "openai"\nurl = "http://x"\nmodelo = "m1"\n[proveedores.b]\ntipo = "openai"\nurl = "http://x"\nmodelo = "m0"
model_choices(&cfg, "actual") == ["actual", "m0", "m1", "p"]
model_choices(&cfg, "m1")     == ["m1", "m0", "p"]
```
