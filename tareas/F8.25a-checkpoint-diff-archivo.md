# F8.25a-checkpoint-diff-archivo — Puntos de control: diff de un archivo de un turno y revertir solo ese archivo

- crates/pcode-core/tests/checkpoint.rs (test `deshacer_restaura_y_borra_creados`: cómo se prepara un turno en un directorio temporal)

## Objetivo

1. `checkpoint.rs`, en `impl Checkpoints`: añade `file_diff` y `revert_file` (firmas abajo).
2. Las dos buscan `path` en `manifest(turn)["files"]` (comparando con el campo `path`); el índice `i` de esa
   entrada da el archivo `turn_dir(turn)/antes/<i>`. «Antes» es su contenido si `existed` es `true`; si no,
   el archivo no existía.
3. `file_diff(turn, path)`: `None` si el turno o el archivo no están. Si no, el diff unificado entre «antes»
   (cadena vacía si no existía) y el contenido actual de `root/path` (cadena vacía si no existe), con
   `similar::TextDiff::from_lines(&antes, &ahora).unified_diff().context_radius(3).header(&format!("a/{path}"), &format!("b/{path}")).to_string()`.
   Convierte los bytes con `String::from_utf8_lossy`. Si no hay diferencias devuelve `Some(String::new())`.
4. `revert_file(turn, path)`: `Ok(false)` si el turno o el archivo no están. Si no, deja `root/path` como
   «antes» con `put(&self.root.join(path), antes.as_deref())` (lo borra si no existía) y devuelve `Ok(true)`.
   No cambia el manifiesto.
5. Añade los tests de la lista a `tests/checkpoint.rs`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-core/src/checkpoint.rs, en `impl Checkpoints`
    /// Diff unificado de `path` entre como estaba antes de `turn` y como está ahora (`None` si el turno no
    /// tocó ese archivo).
    pub fn file_diff(&self, turn: u64, path: &str) -> Option<String>;

    /// Deja `path` como estaba antes de `turn` (lo borra si el turno lo creó). `Ok(false)` si el turno no
    /// tocó ese archivo.
    pub fn revert_file(&mut self, turn: u64, path: &str) -> io::Result<bool>;
```

## Ejemplo (entrada y resultado esperado)

```
a.txt era "uno\ndos\n"; en el turno 1 se guarda (`cp.save("a.txt")`) y pasa a "uno\nDOS\n"; b.txt se crea con "b\n".
cp.file_diff(1, "a.txt").unwrap() contiene "--- a/a.txt", "+++ b/a.txt", "-dos" y "+DOS"
cp.file_diff(1, "b.txt").unwrap() contiene "+b"
cp.file_diff(1, "c.txt") == None
cp.revert_file(1, "a.txt") == Ok(true)  -> a.txt vuelve a ser "uno\ndos\n"; b.txt sigue existiendo
cp.revert_file(1, "b.txt") == Ok(true)  -> b.txt ya no existe
cp.revert_file(1, "c.txt") == Ok(false)
```

## Tests (con estos nombres)

- `diff_de_un_archivo_del_turno`: los tres casos de `file_diff` del ejemplo
- `revertir_un_archivo_no_toca_los_demas`: tras `revert_file(1, "a.txt")`, `a.txt` tiene el contenido anterior y `b.txt` sigue igual
- `revertir_un_archivo_creado_lo_borra`: `revert_file(1, "b.txt")` devuelve true y `b.txt` deja de existir
- `revertir_un_archivo_ajeno_al_turno`: `revert_file(1, "c.txt")` devuelve `Ok(false)` y no crea nada
- `deshacer_tras_revertir_un_archivo_sigue_funcionando`: tras revertir `a.txt`, `cp.undo()` devuelve el turno y deja `a.txt` como antes y `b.txt` borrado
