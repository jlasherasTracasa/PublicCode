## Objetivo

1. Crea `diff.rs` con `DiffView`, `DiffAction` y `diff_lines` (firmas abajo). Sin E/S.
2. `DiffView::new(turn, files)`: `selected = 0`, `diff` vacío, `scroll = 0`.
3. `DiffView::key(k)`:
   - `Up` o `Char('k')`: si `selected > 0`, lo baja en 1, pone `scroll = 0` y devuelve `Load(ruta nueva)`;
     si ya es 0, `None`. `Down` o `Char('j')`: lo mismo hacia abajo sin pasar de `files.len() - 1`.
   - `PageDown`: `scroll += 10`; `PageUp`: `scroll = scroll.saturating_sub(10)`. → `None`.
   - `Char('r')`: `Revert(ruta seleccionada)`. `Char('a')`, `Char('q')` o `Esc`: `Close`.
   - Otra tecla, o `files` vacío: `None` (salvo cerrar, que siempre funciona).
4. `DiffView::file_rows(width)`: por cada archivo, `(texto, seleccionada)` con
   `"›" + change_row(c, width - 1)` para la seleccionada y `" " + change_row(c, width - 1)` para el resto.
5. `diff_lines(diff, width, th)`: una o más `Line` por línea del diff (pártelas con `wrap`): las que empiezan
   por `+++` o `---` con `th.strong()`; por `@@` con `th.dimmed()`; por `+` con `th.good()`; por `-` con
   `th.bad()`; el resto con `th.text()`. El texto no se altera (el prefijo `+`/`-` se conserva: el color
   nunca es la única señal). Un diff vacío da una sola línea con `t(lang, "diff_empty")` en `th.dimmed()`.
6. `commands.rs`: añade al final de `COMMANDS` `cambios`/`diff` («revisa los cambios del último turno» /
   «review the last turn's changes»), `external: false`.
7. `i18n.rs`: añade al final de `ES` y `EN`: `diff_title` =
   `" Cambios del turno · ↑/↓ archivo · r revierte · a acepta "` / `" Turn changes · ↑/↓ file · r revert · a accept "`,
   `diff_empty` = `"(sin diferencias)"` / `"(no differences)"`, `no_changes` =
   `"El último turno no cambió ningún archivo."` / `"The last turn did not change any file."`,
   `reverted` = `"↶ Revertido:"` / `"↶ Reverted:"`.
8. `lib.rs`: añade `pub mod diff;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/diff.rs
use crate::i18n::Lang;
use crate::theme::Theme;
use pcode_core::FileChange;
use ratatui::crossterm::event::KeyEvent;
use ratatui::text::Line;

/// Revisión de los cambios de un turno.
#[derive(Debug, Clone, PartialEq)]
pub struct DiffView {
    /// Turno (número del punto de control).
    pub turn: u64,
    /// Archivos que cambió.
    pub files: Vec<FileChange>,
    /// Archivo elegido.
    pub selected: usize,
    /// Diff del archivo elegido (lo rellena quien ejecuta `Load`).
    pub diff: String,
    /// Líneas desplazadas del diff.
    pub scroll: u16,
}

/// Lo que pide una tecla en la revisión.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DiffAction { None, Close, Load(String), Revert(String) }

impl DiffView {
    pub fn new(turn: u64, files: Vec<FileChange>) -> DiffView;
    pub fn key(&mut self, k: KeyEvent) -> DiffAction;
    pub fn file_rows(&self, width: u16) -> Vec<(String, bool)>;
}

/// Líneas del diff con estilo, ajustadas a `width`.
pub fn diff_lines(diff: &str, width: u16, th: &Theme, lang: Lang) -> Vec<Line<'static>>;
```

## Ejemplo (entrada y resultado esperado)

```
vista con files = [a.rs (+3 −1), b.rs (creado, +2)]:
  file_rows(30) == [("› M a.rs +3 −1", true), ("  A b.rs +2", false)]
  Down -> Load("b.rs") y selected == 1; otro Down -> None
  `r`  -> Revert("b.rs");  Esc -> Close
diff_lines("--- a/x\n+++ b/x\n@@ -1 +1 @@\n-dos\n+DOS\n uno\n", 80, &th, Lang::Es) -> 6 líneas cuyo texto es el de entrada;
  con un tema con color, la de "+DOS" tiene fg == th.ok y la de "-dos" fg == th.err
diff_lines("", 80, &th, Lang::Es) -> ["(sin diferencias)"]
```

## Tests (con estos nombres)

- `diff_flechas_cambian_de_archivo_y_piden_cargar`: el caso de Down del ejemplo, y Up en el primero devuelve `None`
