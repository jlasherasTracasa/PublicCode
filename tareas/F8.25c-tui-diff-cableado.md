## Objetivo

1. `app.rs`: añade a `App` `pub diff: Option<crate::diff::DiffView>` (`None` en `App::new`) y a `Command` las
   variantes `OpenDiff`, `LoadDiff { turn: u64, path: String }` y `RevertFile { turn: u64, path: String }`
   (con su `///`).
2. `app.rs`, `submit`: brazo `"cambios" | "changes" | "diff"`: si `self.busy`, `Entry::Info(wait)` y
   `vec![]`; si no, `vec![Command::OpenDiff]`. En `leader_key`: `Char('d')` ejecuta `/cambios`.
3. `app.rs`, `key`: tras los bloques de aprobación y ayuda (antes del selector), si `self.diff` es `Some(v)`:
   `match v.key(k)`: `None` → `vec![]`; `Close` → `self.diff = None; vec![]`; `Load(path)` →
   `vec![Command::LoadDiff { turn: v.turn, path }]`; `Revert(path)` → `vec![Command::RevertFile { turn: v.turn, path }]`.
4. `run.rs`: añade la función pública `open_diff(root, lang) -> Result<DiffView, String>`: abre
   `Checkpoints::open(root)`, toma el primer turno de `list()` con `undone == false`, sus `changes(turn)`;
   si no hay turno o no hay cambios → `Err(t(lang, "no_changes").into())`; si no, una `DiffView::new` con
   `diff` = `file_diff(turn, primer archivo).unwrap_or_default()`.
5. `run.rs`, `match cmd`: `Command::OpenDiff` → `match open_diff(&root, lang)`: `Ok(v)` → `app.diff = Some(v)`;
   `Err(m)` → `Entry::Info(m)`. `Command::LoadDiff { turn, path }` → si `app.diff` es `Some`, pon su `diff` a
   `Checkpoints::open(&root).file_diff(turn, &path).unwrap_or_default()`. `Command::RevertFile { turn, path }`
   → `Checkpoints::open(&root).revert_file(turn, &path)`: con `Ok(true)`, añade
   `Entry::Info(format!("{} {path}", t(lang, "reverted")))` y recarga en la vista `files` (con
   `changes(turn)`) y `diff` (con `file_diff`); con `Ok(false)` nada; con `Err(e)`, `Entry::Info(format!("✗ {e}"))`.
6. `render.rs`: al final de `render`, si `app.diff` es `Some(v)`, dibuja sobre todo `body` (con `Clear`) un
   bloque con borde redondeado y título `diff_title`; dentro, arriba, las filas de `v.file_rows(ancho)`
   (como mucho 6; la seleccionada con `th.bubble()`), una línea vacía y debajo
   `Paragraph::new(diff_lines(&v.diff, ancho, th, app.lang)).scroll((v.scroll, 0))`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/app.rs, en `pub enum Command`
    /// Abrir la revisión de los cambios del último turno.
    OpenDiff,
    /// Cargar el diff de un archivo en la revisión abierta.
    LoadDiff { turn: u64, path: String },
    /// Dejar un archivo como estaba antes del turno.
    RevertFile { turn: u64, path: String },

// crates/pcode-tui/src/run.rs
/// Revisión del último turno aplicado del proyecto (`Err` con el aviso si no cambió nada).
pub fn open_diff(root: &std::path::Path, lang: Lang) -> Result<crate::diff::DiffView, String>;
```

## Ejemplo (entrada y resultado esperado)

```
"/cambios" + Intro (no ocupado)            -> [Command::OpenDiff]
con app.diff = Some(vista de a.rs y b.rs): Down -> [Command::LoadDiff { turn: 1, path: "b.rs" }]
                                           `r`  -> [Command::RevertFile { turn: 1, path: "b.rs" }]
                                           Esc  -> app.diff == None
open_diff(dir sin puntos de control, Es)   -> Err("El último turno no cambió ningún archivo.")
open_diff(dir con un turno que cambió a.txt de "uno\n" a "dos\n") -> Ok(v) con v.files.len() == 1 y v.diff que contiene "+dos"
pantalla 80×24 con la vista: contiene "Cambios del turno" y "› M a.rs +3 −1"
```

## Tests (con estos nombres)

- `diff_orden_cambios_pide_abrir`: `/cambios` devuelve `[Command::OpenDiff]`; con `busy = true` no devuelve nada
- `diff_teclas_van_a_la_vista`: con la vista abierta, Down devuelve `LoadDiff`, `r` devuelve `RevertFile` y Esc la cierra, sin escribir en la entrada
- `diff_sin_cambios_no_abre`: (en `run.rs`) `open_diff` en un directorio temporal vacío devuelve el `Err` del ejemplo
- `diff_abre_el_ultimo_turno`: (en `run.rs`) el caso de `open_diff` con un turno (prepáralo como en el test `resumen_de_cambios_y_deshacer`)
- `diff_render_80x24`: con una vista de dos archivos y un diff de 3 líneas, la pantalla contiene `Cambios del turno`, `› M a.rs +3 −1` y una línea del diff
- `diff_render_120x40`: lo mismo a 120×40

## No hagas

- No uses `git` para el diff: sale de los puntos de control
- No cambies `undo_redo` ni las órdenes `/deshacer` y `/rehacer`
- No abras la revisión sola al terminar un turno: solo con `/cambios` o Ctrl+X d
