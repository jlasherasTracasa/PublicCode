## Objetivo

OSC 52 es la secuencia de escape con la que un programa de terminal pone texto en el portapapeles (funciona
también por SSH): `ESC ] 52 ; c ; <texto en base64> BEL`.
1. Crea `osc.rs` con `base64`, `osc52` y `last_assistant_text` (firmas abajo). Sin dependencias nuevas: el
   base64 se escribe a mano.
2. `base64(bytes)`: alfabeto estándar `A–Z a–z 0–9 + /`, con relleno `=`. Procesa de 3 en 3 bytes.
3. `osc52(text)`: `format!("\x1b]52;c;{}\x07", base64(text.as_bytes()))`. Si `text` mide más de 100 000
   bytes, se usa solo el principio (corta en un límite de carácter con `is_char_boundary`).
4. `last_assistant_text(entries)`: el `text` de la última `Entry::Assistant` cuyo texto no está vacío
   (recorre desde el final); `None` si no hay.
5. `lib.rs`: añade `pub mod osc;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/osc.rs
use crate::app::Entry;

/// Base64 estándar con relleno.
pub fn base64(bytes: &[u8]) -> String;
/// Secuencia OSC 52 que copia `text` al portapapeles de la terminal.
pub fn osc52(text: &str) -> String;
/// Texto de la última respuesta del asistente.
pub fn last_assistant_text(entries: &[Entry]) -> Option<String>;
```

## Ejemplo (entrada y resultado esperado)

```
base64(b"") == ""        base64(b"f") == "Zg=="      base64(b"fo") == "Zm8="
base64(b"foo") == "Zm9v" base64(b"foobar") == "Zm9vYmFy"
base64("ñ".as_bytes()) == "w7E="
osc52("hola") == "\x1b]52;c;aG9sYQ==\x07"
last_assistant_text(&[User("a"), Assistant{text:"uno",done:true}, Tool{…}, Assistant{text:"",done:true}]) == Some("uno")
```

## Tests (con estos nombres)

- `base64_vectores_conocidos`: los seis casos de `base64` del ejemplo
- `osc52_bien_formado`: `osc52("hola")` es exactamente la cadena del ejemplo
- `osc52_recorta_textos_enormes`: con un texto de 200 000 letras `a`, la secuencia mide menos de 140 000 bytes y acaba en `\x07`
- `ultima_respuesta_salta_las_vacias`: el caso de `last_assistant_text` del ejemplo, y `None` con una lista sin asistente
