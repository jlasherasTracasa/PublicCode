## Objetivo

1. Crea `empaquetar.py` (ejecutable, `#!/usr/bin/env python3`, solo biblioteca estándar, `argparse`, docstring de
   uso) con las funciones de *Firmas*, y `test_empaquetar.py` con `unittest`.
2. `arquitectura(maquina)`: `x86_64` o `amd64` → `("amd64", "x86_64")`; `aarch64` o `arm64` → `("arm64",
   "aarch64")` (nombre para .deb, nombre para .rpm). Otra cosa: `ValueError`.
3. `control_deb(version, arch_deb)`: el texto exacto del *Ejemplo* (acaba en salto de línea).
4. `arbol(bin_dir, destino)`: crea en `destino` el árbol del paquete y devuelve la lista ordenada de rutas
   relativas creadas: `usr/bin/pcode` (obligatorio: si no existe `bin_dir/pcode`, `FileNotFoundError`),
   `usr/bin/pcode-ide` (solo si existe en `bin_dir`), `usr/share/applications/pcode.desktop` y
   `usr/share/icons/hicolor/scalable/apps/pcode.svg` (copiados de la carpeta de este script). Binarios con modo
   `0o755`; el resto `0o644`.
5. `spec_rpm(version, arch_rpm, arbol_dir, archivos)`: el texto del *Ejemplo*, con una línea por archivo en
   `%files` (cada ruta con `/` delante).
6. `construir_deb(bin_dir, version, arch_deb, salida)`: crea un directorio temporal, llama a `arbol`, escribe
   `DEBIAN/control` y, si `shutil.which("dpkg-deb")` existe, ejecuta
   `dpkg-deb --build --root-owner-group <árbol> <salida>/pcode_<version>_<arch_deb>.deb` (con `timeout=120`) y
   devuelve esa ruta. Si no hay `dpkg-deb`, devuelve `None`.
7. `construir_rpm(bin_dir, version, arch_rpm, salida)`: llama a `arbol`, escribe `pcode.spec` con `spec_rpm` y, si
   existe `rpmbuild`, ejecuta `rpmbuild -bb --target <arch_rpm> --define "_rpmdir <salida>" pcode.spec` (con
   `timeout=300`) y devuelve `salida`; si no hay `rpmbuild`, devuelve `None`.
8. `main(argv)`: `empaquetar.py {deb|rpm} --bin-dir DIR --version X.Y.Z [--maquina x86_64] --salida DIR`. Imprime la
   ruta creada y sale con 0; si falta la herramienta, imprime `falta dpkg-deb` (o `falta rpmbuild`) y sale con 3.

## Tests (con estos nombres)

- `test_arquitectura`: x86_64 da (amd64, x86_64), arm64 da (arm64, aarch64) y «mips» lanza ValueError
- `test_control_deb`: el texto para 1.2.0 y amd64 es exactamente el del ejemplo
- `test_arbol_con_y_sin_ide`: con un bin_dir temporal que solo tiene pcode, arbol crea usr/bin/pcode ejecutable, el .desktop y el icono; al añadir pcode-ide aparece usr/bin/pcode-ide
- `test_arbol_sin_pcode_falla`: un bin_dir vacío lanza FileNotFoundError
- `test_spec_rpm_lista_los_archivos`: el spec contiene «BuildArch: x86_64» y una línea «/usr/bin/pcode» en %files
- `test_construir_deb_si_hay_dpkg`: si shutil.which(«dpkg-deb») existe, el .deb se crea y pesa más de 0 bytes; si no existe, el test se salta con skipTest
