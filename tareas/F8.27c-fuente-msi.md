## Objetivo

1. Crea `wxs.py` (ejecutable, `#!/usr/bin/env python3`, solo biblioteca estándar, `argparse`, docstring de uso) y
   `test_wxs.py`. El `.msi` lo construye después `wix build` en la CI (F8.27d); aquí solo se genera su fuente.
2. `wxs(version, bin_dir, con_ide)`: devuelve el XML del *Ejemplo* con la versión y la carpeta sustituidas. Si
   `con_ide` es `False`, no aparece la línea `<File Source="…pcode-ide.exe" />`. La versión debe tener la forma
   `N.N.N`; si no, `ValueError`. `UPGRADE_CODE` es una constante fija: no puede cambiar nunca entre versiones.
3. `main(argv)`: `wxs.py --version X.Y.Z --bin-dir DIR --salida pcode.wxs`. `con_ide` es `True` si existe
   `DIR/pcode-ide.exe`. Escribe el archivo en UTF-8, imprime su ruta y sale con 0; con una versión no válida, sale
   con 2.

## Ejemplo (entrada y resultado esperado)

```
wxs("1.2.0", "C:/b") ->
<?xml version="1.0" encoding="utf-8"?>
<Wix xmlns="http://wixtoolset.org/schemas/v4/wxs">
  <Package Name="PublicCode" Manufacturer="PublicCode" Version="1.2.0" UpgradeCode="6F1E2B7A-3C4D-4E5F-9A8B-0C1D2E3F4A5B" Scope="perMachine">

          <File Source="C:/b/pcode-ide.exe" />
          <Environment Id="Path" Name="PATH" Value="[INSTALLFOLDER]" Part="last" Action="set" System="yes" Permanent="no" />
        </Component>

    <Feature Id="Principal">
```

## Tests (con estos nombres)

- `test_xml_bien_formado`: xml.etree.ElementTree.fromstring del resultado (codificado en UTF-8) no lanza y la raíz se llama Wix en el espacio de nombres de WiX v4
- `test_version_y_upgrade_code`: el elemento Package lleva Version = 1.2.0 y UpgradeCode = wxs.UPGRADE_CODE
- `test_con_y_sin_ide`: con_ide=True da dos elementos File; con_ide=False da uno, el de pcode.exe
- `test_anade_al_path`: hay un elemento Environment con Name = PATH y Part = last
- `test_version_no_valida`: wxs(«1.2», «C:/b») lanza ValueError

## No hagas

- No cambies `UPGRADE_CODE`: si cambia, Windows deja de reconocer las actualizaciones
- No intentes ejecutar `wix` ni `candle`: no están en Linux
- No uses paquetes de fuera de la biblioteca estándar
