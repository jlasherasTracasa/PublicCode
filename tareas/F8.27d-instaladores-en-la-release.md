## Objetivo

1. `release.yml`, job `build`, Linux: tras «Empaquetar (Linux)», instala `rpm` (`sudo apt-get install -y rpm`) y
   ejecuta `python3 packaging/linux/empaquetar.py deb …` y `… rpm …` con `--bin-dir target/<target>/release`,
   `--version ${TAG#v}` y `--salida .`; renombra a `pcode-$TAG-<arch>.deb` y `.rpm` y añádelos al artefacto.
2. `release.yml`, job `build`, Windows: `dotnet tool install --global wix`, `python packaging/windows/wxs.py …` y
   `wix build pcode.wxs -o pcode-$TAG-x86_64.msi`; añádelo al artefacto.
3. `release.yml`, job `verify-install`: en Linux, `sudo dpkg -i` del `.deb` descargado y `pcode --version`; en
   Windows, `msiexec /i … /qn` y `pcode --version` en una consola nueva.
4. Publica una release de prueba (etiqueta de parche) y comprueba que los cuatro pasos pasan.
5. Genera el manifiesto con `packaging/winget/manifiesto.py --version … --sha256 <suma del zip en SHA256SUMS>` y abre
   el PR en `microsoft/winget-pkgs`. Cuando lo acepten, comprueba `winget install PublicCode.pcode`.
6. `docs/usuario.md`: sección de instalación con las cuatro vías (winget, .msi, .deb, .rpm) además de los scripts.
