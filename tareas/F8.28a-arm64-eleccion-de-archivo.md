# F8.28a-arm64-eleccion-de-archivo — ARM64: que `pcode actualizar`, install.sh e install.ps1 elijan el archivo de la arquitectura

## Contexto (lee esto y nada más)

- crates/pcode-cli/src/update.rs (función `asset_suffix` y su test `elige_el_archivo_de_la_plataforma`)
- install.sh (el `case "$(uname -m)"` y la línea `name="pcode-$tag-x86_64-unknown-linux-gnu.tar.gz"`)
- install.ps1 (la línea `$name = "pcode-$Version-x86_64-pc-windows-msvc.zip"`)

## Objetivo

1. `update.rs`, `asset_suffix`: añade dos casos: `("linux", "aarch64")` →
   `"-aarch64-unknown-linux-gnu.tar.gz"` y `("windows", "aarch64")` → `"-aarch64-pc-windows-msvc.zip"`. Lo demás
   (por ejemplo macOS) sigue dando `None`. Añade el test `asset_suffix_para_aarch64_y_arm64`.
2. `install.sh`: el `case "$(uname -m)"` pasa a fijar una variable: `x86_64|amd64) arch=x86_64;;` y
   `aarch64|arm64) arch=aarch64;;`; el caso `*)` sigue dando el mismo error. La línea del nombre pasa a
   `name="pcode-$tag-$arch-unknown-linux-gnu.tar.gz"`. Cambia el comentario de la línea 2 a
   `# Instala o actualiza pcode en Linux (x86_64 y aarch64), por usuario y sin sudo.`
3. `install.ps1`: justo antes de la línea de `$name`, añade
   `$arch = if ($env:PROCESSOR_ARCHITECTURE -eq "ARM64") { "aarch64" } else { "x86_64" }` y cambia el nombre a
   `$name = "pcode-$Version-$arch-pc-windows-msvc.zip"`.

## Ejemplo (entrada y resultado esperado)

```
asset_suffix("linux", "aarch64")   -> Some("-aarch64-unknown-linux-gnu.tar.gz")
asset_suffix("windows", "aarch64") -> Some("-aarch64-pc-windows-msvc.zip")
asset_suffix("linux", "x86_64")    -> Some("-x86_64-unknown-linux-gnu.tar.gz")   (igual que antes)
asset_suffix("macos", "aarch64")   -> None
```
