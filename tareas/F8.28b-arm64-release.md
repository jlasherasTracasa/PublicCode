# F8.28b-arm64-release — Release: compilar y publicar los binarios de Linux aarch64 y Windows ARM64

**Fase** F8 · **Ejecutor** coordinador · **Hito** 1.8 · **Talla** S · **Depende de** F8.28a-arm64-eleccion-de-archivo

## Objetivo

1. `release.yml`, job `build`, `matrix.include`: añade `{ os: ubuntu-22.04-arm, target: aarch64-unknown-linux-gnu,
   exe: pcode }` y `{ os: windows-11-arm, target: aarch64-pc-windows-msvc, exe: pcode.exe }`. Si la cuenta no tiene
   esos runners, compila cruzado desde x86_64 (`rustup target add` + enlazador `aarch64-linux-gnu-gcc`) y quita la
   «Prueba de humo» solo para esos dos.
2. `ci.yml`: un job semanal (no en cada push) que compile `pcode-cli` para `aarch64-unknown-linux-gnu`.
3. Publica una release de prueba y comprueba que `SHA256SUMS` lista los cuatro archivos y que `install.sh` instala
   en un equipo aarch64 (una Raspberry Pi o una máquina virtual ARM).
