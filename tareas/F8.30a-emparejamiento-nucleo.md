## Objetivo

1. Crea `pairing.rs` con las funciones de *Firmas* y sus tests. En `main.rs` añade `mod pairing;` (orden alfabético,
   entre `launcher` y `provider`) con `#[allow(dead_code)] // lo usa la orden «emparejar» (F8.30b)` encima.
2. `percent_encode`: deja igual letras ASCII, cifras y `-`, `.`, `_`, `~`; cada otro BYTE (UTF-8) pasa a `%XX` en
   mayúsculas.
3. `parse_daemon_url(url)`: acepta `http://…` o `https://…` con un parámetro `t=` en la consulta. Devuelve
   `(origen, token)`: el origen es esquema + `://` + host[:puerto], sin ruta ni barra final. Si falta el esquema, el
   host o el token (o el token está vacío), `None`. No uses crates de URL: corta por `://`, por la primera `/` o `?`
   y busca `t=` entre los `&` de la consulta.
4. `pairing_uri(origin, token, fingerprint)`: `pcode://emparejar?u=<percent_encode(origin)>&t=<percent_encode(token)>`
   y, si `fingerprint` es `Some(h)` no vacío, añade `&h=<h>`.
5. `pem_to_der(pem)`: toma las líneas entre `-----BEGIN CERTIFICATE-----` y `-----END CERTIFICATE-----` (el primer
   bloque), las une sin espacios y decodifica base64 estándar (alfabeto `A–Z a–z 0–9 + /`, relleno `=`) con un
   decodificador escrito a mano. Si no hay bloque o hay un carácter no válido, `None`.
6. `fingerprint(der)`: SHA-256 de los bytes en hexadecimal minúsculas (64 caracteres).
7. `qr_command(uri)`: `["qrencode", "-t", "ANSIUTF8", "-m", "2", uri]`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/pairing.rs
//! Emparejar el móvil con el demonio: enlace `pcode://emparejar`, huella del certificado y código QR.

/// Codificación por ciento de un texto para usarlo como valor de un parámetro de URL.
pub fn percent_encode(s: &str) -> String;
/// (origen, token) de la URL que imprime `pcode daemon` (`http://host:puerto/?t=TOKEN`).
pub fn parse_daemon_url(url: &str) -> Option<(String, String)>;
/// Enlace de emparejamiento que entiende la app.
pub fn pairing_uri(origin: &str, token: &str, fingerprint: Option<&str>) -> String;
/// Bytes DER del primer certificado de un PEM.
pub fn pem_to_der(pem: &str) -> Option<Vec<u8>>;
/// Huella SHA-256 (hexadecimal en minúsculas) de un certificado en DER.
pub fn fingerprint(der: &[u8]) -> String;
/// Orden que dibuja el enlace como código QR en la terminal.
pub fn qr_command(uri: &str) -> Vec<String>;
```

## Ejemplo (entrada y resultado esperado)

```
percent_encode("http://a:1/ñ")  -> "http%3A%2F%2Fa%3A1%2F%C3%B1"
parse_daemon_url("http://192.168.1.10:7878/?t=abc123") -> Some(("http://192.168.1.10:7878", "abc123"))
parse_daemon_url("http://192.168.1.10:7878/")          -> None
pairing_uri("http://192.168.1.10:7878", "abc123", None)
   -> "pcode://emparejar?u=http%3A%2F%2F192.168.1.10%3A7878&t=abc123"
pairing_uri("https://h:1", "t", Some("ab12")) -> "pcode://emparejar?u=https%3A%2F%2Fh%3A1&t=t&h=ab12"
pem_to_der("-----BEGIN CERTIFICATE-----\naG9sYQ==\n-----END CERTIFICATE-----\n") -> Some(b"hola".to_vec())
fingerprint(b"hola") -> "b221d9dbb083a7f33428d7c2a3c3198ae925614d70210e28716ccaa7cd4ddb79"
```

## Tests (con estos nombres)

- `codifica_por_ciento`: el ejemplo de percent_encode; «abc-._~» queda igual
- `lee_la_url_del_demonio`: el ejemplo con token da origen y token; sin t=, con t vacío o sin esquema dan None; https con otros parámetros (?x=1&t=zz) da el token zz
- `enlace_de_emparejamiento`: los dos ejemplos de pairing_uri, con y sin huella; Some(«») no añade h
- `pem_a_der`: el ejemplo da los bytes de «hola»; un PEM sin bloque y uno con el carácter «*» dan None
- `huella_sha256`: fingerprint de «hola» es la cadena del ejemplo (64 caracteres en minúsculas)
- `orden_del_qr`: qr_command(«x») es [qrencode, -t, ANSIUTF8, -m, 2, x]
