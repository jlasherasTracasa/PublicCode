## Objetivo

1. `main.rs`, enum `Cmd`: variante nueva `Emparejar` con su `///` («Enseña el enlace y el código QR para emparejar
   el móvil con un demonio en marcha») y estos campos: `url: String` (posicional: la URL que imprime `pcode
   daemon`), `#[arg(long = "certificado")] cert: Option<std::path::PathBuf>` (PEM del certificado TLS, para incluir
   su huella) y `#[arg(long = "sin-qr")] no_qr: bool`.
2. Brazo nuevo en el `match` de `main`: con `pairing::parse_daemon_url(&url)`; si da `None`, imprime en stderr
   `URL no válida: se esperaba http://host:puerto/?t=TOKEN` y sale con 2. Si hay `--certificado`: lee el archivo,
   `pem_to_der` y `fingerprint`; si no se puede leer o no es un PEM, stderr `certificado no válido: <ruta>` y sale
   con 2.
3. Imprime en stdout el enlace de `pairing::pairing_uri(...)` en una línea. Después, si no se pasó `--sin-qr` y
   stdout es una terminal (`std::io::IsTerminal`), ejecuta `pairing::qr_command(&enlace)` con
   `std::process::Command` (hereda la salida); si `qrencode` no está instalado, imprime en stderr
   `Instala qrencode para ver el código QR, o pega el enlace en la app.` Sale con 0.
4. Quita el `#[allow(dead_code)]` que F8.30a puso sobre `mod pairing;`.
5. `Cmd::Daemon`: después de la línea que imprime `pcoded: http://…`, añade
   `eprintln!("móvil: pcode emparejar 'http://{host}:{puerto}/?t={token}'");`.
6. `tests/emparejar.rs`: los tests de la lista, con `assert_cmd` (stdout no es una terminal, así que no hay QR).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/main.rs — variante nueva de `Cmd`
/// Enseña el enlace y el código QR para emparejar el móvil con un demonio en marcha.
Emparejar {
    /// URL que imprime `pcode daemon` (`http://host:puerto/?t=TOKEN`).
    url: String,
    /// Certificado TLS del demonio (PEM), para incluir su huella en el enlace.
    #[arg(long = "certificado")]
    cert: Option<std::path::PathBuf>,
    /// No dibujar el código QR.
    #[arg(long = "sin-qr")]
    no_qr: bool,
},
```

## Ejemplo (entrada y resultado esperado)

```
$ pcode emparejar 'http://192.168.1.10:7878/?t=abc123' --sin-qr
pcode://emparejar?u=http%3A%2F%2F192.168.1.10%3A7878&t=abc123
$ pcode emparejar 'http://192.168.1.10:7878/'          (código de salida 2)
URL no válida: se esperaba http://host:puerto/?t=TOKEN
```

## Tests (con estos nombres)

- `emparejar_imprime_el_enlace`: con la URL del ejemplo y --sin-qr, stdout es exactamente el enlace del ejemplo más un salto de línea y el código de salida es 0
- `emparejar_url_sin_token_falla`: sin t= sale con 2 y stderr contiene «URL no válida»
- `emparejar_con_certificado_anade_la_huella`: con un PEM temporal cuyo contenido base64 es aG9sYQ==, stdout acaba en &h=b221d9dbb083a7f33428d7c2a3c3198ae925614d70210e28716ccaa7cd4ddb79
- `emparejar_certificado_roto_falla`: con un archivo que no es PEM sale con 2 y stderr contiene «certificado no válido»

## No hagas

- No arranques el demonio en los tests
- No imprimas el token en ningún otro sitio (ni en registros ni en archivos)
- No dibujes el QR a mano: se delega en `qrencode` si está instalado
