## Objetivo

1. `Conexion.java`: campo nuevo `private final String huella;` (cadena vacía si no hay) y su acceso
   `public String huella()`. El constructor privado pasa a recibir `(origen, token, huella)`; `parse` sigue creando
   conexiones con huella vacía para las URL `http(s)://…`.
2. `Conexion.java`: nuevo método público `parseEmparejamiento(String texto)`. Acepta
   `pcode://emparejar?u=<origen codificado>&t=<token codificado>[&h=<huella>]` (el esquema y `emparejar` sin
   distinguir mayúsculas). Decodifica `u` y `t` con `java.net.URLDecoder.decode(valor, "UTF-8")`. El origen
   decodificado se valida reutilizando `parse(origen + "/?t=" + token)`: si eso da `null`, devuelve `null`. La
   huella, si viene, debe ser hexadecimal de 64 caracteres (se guarda en minúsculas); si viene y no lo es, `null`.
3. `parse(texto)`: si el texto (tras `trim`) empieza por `pcode://` (sin distinguir mayúsculas), devuelve
   `parseEmparejamiento(texto)`. Así el formulario de la app acepta las dos formas sin tocar `MainActivity`.
4. `ConexionTest.java`: añade los tests de la lista sin cambiar los que hay.

## Ejemplo (entrada y resultado esperado)

```
Conexion c = Conexion.parse("pcode://emparejar?u=http%3A%2F%2F192.168.1.10%3A7878&t=abc123");
c.origen() -> "http://192.168.1.10:7878"     c.token() -> "abc123"     c.huella() -> ""
Conexion.parse("pcode://emparejar?u=https%3A%2F%2Fh%3A1&t=t&h=" + "AB".repeat(32)).huella() -> "ab" repetido 32 veces
Conexion.parse("pcode://emparejar?u=ftp%3A%2F%2Fx&t=t") -> null
Conexion.parse("pcode://emparejar?u=https%3A%2F%2Fh&t=t&h=xyz") -> null
```

## Tests (con estos nombres)

- `emparejarConEnlace`: el primer ejemplo da el origen http://192.168.1.10:7878, el token abc123 y la huella vacía
- `emparejarConHuella`: una huella de 64 cifras hexadecimales en mayúsculas se guarda en minúsculas
- `emparejarRechazaLoNoValido`: un origen ftp, una huella «xyz», un enlace sin t y «pcode://otra?u=x&t=y» dan null
- `parseDeUrlNormalTieneHuellaVacia`: Conexion.parse(«http://192.168.1.10:7878/?t=abc123»).huella() es la cadena vacía
