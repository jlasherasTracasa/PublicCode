## Objetivo

1. Crea `roots.rs` con `Root` y `Roots` (firmas abajo). El nombre de una raíz es el último componente de
   su ruta (`file_name()`), o `proyecto` si no tiene.
2. `Roots::new(primary)`: una sola raíz, la principal, con la ruta tal cual llega (sin canonizar).
3. `add(path)`: canoniza la ruta (`canonicalize`); si falla o no es un directorio,
   `Err(format!("no es una carpeta: {}", path.display()))`. Si ya hay una raíz con esa misma ruta
   canonizada (compara también con la principal canonizada), devuelve su nombre sin añadir nada. Si el
   nombre ya está en uso, prueba `nombre-2`, `nombre-3`… hasta 99. Devuelve el nombre asignado.
4. `resolve(name)`: la cadena vacía es la raíz principal; un nombre conocido devuelve su ruta; si no,
   `Err(format!("raíz desconocida: {name}"))`. `list()` devuelve todas, la principal primero.
5. `lib.rs`: añade `pub mod roots;` (después de `pub mod assist;`). Tests en `roots.rs` con `tempfile::tempdir()`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/roots.rs
use std::path::{Path, PathBuf};

/// Una carpeta abierta en Studio.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct Root { pub name: String, pub path: PathBuf }

/// Carpetas abiertas: la principal y las extra.
#[derive(Debug, Clone)]
pub struct Roots { items: Vec<Root> }

impl Roots {
    /// Solo la raíz principal.
    pub fn new(primary: PathBuf) -> Roots;
    /// Añade una carpeta y devuelve su nombre.
    pub fn add(&mut self, path: &Path) -> Result<String, String>;
    /// Ruta de la raíz `name` (vacío = principal).
    pub fn resolve(&self, name: &str) -> Result<PathBuf, String>;
    /// Todas las raíces, la principal primero.
    pub fn list(&self) -> &[Root];
}
```

## Ejemplo (entrada y resultado esperado)

```
let mut r = Roots::new("/tmp/x/app".into());           // list() -> [Root { name: "app", path: "/tmp/x/app" }]
r.add(Path::new("/tmp/y/lib"))      -> Ok("lib")
r.add(Path::new("/tmp/z/app"))      -> Ok("app-2")     // el nombre "app" ya está en uso
r.add(Path::new("/tmp/y/lib/"))     -> Ok("lib")       // misma carpeta: no se duplica
r.add(Path::new("/tmp/no-existe"))  -> Err("no es una carpeta: /tmp/no-existe")
r.resolve("")      -> Ok("/tmp/x/app")
r.resolve("lib")   -> Ok(<ruta canonizada de /tmp/y/lib>)
r.resolve("otra")  -> Err("raíz desconocida: otra")
```

## Tests (con estos nombres)

- `la_principal_es_la_primera`: `Roots::new` da una lista de un elemento con el nombre de la carpeta
- `añadir_devuelve_el_nombre`: añadir una carpeta temporal `lib` devuelve `lib` y `list()` tiene dos elementos
- `nombres_repetidos_llevan_sufijo`: dos carpetas distintas llamadas `app` dan `app` y `app-2`
- `misma_carpeta_no_se_duplica`: añadir dos veces la misma ruta devuelve el mismo nombre y no crece la lista
- `lo_que_no_es_carpeta_se_rechaza`: una ruta que no existe y un archivo normal dan `Err` que empieza por `no es una carpeta`
- `resolver_vacio_es_la_principal`: `resolve("")` devuelve la ruta principal y un nombre desconocido da `Err`
