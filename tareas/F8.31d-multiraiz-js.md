## Objetivo

La raíz principal se representa con la cadena vacía; las extra, con su nombre.
1. Crea `raices.js` con las cuatro funciones de las firmas.
2. `usesRoot(method)`: `true` si el método empieza por `fs.`, `search.` o `git.`.
3. `withRoot(method, params, root)`: devuelve una copia de `params` (o `{}` si es `undefined`) con
   `root` añadido solo si `usesRoot(method)`, `root` no es vacío y `params.root` no está ya definido. En
   cualquier otro caso devuelve los parámetros sin `root` nuevo.
4. `tabId(root, path)`: `"f:" + path` para la raíz principal y `"f:" + root + ":" + path` para una extra.
   `label(root, path)`: el nombre del archivo (lo que va tras la última `/`), seguido de ` · ` y la raíz
   si no es la principal.
5. Crea `raices.test.js` con los tests de la lista.

## Firmas (cópialas tal cual)

```javascript
// crates/pcode-server/web/studio/raices.js
/** El método de la API trabaja sobre una raíz. */
export function usesRoot(method) {}
/** Parámetros de la petición con `root` cuando hace falta. */
export function withRoot(method, params, root) {}
/** Id de la pestaña de un archivo. */
export function tabId(root, path) {}
/** Texto de la pestaña. */
export function label(root, path) {}
```

## Ejemplo (entrada y resultado esperado)

```
withRoot("fs.read", { path: "a.txt" }, "lib")               -> { path: "a.txt", root: "lib" }
withRoot("fs.read", { path: "a.txt" }, "")                  -> { path: "a.txt" }
withRoot("fs.read", { path: "a.txt", root: "" }, "lib")     -> { path: "a.txt", root: "" }
withRoot("session.list", undefined, "lib")                  -> {}
tabId("", "src/main.rs")     -> "f:src/main.rs"          tabId("lib", "src/main.rs") -> "f:lib:src/main.rs"
label("", "src/main.rs")     -> "main.rs"                label("lib", "src/main.rs") -> "main.rs · lib"
```

## Tests (con estos nombres)

- `metodos_con_raiz`: `fs.read`, `search.text` y `git.status` usan raíz; `session.list`, `lsp.sync` y `terminal.run` no
- `añade_la_raiz_activa`: el primer caso de `withRoot` del ejemplo
- `la_principal_no_añade_nada`: el segundo caso de `withRoot` del ejemplo
- `no_pisa_una_raiz_explicita`: el tercer caso de `withRoot` del ejemplo (la cadena vacía explícita se respeta)
- `sin_parametros_devuelve_objeto`: el cuarto caso de `withRoot` del ejemplo
- `no_modifica_la_entrada`: tras `withRoot`, el objeto original no tiene `root`
- `ids_y_etiquetas`: los cuatro casos de `tabId` y `label` del ejemplo
