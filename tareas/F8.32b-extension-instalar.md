# F8.32b-extension-instalar — Extensiones: instalar solo con las capacidades aprobadas, listar y sacar sus servidores MCP

## Objetivo

1. En `plugin.rs`, añade `install_plugin`, `list_plugins` y `mcp_servers` (firmas abajo) con sus tests.
2. `install_plugin(source, root, approved)`: lee `source/pcode-extension.toml` con `parse_manifest`. Si
   `missing_approval(&m, approved)` no está vacío, NO copia nada y devuelve
   `ExtError::Plugin("faltan por aprobar las capacidades: mcp, red")` (las que falten, separadas por coma y espacio).
   Si está todo aprobado: borra `root/<id>` si existía; copia el manifiesto, cada archivo de `ordenes` y cada
   carpeta de `skills` (recursivo, solo archivos y carpetas normales; los enlaces simbólicos se saltan) conservando
   sus rutas relativas; y escribe `root/<id>/aprobado.txt` con las capacidades del manifiesto, una por línea.
   Si una orden o skill declarada no existe en `source`, error `ExtError::Plugin("no existe <ruta>")` y no deja
   nada a medias (borra `root/<id>`).
3. `list_plugins(root)`: manifiestos de las subcarpetas de `root` que tienen `pcode-extension.toml` válido Y
   `aprobado.txt`; ordenados por `id`. Las carpetas cuyo nombre empieza por `.` se ignoran.
4. `mcp_servers(root)`: para cada extensión de `list_plugins` cuyo `aprobado.txt` contiene la línea `mcp`, una
   entrada por servidor: nombre `<id con el punto cambiado por guion>-<nombre>` y su `McpDecl`. Ordenado por nombre.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-extensions/src/plugin.rs
use std::path::Path;

/// Archivo que guarda las capacidades aprobadas al instalar.
pub const APPROVED_FILE: &str = "aprobado.txt";

/// Instala la extensión de la carpeta `source` en `root/<id>` si `approved` cubre todas sus capacidades.
pub fn install_plugin(source: &Path, root: &Path, approved: &[String]) -> Result<PluginManifest, ExtError>;
/// Extensiones instaladas y aprobadas, por id.
pub fn list_plugins(root: &Path) -> Vec<PluginManifest>;
/// Servidores MCP de las extensiones aprobadas: (nombre único, declaración).
pub fn mcp_servers(root: &Path) -> Vec<(String, McpDecl)>;
```

## Ejemplo (entrada y resultado esperado)

```
source/pcode-extension.toml = el manifiesto «ana.herramientas» con capacidades ["mcp", "red"] y [mcp.github]
install_plugin(source, root, &[])                          -> Err(Plugin("faltan por aprobar las capacidades: mcp, red")); root queda vacío
install_plugin(source, root, &["mcp".into(), "red".into()]) -> Ok(m); existen root/ana.herramientas/pcode-extension.toml,
                                                              root/ana.herramientas/ordenes/revisar-sql.md y root/ana.herramientas/aprobado.txt ("mcp\nred\n")
list_plugins(root)  -> [m]
mcp_servers(root)   -> [("ana-herramientas-github", McpDecl { command: ["npx", "-y", "…"], env: {GITHUB_TOKEN: "{env:GITHUB_TOKEN}"} })]
crate::uninstall(root, "ana.herramientas") -> Ok(true); list_plugins(root) -> []
```

## Tests (con estos nombres)

- `instalar_sin_aprobar_no_copia_nada`: con approved vacío devuelve el error «faltan por aprobar las capacidades: mcp, red» y root no tiene la carpeta de la extensión
- `instalar_aprobada_copia_lo_declarado`: con las dos capacidades aprobadas existen el manifiesto, la orden, la skill y aprobado.txt; un archivo no declarado de source (p. ej. extra.sh) no se copia
- `instalar_con_archivo_declarado_que_falta`: si la orden declarada no existe en source, da «no existe» y no queda la carpeta
- `instalar_lista_y_servidores`: tras instalar, list_plugins devuelve la extensión y mcp_servers el servidor ana-herramientas-github
- `desinstalar_limpia`: tras crate::uninstall, list_plugins y mcp_servers quedan vacíos
- `instalar_sin_marca_de_aprobacion_no_cuenta`: una carpeta en root con manifiesto pero sin aprobado.txt no sale en list_plugins

## No hagas

- No ejecutes nada de la extensión al instalarla
- No sigas enlaces simbólicos al copiar
- No copies archivos que el manifiesto no declara
- No cambies `parse_manifest` ni sus tests
