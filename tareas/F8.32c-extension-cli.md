## Objetivo

1. `main.rs`, `ExtCmd::Instalar`: campo nuevo `#[arg(long = "aceptar")] aceptar: bool` con `///` («Aprueba sin
   preguntar las capacidades que pide la extensión»). Ajusta los sitios donde se desestructura
   `ExtCmd::Instalar { origen }` para que incluyan `aceptar` (o `..`).
2. `ext_cmd`, brazo `ExtCmd::Instalar`: si `origen` es una carpeta que contiene `pcode-extension.toml`
   (`pcode_extensions::plugin::MANIFEST_FILE`), es una extensión de PublicCode; si no, sigue como hasta ahora
   (`pcode_extensions::install`).
3. Extensión de PublicCode: lee el manifiesto con `parse_manifest` (si falla, propaga el error). Imprime
   `<id> <version> pide estas capacidades: mcp, red` (o `no pide capacidades`) y una línea `  servidor MCP <nombre>:
   <orden unida con espacios>` por servidor. Decide la aprobación:
   - con `--aceptar`: aprobadas todas las del manifiesto;
   - sin `--aceptar` y con stdin en una terminal (`std::io::IsTerminal`): pregunta `¿Instalar y aprobar? [s/N] ` y
     lee una línea; solo `s` o `S` aprueba;
   - sin `--aceptar` y sin terminal: no aprueba nada.
   Si no se aprueba: imprime en stderr `no instalada: vuelve a ejecutar con --aceptar para aprobar las capacidades`
   y devuelve `Ok(2)`. Si se aprueba: `install_plugin(&origen, &root, &capacidades)` e imprime
   `✓ <id> <version> · <n> servidores MCP · <n> órdenes · <n> skills`.
4. `ext_cmd`, brazo `ExtCmd::Listar`: después de las de VS Code, una línea por cada `list_plugins(&root)` con el
   mismo formato `✓ …` del paso 3.
5. `tests/extensiones.rs`: los tests de la lista. Usa un directorio temporal como `XDG_DATA_HOME` (así
   `default_root()` cae dentro) y otra carpeta temporal con el manifiesto y un `ordenes/a.md`.

## Ejemplo (entrada y resultado esperado)

```
$ pcode extensiones instalar ./mi-ext            (sin terminal; código de salida 2)
ana.herramientas 1.0.0 pide estas capacidades: mcp
  servidor MCP github: npx -y srv
no instalada: vuelve a ejecutar con --aceptar para aprobar las capacidades
$ pcode extensiones instalar ./mi-ext --aceptar  (código de salida 0)
ana.herramientas 1.0.0 pide estas capacidades: mcp
  servidor MCP github: npx -y srv
✓ ana.herramientas 1.0.0 · 1 servidores MCP · 1 órdenes · 0 skills
$ pcode extensiones listar
✓ ana.herramientas 1.0.0 · 1 servidores MCP · 1 órdenes · 0 skills
```

## Tests (con estos nombres)

- `instalar_sin_aceptar_no_instala`: sin --aceptar (stdin no es terminal) sale con 2, stdout nombra la capacidad mcp, stderr contiene «--aceptar» y `listar` no muestra la extensión
- `instalar_con_aceptar_y_listar`: con --aceptar sale con 0 y `pcode extensiones listar` muestra «ana.herramientas 1.0.0»
- `quitar_la_extension`: tras instalar, `pcode extensiones quitar ana.herramientas` sale con 0 y `listar` ya no la muestra
- `manifiesto_roto_falla`: una carpeta con un pcode-extension.toml sin id no sale con 0 y stderr contiene «pcode-extension.toml no válido»

## No hagas

- No apruebes nada por defecto: sin `--aceptar` y sin terminal, no se instala
- No cambies cómo se instalan las extensiones de VS Code (`.vsix`, carpeta con `package.json`, `editor.nombre`)
- No ejecutes los servidores MCP al instalar
- No uses la carpeta real del usuario en los tests: siempre `XDG_DATA_HOME` temporal
