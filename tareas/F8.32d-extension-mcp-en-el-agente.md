## Contexto (lee esto y nada más)

- crates/pcode-cli/src/provider.rs (función `mcp_tools`: construye `Vec<pcode_tools::mcp::McpServer>` a partir de `cfg.mcp`)
- crates/pcode-extensions/src/plugin.rs (`mcp_servers(root: &Path) -> Vec<(String, McpDecl)>`; `McpDecl { command, env }`)
- crates/pcode-config/src/lib.rs (`pub fn expand_env(s: &str) -> Result<String, ConfigError>`: sustituye `{env:VAR}`)

## Objetivo

1. `provider.rs`: nueva función `plugin_servers(root)` (firma abajo). Por cada `(nombre, decl)` de
   `pcode_extensions::plugin::mcp_servers(root)` crea un `pcode_tools::mcp::McpServer { name: nombre, command:
   decl.command, env, ask: true }`. `env` es `decl.env` con cada valor pasado por `pcode_config::expand_env`; si
   alguna variable no está definida, ese servidor NO se devuelve y se añade a los avisos el texto
   `extensión <nombre>: falta la variable de entorno de <CLAVE>`.
2. `provider.rs`, `mcp_tools`: después de construir `servers` a partir de `cfg.mcp`, si
   `pcode_extensions::default_root()` es `Some(root)`, añade los de `plugin_servers(&root)` que no repitan un nombre
   ya presente, y guarda sus avisos para sumarlos a `warnings` al final. (`servers` pasa a ser `let mut`.)
3. Tests en el `mod tests` de `provider.rs` (créalo si no existe), con `tempfile` y
   `pcode_extensions::plugin::install_plugin` para preparar la carpeta.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/provider.rs
/// Servidores MCP de las extensiones aprobadas (siempre piden aprobación por llamada) y avisos de los que se saltan.
pub fn plugin_servers(root: &std::path::Path) -> (Vec<pcode_tools::mcp::McpServer>, Vec<String>);
```

## Ejemplo (entrada y resultado esperado)

```
Extensión «ana.herramientas» instalada y aprobada, con [mcp.github] orden = ["npx", "-y", "srv"], entorno = { A = "fijo" }
plugin_servers(root) -> ([McpServer { name: "ana-herramientas-github", command: ["npx", "-y", "srv"], env: {"A": "fijo"}, ask: true }], [])
Con entorno = { T = "{env:PCODE_TEST_NO_EXISTE_JAMAS}" }
plugin_servers(root) -> ([], ["extensión ana-herramientas-github: falta la variable de entorno de T"])
```

## Tests (con estos nombres)

- `plugin_servers_de_una_extension_aprobada`: el primer ejemplo devuelve un servidor con ask = true y sin avisos
- `plugin_servers_sin_variable_se_salta`: el segundo ejemplo no devuelve servidores y el aviso nombra la clave T
- `plugin_servers_sin_extensiones`: con una carpeta vacía (o que no existe) devuelve dos listas vacías

## No hagas

- No pongas `ask: false`: las tools de una extensión de terceros siempre piden aprobación
- No lances los servidores en los tests: `plugin_servers` solo construye la lista
- No cambies la firma de `mcp_tools`
- No escribas valores de variables de entorno en avisos ni registros: solo el nombre de la clave
