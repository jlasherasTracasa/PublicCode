# F8.33-github-pr — GitHub: crear un PR con descripción generada y revisar PRs con el agente

## Objetivo

1. En un repositorio de pruebas, con `GITHUB_TOKEN`: `pcode pr crear --publicar --si` debe subir la rama y
   abrir el PR con el título y el cuerpo generados; `pcode pr revisar <n>` debe dejar el borrador en
   `.pcode/revisiones/pr-<n>.md` y `pcode pr revisar <n> --publicar --si` publicar los comentarios.
2. Corrige lo que difiera de la API real y documenta las dos órdenes en `docs/usuario.md` (tabla de flags,
   permisos del token y aviso de que nada se publica sin `--publicar --si`).
3. Anota en el informe que la parte de Studio (botón «Crear PR» en el panel de git) queda fuera: se planifica
   aparte cuando exista el módulo de git de Studio.

## Tests (con estos nombres)
