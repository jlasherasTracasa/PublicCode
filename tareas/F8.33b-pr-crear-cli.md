## Objetivo

1. Crea `pr_cmd.rs` con `PrCmd` y `pr_cmd` (firmas abajo). Variante `Crear { base: String, publish: bool, yes:
   bool, model, provider, config }`: `--base` (por defecto `main`), `--publicar`, `--si`, `--modelo`,
   `--proveedor`, `--config` (por defecto `pcode.toml`).
2. Rama `Crear`, con `std::process::Command` de `git` en el directorio actual:
   - commits = líneas de `git log --format=%s <base>..HEAD`; si no hay ninguno: stderr
     `no hay commits que no estén en <base>` y devuelve 2;
   - diff = `git diff <base>...HEAD`;
   - una petición de chat (como en `ask`) con `pr_prompt(&commits, &diff)`; `parse_pr_text` sobre la respuesta;
     si da `None`: stderr `el modelo no devolvió TITULO: y CUERPO:` y devuelve 2;
   - imprime `# <título>`, una línea vacía y el cuerpo.
3. Sin `--publicar` termina ahí con 0 (no toca nada). Con `--publicar` pero sin `--si`: stderr
   `publicar sube la rama y abre el PR: repite con --publicar --si` y devuelve 2. Con los dos: rama actual
   (`git rev-parse --abbrev-ref HEAD`), `git push origin <rama>` (sin forzar), `parse_remote` sobre
   `git remote get-url origin`, `GitHubHttp::from_env(dueño, repo)?.create_pr(&rama, &base, &título, &cuerpo)`
   e imprime `PR #<n> abierto`.
4. `main.rs`: `mod pr_cmd;`, variante `#[command(subcommand)] Pr(pr_cmd::PrCmd)` («Pull requests: crear con
   descripción generada y revisar.») y la rama `Some(Cmd::Pr(c)) => std::process::exit(pr_cmd::pr_cmd(c).await?),`
   junto a la de `Flow`.
5. Crea `tests/pr.rs` con los tests `crear_*`: repo temporal con `git init -b main`, un commit, una rama
   `tema` con otro commit, y el guion del modelo simulado.

## Ejemplo (entrada y resultado esperado)

```
(en la rama `tema`, con un commit «añade csv» que no está en main; guion: "TITULO: Exporta a CSV\nCUERPO:\n## Qué cambia\nAñade csv.rs")
$ pcode pr crear
# Exporta a CSV

## Qué cambia
Añade csv.rs
→ código 0, sin push ni petición a GitHub
$ pcode pr crear --publicar        → código 2, stderr contiene "--publicar --si"
(en main, sin commits propios) $ pcode pr crear → código 2, stderr "no hay commits que no estén en main"
```

## Tests (con estos nombres)

- `crear_imprime_titulo_y_cuerpo`: el primer caso del ejemplo imprime el título con `# ` y el cuerpo
- `crear_publicar_exige_si`: con --publicar y sin --si sale con 2 y no hace push (el repo no tiene remoto y aun así no falla por git)
- `crear_sin_commits_propios`: en main sale con 2 y el mensaje de que no hay commits
- `crear_respuesta_sin_formato`: un guion con «no sé» sale con 2 y el mensaje de TITULO: y CUERPO:

## No hagas

- No publiques nada sin `--publicar --si`
- No uses `git push --force`
- No uses `gh`: la API va por `GitHubHttp`
- No toques otras órdenes de `main.rs`
