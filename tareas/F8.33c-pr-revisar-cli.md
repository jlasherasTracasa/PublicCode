# F8.33c-pr-revisar-cli — CLI: `pcode pr revisar <n>` deja los comentarios en borrador y solo los publica con `--publicar --si`

## Objetivo

1. En `pr_cmd.rs`, variante nueva `Revisar { number: u64, diff_file: Option<PathBuf>, publish: bool, yes: bool,
   model, provider, config }`: número posicional, `--diff-archivo`, `--publicar`, `--si`, `--modelo`,
   `--proveedor`, `--config`.
2. Borrador = `.pcode/revisiones/pr-<n>.md` en el directorio actual.
3. Sin `--publicar` (generar el borrador):
   - diff = contenido de `--diff-archivo` si se da; si no, `GitHubHttp` desde el remoto `origin` (como en
     `Crear`) y `pr_diff(number)`;
   - una petición de chat con `pr_review_prompt(&diff)`; `parse_review_comments` sobre la respuesta;
   - crea la carpeta, escribe `render_drafts(number, &comentarios)` en el borrador (aquí sí se sobrescribe:
     es un borrador regenerado) e imprime `borrador: <ruta> (<k> comentarios, nada publicado)`. Devuelve 0.
4. Con `--publicar`: sin `--si` → stderr `publicar escribe en el PR: repite con --publicar --si` y devuelve 2.
   Si el borrador no existe → stderr `no hay borrador: ejecuta antes pcode pr revisar <n>` y devuelve 2. Con
   todo: lee el borrador con `parse_review_comments` (lo que la persona haya dejado), y por cada comentario
   llama a `comment(number, &format!("**{}:{}** — {}", file, line, body))`; imprime
   `publicados <k> comentarios en el PR #<n>`. No se llama al modelo.
5. Añade a `tests/pr.rs` los tests `revisar_*` (todos con `--diff-archivo` o sin llegar a la red).

Sin firmas: solo añade una variante de `PrCmd` y su rama; la API está en `pcode_flow::pr`

## Ejemplo (entrada y resultado esperado)

```
cambio.diff: un diff cualquiera.  Guion del modelo: "- src/a.rs:12: falta comprobar el vacío\n- src/b.rs:3: test que falta"
$ pcode pr revisar 7 --diff-archivo cambio.diff
borrador: .pcode/revisiones/pr-7.md (2 comentarios, nada publicado)
→ el archivo contiene "# Revisión del PR #7 (borrador)" y "- src/a.rs:12: falta comprobar el vacío"
$ pcode pr revisar 7 --publicar       → código 2, stderr contiene "--publicar --si"
$ pcode pr revisar 8 --publicar --si  → código 2, stderr contiene "no hay borrador"
```

## Tests (con estos nombres)

- `revisar_deja_borrador`: el primer caso del ejemplo crea el archivo con el título y los dos comentarios
- `revisar_sin_comentarios`: un guion con `SIN COMENTARIOS` deja un borrador con `Sin comentarios.` y dice 0 comentarios
- `revisar_publicar_exige_si`: con --publicar y sin --si sale con 2
- `revisar_publicar_sin_borrador`: con --publicar --si y sin borrador sale con 2 y lo dice

## No hagas

- No publiques nada sin `--publicar --si`
- No llames al modelo al publicar: se publica lo que hay en el borrador
- No toques la rama `Crear`
