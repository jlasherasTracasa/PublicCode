## Objetivo

1. Crea `contraste.js` con las funciones de las firmas. `luminance` y `contrastRatio` siguen WCAG 2.1:
   cada canal `c = valor / 255`; si `c <= 0.03928`, `c / 12.92`; si no, `((c + 0.055) / 1.055) ** 2.4`;
   `L = 0.2126 R + 0.7152 G + 0.0722 B`; razón `(Lmayor + 0.05) / (Lmenor + 0.05)`. Acepta `#rgb` y `#rrggbb`.
2. `themeColors(css)`: recibe el texto de `index.html` y devuelve `{ claro, oscuro, medianoche }`, cada uno
   un objeto `{ nombreSinGuiones: "#hex" }` con las variables `--nombre: #hex` (solo valores hexadecimales).
   `claro` sale del bloque `:root {`; `oscuro` es `claro` más lo que redefine `:root[data-dark] {`;
   `medianoche` es `oscuro` más lo que redefine `:root[data-theme="medianoche"] {`. Cada bloque acaba en
   la primera `}`.
3. `failures(colors, pairs)`: `pairs` es una lista `[texto, fondo, mínimo]`; devuelve las que no llegan,
   como `{ fg, bg, ratio, min }` (`ratio` redondeado a 2 decimales).
4. Crea `contraste.test.js`. El test de la paleta lee `index.html` con
   `fs.readFileSync(path.join(import.meta.dirname, "../../index.html"), "utf8")` y comprueba en los tres
   temas los pares de `PAIRS` (exportados por el módulo, ver firmas).
5. `index.html`: cambia solo los colores que hoy no llegan. En `:root {`: `--t-com: #7b8aa3` pasa a
   `#5f6f8a` y `--ed-gutter: #8a9bb5` pasa a `#6f84a6`. En `:root[data-dark] {`: `--t-com: #6b7f9e` pasa a
   `#7f93b3`. Si el test señala otro par, ajusta ese color lo mínimo y anótalo en *Decisiones*.

## Ejemplo (entrada y resultado esperado)

```
contrastRatio("#000000", "#ffffff") -> 21         contrastRatio("#fff", "#ffffff") -> 1
contrastRatio("#777777", "#ffffff") -> 4.48 (redondeado)      // no llega a AA
themeColors(":root { --texto: #0b1b33; --sombra: 0 1px 2px rgba(0,0,0,.1); }\n:root[data-dark] { --texto: #e3ecfb; }\n:root[data-theme=\"medianoche\"] { --fondo: #03060c; }")
  -> { claro: { texto: "#0b1b33" }, oscuro: { texto: "#e3ecfb" }, medianoche: { texto: "#e3ecfb", fondo: "#03060c" } }
failures({ texto: "#777777", fondo: "#ffffff" }, [["texto", "fondo", 4.5]]) -> [{ fg: "texto", bg: "fondo", ratio: 4.48, min: 4.5 }]
```

## Tests (con estos nombres)

- `razon_de_contraste_conocida`: negro sobre blanco da 21, blanco sobre blanco da 1 y `#777777` sobre blanco da 4.48
- `color_corto_y_largo`: `#fff` y `#ffffff` tienen la misma luminancia (1)
- `temas_heredan_y_redefinen`: el caso de `themeColors` del ejemplo
- `fallos_listados`: el caso de `failures` del ejemplo; con `#000000` sobre `#ffffff` la lista queda vacía
- `contraste_aa_de_la_paleta`: para `claro`, `oscuro` y `medianoche` de `index.html`, `failures(tema, PAIRS)` es una lista vacía (el mensaje del fallo incluye el tema y los pares)
