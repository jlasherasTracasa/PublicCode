## Objetivo

Todo va en la función `cargaDir` de `index.html`.
1. Atributos: cada `li` lleva `aria-level` igual a `nivel + 1`; si es carpeta, `aria-expanded` (`"true"`
   si `S.abiertas.has(it.path)`, si no `"false"`) y su `ul` hijo lleva `role="group"`. La fila guarda
   `fila.dataset.nivel = nivel` y, si es carpeta, `fila.dataset.dir = "1"`.
2. En el `onclick` de las carpetas, actualiza `aria-expanded` del `li` al abrir y al cerrar.
3. `fila.onkeydown`: conserva Intro, espacio, F2 y Supr. Para las demás teclas construye la lista de filas
   visibles `filas = [...$("arbol").querySelectorAll(".nodo")]` y
   `items = filas.map((f) => ({ level: Number(f.dataset.nivel), expanded: f.dataset.dir ? S.abiertas.has(f.dataset.path) : null }))`;
   llama a `Studio.foco.treeMove(items, filas.indexOf(fila), e.key)`. Si devuelve `null`, no hagas nada.
   Si no: `e.preventDefault()`; con `action` `"expand"` o `"collapse"`, `fila.click()`; si el índice
   cambia, `filas[r.index].focus()`.
4. Comprueba que el foco se ve: la regla CSS `[tabindex]:focus-visible` ya dibuja el contorno; no la cambies.

Sin firmas: solo cableado en index.html: no añade API
