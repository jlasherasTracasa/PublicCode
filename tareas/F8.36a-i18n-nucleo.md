## Objetivo

1. Crea `i18n.js` con las cuatro funciones de las firmas.
   - `pickLanguage(saved, preferred, available)`: si `saved` está en `available`, lo devuelve. Si no,
     recorre `preferred` (como `navigator.languages`: `["en-US", "es"]`) y devuelve el primero cuyo prefijo
     antes de `-`, en minúsculas, esté en `available`. Si ninguno, `"es"`.
   - `translate(catalog, text, vars)`: busca `text` en `catalog` (si `catalog` es `undefined` o no tiene
     la clave, usa `text`) y sustituye cada `{nombre}` por `vars.nombre` (si falta, deja `{nombre}`).
   - `extractTexts(source)`: devuelve, sin repetidos y en orden de aparición, los textos marcados en un
     HTML con JS: los valores de los atributos `data-i18n="…"`, `data-i18n-title="…"`,
     `data-i18n-placeholder="…"` y `data-i18n-aria="…"`, y el primer argumento de cada llamada
     `tr("…")` (solo comillas dobles; admite `\"` dentro).
   - `missing(texts, catalog)`: los textos que no son clave de `catalog`.
2. Crea `catalogos.js` con `export const en = { … };` y estas entradas iniciales: `"Explorador": "Explorer"`,
   `"Buscar": "Search"`, `"Problemas": "Problems"`, `"Terminal": "Terminal"`, `"Agente": "Agent"`,
   `"Guardado {nombre}": "Saved {nombre}"`. Exporta también `export const LANGUAGES = { es: "Español", en: "English" };`.
3. Crea `i18n.test.js` y `catalogos.test.js` con los tests de la lista. `catalogos.test.js` lee `index.html`
   con `fs.readFileSync(path.join(import.meta.dirname, "../../index.html"), "utf8")`.

## Ejemplo (entrada y resultado esperado)

```
pickLanguage("en", ["es-ES"], ["es", "en"])        -> "en"
pickLanguage(null, ["en-US", "es"], ["es", "en"])  -> "en"
pickLanguage("fr", ["de-DE"], ["es", "en"])        -> "es"
translate({ "Guardado {nombre}": "Saved {nombre}" }, "Guardado {nombre}", { nombre: "a.rs" }) -> "Saved a.rs"
translate(undefined, "Guardado {nombre}", { nombre: "a.rs" })                                  -> "Guardado a.rs"
translate({}, "Sin {x}", {})                                                                    -> "Sin {x}"
extractTexts('<b data-i18n="Explorador"></b><input data-i18n-placeholder="Buscar"> aviso(tr("Guardado {nombre}", v)); tr("Explorador")')
  -> ["Explorador", "Buscar", "Guardado {nombre}"]
missing(["Explorador", "Nuevo"], { "Explorador": "Explorer" }) -> ["Nuevo"]
```

## Tests (con estos nombres)

- `idioma_guardado_gana`: el primer caso de `pickLanguage` del ejemplo
- `idioma_del_navegador_por_prefijo`: el segundo caso (`en-US` elige `en`)
- `idioma_por_defecto_es_español`: el tercer caso (ni `fr` ni `de-DE` están disponibles)
- `traduce_y_rellena_variables`: los tres casos de `translate` del ejemplo
- `extrae_atributos_y_llamadas`: el caso de `extractTexts` del ejemplo (sin repetidos, en orden)
- `mismas_claves_en_todos_los_idiomas`: (catalogos) `missing(extractTexts(index.html), en)` es una lista vacía; el mensaje del fallo enumera los textos que faltan
- `variables_iguales_en_clave_y_traduccion`: (catalogos) cada entrada de `en` tiene en la traducción las mismas `{variables}` que en la clave
- `sin_traducciones_vacias`: (catalogos) ningún valor de `en` es una cadena vacía y `LANGUAGES` tiene `es` y `en`

## No hagas

- No uses `document`, `window`, `navigator` ni imports en `i18n.js` ni en `catalogos.js`
- No crees un catálogo `es`: la clave ya es el texto en español

aquí obliga a que cada texto marcado tenga traducción.
