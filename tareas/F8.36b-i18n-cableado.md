## Objetivo

1. `web_assets.rs`: añade a `ASSETS` `("i18n.js", include_str!("../web/studio/i18n.js")),` y
   `("catalogos.js", include_str!("../web/studio/catalogos.js")),`. `index.html`, bloque
   `<script type="module">` final, antes de `inicio();`: `import * as i18n from "/studio/i18n.js"; Studio.i18n = i18n;`
   y `import * as catalogos from "/studio/catalogos.js"; Studio.catalogos = catalogos;`.
2. `index.html`, encima de `function aviso`: añade `S.idioma = "es";`,
   `function tr(texto, vars) { return Studio.i18n.translate(Studio.catalogos[S.idioma], texto, vars); }` y
   `function traduce()`: para cada elemento con `data-i18n` pone `textContent = tr(valor)`; con
   `data-i18n-title`, `title`; con `data-i18n-placeholder`, `placeholder`; con `data-i18n-aria`,
   `aria-label`. Además `document.documentElement.lang = S.idioma`.
3. Idioma: `function idiomaGuardado()` lee `localStorage.getItem("pcode.idioma")` (con `try`, como
   `temaGuardado`) y `function cambiaIdioma(id)` lo guarda, pone `S.idioma = id`, llama a `traduce()` y
   repinta lo dinámico (`pintaPestanas(); muestra();`). En `inicio`, primera línea:
   `S.idioma = Studio.i18n.pickLanguage(idiomaGuardado(), navigator.languages || [], Object.keys(Studio.catalogos.LANGUAGES)); traduce();`.
   Añade a `ORDENES`: `["Idioma: español", "", () => cambiaIdioma("es")]` y `["Language: English", "", () => cambiaIdioma("en")]`.
4. Marca los textos fijos del HTML (entre `<body` y el `<script>` grande). El valor del atributo es el
   texto en español, tal cual está hoy:
   - elemento cuyo contenido es solo texto: `data-i18n="Texto"`;
   - `title="…"`: añade `data-i18n-title="…"`; `placeholder="…"`: `data-i18n-placeholder="…"`;
     `aria-label="…"`: `data-i18n-aria="…"`.
   No pongas `data-i18n` en elementos que mezclan texto con otros elementos (`<svg>`, `<kbd>`, `<span>`):
   en esos, marca solo `title` o `aria-label`. Como mínimo 40 marcas: la cabecera, la barra de vistas, las
   cabeceras y campos de los paneles, el buscador del archivo, la terminal, el agente, el pie y `nav-movil`.
5. `catalogos.js`: añade a `en` la traducción de **cada** texto marcado (el test `catalogos.test.js` dice
   cuáles faltan). Traducciones cortas y habituales en editores («Explorador» → «Explorer»).

Sin firmas: solo cableado en index.html, dos líneas en la tabla ASSETS y entradas del catálogo: no añade API
