## Objetivo

`tr("Texto en español", vars)` devuelve el texto en el idioma activo; la clave es el texto en español y
el test del catálogo vigila cada `tr("…")`. Las constantes de nivel superior (`ORDENES`, `NOMBRE_TEMA`,
`ESTADOS`) se evalúan antes de cargar los módulos: se dejan en español y se traducen **al pintar**.
1. `index.html`, debajo de `function tr`: añade
   `function trv(texto) { return Studio.i18n.translate(Studio.catalogos[S.idioma], texto); }`
   (para textos que vienen de una tabla y no son un literal).
2. Paleta: en `filtraOrdenes`, usa `trv(o[0])` en lugar de `o[0]` para puntuar (`puntua(q, trv(o[0]))`)
   y para pintar el nombre. No cambies `ORDENES`.
3. Temas y estados: en `aplicaTema`, cada `"Tema: " + NOMBRE_TEMA[t]` pasa a
   `tr("Tema: {nombre}", { nombre: trv(NOMBRE_TEMA[t]) })`. Donde se pinta `ESTADOS[…]`, usa `trv(ESTADOS[…])`.
4. Avisos y diálogos: cambia cada `aviso("Texto fijo"…)` por `aviso(tr("Texto fijo")…)` y cada texto
   compuesto por una clave con variables (ver ejemplo). Haz lo mismo con los textos de `confirm(…)` y
   `prompt(…)`. Como mínimo 40 llamadas `tr("…")` en total.
5. `catalogos.js`: añade a `en` la traducción de todas las entradas de `ORDENES` (su primer elemento), de
   los valores de `NOMBRE_TEMA` y `ESTADOS`, y de cada clave nueva de `tr("…")`.
6. `catalogos.test.js`: añade los dos tests de la lista. Los nombres de las órdenes se sacan del texto
   de `index.html` entre `const ORDENES = [` y `let selOrden` con la expresión `/^\s*\["([^"]+)"/gm`.

Sin firmas: solo cableado en index.html, entradas del catálogo y dos tests: no añade API

## Ejemplo (entrada y resultado esperado)

```
// antes                                              // después
aviso("Ruta copiada")                                 aviso(tr("Ruta copiada"))
aviso("Guardado " + base(t.path), "ok")               aviso(tr("Guardado {nombre}", { nombre: base(t.path) }), "ok")
aviso(`${n} reemplazos`)                              aviso(tr("{n} reemplazos", { n }))
confirm(`¿Borrar ${path}? …`)                         confirm(tr("¿Borrar {ruta}? …", { ruta: path }))

// catalogos.js
export const en = { …, "Ruta copiada": "Path copied", "{n} reemplazos": "{n} replacements",
  "Abrir archivo": "Open file", "Tema: {nombre}": "Theme: {nombre}", "Automático": "Automatic", "En marcha": "Running" };
```

## Tests (con estos nombres)

- `ordenes_de_la_paleta_traducidas`: cada nombre de `ORDENES` extraído de `index.html` es clave de `en` (hay más de 30 nombres; el fallo enumera los que faltan)
- `temas_y_estados_traducidos`: `Automático`, `Claro`, `Oscuro`, `Medianoche`, `En marcha`, `Esperando aprobación`, `Lista`, `Fallida`, `Atascada` y `Detenida` son claves de `en`

## No hagas

- No llames a `tr()` ni a `trv()` en constantes de nivel superior (se evalúan antes de cargar los módulos)
- No uses plantillas con acento grave dentro de `tr(…)`: el primer argumento es siempre un literal entre comillas dobles
- No cambies los textos en español ni borres tests de `catalogos.test.js`

## Notas

cuando otra tarea toque esa parte. Anota en el informe cuántas llamadas `tr("…")` hay al terminar.
