## Objetivo

La ayuda de `clap` sale de los comentarios `///` (en español) al compilar. Para el inglés se sustituye el
texto `about` de la orden raíz y de cada suborden al arrancar.
1. `i18n.rs`: añade la tabla `HELP_EN: &[(&str, &str)]` con una entrada por suborden de primer nivel de
   `Cmd` (la clave es el nombre que muestra `pcode --help`: `tui`, `chat`, `run`, `preguntar`, `daemon`,
   `flow`, `spec`, `studio`, `ide`…) más la clave `""` para la descripción general de `pcode`. El valor
   es la traducción al inglés de la primera frase de su comentario `///`.
2. `i18n.rs`: añade `localize_help` (firma abajo). Con `Lang::Es` devuelve `cmd` sin cambios. Con
   `Lang::En`: si hay entrada `""`, `cmd = cmd.about(texto)`; y para cada nombre de `HELP_EN` que sea una
   suborden de `cmd`, `cmd = cmd.mut_subcommand(nombre, |c| c.about(texto))`.
3. `main.rs`: sustituye `let cli = Cli::parse();` por
   `let cli = Cli::from_arg_matches(&i18n::localize_help(Cli::command(), pcode_tui::i18n::Lang::from_env()).get_matches()).unwrap_or_else(|e| e.exit());`
   y amplía el `use` de clap: `use clap::{CommandFactory, FromArgMatches, Parser, Subcommand};`.
4. Tests en `i18n.rs` (usan `<crate::Cli as clap::CommandFactory>::command()`).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/i18n.rs
/// Descripción en inglés de cada suborden de primer nivel (clave "" = la de `pcode`).
pub const HELP_EN: &[(&str, &str)] = &[("", "PublicCode: agentic programming with several agents."), /* … */];

/// Devuelve `cmd` con las descripciones de las órdenes en el idioma `lang`.
pub fn localize_help(cmd: clap::Command, lang: Lang) -> clap::Command;
```

## Ejemplo (entrada y resultado esperado)

```
$ LANG=en_US.UTF-8 pcode --help
PublicCode: agentic programming with several agents.

Usage: pcode [OPTIONS] [COMMAND]

Commands:
  tui     Full-screen terminal interface (what plain `pcode` opens in a terminal).
  studio  PublicCode Studio: editor, git, terminal and agent in the browser, on this machine only.
  …
$ LANG=es_ES.UTF-8 pcode --help      # igual que hoy, en español
```

## Tests (con estos nombres)

- `todas_las_ordenes_tienen_ayuda_en_ingles`: cada suborden no oculta de `Cli::command()` (`get_subcommands()`, `!is_hide_set()`, salvo `help`) tiene clave en `HELP_EN`
- `no_hay_claves_de_ordenes_que_no_existen`: cada clave de `HELP_EN` distinta de la vacía es el nombre de una suborden
- `en_ingles_cambia_la_descripcion`: tras `localize_help(cmd, Lang::En)`, el `get_about()` de la suborden `studio` contiene `browser`
- `en_español_no_cambia_nada`: tras `localize_help(cmd, Lang::Es)`, el `get_about()` de `studio` contiene `navegador`

## No hagas

- No traduzcas los nombres de las órdenes ni de las opciones (`--no-abrir`, `preguntar`): solo las descripciones
- No cambies los comentarios `///` en español
- No añadas dependencias

sigue en español; se traduce con el mismo mecanismo (`mut_arg`) en una tarea posterior.
