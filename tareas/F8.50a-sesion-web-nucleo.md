## Objetivo

1. Crea `web_session.rs` con `constant_time_eq`, `Redeem` y `WebSessions` (firmas abajo). Sin E/S ni
   aleatoriedad: el valor de la cookie nueva lo pasa quien llama.
2. `constant_time_eq(a, b)`: `false` si las longitudes difieren; si no, recorre todos los bytes
   acumulando `a[i] ^ b[i]` con `|=` y devuelve `acumulado == 0` (sin salir antes).
3. `redeem(presented, token, fresh)`: si `presented` no es igual a `token` (con `constant_time_eq`),
   `Redeem::Wrong`. Si el modo de un solo uso está apagado, `Redeem::Legacy`. Si está encendido y el
   enlace ya se canjeó, `Redeem::AlreadyUsed`; si no, lo marca como canjeado, guarda `fresh` como cookie
   válida (como mucho `MAX_WEB_SESSIONS`: al pasar, se descarta la más antigua) y devuelve
   `Redeem::Session(fresh)`.
4. `is_valid(cookie)`: `true` si `cookie` es una de las guardadas (comparadas con `constant_time_eq`).
5. `lib.rs`: añade `pub mod web_session;` (después de `pub mod settings;`). Tests en `web_session.rs`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/web_session.rs
/// Sesiones de navegador que se guardan como mucho.
pub const MAX_WEB_SESSIONS: usize = 16;

/// Compara dos cadenas sin que el tiempo dependa de dónde difieren.
pub fn constant_time_eq(a: &str, b: &str) -> bool;

/// Resultado de canjear el token de la URL.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Redeem {
    /// Modo antiguo: el token vale siempre y la cookie es el propio token.
    Legacy,
    /// Canje correcto: valor de la cookie de sesión nueva.
    Session(String),
    /// El enlace ya se usó.
    AlreadyUsed,
    /// El token no es el del demonio.
    Wrong,
}

/// Estado del canje del enlace y cookies de sesión válidas.
#[derive(Debug, Default)]
pub struct WebSessions { single_use: bool, used: bool, cookies: Vec<String> }

impl WebSessions {
    /// Activa o desactiva el enlace de un solo uso.
    pub fn set_single_use(&mut self, on: bool);
    /// Está activo el enlace de un solo uso.
    pub fn single_use(&self) -> bool;
    /// Canjea el token presentado en la URL.
    pub fn redeem(&mut self, presented: &str, token: &str, fresh: String) -> Redeem;
    /// La cookie de sesión es válida.
    pub fn is_valid(&self, cookie: &str) -> bool;
}
```

## Ejemplo (entrada y resultado esperado)

```
let mut w = WebSessions::default();
w.redeem("tk", "tk", "c1".into())    -> Redeem::Legacy        // modo antiguo, se puede repetir
w.set_single_use(true);
w.redeem("mal", "tk", "c1".into())   -> Redeem::Wrong         // no gasta el enlace
w.redeem("tk", "tk", "c1".into())    -> Redeem::Session("c1")
w.redeem("tk", "tk", "c2".into())    -> Redeem::AlreadyUsed
w.is_valid("c1") -> true             w.is_valid("c2") -> false            w.is_valid("tk") -> false
```

## Tests (con estos nombres)

- `comparacion_en_tiempo_constante`: `constant_time_eq` es `true` para cadenas iguales y `false` para distinta longitud o un byte distinto
- `modo_antiguo_no_gasta_el_enlace`: sin `set_single_use`, dos canjes seguidos con el token correcto dan `Legacy`
- `un_solo_uso_canjea_una_vez`: con un solo uso, el primer canje da `Session("c1")` y el segundo `AlreadyUsed`
- `token_incorrecto_no_gasta_el_enlace`: un canje con `mal` da `Wrong` y el siguiente con el token correcto da `Session`
- `la_cookie_canjeada_es_valida`: tras el canje, `is_valid("c1")` es `true` y `is_valid("tk")` es `false`
- `se_guardan_como_mucho_dieciseis`: tras llamar 17 veces a `remember` con valores distintos, la primera cookie deja de ser válida y la última sí lo es
