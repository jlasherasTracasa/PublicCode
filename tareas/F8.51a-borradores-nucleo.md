## Objetivo

Un borrador es lo que el usuario tecleó y aún no guardó; se guarda en `localStorage` como JSON
`{ content, base, at }`: el texto, la huella del contenido del disco del que partía y la hora (ms).
1. Crea `borradores.js` con las funciones de las firmas (sin tocar `localStorage`: eso lo hace `index.html`).
2. `PREFIX = "pcode.borrador."` y `draftKey(project, path)` = `PREFIX + project + ":" + path`.
3. `hash(text)`: huella determinista djb2: empieza en 5381 y, por cada unidad de `text`,
   `h = ((h * 33) ^ text.charCodeAt(i)) >>> 0`; devuelve `h.toString(16)`.
4. `makeDraft(content, saved, now)` = `{ content, base: hash(saved), at: now }`.
   `parseDraft(json)`: devuelve el objeto si el JSON es válido y tiene `content` de tipo cadena, `base`
   de tipo cadena y `at` numérico; en cualquier otro caso (también `null`), `null`.
5. `status(draft, disk)`: `"none"` si no hay borrador o su `content` es igual a `disk`; `"recover"` si
   `draft.base === hash(disk)` (el disco no cambió desde el borrador); `"conflict"` en otro caso.
6. `prune(entries, max)`: `entries` es `[{ key, at }]`; devuelve las claves que hay que borrar para que
   queden las `max` más recientes (las de `at` menor primero).
7. Crea `borradores.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
draftKey("app", "src/main.rs")              -> "pcode.borrador.app:src/main.rs"
hash("")                                    -> "1505"            // 5381 en hexadecimal
makeDraft("nuevo", "viejo", 1700)           -> { content: "nuevo", base: hash("viejo"), at: 1700 }
status(null, "viejo")                                   -> "none"
status(makeDraft("nuevo", "viejo", 1), "nuevo")         -> "none"       // ya está guardado
status(makeDraft("nuevo", "viejo", 1), "viejo")         -> "recover"
status(makeDraft("nuevo", "viejo", 1), "otra cosa")     -> "conflict"   // el archivo cambió en disco
parseDraft('{"content":"x","base":"1505","at":3}')      -> { content: "x", base: "1505", at: 3 }
parseDraft("no es json")                                -> null
prune([{ key: "a", at: 3 }, { key: "b", at: 1 }, { key: "c", at: 2 }], 2) -> ["b"]
```

## Tests (con estos nombres)

- `clave_por_proyecto_y_ruta`: el caso de `draftKey` del ejemplo
- `huella_determinista`: `hash("")` es `1505`, `hash("a")` es igual en dos llamadas y distinta de `hash("b")`
- `estado_del_borrador`: los cuatro casos de `status` del ejemplo
- `borrador_invalido_es_null`: `parseDraft` devuelve `null` para `null`, texto que no es JSON, `{}` y un objeto con `content` numérico
- `borrador_valido_se_lee`: el caso válido de `parseDraft` del ejemplo
- `limpieza_conserva_los_recientes`: el caso de `prune` del ejemplo; con `max` mayor que la lista devuelve `[]`
