## Objetivo

1. `web_assets.rs`: añade `("borradores.js", include_str!("../web/studio/borradores.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as borradores from "/studio/borradores.js"; Studio.borradores = borradores;`.
2. Debajo de `guarda` añade (todo acceso a `localStorage` va dentro de `try { … } catch { }`):
   - `claveBorrador(t)`: `Studio.borradores.draftKey($("proyecto").textContent || "", t.path)`.
   - `guardaBorrador(t)`: si `t.dirty` y `t.content.length <= 500000`, guarda
     `JSON.stringify(Studio.borradores.makeDraft(t.content, t.saved, Date.now()))`; si no está sucia,
     borra la clave. Después limpia: reúne las claves de `localStorage` que empiezan por
     `Studio.borradores.PREFIX` con su `at` y borra las que devuelva `Studio.borradores.prune(lista, 30)`.
   - `autoguardado()`: `true` si `localStorage.getItem("pcode.autoguardado") === "1"`.
3. `ta.addEventListener("input"`: al final, reinicia un temporizador (`let tBorrador = 0;` fuera del
   manejador; `clearTimeout(tBorrador); tBorrador = setTimeout(…, 800)`) que llama a `guardaBorrador(t)` y,
   si `autoguardado()` y `t` sigue siendo la pestaña activa y está sucia, a `guarda(true)`.
4. `guarda`: admite un parámetro `silencio`; con `true` no muestra el aviso «Guardado …». Tras guardar
   bien, borra el borrador (`localStorage.removeItem(claveBorrador(t))`). `cierra`: cuando el usuario
   confirma cerrar una pestaña sucia, borra también su borrador.
5. `abre`: después de crear la pestaña y activarla, lee
   `d = Studio.borradores.parseDraft(localStorage.getItem(claveBorrador(t)))` y
   `st = Studio.borradores.status(d, f.content)`. Si `st` es `"recover"` o `"conflict"`, muestra
   `aviso("Hay cambios sin guardar de " + base(path) + (st === "conflict" ? " (el archivo cambió en disco)" : ""), "", ["Recuperar", () => { … }])`;
   al recuperar: `t.content = d.content; t.dirty = true; pintaPestanas(); if (S.activa === t.id) muestra();`.
   Si `st` es `"none"` y había borrador, bórralo.
6. Añade a `ORDENES`: `["Guardado automático: activar o desactivar", "", …]` (alterna `pcode.autoguardado`
   entre `"1"` y ausente y avisa del estado) y `["Borradores: descartar todos", "", …]` (borra todas las
   claves con `PREFIX`).

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
