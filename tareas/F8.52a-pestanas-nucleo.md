## Objetivo

Las pestañas son objetos con `id` y, si están fijadas, `pinned: true`. Las fijadas van siempre delante.
Las funciones devuelven listas nuevas con los mismos objetos (no los copian ni modifican la lista).
1. Crea `pestanas.js` con las cuatro funciones de las firmas.
2. `move(tabs, from, to)`: saca la pestaña de la posición `from` y la inserta en la posición `to` de la
   lista resultante. Una fijada solo se mueve entre fijadas y una normal solo entre normales: `to` se
   recorta a su grupo (si hay `n` fijadas, una fijada queda en `0..n-1` y una normal en `n..`). Índices
   fuera de rango o `from === to`: devuelve una copia sin cambios.
3. `togglePin(tabs, id)`: si no estaba fijada, pone `pinned = true` en ese objeto y la coloca la última
   de las fijadas; si lo estaba, pone `pinned = false` y la coloca la primera de las normales. `id`
   desconocido: copia sin cambios. (Aquí sí se modifica la propiedad `pinned` del objeto.)
4. `closeOthers(tabs, id)`: ids de las pestañas que se cierran: todas menos `id` y las fijadas.
   `closeRight(tabs, id)`: ids de las no fijadas que están a la derecha de `id`.
5. Crea `pestanas.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const T = () => [{ id: "a", pinned: true }, { id: "b" }, { id: "c" }, { id: "d" }];
move(T(), 3, 1).map((t) => t.id)        -> ["a", "d", "b", "c"]
move(T(), 3, 0).map((t) => t.id)        -> ["a", "d", "b", "c"]     // no puede pasar por delante de la fijada
move(T(), 0, 2).map((t) => t.id)        -> ["a", "b", "c", "d"]     // la fijada no sale de su grupo
togglePin(T(), "c").map((t) => t.id)    -> ["a", "c", "b", "d"]     // y c.pinned === true
togglePin(T(), "a").map((t) => t.id)    -> ["a", "b", "c", "d"]     // y a.pinned === false
closeOthers(T(), "c")                   -> ["b", "d"]
closeRight(T(), "b")                    -> ["c", "d"]
```

## Tests (con estos nombres)

- `mover_entre_normales`: el primer caso de `move` del ejemplo
- `las_fijadas_van_delante`: el segundo y el tercer caso de `move` del ejemplo
- `indices_fuera_de_rango_no_cambian_nada`: `move(T(), 9, 0)` y `move(T(), 1, 1)` conservan el orden
- `fijar_coloca_tras_las_fijadas`: `togglePin(T(), "c")` da el orden del ejemplo y `pinned` verdadero
- `soltar_coloca_delante_de_las_normales`: `togglePin(T(), "a")` da el orden del ejemplo y `pinned` falso
- `cerrar_las_demas_respeta_las_fijadas`: `closeOthers(T(), "c")` da `["b", "d"]`
- `cerrar_las_de_la_derecha`: `closeRight(T(), "b")` da `["c", "d"]` y `closeRight(T(), "d")` da `[]`
- `no_modifica_la_lista_de_entrada`: tras `move`, la lista original conserva su orden
