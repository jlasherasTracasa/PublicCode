## Objetivo

1. `web_assets.rs`: añade `("pestanas.js", include_str!("../web/studio/pestanas.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as pestanas from "/studio/pestanas.js"; Studio.pestanas = pestanas;`.
2. Debajo de `pintaPestanas` añade:
   - `muevePestana(desde, hasta)`: índices en `S.tabs`; `S.tabs = Studio.pestanas.move(S.tabs, desde, hasta); pintaPestanas();`.
   - `fijaPestana(id)`: `S.tabs = Studio.pestanas.togglePin(S.tabs, id); pintaPestanas();`.
   - `cierraVarias(ids)`: llama a `cierra(id)` para cada uno (cada pestaña sucia pregunta, como siempre).
3. En `pintaPestanas`, para cada pestaña `b`:
   - clase `fijada` si `t.pinned`, y delante del nombre `el("span", "pin", "⚲")` con `aria-label` «Fijada»;
   - `b.draggable = true`; `b.ondragstart` guarda el id con
     `e.dataTransfer.setData("text/plain", t.id)` y `e.dataTransfer.effectAllowed = "move"`;
     `b.ondragover = (e) => e.preventDefault()`; `b.ondrop`: `e.preventDefault()` y
     `muevePestana(índice del id arrastrado, índice de t)`;
   - `b.oncontextmenu`: `e.preventDefault()` y `menu(e.clientX, e.clientY, [...])` con las entradas
     `[t.pinned ? "Soltar la pestaña" : "Fijar la pestaña", () => fijaPestana(t.id)]`,
     `["Cerrar las demás", () => cierraVarias(Studio.pestanas.closeOthers(S.tabs, t.id))]` y
     `["Cerrar las de la derecha", () => cierraVarias(Studio.pestanas.closeRight(S.tabs, t.id))]`.
4. CSS: `.pestana.fijada .cerrar { display: none; }` y `.pestana .pin { font-size: 11px; color: var(--primario); }`.
5. Atajos en el `keydown` final: Ctrl+Mayús+RePág (`e.key === "PageUp" && e.shiftKey`) mueve la pestaña
   activa una posición a la izquierda y Ctrl+Mayús+AvPág a la derecha. En `ORDENES`:
   `["Pestaña: fijar o soltar", "", …]`, `["Pestaña: mover a la izquierda", "Ctrl Mayús RePág", …]`,
   `["Pestaña: mover a la derecha", "Ctrl Mayús AvPág", …]` y `["Pestañas: cerrar las demás", "", …]`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
