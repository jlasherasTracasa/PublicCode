## Objetivo

1. Crea `ajustes_editor.js` con `DEFAULTS` y las cinco funciones de las firmas.
2. `normalize(raw)`: devuelve un objeto con exactamente las claves de `DEFAULTS`. Para cada una usa el
   valor de `raw` si es del tipo correcto y, si no (o si `raw` no es un objeto), el de `DEFAULTS`.
   `fontSize` se recorta a `11..16` y se redondea a medios puntos (`Math.round(x * 2) / 2`); `tabSize` se
   trunca a entero (`Math.trunc`) y se recorta a `1..8`.
3. `merge(base, override)`: copia de `base` con las claves de `override` cuyo valor no sea `undefined`,
   pasada por `normalize`.
4. `indentUnit(s)`: `"\t"` si `!s.insertSpaces`; si no, `s.tabSize` espacios.
   `dedentPattern(s)`: expresión regular con banderas `gm` que casa al principio de cada línea con un
   tabulador o con entre 1 y `s.tabSize` espacios (para Mayús+Tab).
5. `onSave(text, s)`: si `s.trimTrailingWhitespace`, quita espacios y tabuladores al final de cada línea;
   si `s.insertFinalNewline` y el texto no está vacío y no acaba en `\n`, añade uno. Devuelve el texto.
6. Crea `ajustes_editor.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
normalize(null)                                   -> DEFAULTS (una copia)
normalize({ fontSize: 40, tabSize: "2", x: 1 })   -> { fontSize: 16, tabSize: 4, insertSpaces: true, trimTrailingWhitespace: false, insertFinalNewline: false }
normalize({ fontSize: 12.3, tabSize: 2.9 })       -> fontSize 12.5, tabSize 2
merge(DEFAULTS, { tabSize: 2, insertSpaces: undefined }) -> tabSize 2, insertSpaces true
indentUnit({ ...DEFAULTS, tabSize: 2 })           -> "  "            indentUnit({ ...DEFAULTS, insertSpaces: false }) -> "\t"
"      x\n\ty".replace(dedentPattern({ ...DEFAULTS, tabSize: 2 }), "")  -> "    x\ny"
onSave("a  \nb\t", { ...DEFAULTS, trimTrailingWhitespace: true, insertFinalNewline: true }) -> "a\nb\n"
onSave("", { ...DEFAULTS, insertFinalNewline: true })                    -> ""
```

## Tests (con estos nombres)

- `valores_por_defecto`: `normalize(null)`, `normalize("x")` y `normalize({})` son iguales a `DEFAULTS`
- `recorta_y_descarta_tipos_malos`: el segundo caso de `normalize` del ejemplo (40 pasa a 16, la cadena `"2"` se descarta, la clave `x` desaparece)
- `redondea_letra_y_sangria`: el tercer caso de `normalize` del ejemplo
- `mezcla_ignora_indefinidos`: el caso de `merge` del ejemplo
- `unidad_de_sangria`: los dos casos de `indentUnit` del ejemplo
- `quitar_sangria_respeta_el_ancho`: el caso de `dedentPattern` del ejemplo
- `limpieza_al_guardar`: los dos casos de `onSave` del ejemplo; con las dos opciones apagadas el texto no cambia
