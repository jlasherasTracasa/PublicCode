## Objetivo

1. Crea `editorconfig.js` con las tres funciones de las firmas.
2. `parse(text)`: línea a línea. Ignora líneas vacías y comentarios (empiezan por `#` o `;`). `[glob]`
   abre una sección. `clave = valor` (clave y valor recortados y en minúsculas) se guarda en la sección
   abierta; las que van antes de la primera sección (`root = true`) se ignoran. Devuelve
   `[{ glob, props }]` en orden.
3. `matches(glob, path)`: `path` es relativa al proyecto, con `/`. Si el glob no contiene `/`, se compara
   con el nombre del archivo (lo que va tras la última `/`); si la contiene, con la ruta entera (quitando
   una `/` inicial del glob). Comodines: `*` (cualquier cosa menos `/`), `**` (cualquier cosa), `?` (un
   carácter que no sea `/`) y `{a,b,c}` (alternativas, sin anidar). El resto es literal. Tradúcelo a una
   expresión regular anclada (`^…$`), escapando los caracteres especiales.
4. `settingsFor(sections, path)`: recorre las secciones en orden y acumula las propiedades de las que
   casan (las posteriores ganan). Devuelve solo las claves que se puedan deducir:
   `insertSpaces` (`indent_style`: `space` → `true`, `tab` → `false`), `tabSize` (`indent_size` numérico;
   si es `tab` o falta, `tab_width` numérico), `trimTrailingWhitespace` e `insertFinalNewline`
   (`true`/`false`). Valores desconocidos (`unset`, texto raro) se ignoran.
5. Crea `editorconfig.test.js` con los tests de la lista.

## Firmas (cópialas tal cual)

```javascript
// crates/pcode-server/web/studio/editorconfig.js
/** Secciones de un `.editorconfig`: [{ glob, props: { clave: valor } }]. */
export function parse(text) {}
/** El glob de una sección casa con la ruta. */
export function matches(glob, path) {}
/** Ajustes que `.editorconfig` fija para `path`: { insertSpaces?, tabSize?, trimTrailingWhitespace?, insertFinalNewline? }. */
export function settingsFor(sections, path) {}
```

## Ejemplo (entrada y resultado esperado)

```
const E = "root = true\n\n[*]\nindent_style = space\nindent_size = 2\ntrim_trailing_whitespace = true\n\n# rust\n[*.{rs,toml}]\nindent_size = 4\n\n[Makefile]\nindent_style = tab\n\n[docs/**.md]\ntrim_trailing_whitespace = false\n";
parse(E) -> [ { glob: "*", props: { indent_style: "space", indent_size: "2", trim_trailing_whitespace: "true" } },
              { glob: "*.{rs,toml}", props: { indent_size: "4" } },
              { glob: "Makefile", props: { indent_style: "tab" } },
              { glob: "docs/**.md", props: { trim_trailing_whitespace: "false" } } ]
matches("*.{rs,toml}", "src/main.rs") -> true      matches("*.{rs,toml}", "src/main.js") -> false
matches("docs/**.md", "docs/a/b.md")  -> true      matches("docs/*.md", "docs/a/b.md")   -> false
settingsFor(parse(E), "src/main.rs")  -> { insertSpaces: true, tabSize: 4, trimTrailingWhitespace: true }
settingsFor(parse(E), "web/app.js")   -> { insertSpaces: true, tabSize: 2, trimTrailingWhitespace: true }
settingsFor(parse(E), "Makefile")     -> { insertSpaces: false, tabSize: 2, trimTrailingWhitespace: true }
settingsFor(parse(E), "docs/a/b.md")  -> { insertSpaces: true, tabSize: 2, trimTrailingWhitespace: false }
```

## Tests (con estos nombres)

- `secciones_y_propiedades`: `parse(E)` da las cuatro secciones del ejemplo (sin `root` y sin el comentario)
- `texto_vacio_no_tiene_secciones`: `parse("")` da `[]`
- `glob_con_llaves_y_asterisco`: los dos primeros casos de `matches` del ejemplo
- `doble_asterisco_cruza_carpetas`: los dos últimos casos de `matches` del ejemplo
- `interrogacion_y_literales`: `matches("a?.txt", "ab.txt")` es `true`; `matches("a.txt", "abtxt")` es `false` (el punto es literal)
- `las_secciones_posteriores_ganan`: los cuatro casos de `settingsFor` del ejemplo
- `valores_raros_se_ignoran`: `[*]\nindent_size = unset\nindent_style = raro` da `{}`
- `indent_size_tab_usa_tab_width`: `[*]\nindent_size = tab\ntab_width = 8` da `{ tabSize: 8 }`
