## Objetivo

1. Crea `replace.rs` con `ReplaceLine`, `build_regex` y `replace_text` (firmas abajo). Sin E/S.
2. `build_regex(query, is_regex, case_sensitive)`: igual que en `workspace::search`: si no es regex,
   `regex::escape(query)`; `case_insensitive(!case_sensitive)`; `size_limit(1 << 20)`. Consulta vacía:
   `Err("búsqueda vacía".into())`; expresión inválida: `Err(format!("expresión inválida: {e}"))`.
3. `replace_text(re, text, replacement, expand)`: trabaja línea a línea con `text.split_inclusive('\n')`
   para conservar los finales de línea (`\n` o `\r\n`) tal cual. En cada línea (sin su final) cuenta las
   coincidencias (`re.find_iter`); si hay alguna, la sustituye con `re.replace_all`: con `expand` `true`,
   `replacement` admite `$1`, `${nombre}`; con `false`, se usa `regex::NoExpand(replacement)` (texto
   literal). Devuelve `None` si no hubo ninguna coincidencia; si no,
   `Some((texto_nuevo, total_de_coincidencias, lineas))` con una `ReplaceLine` por línea cambiada
   (`line` desde 1; `before` y `after` recortados con `trim()` y a 240 caracteres), como mucho
   `MAX_PREVIEW_LINES` (el total sigue contando todas).
4. `lib.rs`: añade `pub mod replace;` (después de `pub mod assist;`). Tests en `replace.rs`, con nombres
   que empiecen por `texto_`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/replace.rs
/// Líneas de vista previa que se devuelven por archivo como mucho.
pub const MAX_PREVIEW_LINES: usize = 20;

/// Una línea antes y después del reemplazo.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct ReplaceLine { pub line: u32, pub before: String, pub after: String }

/// Expresión de búsqueda (texto literal o regex).
pub fn build_regex(query: &str, is_regex: bool, case_sensitive: bool) -> Result<regex::Regex, String>;

/// Reemplaza en `text`: (texto nuevo, número de coincidencias, líneas cambiadas) o `None` si no hay ninguna.
pub fn replace_text(re: &regex::Regex, text: &str, replacement: &str, expand: bool) -> Option<(String, u32, Vec<ReplaceLine>)>;
```

## Ejemplo (entrada y resultado esperado)

```
let re = build_regex("foo", false, false).unwrap();
replace_text(&re, "a foo\r\nb\nFoo foo\n", "bar", false)
  -> Some(("a bar\r\nb\nbar bar\n", 3, vec![
       ReplaceLine { line: 1, before: "a foo".into(), after: "a bar".into() },
       ReplaceLine { line: 3, before: "Foo foo".into(), after: "bar bar".into() } ]))
replace_text(&re, "nada\n", "bar", false) -> None
let re = build_regex(r"(\w+)@(\w+)", true, true).unwrap();
replace_text(&re, "ana@casa", "$2@$1", true)   -> Some(("casa@ana", 1, …))
replace_text(&re, "ana@casa", "$2@$1", false)  -> Some(("$2@$1", 1, …))
build_regex("", false, false)   -> Err("búsqueda vacía")
build_regex("(", true, false)   -> Err("expresión inválida: …")
```

## Tests (con estos nombres)

- `texto_literal_sin_distinguir_mayusculas`: el primer caso del ejemplo (3 coincidencias, dos líneas, finales de línea intactos)
- `texto_sin_coincidencias_es_none`: `replace_text` sobre `nada\n` devuelve `None`
- `texto_regex_con_grupos`: con `expand` `true`, `$2@$1` intercambia los grupos
- `texto_reemplazo_literal_no_expande`: con `expand` `false`, `$2@$1` se escribe tal cual
- `texto_distingue_mayusculas_si_se_pide`: `build_regex("foo", false, true)` no cambia `Foo`
- `texto_busqueda_vacia_o_invalida`: los dos casos de `Err` del ejemplo
- `texto_vista_previa_limitada`: en un texto de 30 líneas `foo`, el total es 30 y hay 20 `ReplaceLine`
