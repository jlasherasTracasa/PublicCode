## Objetivo

1. `replace.rs`: añade `FileReplace` y `replace_in_files` (firmas abajo). Para cada ruta de
   `crate::workspace::files(root)?`, en orden: sáltala si ocupa más de 1 MiB, si no se puede leer, si
   contiene el byte 0 o si no es UTF-8 válido (`String::from_utf8`; no uses `from_utf8_lossy`: estropearía
   el archivo al escribirlo). Llama a `replace_text(&re, &texto, replacement, is_regex)`; si devuelve
   `Some`, añade un `FileReplace { path, count, lines }` y, si `apply`, escribe el texto nuevo en
   `crate::workspace::safe_path(root, &path)?` (error: `format!("no se puede escribir {path}: {e}")`).
   Con `apply` `false` para al llegar a `MAX_REPLACE_FILES` archivos con coincidencias; con `true`, los
   procesa todos.
2. `lib.rs` de `pcode-protocol`: en `pub mod methods`, después de `SEARCH_TEXT`, añade
   `/// Reemplaza en el proyecto: `{query, replacement, regex?, caseSensitive?, apply?}` → `{path, count, lines: {line, before, after}[]}[]` (sin `apply`, solo vista previa).`
   y `pub const SEARCH_REPLACE: &str = "search.replace";`.
3. `server.rs`, `match` de `rpc`: después de la rama `methods::SEARCH_TEXT`, añade `methods::SEARCH_REPLACE`:
   lee `query` y `replacement` con `str_param` y `regex`, `caseSensitive` y `apply` como booleanos (por
   defecto `false`); ejecuta `crate::replace::replace_in_files` dentro de `blocking(move || …)`; si
   `apply` y el resultado es `Ok`, `st.emit(Event::FilesChanged {});`; responde con `ws_reply(id, r)`.
4. Tests en `replace.rs` con `tempfile::tempdir()` (sin git: `files` recorre el directorio), con nombres
   que empiecen por `archivos_`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/replace.rs
/// Archivos con coincidencias que se devuelven como mucho en una vista previa.
pub const MAX_REPLACE_FILES: usize = 200;

/// Cambios de un archivo.
#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct FileReplace { pub path: String, pub count: u32, pub lines: Vec<ReplaceLine> }

/// Reemplaza `query` por `replacement` en los archivos de texto del proyecto. Con `apply` `false` no escribe nada.
pub fn replace_in_files(
    root: &std::path::Path, query: &str, replacement: &str,
    is_regex: bool, case_sensitive: bool, apply: bool,
) -> crate::workspace::WsResult<Vec<FileReplace>>;

// crates/pcode-protocol/src/lib.rs (dentro de `pub mod methods`)
pub const SEARCH_REPLACE: &str = "search.replace";
```

## Ejemplo (entrada y resultado esperado)

```
// directorio con a.txt = "foo uno\nfoo dos\n", sub/b.txt = "nada\n", bin.dat = [0u8, 1, 2]
replace_in_files(dir, "foo", "bar", false, false, false)
  -> Ok(vec![FileReplace { path: "a.txt", count: 2, lines: [línea 1 "foo uno" → "bar uno", línea 2 "foo dos" → "bar dos"] }])
     // a.txt sigue igual en el disco
replace_in_files(dir, "foo", "bar", false, false, true)   -> el mismo resultado y a.txt == "bar uno\nbar dos\n"
replace_in_files(dir, "", "x", false, false, false)       -> Err("búsqueda vacía")
```

## Tests (con estos nombres)

- `archivos_vista_previa_no_escribe`: con `apply` `false` devuelve los cambios de `a.txt` y el archivo no cambia en el disco
- `archivos_aplicar_escribe`: con `apply` `true`, `a.txt` queda `bar uno\nbar dos\n` y `sub/b.txt` no cambia
- `archivos_binarios_y_no_utf8_se_saltan`: `bin.dat` (con byte 0) y un archivo con bytes `0xff 0xfe` no aparecen ni se modifican
- `archivos_busqueda_vacia_da_error`: la consulta vacía devuelve `Err` con `búsqueda vacía`
- `archivos_sin_coincidencias_lista_vacia`: buscar `zzz` devuelve `Ok(vec![])`
