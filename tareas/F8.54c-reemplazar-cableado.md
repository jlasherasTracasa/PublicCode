## Objetivo

El método `search.replace` recibe `{ query, replacement, regex, caseSensitive, apply }` y devuelve
`[{ path, count, lines: [{ line, before, after }] }]`; con `apply: false` no escribe nada.
1. Crea `reemplazo.js` con `summary` y `blocked` (firmas abajo) y `reemplazo.test.js` con sus tests.
   `summary(files)` = `{ files: files.length, changes: suma de count }`. `blocked(files, tabs)`: rutas de
   `files` que están abiertas en una pestaña de archivo con cambios sin guardar (`kind === "file"` y
   `dirty`), en el orden de `files`.
2. `web_assets.rs`: añade `("reemplazo.js", include_str!("../web/studio/reemplazo.js")),` a `ASSETS`.
   `index.html`, bloque `<script type="module">` final, antes de `inicio();`:
   `import * as reemplazo from "/studio/reemplazo.js"; Studio.reemplazo = reemplazo;`.
3. HTML, en `<section id="p-buscar">`, entre el `div.campo-lat` y `#resultados`:
   `<div class="campo-lat"><input id="q-reemplazo" placeholder="Reemplazar por" aria-label="Reemplazar por"><button id="b-vista-reemplazo" title="Ver qué cambiaría">Vista previa</button></div>`.
4. Debajo de `busca` añade `async function vistaReemplazo()`: si `$("q").value` está vacío, sale. Llama a
   `rpc("search.replace", { query, replacement: $("q-reemplazo").value, regex, caseSensitive, apply: false })`
   (los dos conmutadores, como en `busca`) y pinta en `#resultados`: una cabecera con
   `"{changes} cambios en {files} archivos"` (de `Studio.reemplazo.summary`) y un botón
   `el("button", "relleno", "Reemplazar todo")`; por cada archivo, un `div.grupo` con su título (como en
   `busca`) y, por cada línea, dos filas de texto: `"− " + before` (clase `del`) y `"+ " + after` (clase
   `add`), con `onclick` que abre el archivo en esa línea (`abre(path, line)`). Sin resultados:
   `el("div", "vacio", "Sin resultados.")`. Errores: `fallo(e)`.
5. «Reemplazar todo»: si `Studio.reemplazo.blocked(resultado, S.tabs)` no está vacío,
   `aviso("Guarda antes estos archivos: " + lista.join(", "), "error")` y sale. Si no, pide confirmación con
   `confirm(…)` indicando cambios y archivos; si acepta, repite la llamada con `apply: true`, avisa con
   `aviso("{changes} reemplazos en {files} archivos", "ok")` y llama a `busca()`.
6. Enlaces: `$("b-vista-reemplazo").onclick = vistaReemplazo;` e Intro en `#q-reemplazo` hace lo mismo.
   CSS: `#resultados .del { color: var(--error); }` y `#resultados .add { color: var(--ok); }`.

## Ejemplo (entrada y resultado esperado)

```
const R = [{ path: "a.txt", count: 2, lines: [] }, { path: "src/b.rs", count: 1, lines: [] }];
summary(R)   -> { files: 2, changes: 3 }        summary([]) -> { files: 0, changes: 0 }
blocked(R, [{ kind: "file", path: "src/b.rs", dirty: true }, { kind: "file", path: "a.txt", dirty: false }, { kind: "diff", path: "a.txt", dirty: true }])
             -> ["src/b.rs"]
```
