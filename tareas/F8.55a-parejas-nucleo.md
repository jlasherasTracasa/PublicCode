## Objetivo

`a` y `b` son el principio y el final de la selección (`a === b` es un cursor).
1. Crea `parejas.js` con `PAIRS` y las tres funciones de las firmas.
2. `matchBracket(text, offset, limit = 20000)`: mira primero el carácter en `offset` y, si no es un
   paréntesis (`( ) [ ] { }`), el de `offset - 1`. Desde un paréntesis de apertura avanza, y desde uno de
   cierre retrocede, contando solo los de su mismo tipo hasta encontrar el que lo equilibra, sin recorrer
   más de `limit` caracteres. Devuelve `{ open, close }` (índices) o `null`.
3. `onKey(text, a, b, key)` devuelve `{ text, a, b }` o `null` (no se trata la tecla; el editor hace lo normal):
   - Envolver: `key` es una apertura de `PAIRS` y hay selección → mete la selección entre `key` y su
     cierre; la selección nueva es el mismo texto (`a + 1`, `b + 1`).
   - Saltar: `a === b`, `key` es un cierre (`)`, `]`, `}` o una comilla) y `text[a] === key` → no inserta
     nada; cursor en `a + 1`.
   - Auto-cierre: `a === b` y `key` es una apertura. Para paréntesis: solo si el carácter siguiente no
     existe, es un espacio o salto de línea, o es uno de `) ] } , ;`. Para comillas (`"`, `'` y acento
     grave): además, el carácter anterior no puede ser una letra, cifra, `_` ni la misma comilla. Inserta
     la pareja y deja el cursor en medio (`a + 1`).
   - En cualquier otro caso, `null`. La regla de saltar se comprueba antes que la de auto-cierre.
4. `onBackspace(text, a, b)`: si `a === b`, `a > 0` y `text[a - 1]` y `text[a]` forman una pareja de
   `PAIRS`, borra los dos y devuelve `{ text, a: a - 1, b: a - 1 }`; si no, `null`.
5. Crea `parejas.test.js` con los tests de la lista.

## Firmas (cópialas tal cual)

```javascript
// crates/pcode-server/web/studio/parejas.js
/** Parejas de apertura y cierre. */
export const PAIRS = { "(": ")", "[": "]", "{": "}", '"': '"', "'": "'", "`": "`" };
/** Pareja del paréntesis que toca `offset`: { open, close } o null. */
export function matchBracket(text, offset, limit = 20000) {}
/** Efecto de teclear `key`: { text, a, b } o null si no hay nada especial. */
export function onKey(text, a, b, key) {}
/** Efecto de Retroceso entre una pareja vacía: { text, a, b } o null. */
export function onBackspace(text, a, b) {}
```

## Ejemplo (entrada y resultado esperado)

```
matchBracket("a(b[c]d)e", 1)  -> { open: 1, close: 7 }      matchBracket("a(b[c]d)e", 8) -> { open: 1, close: 7 }
matchBracket("a(b[c]d)e", 3)  -> { open: 3, close: 5 }      matchBracket("(()", 0)       -> null
matchBracket("abc", 1)        -> null
onKey("foo", 3, 3, "(")       -> { text: "foo()", a: 4, b: 4 }
onKey("foo()", 4, 4, ")")     -> { text: "foo()", a: 5, b: 5 }        // salta el cierre que ya está
onKey("a b", 0, 1, "[")       -> { text: "[a] b", a: 1, b: 2 }        // envuelve la selección
onKey("xfoo", 1, 1, "(")      -> null                                 // delante de una palabra no se cierra
onKey("don", 3, 3, "'")       -> null                                 // apóstrofo tras una letra
onKey("x = ", 4, 4, "\"")     -> { text: "x = \"\"", a: 5, b: 5 }
onKey("foo", 3, 3, "a")       -> null
onBackspace("foo()", 4, 4)    -> { text: "foo", a: 3, b: 3 }          onBackspace("foo()", 5, 5) -> null
```

## Tests (con estos nombres)

- `pareja_desde_la_apertura_y_el_cierre`: los dos primeros casos de `matchBracket` del ejemplo
- `pareja_anidada_de_otro_tipo`: `matchBracket("a(b[c]d)e", 3)` da `{ open: 3, close: 5 }`
- `sin_pareja_es_null`: `(()` en 0 y `abc` en 1 dan `null`
- `limite_de_busqueda`: un `(` seguido de 30000 letras y un `)` da `null` con el límite por defecto y la pareja con `limit` 40000
- `autocierre_al_final`: `onKey("foo", 3, 3, "(")` da `foo()` con el cursor en 4
- `salta_el_cierre_existente`: `onKey("foo()", 4, 4, ")")` no cambia el texto y mueve el cursor a 5
- `envuelve_la_seleccion`: `onKey("a b", 0, 1, "[")` da `[a] b` con la selección en 1–2
- `no_cierra_delante_de_una_palabra`: `onKey("xfoo", 1, 1, "(")` es `null`
- `comillas_tras_letra_no_se_cierran`: `onKey("don", 3, 3, "'")` es `null`; tras un espacio sí inserta la pareja
- `retroceso_borra_la_pareja_vacia`: los dos casos de `onBackspace` del ejemplo
