## Objetivo

`a` y `b` son el principio y el final de la selección. Las **líneas afectadas** van de la línea de `a` a
la línea de `b`; si hay selección (`b > a`) y `b` está justo al principio de una línea, esa última línea
no cuenta. Las funciones devuelven `{ text, a, b }` (o `null` si no hay nada que hacer).
1. Crea `lineas.js` con las cuatro funciones de las firmas.
2. `moveLines(text, a, b, dir)`: intercambia el bloque de líneas afectadas con la línea de encima
   (`dir = -1`) o de debajo (`dir = 1`). `null` si el bloque ya está arriba del todo o abajo del todo. La
   selección devuelta cubre el mismo texto que antes (se desplaza lo que mide la línea saltada más 1).
3. `duplicateLines(text, a, b)`: inserta una copia del bloque justo debajo. La selección devuelta es la
   misma que la de entrada pero sobre la copia (desplazada lo que mide el bloque más 1).
4. `commentPrefix(lang)`: `"//"` para `rust`, `js`, `go`, `java` y `c`; `"#"` para `py`, `sh` y `toml`;
   `"--"` para `sql`; `null` para los demás (`json`, `css`, `md`, `html`, `txt`…).
5. `toggleComment(text, a, b, prefix)`: mira las líneas afectadas que no están en blanco. Si todas
   empiezan (tras su sangría) por `prefix`, lo quita de cada una junto con un espacio que lo siga. Si no,
   inserta `prefix + " "` en todas ellas en la columna de la sangría más pequeña del bloque. Las líneas en
   blanco no se tocan. Si todas están en blanco, `null`. La selección devuelta va del principio de la
   primera línea afectada al final de la última.
6. Crea `lineas.test.js` con los tests de la lista.

/** Mueve las líneas de la selección una posición arriba (dir = -1) o abajo (dir = 1). */

/** Prefijo de comentario de línea del lenguaje, o null. */

## Ejemplo (entrada y resultado esperado)

```
moveLines("a\nb\nc", 2, 3, -1)     -> { text: "b\na\nc", a: 0, b: 1 }      // «b» sigue seleccionada
moveLines("a\nb\nc", 0, 0, 1)      -> { text: "b\na\nc", a: 2, b: 2 }
moveLines("a\nb\nc", 0, 0, -1)     -> null                                  moveLines("a\nb\nc", 5, 5, 1) -> null
moveLines("a\nb\nc\nd", 0, 4, 1)   -> { text: "c\na\nb\nd", a: 2, b: 6 }    // b = 4 está al principio de «c»: no cuenta
duplicateLines("a\nb", 0, 0)       -> { text: "a\na\nb", a: 2, b: 2 }
duplicateLines("a\nb", 2, 3)       -> { text: "a\nb\nb", a: 4, b: 5 }
toggleComment("  x\n\n    y", 0, 10, "//")      -> { text: "  // x\n\n  //   y", a: 0, b: 16 }
toggleComment("  // x\n\n  //   y", 0, 16, "//") -> { text: "  x\n\n    y", a: 0, b: 10 }
toggleComment("# a\nb", 0, 5, "#")              -> { text: "# # a\n# b", a: 0, b: 9 }   // mezcla: se comenta todo
commentPrefix("rust") -> "//"      commentPrefix("py") -> "#"      commentPrefix("json") -> null
```

- `mover_una_linea_arriba_y_abajo`: los dos primeros casos de `moveLines` del ejemplo
