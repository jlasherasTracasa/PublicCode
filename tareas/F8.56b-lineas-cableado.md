## Objetivo

1. `web_assets.rs`: añade `("lineas.js", include_str!("../web/studio/lineas.js")),` a `ASSETS`. `index.html`,
   bloque `<script type="module">` final, antes de `inicio();`:
   `import * as lineas from "/studio/lineas.js"; Studio.lineas = lineas;`.
2. Si no existe todavía, añade encima del primer `ta.addEventListener("keydown"` la función
   `aplicaEdicion(r)`: con `v = ta.value`, calcula el prefijo común `p` y el sufijo común `s` de `v` y
   `r.text` (sin solaparse) y llama a `ta.setRangeText(r.text.slice(p, r.text.length - s), p, v.length - s, "end")`;
   después `ta.setSelectionRange(r.a, r.b); ta.dispatchEvent(new Event("input"));`.
3. Debajo añade `function accionLinea(cual)`: con `v = ta.value`, `a = ta.selectionStart`,
   `b = ta.selectionEnd`: `"subir"` → `Studio.lineas.moveLines(v, a, b, -1)`; `"bajar"` → `moveLines(v, a, b, 1)`;
   `"duplicar"` → `duplicateLines(v, a, b)`; `"comentar"` → con
   `p = Studio.lineas.commentPrefix(tabActiva()?.lang)`: si es `null`,
   `aviso("Este tipo de archivo no tiene comentario de línea")` y sale; si no, `toggleComment(v, a, b, p)`.
   Si el resultado no es `null`, `aplicaEdicion(r)`.
4. En ese primer manejador de `keydown`, antes de las ramas de Tab e Intro (todas con `e.preventDefault()`
   y `return`): Alt+↑ (sin Mayús ni Ctrl) → `accionLinea("subir")`; Alt+↓ → `"bajar"`; Mayús+Alt+↓ →
   `"duplicar"`; Ctrl+/ o Cmd+/ (`e.key === "/"` o `e.code === "Slash"`) → `"comentar"`.
5. `ORDENES`: `["Línea: mover arriba", "Alt ↑", …]`, `["Línea: mover abajo", "Alt ↓", …]`,
   `["Línea: duplicar", "Mayús Alt ↓", …]` y `["Línea: comentar o descomentar", "Ctrl /", …]`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
