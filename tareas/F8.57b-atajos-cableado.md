## Objetivo

Los atajos del usuario se guardan en `localStorage`, clave `pcode.atajos`, como
`{ "Ctrl+Alt+S": "Guardar" }` (combinación canónica → nombre exacto de la orden en `ORDENES`; cadena
vacía = esa combinación no hace nada). Los atajos de fábrica siguen funcionando salvo que el usuario
use su misma combinación.
1. `web_assets.rs`: añade `("atajos.js", include_str!("../web/studio/atajos.js")),` a `ASSETS`. `index.html`,
   bloque `<script type="module">` final, antes de `inicio();`:
   `import * as atajos from "/studio/atajos.js"; Studio.atajos = atajos;`.
2. Encima del `document.addEventListener("keydown"` final añade:
   - `atajosUsuario()`: `JSON.parse(localStorage.getItem("pcode.atajos") || "{}")` con `try` (si falla, `{}`);
   - `guardaAtajos(b)`: guarda `JSON.stringify(b)` con `try`;
   - `atajosDeFabrica()`: objeto `{ combinación: nombre }` a partir de `ORDENES`: para cada entrada con
     atajo (`o[1]` no vacío), la clave es
     `Studio.atajos.parseCombo(o[1].replace(/Mayús/g, "Shift").split(" ").join("+"))` (si da `null`, se salta).
3. En ese manejador de `keydown`, **antes** de la línea `const c = e.ctrlKey || e.metaKey; if (!c) return;`:
   `const cb = Studio.atajos.combo(e); const dest = cb ? Studio.atajos.resolve(atajosUsuario(), cb) : undefined;`
   Si `dest !== undefined`: `e.preventDefault()`; si `dest` no es vacío, busca
   `ORDENES.find((o) => o[0] === dest)` y ejecuta su función (`o[2]()`); `return`.
4. Añade `async function asignaAtajo()`: pide con `prompt` el nombre de la orden (debe coincidir con el de
   una entrada de `ORDENES`; si no, `aviso("No hay ninguna orden con ese nombre", "error")`) y después la
   combinación (`prompt("Combinación, por ejemplo Ctrl+Alt+S (vacío: quitar el atajo propio)")`). Vacío:
   quita todas las combinaciones del usuario que apuntan a esa orden. Si `parseCombo` da `null`,
   `aviso("Combinación no válida", "error")`. Si es válida, guarda
   `Studio.atajos.setBinding(atajosUsuario(), combo, nombre)` y, si
   `Studio.atajos.conflicts({ [combo]: nombre }, atajosDeFabrica())` no está vacío, avisa:
   `"Esa combinación era de «" + was + "»; ahora ejecuta «" + nombre + "»"`.
5. `filtraOrdenes`: junto al atajo de fábrica (`o[1]`) muestra el del usuario si lo hay (la primera
   combinación de `atajosUsuario()` cuyo valor sea `o[0]`), con los `+` cambiados por espacios.
6. `ORDENES`: `["Atajos: asignar un atajo a una orden", "", () => asignaAtajo()]` y
   `["Atajos: quitar todos los atajos propios", "", () => { guardaAtajos({}); aviso("Atajos propios quitados", "ok"); }]`.

Sin firmas: solo cableado en index.html y una línea en la tabla ASSETS: no añade API
