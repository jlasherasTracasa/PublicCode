## Objetivo

Todo va en `index.html`. El modo zen deja solo las pestañas, las migas y el editor.
1. CSS (al final del `<style>`):
   `body.zen { grid-template-rows: 1fr; }`,
   `body.zen > header.barra, body.zen > footer.estado-ed, body.zen > nav.nav-movil { display: none; }`,
   `body.zen .cuerpo, body.zen .cuerpo.sin-agente { grid-template-columns: 1fr; }`,
   `body.zen .cuerpo > nav.actividad, body.zen .cuerpo > aside, body.zen [data-asa], body.zen #terminal { display: none; }`,
   `body.zen .centro.con-terminal { --alto-terminal: 0px; }`.
2. Encima del `document.addEventListener("keydown"` final añade `function zen(on)`: `on` por defecto es
   lo contrario del estado actual (`!document.body.classList.contains("zen")`). Pone o quita la clase
   `zen` en `document.body`. Al entrar, intenta la pantalla completa con
   `document.documentElement.requestFullscreen?.().catch(() => {})` y muestra
   `aviso("Modo zen: Esc dos veces o Ctrl+Alt+F para salir")`; al salir, si `document.fullscreenElement`,
   `document.exitFullscreen?.()`. Al final llama a `sincroniza()` y enfoca el editor (`ta.focus()`) si hay
   un archivo abierto.
3. Si el usuario sale de la pantalla completa con Esc, se sale también del modo zen:
   `document.addEventListener("fullscreenchange", () => { if (!document.fullscreenElement && document.body.classList.contains("zen")) zen(false); });`.
4. Teclas, en el manejador de `keydown` final: **antes** de la línea que descarta las teclas sin Ctrl,
   trata Escape en modo zen: si se pulsa dos veces en menos de 600 ms (guarda la hora de la última en una
   variable `let tEscZen = 0;`), `zen(false)`. Y entre las ramas con Ctrl añade Ctrl+Alt+F
   (`k === "f" && e.altKey`) → `zen()`; ponla antes de la rama de `k === "f"` que abre el buscador.
5. `ORDENES`: `["Modo zen: solo el editor", "Ctrl Alt F", () => zen()]`.

Sin firmas: solo CSS y cableado en index.html: no añade API

## Tests (con estos nombres)

## No hagas

- No ocultes las pestañas ni las migas (la rejilla de `.centro` cuenta con ellas)
- No guardes el modo zen en `localStorage`: al recargar se vuelve a la vista normal
- No cambies otras reglas CSS de `.cuerpo` ni de `.centro`

## Notas

Sin lógica pura que probar: es CSS y un conmutador. Si el navegador rechaza la pantalla completa (por
ejemplo, dentro de un marco), el modo zen funciona igual en la ventana.
