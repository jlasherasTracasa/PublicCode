# F8.61a-git-trozos-nucleo — Git: partir un diff en trozos y construir el parche de uno (lógica pura)

## Objetivo

1. Crea `hunks.rs` con las firmas de abajo y tests en el mismo archivo. La entrada es el diff unificado de UN solo archivo
   (lo que devuelve `git diff -- <archivo>`).
2. `split_hunks(diff)`: recorre con `split_inclusive('\n')` (se conservan los saltos de línea). Todo lo anterior a la primera
   línea que empieza por `@@` es la cabecera del archivo (`diff --git …`, `index …`, `--- a/…`, `+++ b/…`). Cada trozo empieza
   en una línea `@@` y llega hasta justo antes de la siguiente `@@` o hasta el final. `index` va de 0 en adelante y `header`
   es la línea `@@ … @@` sin el salto de línea. Un diff vacío o sin `@@` da cabecera = todo el texto y cero trozos.
3. `hunk_patch(diff, index)`: `Some(cabecera + texto del trozo index)`, que es un parche válido para `git apply`; `None` si
   no existe ese trozo.
4. `lib.rs`: añade `pub mod hunks;` debajo de `pub mod assist;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/hunks.rs
/// Un trozo (hunk) de un diff unificado.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct Hunk { pub index: usize, pub header: String, pub text: String }

/// Cabecera del archivo y trozos del diff de un solo archivo.
pub fn split_hunks(diff: &str) -> (String, Vec<Hunk>);
/// Parche con solo el trozo `index` (cabecera + trozo).
pub fn hunk_patch(diff: &str, index: usize) -> Option<String>;
```

## Ejemplo (entrada y resultado esperado)

```
diff = "diff --git a/a.txt b/a.txt\n--- a/a.txt\n+++ b/a.txt\n@@ -1,2 +1,2 @@\n-uno\n+UNO\n dos\n@@ -9,2 +9,3 @@\n nueve\n+nueve y medio\n diez\n"
split_hunks(diff).0 == "diff --git a/a.txt b/a.txt\n--- a/a.txt\n+++ b/a.txt\n"
split_hunks(diff).1[1] == Hunk { index: 1, header: "@@ -9,2 +9,3 @@", text: "@@ -9,2 +9,3 @@\n nueve\n+nueve y medio\n diez\n" }
hunk_patch(diff, 1) == Some("diff --git a/a.txt b/a.txt\n--- a/a.txt\n+++ b/a.txt\n@@ -9,2 +9,3 @@\n nueve\n+nueve y medio\n diez\n")
hunk_patch(diff, 2) == None
```

## Tests (con estos nombres)

- `parte_en_dos_trozos`: el ejemplo da la cabecera de tres líneas y dos trozos con sus cabeceras `@@`
- `parche_de_un_trozo`: `hunk_patch(diff, 1)` es la cabecera más el segundo trozo, como en el ejemplo
- `trozo_que_no_existe`: `hunk_patch(diff, 2)` es `None`
- `diff_vacio`: cadena vacía da cabecera vacía y cero trozos
