# F8.61b-git-descartar-nucleo — Git: descartar los cambios de un archivo o de un trozo en el demonio

## Objetivo

1. Crea `discard.rs` con las firmas de abajo y tests en el mismo archivo (cada uno con su repo temporal: copia la función
   `repo()` de los tests de `workspace.rs`).
2. `discard_file(root, rel)`: `crate::workspace::safe_path(root, rel)?`. Si el archivo no está versionado
   (`crate::workspace::git(root, &["ls-files", "--error-unmatch", "--", rel])` falla) →
   `Err("archivo nuevo sin versionar: bórralo desde el explorador".into())`. Si no, `git(root, &["checkout", "--", rel])`
   (deja el archivo como está en el índice; lo ya preparado con `git add` no se pierde).
3. `git_apply_reverse(root, patch)`: lanza `git -C <root> apply --reverse --whitespace=nowarn -` con
   `std::process::Command`, `stdin(Stdio::piped())`, escribe `patch` en la entrada, la cierra (`drop`) y espera con
   `wait_with_output()`. Si git sale mal, `Err` con su stderr recortado (`trim`).
4. `discard_hunk(root, rel, index)`: `diff = crate::workspace::git_diff(root, Some(rel), false)?`;
   `patch = crate::hunks::hunk_patch(&diff, index)` o `Err("ese trozo ya no existe: refresca el diff".into())`;
   `git_apply_reverse(root, &patch)`.
5. `lib.rs`: añade `pub mod discard;` debajo de `pub mod assist;`.

use crate::workspace::WsResult;

/// Descarta los cambios sin preparar de un archivo versionado.
pub fn discard_file(root: &Path, rel: &str) -> WsResult<()>;

## Ejemplo (entrada y resultado esperado)

```
Repo con a.txt de 12 líneas ("l1\n" … "l12\n") confirmado. Se cambia la línea 1 por "UNO" y la 12 por "DOCE" (dos trozos).
discard_hunk(root, "a.txt", 1) → Ok(()) y a.txt conserva "UNO" en la línea 1 pero vuelve a tener "l12" en la 12
discard_file(root, "a.txt")    → Ok(()) y a.txt vuelve a ser el del commit
discard_file(root, "nuevo.txt") (sin versionar) → Err("archivo nuevo sin versionar: bórralo desde el explorador")
```

## Tests (con estos nombres)

- `descarta_un_archivo`: tras modificar un archivo versionado, `discard_file` lo deja igual que en el commit
- `descarta_solo_un_trozo`: con dos trozos, `discard_hunk(…, 1)` deshace el segundo y conserva el primero
- `archivo_nuevo_no_se_descarta`: un archivo sin versionar da `Err` que contiene `sin versionar` y el archivo sigue existiendo
- `trozo_que_no_existe_avisa`: `discard_hunk(…, 9)` da `Err` que contiene `ya no existe`
- `ruta_fuera_de_la_raiz_se_rechaza`: `discard_file(root, "../x")` da `Err`

## No hagas

- No uses `git reset --hard`, `git clean` ni `git stash`
- Los tests usan siempre un repo temporal, nunca el de PublicCode
- No borres archivos sin versionar
