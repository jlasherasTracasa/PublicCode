## Objetivo

1. Crea `stash.rs` con las firmas de abajo y tests en el mismo archivo (repo temporal copiando `repo()` de los tests de
   `workspace.rs`).
2. `parse_stash_list(raw)`: salida de `git stash list --format=%gd%x1f%gs`: una línea por entrada con `stash@{N}`, el carácter
   `\u{1f}` y el mensaje. `index` = N. Las líneas que no cumplen la forma se ignoran.
3. `stash_list(root)`: `crate::workspace::git(root, &["stash", "list", "--format=%gd%x1f%gs"])` y `parse_stash_list`.
4. `stash_push(root, message)`: si `git(root, &["status", "--porcelain"])` devuelve vacío →
   `Err("no hay cambios que guardar".into())`. Mensaje: el recibido recortado, o `"Guardado desde Studio"` si está vacío.
   Lanza `git(root, &["stash", "push", "--include-untracked", "-m", mensaje])`.
5. `stash_pop(root, index)`: `git(root, &["stash", "pop", &format!("stash@{{{index}}}")])`.
6. `lib.rs`: añade `pub mod stash;` debajo de `pub mod settings;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/stash.rs
use crate::workspace::WsResult;
use std::path::Path;

/// Una entrada de `git stash list`.
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
pub struct StashEntry { pub index: u32, pub message: String }

pub fn parse_stash_list(raw: &str) -> Vec<StashEntry>;
pub fn stash_list(root: &Path) -> WsResult<Vec<StashEntry>>;
/// Guarda aparte todos los cambios (también archivos nuevos) y deja el árbol limpio.
pub fn stash_push(root: &Path, message: &str) -> WsResult<String>;
/// Recupera la entrada `index` y la quita de la lista.
pub fn stash_pop(root: &Path, index: u32) -> WsResult<String>;
```

## Ejemplo (entrada y resultado esperado)

```
parse_stash_list("stash@{0}\u{1f}On main: a medias\nstash@{1}\u{1f}WIP on main: 1a2b3c4 inicio\n")
  == [StashEntry { index: 0, message: "On main: a medias" }, StashEntry { index: 1, message: "WIP on main: 1a2b3c4 inicio" }]
```

## Tests (con estos nombres)

- `parsea_la_lista`: el ejemplo da dos entradas con índices 0 y 1
- `guardar_y_recuperar`: tras modificar un archivo, `stash_push` deja el archivo como en el commit, `stash_list` tiene 1 entrada y `stash_pop(root, 0)` devuelve el cambio
- `guardar_incluye_archivos_nuevos`: un archivo sin versionar desaparece al guardar y vuelve al recuperar
- `sin_cambios_no_guarda`: en un repo limpio `stash_push` da `Err` con `no hay cambios que guardar`
- `mensaje_vacio_usa_el_predeterminado`: con mensaje vacío la entrada contiene `Guardado desde Studio`

## No hagas

- Los tests usan SIEMPRE un repo temporal (`tempfile::tempdir()`): nunca ejecutes `git stash` en el repo de PublicCode
- No uses `stash drop` ni `stash clear`
