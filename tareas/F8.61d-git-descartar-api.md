## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`, debajo de `GIT_COMMIT`, añade con su comentario `///`:
   `GIT_DISCARD = "git.discard"` (`{path, hunk?}` → `true`; descarta el archivo o solo ese trozo),
   `GIT_STASH = "git.stash"` (`{message?}` → texto de git), `GIT_STASH_LIST = "git.stashList"` (`{}` → `{index, message}[]`) y
   `GIT_STASH_POP = "git.stashPop"` (`{index}` → texto de git).
2. `server.rs`, función `rpc`, `match req.method.as_str()`, después del brazo `methods::GIT_COMMIT`, cuatro brazos con la
   forma de `GIT_COMMIT`:
   - `GIT_DISCARD`: `hunk = p.get("hunk").and_then(|v| v.as_u64())`; dentro de `blocking`: con `Some(h)` →
     `crate::discard::discard_hunk(&root, &rel, h as usize)`, con `None` → `crate::discard::discard_file(&root, &rel)`. Emite
     `Event::FilesChanged {}` y responde `ws_reply(id, r.map(|_| true))`.
   - `GIT_STASH`: `crate::stash::stash_push(&root, &str_param(&p, "message"))`; emite `FilesChanged`.
   - `GIT_STASH_LIST`: `crate::stash::stash_list(&root)`.
   - `GIT_STASH_POP`: `index = p.get("index").and_then(|v| v.as_u64()).unwrap_or(0) as u32`; `crate::stash::stash_pop(&root, index)`; emite `FilesChanged`.
3. Test en `mod tests` de `server.rs`: repo temporal creado con `std::process::Command::new("git")` (`init -q`,
   `config user.email t@t`, `config user.name t`, escribe `a.txt`, `add .`, `commit -qm inicio`) y las aserciones de la lista.
