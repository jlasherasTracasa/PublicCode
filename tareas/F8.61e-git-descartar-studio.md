## Objetivo

Todo en `index.html`. API: `git.discard {path, hunk?}` → `true`; `git.stash {message?}` → texto; `git.stashList {}` → `[{index, message}]`;
`git.stashPop {index}` → texto. Tras cada operación el demonio emite `filesChanged` y Studio se refresca solo.
1. `descarta(path, hunk)`: pide confirmación con
   `confirm("Se perderán los cambios sin preparar de " + path + (hunk === undefined ? "" : " (solo este trozo)") + ". No se puede deshacer. ¿Descartar?")`;
   si acepta, `rpc("git.discard", hunk === undefined ? { path } : { path, hunk })` y `aviso("Cambios descartados", "ok")`; errores con `fallo(e)`.
2. En `refrescaGit`, función interna `grupo`: en las filas NO preparadas (`!staged`) de archivos versionados (`f.index !== "?"`),
   añade antes del botón `+` otro `button` de clase `mini` con texto `↶` y `title = "Descartar los cambios"`, con
   `onclick = (e) => { e.stopPropagation(); descarta(f.path); }`.
3. En `pintaDiff(t)`: lleva la cuenta de las líneas que empiezan por `@@` (0, 1, 2…). Si `t.staged` es falso y la pestaña no es
   fija (`!t.fijo`), añade dentro del `div` de cada línea `@@` un `button` de clase `mini` con texto `↶ Descartar trozo` y
   `onclick = () => descarta(t.path, n)` (con `n` el número de ese trozo).
4. Guardar aparte: en el `<header>` de `<section id="p-git">`, dentro de `<div class="acciones">`, añade antes de `b-git` el botón
   `<button id="b-stash" title="Guardar los cambios aparte (stash)">⇩</button>` y
   `<button id="b-stash-lista" title="Recuperar cambios guardados">⇧</button>`.
   `b-stash`: `prompt("Nombre para los cambios guardados (opcional)")`; si no se cancela (`!== null`),
   `rpc("git.stash", { message })` y `aviso("Cambios guardados aparte", "ok")`.
   `b-stash-lista`: `rpc("git.stashList")`; sin entradas → `aviso("No hay cambios guardados")`; con entradas, `menu(x, y, opciones)`
   bajo el botón (usa `getBoundingClientRect()`), una opción por entrada con su `message`, que hace
   `rpc("git.stashPop", { index })` y `aviso("Cambios recuperados", "ok")`. Errores con `fallo(e)`.
5. `ORDENES`: `["Git: guardar los cambios aparte (stash)", "", () => $("b-stash").click()]`,
   `["Git: recuperar cambios guardados", "", () => { panel("git"); $("b-stash-lista").click(); }]` y
   `["Git: descartar los cambios del archivo abierto", "", () => { const t = tabActiva(); if (t && t.kind === "file") descarta(t.path); }]`.
