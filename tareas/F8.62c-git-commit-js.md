## Objetivo

1. Crea `commit.js`: módulo ES sin imports ni DOM, con las tres funciones de abajo exportadas. `info` es lo que devuelve
   `git.commitInfo`: `{ sha, short, author, email, time, subject, body, files: [{ path, added, deleted }] }`.
2. `totals(files)`: `{ files: n, added: suma, deleted: suma }` (los `null` de los binarios cuentan 0).
3. `fileRow(f)`: texto de una fila: `"+3 −1  src/a.rs"` (el signo menos es `−`, U+2212) o, si `added` es `null`, `"bin  logo.png"`.
4. `headerLines(info, dateText)`: array de líneas de texto para la cabecera:
   `["commit <sha>", "Autor: <author> <<email>>", "Fecha: <dateText>", "", "<subject>"]`, después, si `body` no está vacío,
   `""` y cada línea del cuerpo, y al final `""` y `"<n> archivos, +<added> −<deleted>"` (`"1 archivo"` en singular).
   `dateText` llega ya formateado (el módulo no usa `Date`).
5. Crea `commit.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
const info = { sha: "a1b2c3d4e5", short: "a1b2c3d4", author: "Ana", email: "ana@x.es", time: 1700000000, subject: "arregla x", body: "Detalle.",
  files: [{ path: "src/a.rs", added: 3, deleted: 1 }, { path: "logo.png", added: null, deleted: null }] };
totals(info.files)        → { files: 2, added: 3, deleted: 1 }
fileRow(info.files[0])    → "+3 −1  src/a.rs"
fileRow(info.files[1])    → "bin  logo.png"
headerLines(info, "14/11/2023 22:13") → ["commit a1b2c3d4e5", "Autor: Ana <ana@x.es>", "Fecha: 14/11/2023 22:13", "", "arregla x", "", "Detalle.", "", "2 archivos, +3 −1"]
```

## Tests (con estos nombres)

- `totales_suman_y_tratan_binarios_como_cero`: el ejemplo da 2 archivos, +3 y −1
- `fila_de_archivo_de_texto`: `+3 −1  src/a.rs` con el signo menos U+2212
- `fila_de_binario`: un archivo con `added` nulo da `bin  logo.png`
- `cabecera_con_cuerpo`: el ejemplo da las nueve líneas indicadas
- `cabecera_sin_cuerpo_y_en_singular`: con `body` vacío y un solo archivo no hay líneas de cuerpo y el final es `1 archivo, +3 −1`

## No hagas

- No uses `Date`, `document`, `window` ni imports
- No devuelvas HTML: solo texto
