## Objetivo

API: `git.commitInfo {sha}` → `{sha, short, author, email, time, subject, body, files}`; `git.show {sha}` (sin `path`) → diff completo del commit.
1. `web_assets.rs`: añade a `ASSETS` la línea `("commit.js", include_str!("../web/studio/commit.js")),`. `index.html`: en el bloque
   `<script type="module">` final, antes de `inicio();`: `import * as commit from "/studio/commit.js"; Studio.commit = commit;`.
2. `abreCommit(sha)`: si ya hay una pestaña con `id === "k:" + sha`, actívala. Si no, pide a la vez
   `rpc("git.commitInfo", { sha })` y `rpc("git.show", { sha })` (`Promise.all`) y añade la pestaña
   `{ id: "k:" + info.sha, kind: "diff", path: "commit " + info.short, text, info, fijo: true }`; errores con `fallo(e)`.
3. En `pintaDiff(t)`, al principio (después de `box.replaceChildren()`): si `t.info`, pinta la cabecera antes del diff:
   un `div` de clase `meta` por cada línea de `Studio.commit.headerLines(t.info, new Date(t.info.time * 1000).toLocaleString())`
   (`textContent`; las líneas vacías como `" "`), y después un `button` de clase `problema` por archivo con el texto
   `Studio.commit.fileRow(f)`; al pulsarlo, busca en `box` el primer `div` cuyo texto empieza por `"diff --git"` y contiene
   `" b/" + f.path` y llama a `scrollIntoView({ block: "start" })`. La comprobación `if (!t.text.trim())` de «Sin diferencias» va
   después de pintar la cabecera.
4. Entradas: a) en `pintaHistorial`, cada commit lleva además un botón `mini` con texto `⤢` y `title = "Ver el commit completo"`
   que llama a `abreCommit(c.sha)` (con `e.stopPropagation()`); b) en `pintaBlame`, la anotación de la línea es clicable
   (`style.pointerEvents = "auto"`, `style.cursor = "pointer"`, `title = "Ver el commit"`) y abre `abreCommit(b.sha)` si `b.author !== ""`;
   c) `ORDENES`: `["Git: ver un commit…", "", () => { const s = prompt("Identificador del commit (sha)"); if (s) abreCommit(s.trim()); }]`.
