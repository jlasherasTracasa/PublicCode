## Objetivo

1. Crea `terminales.js`: módulo ES sin imports ni DOM. Todas las funciones devuelven un estado NUEVO (no mutan el recibido).
   Estado: `{ tabs: [{ id, title, buffer, proc, running, code, command }], active, next }`. `proc` es el id que devuelve
   `terminal.run` (o `null`), `code` el último código de salida (o `null`), `next` el id de la próxima pestaña.
2. `initial()`: una pestaña `{ id: 1, title: "Terminal", buffer: "", proc: null, running: false, code: null, command: "" }`,
   `active: 1`, `next: 2`.
3. `addTab(state)`: añade una pestaña vacía con `id = state.next`, la activa y suma 1 a `next`.
4. `closeTab(state, id)`: quita la pestaña. Si era la activa, pasa a activa la siguiente (o la anterior si era la última).
   Si no queda ninguna, añade una vacía nueva (con `id = next`).
5. `setActive(state, id)`: cambia `active` solo si existe esa pestaña.
6. `title(command)`: primera palabra de la orden; si contiene `/`, lo que va tras la última; como mucho 16 caracteres;
   orden vacía → `"Terminal"`.
7. `append(state, tabId, text)`: añade `text` al `buffer` de esa pestaña y conserva solo los últimos `MAX_BUFFER` caracteres.
8. `started(state, tabId, proc, command)`: en esa pestaña pone `proc`, `running: true`, `code: null`, `command`,
   `title: title(command)` y añade al buffer `"❯ " + command + "\n"`.
9. `output(state, proc, text)`: `append` sobre la pestaña cuyo `proc` coincide; si ninguna, devuelve el mismo estado.
10. `exited(state, proc, code)`: en la pestaña de ese `proc`: `running: false`, `proc: null`, `code`, y añade al buffer
    `"✓ terminado\n"` si `code === 0` o `"✗ salió con " + (code ?? "señal") + "\n"` si no.
11. `tabOf(state, proc)` y `activeTab(state)`: devuelven la pestaña (o `null`).
12. Crea `terminales.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
let s = started(initial(), 1, 7, "/usr/bin/cargo test -p x");
activeTab(s) → { id: 1, title: "cargo", buffer: "❯ /usr/bin/cargo test -p x\n", proc: 7, running: true, code: null, command: "/usr/bin/cargo test -p x" }
s = exited(output(s, 7, "ok\n"), 7, 0);
activeTab(s).buffer → "❯ /usr/bin/cargo test -p x\nok\n✓ terminado\n";   activeTab(s).running → false
closeTab(initial(), 1) → { tabs: [{ id: 2, title: "Terminal", … }], active: 2, next: 3 }
```

## Tests (con estos nombres)

- `estado_inicial_con_una_pestana`: `initial()` tiene una pestaña activa con id 1 y `next` 2
- `anadir_y_cerrar_pestanas`: `addTab` activa la nueva; cerrar la activa pasa a la vecina; cerrar la última crea una vacía
- `titulo_de_la_orden`: `/usr/bin/cargo test` da `cargo`, una orden vacía `Terminal` y un nombre largo se corta a 16
- `salida_va_a_la_pestana_de_su_proceso`: con dos pestañas, `output` del proceso de la segunda no toca el buffer de la primera
- `salida_de_proceso_desconocido_no_cambia_nada`: `output(state, 99, "x")` devuelve el mismo estado
- `al_terminar_marca_el_codigo`: `exited` con 0 añade `✓ terminado`, con 2 `✗ salió con 2` y con `null` `✗ salió con señal`
- `el_buffer_tiene_tope`: tras añadir más de `MAX_BUFFER` caracteres el buffer mide `MAX_BUFFER` y conserva el final
- `no_muta_el_estado`: el objeto devuelto por `initial()` queda igual después de `started` y `append`
