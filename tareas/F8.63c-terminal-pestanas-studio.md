## Objetivo

API: `terminal.run {command, interactive?}` → `{id}`; `terminal.input {id, text, eof?}` → `true`; `terminal.kill {id}`; eventos
`terminalOutput {id, text}` y `terminalExit {id, code}`. El estado vive en `S.term` y solo se cambia con `Studio.terminales`.
1. `web_assets.rs`: añade a `ASSETS` la línea `("terminales.js", include_str!("../web/studio/terminales.js")),`. `index.html`: en el
   bloque `<script type="module">` final, antes de `inicio();`:
   `import * as terminales from "/studio/terminales.js"; Studio.terminales = terminales;`. Al principio de `inicio()`:
   `S.term = Studio.terminales.initial();`.
2. HTML del `<header>` de `<section id="terminal">`: después de `TERMINAL <span id="t-estado"></span>` añade
   `<div id="t-pestanas" class="t-pestanas" role="tablist"></div><button id="t-nueva" title="Terminal nueva">＋</button>` y, antes de
   `t-parar`, `<label class="t-inter" title="La orden puede leer lo que escribas (sin pseudoterminal)"><input type="checkbox" id="t-interactiva"> Interactiva</label>`.
   CSS: `.t-pestanas { display: flex; gap: 4px; overflow: auto; }` y `.t-pestanas button[aria-selected="true"] { border-bottom: 2px solid var(--primario); }`.
3. `pintaTerminal()`: repinta `#t-pestanas` (un `button role="tab"` por pestaña con su `title`, `●` delante si `running`,
   `aria-selected`, clic → `S.term = setActive(S.term, id)` y repintar; clic central o un `×` interior → `cierraTerminal(id)`),
   pone `$("salida").textContent = activa.buffer`, baja el scroll al final y `#t-estado` = `· en marcha` si la activa está en marcha.
   Si la activa terminó con `code` distinto de 0 y de `null`, añade bajo la salida el botón «✦ Arreglar con el agente» que ya
   existe en el caso `terminalExit` (misma llamada a `assist.prompt` con `kind: "orden"`, `command: activa.command`,
   `code: activa.code` y `output: activa.buffer.slice(-60000)`).
4. `cierraTerminal(id)`: si la pestaña está en marcha, `rpc("terminal.kill", { id: proc })`; después `closeTab` y repintar.
5. Sustituye el cuerpo de `ejecuta(cmd)`: historial igual que hoy; con `t = activeTab(S.term)`: si `t.running` y la casilla
   `t-interactiva` está marcada → `rpc("terminal.input", { id: t.proc, text: cmd + "\n" })` y `append` del texto al buffer; si
   `t.running` y no → `aviso("Esta pestaña tiene una orden en marcha: abre otra con ＋")`; si no está en marcha →
   `rpc("terminal.run", { command: cmd, interactive: $("t-interactiva").checked })` y `S.term = started(S.term, t.id, r.id, cmd)`;
   si falla, `append` del mensaje de error. Siempre termina con `pintaTerminal()`.
6. `escribeSalida(nodo)` pasa a ser: `S.term = Studio.terminales.append(S.term, S.term.active, nodo.textContent); pintaTerminal();`
   (así sigue valiendo para el resto del código que la llama).
7. `conecta()`: `terminalOutput` → `S.term = output(S.term, e.id, e.text)` y, si la pestaña de ese proceso es la activa,
   `pintaTerminal()`; `terminalExit` → `S.term = exited(S.term, e.id, e.code)` y `pintaTerminal()`. Quita de ambos casos el uso
   de `S.terminal`, `S.salidaOrden` y `S.ultimaOrden`.
8. Botones y teclas: `t-nueva` → `addTab`; `t-parar` y `Ctrl+C` en `#orden` → `terminal.kill` del `proc` de la activa (si hay);
   `Ctrl+D` en `#orden` con la activa en marcha → `rpc("terminal.input", { id: proc, text: "", eof: true })`; `t-limpiar` → vacía el
   `buffer` de la activa (`append` no sirve: crea el estado nuevo con `{ ...pestaña, buffer: "" }`).
   `ORDENES`: `["Terminal: pestaña nueva", "", () => { terminal(true); $("t-nueva").click(); }]`.
