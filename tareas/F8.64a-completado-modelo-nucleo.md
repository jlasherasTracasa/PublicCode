## Objetivo

1. Crea `inline.rs` con las firmas de abajo y tests en el mismo archivo. Sin E/S.
2. `split_at_utf16(content, offset)`: `offset` es la posición del cursor en unidades UTF-16 (lo que da el navegador). Recorre
   los `char` sumando `len_utf16()` hasta llegar a `offset` y devuelve `(antes, después)` partiendo por ese byte. Si `offset`
   pasa del final o cae en medio de un carácter → `None`.
3. `inline_prompt(path, before, after)`: devuelve exactamente este texto (con las últimas `MAX_BEFORE` líneas de `before` y las
   primeras `MAX_AFTER` de `after`):
   línea 1: `Completa el código en el punto marcado con <CURSOR>. Responde SOLO con el texto que falta (como mucho 8 líneas), sin explicaciones, sin repetir lo ya escrito y sin bloques de código.`
   línea 2: `Archivo: <path>`; línea 3: `<ANTES>`; después el trozo de `before` seguido de `<CURSOR>`; salto de línea; `</ANTES>`;
   `<DESPUES>`; el trozo de `after`; salto de línea; `</DESPUES>`.
4. `clean_completion(raw, before)`, en este orden: a) quita los espacios y saltos finales; b) si la primera línea empieza por
   tres acentos graves, quítala, y si la última línea es solo tres acentos graves, quítala; c) borra todas las apariciones de
   `<CURSOR>`; d) solape: sea `linea` lo que hay en `before` tras su último `\n`; busca el sufijo más largo de `linea` (de 3
   caracteres o más) que sea prefijo del resultado y quítalo del resultado; e) deja como mucho `MAX_LINES` líneas; f) si lo que
   queda son solo espacios, devuelve `""`.
5. `lib.rs`: añade `pub mod inline;` debajo de `pub mod assist;`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-server/src/inline.rs
/// Líneas de contexto antes y después del cursor, y máximo de líneas de la propuesta.
pub const MAX_BEFORE: usize = 60;
pub const MAX_AFTER: usize = 20;
pub const MAX_LINES: usize = 8;

/// Parte el texto en la posición del cursor (unidades UTF-16).
pub fn split_at_utf16(content: &str, offset: usize) -> Option<(&str, &str)>;
/// Prompt para pedir al modelo lo que falta en el cursor.
pub fn inline_prompt(path: &str, before: &str, after: &str) -> String;
/// Deja la respuesta del modelo lista para insertar tras el cursor.
pub fn clean_completion(raw: &str, before: &str) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
split_at_utf16("ñ😀x", 3) == Some(("ñ😀", "x"));   split_at_utf16("ñ😀x", 2) == None;   split_at_utf16("ab", 9) == None
clean_completion("```rust\nlet x = 5;\n```\n", "fn f() {\n    ") == "let x = 5;"
clean_completion("let total = a + b;", "    let total = ") == "a + b;"      // solape `let total = `
clean_completion("   \n", "x") == ""
```

## Tests (con estos nombres)

- `parte_por_unidades_utf16`: los tres casos del ejemplo de `split_at_utf16`
- `prompt_recorta_el_contexto`: con 100 líneas antes y 50 después, el prompt contiene la línea 41 de antes pero no la 40, y la 20 de después pero no la 21
- `prompt_lleva_ruta_y_marca`: contiene `Archivo: src/a.rs` y `<CURSOR>` justo después del texto anterior
- `limpia_cercas_de_codigo`: el ejemplo con acentos graves queda `let x = 5;`
- `quita_el_solape_con_la_linea_actual`: el ejemplo de `let total = ` queda `a + b;`
- `limita_las_lineas`: una respuesta de 20 líneas queda en 8
- `respuesta_en_blanco_es_vacia`: solo espacios y saltos da cadena vacía
