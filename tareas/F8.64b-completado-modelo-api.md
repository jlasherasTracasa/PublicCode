## Objetivo

1. `crates/pcode-protocol/src/lib.rs`, en `pub mod methods`, debajo de `ASSIST_RUN`, añade
   `/// Propuesta del modelo para continuar el código en el cursor: `{path, content, offset}` → `{text}` (desactivado en el perfil ligero).`
   y `pub const ASSIST_INLINE: &str = "assist.inline";`.
2. `server.rs`, función `rpc`, `match req.method.as_str()`, después del brazo `ASSIST_PROMPT | ASSIST_RUN`, añade
   `methods::ASSIST_INLINE`, en este orden:
   a) si `st.lsp.limits().light` → `rpc_err(id, -32000, "el completado con el modelo está desactivado en el perfil ligero")`;
   b) `rel = str_param(&p, "path")`; si `crate::workspace::safe_path(&st.repo, &rel)` falla → `rpc_err(id, -32000, e)`;
   c) `content = str_param(&p, "content")`, `offset = p.get("offset").and_then(|v| v.as_u64()).unwrap_or(0) as usize`;
      `crate::inline::split_at_utf16(&content, offset)`; si es `None` → `rpc_err(id, -32602, "posición fuera del texto")`;
   d) `prompt = crate::inline::inline_prompt(&rel, before, after)`;
      `crate::assist::ask(&st.pcode_bin, &st.repo, &prompt).await` y responde
      `ws_reply(id, r.map(|t| serde_json::json!({"text": crate::inline::clean_completion(&t, before)})))`.
3. Tests en `mod tests` de `server.rs` (lista de abajo). Para el perfil ligero:
   `st.lsp.set_limits(pcode_lsp::LspLimits { light: true, ..Default::default() });` antes de llamar.
