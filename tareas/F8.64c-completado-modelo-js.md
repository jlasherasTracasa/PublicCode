## Objetivo

1. Crea `fantasma.js`: módulo ES sin imports ni DOM, con las cuatro funciones de abajo exportadas.
2. `shouldSuggest(text, pos)`: `true` solo si el cursor está al final de una línea (`pos === text.length` o
   `text[pos] === "\n"`) y la línea actual, desde su inicio hasta `pos`, tiene al menos 3 caracteres que no son espacio ni tabulador.
3. `accept(text, pos, suggestion)`: inserta `suggestion` en `pos`; devuelve `{ text, cursor }` con el cursor al final de lo insertado.
4. `advance(suggestion, typed)`: el usuario ha tecleado `typed` con la sugerencia a la vista. Si `suggestion` empieza por
   `typed`, devuelve lo que queda (`suggestion.slice(typed.length)`); si no, `""` (la sugerencia ya no vale).
5. `display(suggestion)`: `{ inline, more }`: `inline` es la primera línea de la sugerencia y `more` cuántas líneas más tiene.
6. Crea `fantasma.test.js` con los tests de la lista.

## Ejemplo (entrada y resultado esperado)

```
shouldSuggest("let total = ", 12)        → true
shouldSuggest("let total = 1;\nx", 5)    → false   (el cursor está en mitad de la línea)
shouldSuggest("  \n", 2)                 → false   (línea casi vacía)
accept("let t = ", 8, "a + b;")          → { text: "let t = a + b;", cursor: 14 }
advance("a + b;", "a ")                  → "+ b;";    advance("a + b;", "x") → ""
display("a + b;\nreturn t;\n}")          → { inline: "a + b;", more: 2 }
```

## Tests (con estos nombres)

- `sugiere_solo_al_final_de_la_linea`: los tres casos del ejemplo de `shouldSuggest`
- `aceptar_inserta_y_mueve_el_cursor`: el ejemplo de `accept` da el texto unido y el cursor en 14
- `aceptar_en_mitad_del_texto`: insertar antes de un `\n` conserva lo que venía después
- `avanza_si_se_teclea_lo_sugerido`: teclear `a ` deja `+ b;` y teclear `x` deja cadena vacía
- `muestra_la_primera_linea_y_cuenta_el_resto`: el ejemplo de `display` da `a + b;` y 2
