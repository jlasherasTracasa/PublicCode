## Objetivo

API: `assist.inline {path, content, offset}` → `{text}` (`offset` = `ta.selectionStart`). Puede tardar segundos y gasta tokens:
por eso está desactivado hasta que el usuario lo activa, y el demonio lo rechaza en el perfil ligero.
1. `web_assets.rs`: añade a `ASSETS` la línea `("fantasma.js", include_str!("../web/studio/fantasma.js")),`. `index.html`: en el bloque
   `<script type="module">` final, antes de `inicio();`: `import * as fantasma from "/studio/fantasma.js"; Studio.fantasma = fantasma;`.
2. En `<div class="codigo">`, después de `<div id="capa-diag" …>`, añade `<div id="capa-fantasma" class="capa-diag" aria-hidden="true"></div>`
   y en `sincroniza()` dale el mismo `transform` que a `capa-diag`. CSS `.fantasma { position: absolute; white-space: pre; opacity: .45; font: inherit; color: var(--ed-texto); }`
   (misma fuente y alto de línea que el editor: 21 px por línea).
3. Estado: `S.fantasma = null` (`{ pos, text }`), `S.fantasmaN = 0`, `S.fantasmaNo = false`. `fantasmaActivo()`:
   `localStorage["pcode.fantasma"] === "1"` (try/catch) y `!S.fantasmaNo`.
4. `pideFantasma()`: si `!fantasmaActivo()`, no hay pestaña de archivo, hay selección (`selectionStart !== selectionEnd`), la lista de
   autocompletado está abierta (`S.comp`) o `!Studio.fantasma.shouldSuggest(ta.value, ta.selectionStart)`, termina. Guarda
   `const n = ++S.fantasmaN, pos = ta.selectionStart`; `r = await rpc("assist.inline", { path: t.path, content: ta.value, offset: pos })`.
   Al volver, solo si `n === S.fantasmaN`, `ta.selectionStart === pos` y `r.text`: `S.fantasma = { pos, text: r.text }` y `pintaFantasma()`.
   Si el error contiene `perfil ligero`: `S.fantasmaNo = true` y un único `aviso(e.message)`; otros errores se ignoran en silencio.
5. `pintaFantasma()`: vacía `#capa-fantasma`; si hay `S.fantasma`, añade un `div.fantasma` con el texto
   `d.inline + (d.more ? "  ⏎ +" + d.more + " líneas" : "")` (`d = Studio.fantasma.display(S.fantasma.text)`), colocado en la posición del
   cursor: `top = 10 + línea0 * 21` px y `left = 16 + colVisual(textoLinea, columna) * medirCaracter()` px. `quitaFantasma()`:
   `S.fantasma = null; S.fantasmaN++;` y vacía la capa.
6. Teclado, al principio del listener de `keydown` de `Tab`/`Enter`: si `S.fantasma` y `e.key === "Tab"` sin Mayús →
   `e.preventDefault()`, `r = Studio.fantasma.accept(ta.value, S.fantasma.pos, S.fantasma.text)`, `quitaFantasma()`, `ta.value = r.text`,
   `ta.setSelectionRange(r.cursor, r.cursor)`, `ta.dispatchEvent(new Event("input"))` y `return`; si `S.fantasma` y `Escape` →
   `quitaFantasma()` y `return`.
7. En el listener de `input`: si `S.fantasma` y el cursor avanzó (`ta.selectionStart > S.fantasma.pos`), calcula
   `resto = Studio.fantasma.advance(S.fantasma.text, ta.value.slice(S.fantasma.pos, ta.selectionStart))`; si `resto` no está vacío,
   `S.fantasma = { pos: ta.selectionStart, text: resto }` y `pintaFantasma()`; en cualquier otro caso `quitaFantasma()`. Después
   programa `pideFantasma()` con retardo de 900 ms (`clearTimeout`/`setTimeout`). También `quitaFantasma()` al cambiar de pestaña
   (en `activa`) y en el evento `click` de `ta`.
8. `ORDENES`: `["Completado con el modelo (texto fantasma): activar o desactivar", "", () => { … }]`: invierte
   `localStorage["pcode.fantasma"]`, pone `S.fantasmaNo = false`, llama a `quitaFantasma()` y muestra
   `aviso("Completado con el modelo: activado (Tab acepta, Esc descarta)")` o `"…: desactivado"`.
