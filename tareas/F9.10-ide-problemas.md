## Objetivo

1. `problems.rs`: `Problems` guarda por ruta los diagnósticos del último evento (reemplaza, no acumula). `apply` recibe
   el JSON de un evento; si `ev["tipo"] == "diagnostics"` lee `path` e `items` (`line`, `character`, `severity`,
   `message`, `source`) y devuelve `true`; con cualquier otro evento devuelve `false`. `items` vacío borra la ruta.
   `counts` devuelve (errores = severity 1, avisos = severity 2). `sorted` da la lista plana ordenada por ruta y línea.
2. `lib.rs`: `pub mod problems;`.
3. `app.rs`: el `Ide` tiene `problems: Problems`; `on_event` llama a `apply`; la barra de estado muestra `✗ n ⚠ m`
   (símbolos, no solo color); `ui_bottom` con `Bottom::Problems` lista `ruta:línea mensaje` y un clic abre el
   archivo (como el explorador) y coloca el cursor en la línea.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/problems.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Problem { pub path: String, pub line: u32, pub character: u32, pub severity: u8, pub message: String, pub source: String }
#[derive(Debug, Default)]
pub struct Problems { pub by_path: std::collections::BTreeMap<String, Vec<Problem>> }
impl Problems {
    pub fn apply(&mut self, ev: &serde_json::Value) -> bool;
    pub fn counts(&self) -> (usize, usize);
    pub fn sorted(&self) -> Vec<Problem>;
}
```
