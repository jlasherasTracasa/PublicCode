## Objetivo

1. `git.rs`: `status_label(index, worktree)` da la letra que se ve (`"M"`, `"A"`, `"D"`, `"R"`, `"?"` para `??`,
   `"U"` para conflictos `UU`/`AA`/`DD`); `is_staged(index)` es true si `index` no es `" "` ni `"?"`;
   `diff_lines` clasifica cada línea de un diff unificado: `+`→Added, `-`→Removed, `@@`→Hunk, `diff `/`index `/`+++`/
   `---`→Header, resto Context.
2. `lib.rs`: `pub mod git;`.
3. `app.rs`: el panel de git separa «Preparados» y «Cambios»; cada archivo tiene botones `+`/`−` (stage/unstage) y un
   clic muestra su diff en la pestaña inferior con colores por `DiffLine` (y el signo, no solo el color). Un cuadro de
   mensaje y botón «Commit» (Ctrl+Intro). Tras cada acción se vuelve a pedir `git.status`.
