## Objetivo

1. `agent.rs`: `TurnCard::from_event` lee un evento `turnFinished` (`session`, `changes[]` con `path`, `added`,
   `removed`, `created`, `deleted`) y devuelve None para cualquier otro. `summary()` da exactamente
   `✎ 2 archivos · src/a.rs +3 −1 · b.rs nuevo +12` (singular «1 archivo»; «borrado» si `deleted`; «nuevo» si
   `created`). `Stream` concatena los `assistantDelta` de una sesión hasta que llega su entrada `assistant` completa.
2. `lib.rs`: `pub mod agent;`.
3. `app.rs`: debajo de cada respuesta del agente pinta la tarjeta del turno con botones «↶ Deshacer el turno»
   (`checkpoint.undo` con `{}`) y «↷ Rehacer» (`checkpoint.redo`); el texto en streaming se ve mientras llega.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/agent.rs
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Change { pub path: String, pub added: u32, pub removed: u32, pub created: bool, pub deleted: bool }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TurnCard { pub session: i64, pub changes: Vec<Change> }
impl TurnCard { pub fn from_event(ev: &serde_json::Value) -> Option<TurnCard>; pub fn summary(&self) -> String; }
#[derive(Debug, Default)]
pub struct Stream { pub text: std::collections::HashMap<i64, String> }
impl Stream { pub fn apply(&mut self, ev: &serde_json::Value) -> bool; }
```
