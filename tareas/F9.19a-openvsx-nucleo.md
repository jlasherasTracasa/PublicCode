## Objetivo

1. `lib.rs`: añade `pub mod openvsx;` después del comentario `//!` inicial, y en `enum ExtError` la variante
   `Remote(String)` con `#[error("Open VSX: {0}")]` y su `///` («El registro no contestó lo esperado»).
2. Crea `openvsx.rs` con lo de *Firmas* y sus tests. Nada de red aquí: solo texto.
3. `parse_id`: parte `id` por el PRIMER punto en espacio de nombres y nombre. Los dos deben tener entre 1 y 100
   caracteres y solo letras ASCII, cifras, `-` y `_` (el nombre admite además `.`). Si no, `None`.
4. `api_url`: `"{base}/api/{namespace}/{name}"`, quitando antes las `/` finales de `base`.
5. `download_of`: `body` es el JSON de esa URL. Lee `version` (cadena) y `files.download` (cadena). Errores, siempre
   `ExtError::Remote(mensaje)`: JSON no válido → `"respuesta no válida"`; si el JSON trae `error` (cadena) → ese
   texto; falta `files.download` → `"la extensión no tiene archivo .vsix"`; la URL de descarga no empieza por
   `base` (sin `/` finales) seguido de `/` → `"descarga fuera del registro: <url>"`. Si falta `version`, usa `""`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-extensions/src/openvsx.rs
//! Registro Open VSX: solo las URL y la lectura de la respuesta (la descarga la hace la CLI).
use crate::ExtError;

/// Registro por defecto.
pub const OPEN_VSX: &str = "https://open-vsx.org";

/// Parte `editor.nombre` en (espacio de nombres, nombre); `None` si no tiene esa forma.
pub fn parse_id(id: &str) -> Option<(String, String)>;

/// URL de los metadatos de la última versión.
pub fn api_url(base: &str, namespace: &str, name: &str) -> String;

/// (versión, URL del `.vsix`) a partir del JSON de `api_url`.
pub fn download_of(body: &str, base: &str) -> Result<(String, String), ExtError>;
```

## Ejemplo (entrada y resultado esperado)

```
parse_id("redhat.java")            -> Some(("redhat", "java"))
parse_id("sin-punto")              -> None
api_url("https://open-vsx.org/", "redhat", "java") -> "https://open-vsx.org/api/redhat/java"
download_of(r#"{"version":"1.2.0","files":{"download":"https://open-vsx.org/api/redhat/java/1.2.0/file/redhat.java-1.2.0.vsix"}}"#,
            "https://open-vsx.org")
   -> Ok(("1.2.0", "https://open-vsx.org/api/redhat/java/1.2.0/file/redhat.java-1.2.0.vsix"))
download_of(r#"{"error":"Extension not found: a.b"}"#, "https://open-vsx.org") -> Err(Remote("Extension not found: a.b"))
```

## Tests (con estos nombres)

- `id_con_editor_y_nombre`: redhat.java da (redhat, java); sin punto, vacío, con barra o con espacio dan None
- `url_de_metadatos`: la base con barra final da https://open-vsx.org/api/redhat/java
- `lee_version_y_descarga`: el JSON del ejemplo da la versión 1.2.0 y la URL del .vsix
- `error_del_registro`: un JSON con el campo error devuelve ExtError::Remote con ese texto
- `descarga_de_otro_sitio_se_rechaza`: files.download en https://otro.example/x.vsix da Remote que contiene «fuera del registro»
- `json_roto`: la cadena «no es json» da Remote(«respuesta no válida»)
