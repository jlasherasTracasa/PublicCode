## Objetivo

1. Crea `ext_remote.rs` con `base_url` y `resolve_source` (firmas abajo) y declara `mod ext_remote;` en `main.rs`
   (en orden alfabético, entre `doctor` y `flow_cmd`).
2. `base_url`: el valor de la variable `PCODE_OPENVSX_URL` si existe y no está vacía; si no,
   `pcode_extensions::openvsx::OPEN_VSX`. Sin `/` al final.
3. `resolve_source(origen, base, tmp)`: si `origen` existe en disco, lo devuelve tal cual (no hay red). Si no existe
   y `parse_id(texto de origen)` da `Some((ns, name))`: hace GET a `api_url(base, ns, name)`, pasa el cuerpo a
   `download_of(cuerpo, base)`, descarga esa URL y la guarda en `tmp/<ns>.<name>-<versión>.vsix`; devuelve esa
   ruta. En cualquier otro caso, error `no existe <origen> ni es un identificador editor.nombre`.
4. Cliente: `reqwest::Client::builder().timeout(Duration::from_secs(60)).build()`. Una respuesta que no sea 2xx en
   los metadatos se pasa igualmente a `download_of` (el registro contesta JSON con `error`); en la descarga es un
   error `descarga fallida: HTTP <código>`. Si el `.vsix` pasa de 64 MiB (`MAX_VSIX`), error `el .vsix es demasiado
   grande`. Antes de pedir nada imprime `Descargando <id> de <base>…` con `eprintln!`.
5. `main.rs`, brazo `Some(Cmd::Extensiones(c))`: antes de llamar a `ext_cmd`, si `c` es `ExtCmd::Instalar { origen }`
   sustituye `origen` por `ext_remote::resolve_source(&origen, &ext_remote::base_url(), &std::env::temp_dir()).await?`.
   En `ExtCmd::Instalar`, cambia el comentario `///` de `origen` a «Archivo `.vsix`, carpeta o `editor.nombre`
   (se descarga de Open VSX)».
6. Tests en `ext_remote.rs` con un servidor HTTP falso en `127.0.0.1:0` hecho con `tokio::net::TcpListener`: acepta
   como mucho 2 conexiones; en cada una lee hasta `\r\n\r\n`, mira la primera línea y contesta
   `HTTP/1.1 200 OK\r\nContent-Length: N\r\nConnection: close\r\n\r\n` más el cuerpo. Para `GET /api/ana/temas`
   el cuerpo es el JSON con `files.download` apuntando a `http://127.0.0.1:<puerto>/f/ana.temas-1.0.0.vsix`; para
   esa otra ruta, los bytes `PK-falso`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/src/ext_remote.rs
//! Descarga de extensiones de Open VSX para `pcode extensiones instalar editor.nombre`.
use std::path::{Path, PathBuf};

/// Tamaño máximo de un `.vsix` descargado.
pub const MAX_VSIX: usize = 64 * 1024 * 1024;

/// Registro que se usa: `PCODE_OPENVSX_URL` o Open VSX.
pub fn base_url() -> String;

/// Devuelve `origen` si existe; si es `editor.nombre`, lo descarga a `tmp` y devuelve la ruta del `.vsix`.
pub async fn resolve_source(origen: &Path, base: &str, tmp: &Path) -> anyhow::Result<PathBuf>;
```

## Ejemplo (entrada y resultado esperado)

```
resolve_source(Path::new("/tmp/mi.vsix"), base, tmp)   (el archivo existe)  -> Ok("/tmp/mi.vsix"), sin red
resolve_source(Path::new("ana.temas"), "http://127.0.0.1:4000", tmp)        -> Ok(tmp/"ana.temas-1.0.0.vsix")
resolve_source(Path::new("no/existe/x"), base, tmp)    -> Err("no existe no/existe/x ni es un identificador editor.nombre")
```

## Tests (con estos nombres)

- `origen_local_no_usa_la_red`: con un archivo que existe y una base inalcanzable (http://127.0.0.1:1) devuelve la misma ruta
- `descarga_de_un_servidor_falso`: con el servidor falso, ana.temas deja en tmp el archivo ana.temas-1.0.0.vsix con el contenido PK-falso
- `origen_que_no_existe_ni_es_id`: no/existe/x da un error cuyo texto contiene «ni es un identificador»
- `registro_con_error`: si el servidor falso contesta {"error":"no está"} a los metadatos, el error contiene «no está»
