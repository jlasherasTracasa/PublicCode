## Objetivo

Hoy las órdenes `/` solo existen como brazos de un `match` en `App::submit`. Hace falta una tabla para
poder listarlas (paleta de órdenes, ayuda). Esta tarea solo crea la tabla y sus funciones puras; no cambia
`app.rs`.
1. Crea `commands.rs` con `CommandSpec`, `COMMANDS`, `find`, `display_name`, `help` y `matching` (firmas abajo).
2. `COMMANDS` tiene exactamente estas 13 entradas, en este orden, todas con `external: false`
   (nombre español / alias inglés): ayuda/help, nuevo/new, modelo/model, uso/usage, compactar/compact,
   deshacer/undo, rehacer/redo, plan/plan, construir/build, recuerda/remember, memoria/memory, olvida/forget,
   salir/quit. Los textos `es` y `en` son una frase corta (≤ 50 caracteres) de qué hace cada una, p. ej.
   `es: "olvida el historial y empieza otra conversación"`, `en: "forget the history and start again"`.
3. `find(name)`: busca por `name` o por `alias`, exacto y en minúsculas. `display_name`: `name` con
   `Lang::Es`, `alias` con `Lang::En`. `help`: `es` o `en` según el idioma.
4. `matching(prefix, lang)`: `prefix` llega sin la barra; se pasa a minúsculas. Devuelve, en el orden de
   `COMMANDS`, las entradas cuyo `name` o cuyo `alias` empieza por `prefix`. Con `prefix` vacío, todas.
5. `lib.rs`: añade `pub mod commands;` (orden alfabético, tras `pub mod app;`).

## Firmas (cópialas tal cual)

```rust
// crates/pcode-tui/src/commands.rs
use crate::i18n::Lang;

/// Una orden `/` de la TUI.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct CommandSpec {
    /// Nombre en español (sin la barra).
    pub name: &'static str,
    /// Alias en inglés.
    pub alias: &'static str,
    /// Qué hace, en español.
    pub es: &'static str,
    /// Qué hace, en inglés.
    pub en: &'static str,
    /// La ejecuta quien arranca la TUI (no `App`): se usa en tareas posteriores.
    pub external: bool,
}

/// Todas las órdenes, en el orden en que se listan.
pub const COMMANDS: &[CommandSpec] = &[ /* 13 entradas */ ];

/// Orden por nombre o alias exactos.
pub fn find(name: &str) -> Option<&'static CommandSpec>;
/// Nombre que se muestra en `lang`.
pub fn display_name(spec: &CommandSpec, lang: Lang) -> &'static str;
/// Ayuda en `lang`.
pub fn help(spec: &CommandSpec, lang: Lang) -> &'static str;
/// Órdenes cuyo nombre o alias empieza por `prefix` (sin barra).
pub fn matching(prefix: &str, lang: Lang) -> Vec<&'static CommandSpec>;
```

## Ejemplo (entrada y resultado esperado)

```
matching("desh", Lang::Es) -> [deshacer]
matching("reh", Lang::Es)  -> [rehacer]
matching("hel", Lang::Es)  -> [ayuda]                     (casa por el alias `help`)
matching("", Lang::Es).len() == COMMANDS.len()            (y la primera es `ayuda`)
find("quit").unwrap().name == "salir"
display_name(find("salir").unwrap(), Lang::En) == "quit"
```

## Tests (con estos nombres)

- `catalogo_incluye_las_ordenes_basicas_sin_repetir`: `find` encuentra los 13 nombres de la lista y no hay nombres ni alias repetidos entre entradas distintas (no compruebes el número total: otras tareas añaden órdenes)

- `matching_por_prefijo_y_alias`: los cuatro casos de `matching` del ejemplo
- `ayuda_no_vacia_en_los_dos_idiomas`: todas las entradas tienen `es` y `en` no vacíos y de 50 caracteres como mucho
