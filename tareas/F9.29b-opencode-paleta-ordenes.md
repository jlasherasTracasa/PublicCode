# F9.29b-opencode-paleta-ordenes — TUI: al escribir `/` se abre la lista de órdenes (↑/↓, Tab completa, Intro ejecuta)

## Objetivo

Reutiliza la ventana de sugerencias de `@archivo` para las órdenes. `App.suggestions` ya es `Vec<String>` y
`App.suggestion` el índice elegido.
1. `app.rs`, `refresh_suggestions`: antes del `match` actual, si `self.input` empieza por `/` y no contiene
   ningún espacio ni salto de línea, pon `self.suggestions` a las 8 primeras de
   `commands::matching(&self.input[1..], self.lang)` con el formato `"/<display_name>"`, `self.suggestion = 0`
   y vuelve. En otro caso, el comportamiento actual.
2. `app.rs`, `complete_mention`: si la sugerencia elegida empieza por `/`, la entrada pasa a ser
   `"<sugerencia> "` (con un espacio final) y se vacían las sugerencias. Si no, lo de ahora.
3. `app.rs`, `key`, en el bloque `if !self.suggestions.is_empty()`: separa `Tab` de `Enter`. `Tab` llama a
   `complete_mention` como ahora. `Enter`: si la sugerencia elegida empieza por `/`, pon
   `self.input = <sugerencia>` (sin espacio), vacía las sugerencias y devuelve `self.submit()`; si no,
   `complete_mention` como ahora.
4. `render.rs`, ventana de sugerencias: si la primera sugerencia empieza por `/`, el título es `" / "` en vez
   de `" @ "` y cada fila es `"› /nombre  ayuda"` (o con dos espacios en vez de `› ` si no es la elegida),
   donde `ayuda` es `commands::help(spec, app.lang)` de `commands::find(nombre sin barra)`; recorta la fila al
   ancho interior de la ventana con `chars().take(..)`.
5. Añade los tests de la lista: los de estado en `app.rs` y el de dibujo en `render.rs` (usa la función
   `screen` que ya hay en los tests de `render.rs`).

Sin firmas: No añade API pública: cambia el comportamiento de funciones privadas de App y el dibujo

## Ejemplo (entrada y resultado esperado)

```
entrada "/desh"          -> suggestions == ["/deshacer"]
entrada "/" (solo)       -> 8 sugerencias, la primera "/ayuda"
entrada "/mo" + Tab      -> input == "/modelo " y suggestions vacío
entrada "/sal" + Intro   -> devuelve [Command::Quit]
entrada "/modelo x"      -> suggestions vacío (hay un espacio)
pantalla 80×24 con "/desh": una fila contiene "› /deshacer" y el borde superior de la ventana contiene " / "
```

## Tests (con estos nombres)

- `paleta_sugiere_al_escribir_barra`: tras teclear `/desh`, `suggestions` es `["/deshacer"]`; tras teclear solo `/` hay 8
- `paleta_tab_completa_con_espacio`: `/mo` y Tab dejan `input == "/modelo "` y sin sugerencias
- `paleta_intro_ejecuta_la_elegida`: `/sal` e Intro devuelven `[Command::Quit]`
- `paleta_no_aparece_con_argumento`: tras teclear `/modelo x` no hay sugerencias
- `paleta_render_80x24_muestra_ayuda`: con `/desh` la pantalla tiene una fila que contiene `› /deshacer`

## No hagas

- No toques el `match name` de `submit`: las órdenes se siguen ejecutando igual
- No borres ni cambies tests que ya existen
