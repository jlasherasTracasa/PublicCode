## Objetivo

1. `theme.rs`, `Theme::by_name`: añade el brazo `"opencode"` con estos colores (todos `Color::Rgb`, salvo `fg`):
   `fg: Color::Reset`, `dim: (128,128,128)`, `accent: (250,178,131)`, `ok: (127,216,143)`, `err: (224,108,117)`,
   `warn: (245,167,66)`, `code_bg: (20,20,20)`, `bar_bg: (20,20,20)`, `bar_fg: (238,238,238)`,
   `bubble_bg: (30,30,30)`, `bubble_fg: (238,238,238)`, `use_color: true`.
2. `theme.rs`: añade `Theme::NAMES` y `Theme::next` (firmas abajo). `next` busca qué nombre de `NAMES` da un
   tema igual a `self` (compara con `Theme::by_name(n, !self.use_color) == Some(*self)`) y devuelve el tema del
   nombre siguiente, volviendo al primero tras el último; si `self` no coincide con ninguno, devuelve el
   primero. Conserva `use_color`.
3. `chat.rs`, `ChatArgs`: añade el campo `theme` (firma abajo) y `theme: None` en `default_args`.
4. `chat.rs`, función `tui`: el tema se elige así: `a.theme` si es un nombre válido; si no, `p.theme`
   (el de la configuración) como ahora; si no, `Theme::from_env()`. Usa el mismo `no_color` que ya se calcula
   (`std::env::var_os("NO_COLOR").is_some()`).

## Ejemplo (entrada y resultado esperado)

```
Theme::by_name("opencode", false).unwrap().accent == Color::Rgb(250, 178, 131)
Theme::by_name("azul", false).unwrap().next() == Theme::by_name("oscuro", false).unwrap()
Theme::by_name("opencode", true).unwrap().next() == Theme::by_name("azul", true).unwrap()   (y use_color sigue false)
```

## Tests (con estos nombres)

- `theme_opencode_existe_y_tiene_su_acento`: `by_name("opencode", false)` es Some y su `accent` es `Rgb(250,178,131)`
- `theme_todos_los_nombres_existen`: `by_name(n, false)` es Some para cada `n` de `Theme::NAMES`
- `theme_next_recorre_y_vuelve_al_primero`: de `azul` se pasa a `oscuro`; de `opencode` a `azul`; con `no_color` se conserva `use_color == false`
