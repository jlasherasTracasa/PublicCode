## Objetivo

1. `app.rs`: añade a `App` el campo `pub leader: bool` (doc: «Se pulsó Ctrl+X y se espera la segunda tecla»),
   a `false` en `App::new`.
2. `app.rs`, `key_main`: añade antes del brazo `KeyCode::Char(c) if !ctrl` el brazo
   `KeyCode::Char('x') if ctrl => { self.leader = true; vec![] }`.
3. `app.rs`, `key`: justo después del bloque de la aprobación pendiente y antes del de sugerencias, si
   `self.leader` es cierto: ponlo a `false` y trata la tecla con un método privado
   `fn leader_key(&mut self, k: KeyEvent) -> Vec<Command>`; devuelve su resultado.
4. `leader_key`, según `k.code`:
   - `Char('n')` ejecuta `/nuevo`; `Char('u')` `/deshacer`; `Char('r')` `/rehacer`; `Char('c')` `/compactar`;
     `Char('h')` `/ayuda`; `Char('q')` `/salir`. «Ejecutar» es: `self.suggestions.clear();
     self.input = "/nuevo".into(); return self.submit();`.
   - `Char('m')`: `self.input = "/modelo ".into();` y devuelve `vec![]` (el usuario escribe el nombre).
   - `Char('t')`: `self.theme = self.theme.next();`, añade `Entry::Info(t(self.lang, "theme_changed").into())`
     y devuelve `vec![]`.
   - Cualquier otra tecla (incluido Esc): no hace nada, devuelve `vec![]`.
5. `i18n.rs`: añade al final de `ES` y `EN` (mismo orden): `theme_changed` = `"Tema cambiado."` /
   `"Theme changed."` y `leader_hint` =
   `" Ctrl+X ▸ n nueva · m modelo · t tema · u deshacer · r rehacer · q salir"` /
   `" Ctrl+X ▸ n new · m model · t theme · u undo · r redo · q quit"`.
6. `render.rs`, barra de estado: si `app.leader`, en lugar de todo lo que se dibuja ahora en `status`, dibuja
   solo `Paragraph::new(Line::from(Span::styled(t(app.lang, "leader_hint"), th.warning())))` y no sigas con
   el resto de esa sección (un `if app.leader { … } else { código actual }`).

Sin firmas: Solo añade el campo público `leader: bool` a App; el resto son métodos privados, textos y dibujo

## Ejemplo (entrada y resultado esperado)

```
Ctrl+X                 -> app.leader == true, sin órdenes
Ctrl+X, n              -> [Command::New] y app.leader == false
Ctrl+X, m              -> input == "/modelo " y sin órdenes
Ctrl+X, t              -> app.theme distinto del anterior
Ctrl+X, z              -> nada; app.leader == false; input intacto
pantalla 80×24 tras Ctrl+X: la fila 23 empieza por " Ctrl+X ▸ n nueva"
```

## Tests (con estos nombres)

- `lider_ctrl_x_n_nueva_sesion`: Ctrl+X y luego `n` devuelven `[Command::New]` y dejan `leader` en false
- `lider_m_prepara_la_orden_de_modelo`: Ctrl+X y `m` dejan `input == "/modelo "` sin devolver órdenes
- `lider_t_cambia_de_tema`: Ctrl+X y `t` dejan un `app.theme` distinto del inicial
- `lider_tecla_desconocida_cancela`: Ctrl+X y `z` no devuelven nada, no escriben `z` en la entrada y `leader` queda false
- `lider_render_80x24_muestra_las_teclas`: con `app.leader = true` la fila 23 empieza por ` Ctrl+X ▸ n nueva`
