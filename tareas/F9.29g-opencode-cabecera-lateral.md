## Objetivo

1. `app.rs`, `submit`: justo antes de `self.entries.push(Entry::User(text.clone()))`, si `self.title` está
   vacío, ponle la primera línea de `text` recortada a 40 caracteres (`chars().take(40)`).
2. `app.rs`, `submit`, brazo `"nuevo" | "new"`: además de lo que hace, `self.title.clear()` y
   `self.changes.clear()`.
3. `app.rs`, `leader_key`: añade `Char('b')`: `self.show_side = !self.show_side;` y devuelve `vec![]`.
4. `run.rs`, brazo `Msg::Turn`, dentro del `if let Ok(a) = agent.try_lock()`: guarda `let ch = a.turn_changes();`,
   usa `&ch` en `changes_summary` y añade `crate::side::merge_changes(&mut app.changes, &ch);`.
5. `render.rs`, tras calcular `[header, body, input_area, status]`: si
   `side_visible(app.show_side, area.width)`, parte `body` con
   `Layout::horizontal([Constraint::Min(1), Constraint::Length(SIDE_WIDTH)]).areas(body)` en `[body, side]`
   (vuelve a ligar `body`) y dibuja en `side` un
   `Paragraph::new(side_lines(app, SIDE_WIDTH - 1)).block(Block::new().borders(Borders::LEFT).border_style(th.dimmed()))`.
   Todo lo demás (transcripción, sugerencias, aprobación) sigue usando el `body` ya estrechado.
6. `render.rs`, barra superior: si `app.title` no está vacío, añade a `left` el texto `"  ·  <título>"`,
   recortando el título para que `left + mode + 1 + right` no pase del ancho de `header` (si no cabe ni un
   carácter, no añadas nada).

Sin firmas: No añade API pública: usa los campos y funciones de F9.29f

## Ejemplo (entrada y resultado esperado)

```
teclear "arregla el test" + Intro           -> app.title == "arregla el test"
teclear "/nuevo" + Intro                    -> app.title == "" y app.changes vacío
Ctrl+X, b                                   -> app.show_side == true; otra vez -> false
pantalla 80×24 con show_side = true         -> alguna fila contiene "Cambios (0)" y la columna 50 de la fila 1 es "│"
pantalla 80×24 con show_side = false        -> ninguna fila contiene "Cambios (0)"
pantalla 60×24 con show_side = true         -> ninguna fila contiene "Cambios (0)" (no cabe)
cabecera con title = "arregla el test"      -> la fila 0 contiene "·  arregla el test"
```

## Tests (con estos nombres)

- `lateral_titulo_sale_del_primer_mensaje`: tras enviar `arregla el test`, `app.title` es ese texto; un segundo mensaje no lo cambia; `/nuevo` lo vacía
- `lateral_ctrl_x_b_alterna`: Ctrl+X y `b` ponen `show_side` a true y repetirlo lo deja en false
- `lateral_render_80x24_y_120x40`: con `show_side = true`, a 80×24 y a 120×40 hay una fila que contiene `Cambios (0)`; con false, ninguna
- `lateral_no_se_dibuja_en_60_columnas`: a 60×24 con `show_side = true` ninguna fila contiene `Cambios (0)`
- `lateral_cabecera_muestra_el_titulo`: con `app.title = "arregla el test"` la fila 0 a 80×24 contiene `·  arregla el test` y sigue acabando en `✓ listo`
