## Objetivo

1. Crea `closing.rs` con `CloseTarget`, `dirty_indexes` y `dirty_titles` (firmas abajo) y sus tests. En `lib.rs`
   añade `pub mod closing;` en orden alfabético (después de `pub mod app;`).
2. `dirty_indexes(tabs, target)`: índices, en orden, de las pestañas con cambios sin guardar (`Tab::dirty()`) a las
   que afecta el cierre: con `CloseTarget::Tab(path)`, solo la pestaña de esa ruta (si existe y tiene cambios); con
   `CloseTarget::Window`, todas las que tengan cambios.
3. `dirty_titles(tabs, target)`: los `title()` de esas mismas pestañas, en el mismo orden. Vacío significa que se
   puede cerrar sin preguntar.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/closing.rs
//! Cierre con cambios sin guardar: qué pestañas hay que guardar antes de cerrar una pestaña o la ventana.
use crate::state::Tabs;

/// Lo que el usuario quiere cerrar.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum CloseTarget {
    /// Una pestaña, por su ruta.
    Tab(String),
    /// La ventana entera.
    Window,
}

/// Índices de las pestañas con cambios sin guardar a las que afecta el cierre.
pub fn dirty_indexes(tabs: &Tabs, target: &CloseTarget) -> Vec<usize>;
/// Nombres cortos de esas pestañas (vacío = se puede cerrar sin preguntar).
pub fn dirty_titles(tabs: &Tabs, target: &CloseTarget) -> Vec<String>;
```

## Ejemplo (entrada y resultado esperado)

```
let mut tabs = Tabs::default();
tabs.open("src/a.rs", "uno".into());  tabs.open("b.md", "dos".into());  tabs.open("c.py", "tres".into());
tabs.list[0].text.push('!');  tabs.list[2].text.push('!');          // a.rs y c.py quedan con cambios
dirty_titles(&tabs, &CloseTarget::Window)                  -> ["a.rs", "c.py"]
dirty_indexes(&tabs, &CloseTarget::Window)                 -> [0, 2]
dirty_titles(&tabs, &CloseTarget::Tab("b.md".into()))      -> []
dirty_titles(&tabs, &CloseTarget::Tab("src/a.rs".into()))  -> ["a.rs"]
dirty_titles(&tabs, &CloseTarget::Tab("no-abierta".into())) -> []
```

## Tests (con estos nombres)

- `ventana_lista_todas_las_modificadas`: el ejemplo con Window da los títulos a.rs y c.py y los índices 0 y 2
- `pestana_sin_cambios_no_pregunta`: Tab(b.md) da listas vacías
- `pestana_con_cambios_pregunta_solo_por_ella`: Tab(src/a.rs) da [a.rs] y el índice 0
- `ruta_que_no_esta_abierta`: Tab(no-abierta) da listas vacías; con Tabs::default() y Window, también
