## Objetivo

1. Crea `project_replace.rs` con `files_of`, `Outcome` y `run` (firmas abajo) y sus tests. En `lib.rs` añade
   `pub mod project_replace;` en orden alfabético (después de `pub mod problems;`).
2. `files_of(hits)`: rutas de los resultados, sin repetir y en orden de primera aparición.
3. `run(files, dirty, query, replacement, case_sensitive, read, write)`: para cada ruta de `files`, en orden:
   - si está en `dirty` (pestaña abierta con cambios sin guardar), se añade a `skipped` y no se toca;
   - `read(ruta)`: si da `Err`, a `skipped`;
   - `crate::find::replace_all(&texto, query, replacement, case_sensitive)`: si hubo 0 sustituciones, no se escribe
     ni cuenta;
   - `write(ruta, &nuevo)`: si da `Err`, a `skipped`; si va bien, `files += 1` y `replacements += n`.
   Con `query` vacía no hace nada y devuelve `Outcome::default()`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/project_replace.rs
//! Reemplazo en todo el proyecto: la lectura y la escritura se inyectan para probarlo sin demonio.

/// Resultado de un reemplazo en varios archivos.
#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct Outcome {
    /// Archivos cambiados.
    pub files: usize,
    /// Sustituciones hechas en total.
    pub replacements: usize,
    /// Archivos que no se tocaron (cambios sin guardar, o no se pudieron leer o escribir).
    pub skipped: Vec<String>,
}

/// Rutas de los resultados de búsqueda, sin repetir y en orden.
pub fn files_of(hits: &[(String, u32, String)]) -> Vec<String>;

/// Sustituye `query` por `replacement` en cada archivo de `files` que no esté en `dirty`.
pub fn run(
    files: &[String], dirty: &[String], query: &str, replacement: &str, case_sensitive: bool,
    read: impl FnMut(&str) -> Result<String, String>,
    write: impl FnMut(&str, &str) -> Result<(), String>,
) -> Outcome;
```

## Ejemplo (entrada y resultado esperado)

```
files_of(&[("a.rs".into(), 1, "x".into()), ("b.rs".into(), 4, "x".into()), ("a.rs".into(), 9, "x".into())]) -> ["a.rs", "b.rs"]

Disco simulado: a.rs = "foo foo", b.rs = "nada", c.rs = "foo", d.rs = "foo" (d.rs está en `dirty`)
run(&[a.rs, b.rs, c.rs, d.rs], &[d.rs], "foo", "bar", true, read, write)
   -> Outcome { files: 2, replacements: 3, skipped: ["d.rs"] }
   y el disco queda: a.rs = "bar bar", b.rs = "nada" (sin escribir), c.rs = "bar", d.rs = "foo"
```

## Tests (con estos nombres)

- `archivos_sin_repetir`: el ejemplo de files_of da [a.rs, b.rs]
- `reemplaza_y_cuenta`: el ejemplo de run (con un HashMap como disco) da 2 archivos, 3 sustituciones y deja a.rs y c.rs cambiados
- `salta_los_que_tienen_cambios_sin_guardar`: d.rs no se lee ni se escribe y sale en skipped
- `no_escribe_si_no_hay_coincidencias`: para b.rs no se llama a write
- `errores_de_lectura_y_escritura_se_apuntan`: si read da Err para un archivo, o write da Err, ese archivo sale en skipped y no cuenta
- `consulta_vacia_no_hace_nada`: con query vacía el resultado es Outcome::default() y no se llama a read

## No hagas

- No reimplementes la búsqueda: usa `crate::find::replace_all`
- No uses `egui`
