## Objetivo

1. Crea `rename.rs` con `word_at` y `valid_name` (firmas abajo) y sus tests. En `lib.rs` añade `pub mod rename;` en
   orden alfabético (después de `pub mod remote;`).
2. `word_at(text, cursor)`: `cursor` es un índice de carácter. Un carácter «de palabra» es alfanumérico
   (`char::is_alphanumeric`) o `_`. Devuelve la palabra que toca el cursor: se extiende hacia la izquierda y hacia
   la derecha desde `cursor` mientras haya caracteres de palabra (el cursor justo al final de una palabra también
   la toca). Si no hay ninguno a los lados, `None`. Si `cursor` es mayor que la longitud, se trata como el final.
3. `valid_name(name)`: `true` si no está vacío, el primer carácter es una letra (`char::is_alphabetic`) o `_`, y el
   resto son caracteres de palabra. Sin espacios ni puntos.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/rename.rs
//! Renombrar símbolo: la palabra bajo el cursor y la validación del nombre nuevo.

/// La palabra que toca el cursor (índice de carácter), o `None` si no hay ninguna.
pub fn word_at(text: &str, cursor: usize) -> Option<String>;
/// Si `name` sirve como identificador.
pub fn valid_name(name: &str) -> bool;
```

## Ejemplo (entrada y resultado esperado)

```
word_at("let total = suma(a);", 6)   -> Some("total")     // cursor en medio de «total»
word_at("let total = suma(a);", 9)   -> Some("total")     // justo al final de «total»
word_at("let total = suma(a);", 10)  -> None              // entre el espacio y «=»
word_at("año_2 = 1", 2)              -> Some("año_2")
valid_name("nuevo_total") -> true    valid_name("_x") -> true    valid_name("ñu") -> true
valid_name("") -> false   valid_name("2x") -> false   valid_name("a b") -> false   valid_name("a.b") -> false
```

## Tests (con estos nombres)

- `palabra_en_medio_y_al_final`: los dos primeros ejemplos dan «total»
- `sin_palabra_da_none`: el tercer ejemplo, el texto vacío y un cursor rodeado de espacios dan None
- `palabra_con_letras_no_ascii`: «año_2 = 1» con cursor 2 da «año_2»
- `cursor_pasado_el_final`: con cursor 999 en «abc» da «abc»
- `nombres_validos_y_no_validos`: los siete casos del ejemplo de valid_name
