# F9.36a-ide-markdown-nucleo — IDE: partir un Markdown en bloques (títulos, párrafos, listas, citas, código) para la vista previa

## Objetivo

1. Crea `markdown.rs` con `Block`, `parse` y `plain_inline` (firmas abajo) y sus tests. En `lib.rs` añade
   `pub mod markdown;` en orden alfabético (después de `pub mod lsp_pos;`).
2. `parse(text)` recorre las líneas y produce bloques en orden:
   - Una línea que empieza por tres acentos graves abre un bloque de código hasta la siguiente línea que empiece
     igual (o el final): `Block::Code(texto de dentro, con sus saltos de línea, sin las dos líneas de valla)`.
     Dentro no se interpreta nada.
   - `#` a `######` seguido de espacio → `Block::Heading(nivel 1..=6, plain_inline(resto))`.
   - `- `, `* ` o `+ ` al principio (tras espacios opcionales) → `Block::Bullet(plain_inline(resto))`; lo mismo para
     listas numeradas (`1. `, `12. `): el número se conserva en el texto (`"1. texto"`).
   - `> ` → `Block::Quote(plain_inline(resto))`.
   - `---`, `***` o `___` solos en la línea → `Block::Rule`.
   - Línea vacía: cierra el párrafo en curso.
   - Cualquier otra línea se añade al párrafo en curso (las líneas seguidas se unen con un espacio):
     `Block::Paragraph(plain_inline(texto unido))`.
3. `plain_inline(s)`: quita las marcas de énfasis `**` y `__` siempre, y `*` y `_` sueltos solo cuando están en el
   borde de una palabra (al principio o al final del texto, o junto a un espacio): un guion bajo ENTRE letras, como
   en `mi_variable`, se conserva. Quita también los acentos graves del código en línea; un enlace `[texto](url)` pasa a `texto (url)`; una imagen `![alt](url)` pasa a `alt`. El
   HTML (`<b>`, `<script>`…) NO se interpreta ni se quita: se deja como texto literal.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/markdown.rs
//! Markdown para la vista previa: se parte en bloques de texto; el HTML nunca se interpreta.

/// Un bloque del documento.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Block {
    /// Título de nivel 1 a 6.
    Heading(u8, String),
    /// Párrafo.
    Paragraph(String),
    /// Elemento de lista.
    Bullet(String),
    /// Cita.
    Quote(String),
    /// Bloque de código (entre vallas).
    Code(String),
    /// Línea horizontal.
    Rule,
}

/// Bloques de un documento Markdown, en orden.
pub fn parse(text: &str) -> Vec<Block>;
/// Texto de una línea sin las marcas de énfasis, código en línea, enlaces ni imágenes.
pub fn plain_inline(s: &str) -> String;
```

## Ejemplo (entrada y resultado esperado)

```
parse("# Título\n\nUn **párrafo**\nen dos líneas.\n\n- uno\n- [dos](http://x)\n\n> cita\n\n---\n")
   -> [Heading(1, "Título"), Paragraph("Un párrafo en dos líneas."), Bullet("uno"), Bullet("dos (http://x)"),
       Quote("cita"), Rule]
(un bloque entre vallas de tres acentos graves con las líneas `let a = 1;` y `# no es título` dentro)
   -> [Code("let a = 1;\n# no es título\n")]
plain_inline("usa `cargo test` y <b>esto</b>") -> "usa cargo test y <b>esto</b>"
plain_inline("![logo](img/a.png) fin")         -> "logo fin"
```

## Tests (con estos nombres)

- `titulos_parrafos_listas_citas_y_regla`: el primer ejemplo da los seis bloques en ese orden
- `codigo_entre_vallas_no_se_interpreta`: el segundo ejemplo da un único Code con las dos líneas
- `valla_sin_cerrar_llega_al_final`: un bloque de código sin valla de cierre incluye todo lo que queda
- `lista_numerada_conserva_el_numero`: «1. uno» da Bullet(«1. uno»)
- `niveles_de_titulo`: de uno a seis almohadillas dan los niveles 1 a 6; siete almohadillas son un párrafo
- `html_se_queda_como_texto`: «<script>alert(1)</script>» da un Paragraph con ese mismo texto
- `enlaces_imagenes_y_enfasis`: los dos ejemplos de plain_inline; «**a** _b_» da «a b»
- `guion_bajo_entre_letras_se_conserva`: «usa mi_variable y a*b» se queda igual
- `documento_vacio`: la cadena vacía da un vector vacío

## No hagas

- No interpretes HTML ni lo elimines: se muestra tal cual, como texto
- No añadas dependencias (ni `pulldown-cmark` ni ninguna otra)
- No uses `egui` en este módulo
- No intentes cubrir tablas ni listas anidadas: quedan como párrafos y elementos sueltos
