## Objetivo

1. Crea `keymap.rs` con `Chord`, `parse_chord`, `chord_text`, `parse_overrides` y `resolve` (firmas abajo) y sus
   tests. En `lib.rs` añade `pub mod keymap;` en orden alfabético (después de `pub mod highlight;`).
2. `parse_chord(s)`: parte `s` por `+`. Las partes menos la última son modificadores, sin distinguir mayúsculas:
   `Ctrl` (también `Control` y `Cmd`) → `ctrl`; `Mayús` (también `Mayus` y `Shift`) → `shift`; `Alt` → `alt`. La
   última parte es la tecla, que se resuelve con `egui::Key::from_name` (acepta `S`, `F12`, `,`, `-`, `=`, el acento
   grave, `Space`, `Tab`…); si es una sola letra en minúscula, pásala a mayúscula antes. Caso especial: si `s` acaba
   en `++`, la tecla es `+`. Cadena vacía, modificador desconocido o tecla desconocida → `None`.
3. `chord_text(c)`: el texto en el orden `Ctrl+Mayús+Alt+<tecla>`, con `egui::Key::symbol_or_name()` para la tecla
   (`Ctrl+Mayús+P`, `F12`).
4. `parse_overrides(toml_text)`: lee la tabla `[atajos]` de un TOML: cada clave es el identificador de una orden y
   cada valor una cadena. Devuelve `(identificador, parse_chord(valor))` por entrada, en orden alfabético de
   identificador: `Some(chord)` si el valor es un atajo válido; `None` si el valor es la cadena vacía (significa
   «sin atajo»). Las entradas con un valor no válido se descartan. TOML roto o sin tabla `[atajos]` → vector vacío.
5. `resolve(overrides, id, default)`: el atajo que vale para la orden `id`: si `overrides` tiene una entrada para
   `id`, su valor (que puede ser `None`); si no, `parse_chord(default)`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/keymap.rs
//! Atajos de teclado: lectura de textos como «Ctrl+Mayús+P» y del archivo `keybindings.toml`.
use eframe::egui::Key;

/// Una combinación de teclas.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Chord {
    /// Ctrl (Cmd en macOS).
    pub ctrl: bool,
    /// Mayúsculas.
    pub shift: bool,
    /// Alt.
    pub alt: bool,
    /// Tecla.
    pub key: Key,
}

/// Lee «Ctrl+Mayús+P»; `None` si no es un atajo válido.
pub fn parse_chord(s: &str) -> Option<Chord>;
/// Texto de un atajo, como se enseña en los menús.
pub fn chord_text(c: &Chord) -> String;
/// Atajos del usuario: (identificador de la orden, atajo o `None` para quitarlo).
pub fn parse_overrides(toml_text: &str) -> Vec<(String, Option<Chord>)>;
/// Atajo de una orden: el del usuario si lo cambió; si no, el de fábrica (`default`).
pub fn resolve(overrides: &[(String, Option<Chord>)], id: &str, default: &str) -> Option<Chord>;
```

## Ejemplo (entrada y resultado esperado)

```
parse_chord("Ctrl+Mayús+P") -> Some(Chord { ctrl: true, shift: true, alt: false, key: Key::P })
parse_chord("ctrl+shift+p") -> lo mismo           parse_chord("F12") -> Some(Chord { …false…, key: Key::F12 })
parse_chord("Ctrl+-")       -> key: Key::Minus    parse_chord("Ctrl++") -> key: Key::Plus
parse_chord("")  -> None    parse_chord("Hiper+S") -> None    parse_chord("Ctrl+NoExiste") -> None
chord_text(&parse_chord("alt+ctrl+s").unwrap()) -> "Ctrl+Alt+S"

keybindings.toml:
[atajos]
guardar = "Ctrl+G"
salir = ""
raro = "Hiper+X"
parse_overrides(ese texto) -> [("guardar", Some(Ctrl+G)), ("salir", None)]
resolve(&o, "guardar", "Ctrl+S") -> Some(Ctrl+G)    resolve(&o, "salir", "Ctrl+Q") -> None
resolve(&o, "buscar", "Ctrl+F")  -> Some(Ctrl+F)    resolve(&o, "tema", "") -> None
```

## Tests (con estos nombres)

- `lee_modificadores_y_tecla`: los cuatro primeros ejemplos de parse_chord, con los alias en inglés y en minúsculas

- `toml_roto_o_sin_tabla`: «esto no es toml» y un TOML sin [atajos] dan vector vacío
