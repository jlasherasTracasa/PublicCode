## Objetivo

1. `keymap.rs`: añade el estado global de los atajos del usuario y dos funciones (firmas abajo):
   `static OVERRIDES: std::sync::OnceLock<Vec<(String, Option<Chord>, &'static str)>>` (identificador, atajo y su
   texto para los menús). `install(overrides)` lo rellena una sola vez: el texto es `chord_text` del atajo (o `""`
   si es `None`), convertido a `&'static str` con `Box::leak` (son pocas cadenas y se crean una vez al arrancar:
   dilo en un comentario). `shown(id, default)` devuelve el texto instalado para `id` o, si no hay, `default`.
   `load()` lee `keybindings.toml` de la carpeta de `IdeSettings::path()` y devuelve `parse_overrides(texto)` (vector
   vacío si no existe).
2. `app.rs`, `impl Command`: nuevo `pub fn id(self) -> &'static str` con un identificador estable en español, en
   minúsculas y con guiones, por orden: `QuickOpen` → `ir-a-archivo`, `Save` → `guardar`, `SaveAll` →
   `guardar-todo`, `CloseEditor` → `cerrar-editor`, `Find` → `buscar`, `Replace` → `reemplazar`, `GoToLine` →
   `ir-a-linea`, `GoToDefinition` → `ir-a-definicion`, `ShowHover` → `informacion`, `ToggleSidebar` →
   `barra-lateral`, `TogglePanel` → `panel`, `ToggleAgent` → `agente`, `Terminal` → `terminal`, `Explorer` →
   `explorador`, `Search` → `buscar-en-proyecto`, `Git` → `git`, `Settings` → `ajustes`, `Problems` → `problemas`,
   `ToggleTheme` → `tema`, `ZoomIn` → `letra-mas`, `ZoomOut` → `letra-menos`, `NewChat` → `nueva-conversacion`,
   `UndoTurn` → `deshacer-turno`, `Quit` → `salir`. Para cualquier otra orden que exista en el enum, elige un
   identificador con el mismo estilo. Test `identificadores_de_ordenes_unicos`.
3. `app.rs`, `Command::label`: renombra el cuerpo actual a una función privada `fn label_default(self, t)` (sin
   cambiar nada) y haz que `label` devuelva `(texto, crate::keymap::shown(self.id(), atajo_de_fabrica))`.
4. `app.rs`: en `struct Ide`, campo `keymap: Vec<(crate::keymap::Chord, Command)>`. En `Ide::new`, antes de crear
   `Ide { … }`: `let overrides = crate::keymap::load(); crate::keymap::install(overrides.clone());` y construye
   `keymap` recorriendo `Command::ALL`: `crate::keymap::resolve(&overrides, c.id(), c.label_default(t).1)`; los
   `Some(chord)` entran en la lista. Ordénala para que vayan primero los atajos con más modificadores
   (`ctrl + shift + alt` contados, de mayor a menor).
5. `app.rs`, `fn shortcuts`: sustituye las tablas fijas de órdenes (la de Mayús y Alt, la de `Modifiers::COMMAND`,
   la de `Key::F12` y la del depurador) por: primero, la paleta: `if press(cs, Key::P) { cmds.push(None); }`;
   después, un bucle sobre una copia de `self.keymap`: construye `Modifiers` a partir del `Chord`
   (`Modifiers::COMMAND` si `ctrl`, `Modifiers::SHIFT` si `shift`, `Modifiers::ALT` si `alt`, unidos con `|`) y, si
   `press(mods, chord.key)`, `cmds.push(Some(cmd))`. Conserva tal cual lo demás: `Ctrl` + `Key::Plus` como segundo
   atajo de `ZoomIn`, el bloque de los fragmentos (Ctrl+Espacio y sus flechas), `Ctrl+Tab` y Esc.

/// Atajos del usuario leídos de `keybindings.toml` (vacío si no existe).
pub fn load() -> Vec<(String, Option<Chord>)>;

## Ejemplo (entrada y resultado esperado)

```
~/.config/pcode/keybindings.toml (junto a ide.toml):
[atajos]
guardar = "Ctrl+G"          # Guardar pasa a Ctrl+G (Ctrl+S deja de guardar)
ir-a-linea = "Ctrl+L"       # antes Ctrl+G
tema = "Ctrl+Alt+T"         # una orden que no tenía atajo
salir = ""                  # sin atajo
```

## Tests (con estos nombres)

- `identificadores_de_ordenes_unicos`: los id() de todas las órdenes de Command::ALL son distintos, no vacíos y solo llevan minúsculas, cifras y guiones; Command::Save.id() es «guardar»
- `sin_instalar_se_ve_el_de_fabrica`: keymap::shown(«una-orden-que-no-existe», «Ctrl+S») devuelve «Ctrl+S»

## No hagas

- No cambies la firma pública de `Command::label` (sigue devolviendo `(String, &'static str)`)
- No compruebes un atajo con menos modificadores antes que uno con más: para egui, Ctrl+Mayús+F también «es» Ctrl+F
- No quites Ctrl+Mayús+P (paleta), Ctrl+Espacio, Ctrl+Tab ni Esc: no son órdenes configurables
- No llames a `keymap::install` en los tests (es global y solo cuenta la primera vez)
