## Objetivo

1. `theme.rs`: añade `static CUSTOM: std::sync::RwLock<Option<&'static Palette>> = std::sync::RwLock::new(None);`
   y `pub fn set_custom(p: Option<Palette>)`, que guarda `p.map(|p| &*Box::leak(Box::new(p)))` (se pierde una
   paleta de pocos bytes por cambio de tema: dilo en un comentario). `palette(dark)` devuelve la de `CUSTOM` si hay
   una, y si no lo de antes. Test `tema_personalizado_sustituye_y_se_quita`.
2. `settings.rs`: campo nuevo en `IdeSettings`: `pub ext_theme: String` con `#[serde(rename = "tema_extension")]` y
   su `///` («Tema de una extensión: `<id>/<ruta>`; vacío = el del IDE»). Por defecto, cadena vacía. Test
   `tema_de_extension_se_guarda_y_se_lee`.
3. `texts.rs`: campos nuevos al final de `Texts`: `ext_themes` (`"Temas de extensiones"` / `"Extension themes"`) y
   `default_theme` (`"Tema del IDE"` / `"IDE theme"`), con su `///`.
4. `app.rs`: nuevo método `fn apply_ext_theme(&mut self, ctx: &egui::Context)`: si `self.settings.ext_theme` está
   vacío o contiene `..`, llama a `theme::set_custom(None)`. Si no, lee el archivo
   `pcode_extensions::default_root()` + `ext_theme`, lo pasa a
   `theme_ext::palette_from_theme(&texto, if self.settings.dark { &theme::DARK } else { &theme::LIGHT })` y llama a
   `theme::set_custom(resultado)` (si algo falla, `None`). Después llama a
   `theme::apply(ctx, self.settings.dark, self.settings.font_size)`.
5. `app.rs`, `Ide::new`: después de crear `ide` (antes de `ide.list_dir("")`), llama a `ide.apply_ext_theme(ctx)`;
   para eso declara `let mut ide = Ide { … }`.
6. `app.rs`, `ui_settings`: debajo de los botones de tema oscuro y claro, un título `t.ext_themes` y una lista:
   primero `ui.selectable_label(self.settings.ext_theme.is_empty(), t.default_theme)`; después, por cada extensión
   de `pcode_extensions::list(&root)` y cada tema suyo, `ui.selectable_label(clave == self.settings.ext_theme,
   &tema.label)` donde `clave = format!("{}/{}", m.id, tema.path.trim_start_matches("./"))`. Al pulsar uno: guarda la
   clave (o vacío), pone `self.settings.dark = theme_ext::is_dark(&tema.ui_theme)` (no lo cambies al elegir el del
   IDE), llama a `self.apply_ext_theme(&ctx)` y a `self.settings.save()`. Calcula la lista una sola vez por
   fotograma, fuera de los cierres que usan `self`.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/theme.rs
/// Pone (o quita con `None`) una paleta de tema de extensión, que sustituye a la clara y a la oscura.
pub fn set_custom(p: Option<Palette>);
// crates/pcode-ide/src/settings.rs — campo nuevo de `IdeSettings`
#[serde(rename = "tema_extension")]
pub ext_theme: String,
// crates/pcode-ide/src/app.rs — dentro de `impl Ide`
/// Aplica el tema de extensión guardado en los ajustes (o lo quita).
fn apply_ext_theme(&mut self, ctx: &egui::Context);
```

## Tests (con estos nombres)

- `tema_personalizado_sustituye_y_se_quita`: tras set_custom(Some(p)) con p.editor distinto, palette(true).editor es el de p; tras set_custom(None) vuelve a ser DARK.editor (deja siempre None al acabar)
- `tema_de_extension_se_guarda_y_se_lee`: IdeSettings con ext_theme = «ana.temas/themes/noche.json» sobrevive a to_toml + parse, y un TOML sin esa clave da cadena vacía

## No hagas

- No cambies la firma de `palette` ni de `apply`
- No leas la carpeta de extensiones más de una vez por fotograma
- No cambies los colores del resaltado (`highlight.rs`)
- No aceptes claves con `..`: el archivo debe quedar dentro de la carpeta de extensiones
