## Objetivo

Entre dos releases todas las compilaciones dicen `pcode 1.1.0`, así que tras un `git pull` y una instalación no se
sabe qué código está instalado. El binario debe llevar el commit corto con el que se compiló.
1. Crea `crates/pcode-cli/build.rs` con el código de *Firmas* tal cual (sin dependencias nuevas: solo `std`). Calcula
   `PCODE_VERSION_LONG` = `<versión> (<commit de 7 cifras>)`, o solo `<versión>` si no hay git o no es un repo, y pide
   recompilar cuando cambian `HEAD`, la rama actual o `packed-refs`.
2. En `main.rs` cambia el atributo a `#[command(name = "pcode", version = env!("PCODE_VERSION_LONG"), about)]`.
3. En `doctor.rs`, donde se imprime la versión con `env!("CARGO_PKG_VERSION")`, usa `env!("PCODE_VERSION_LONG")`. Si
   hay más de un sitio, cámbialos todos dentro de `doctor.rs`; no toques el de `update.rs` (compara versiones semver).
4. Crea `crates/pcode-cli/tests/version.rs` con los tests de la lista (usa `assert_cmd::Command::cargo_bin("pcode")`).
   Para saber el commit esperado ejecuta `git rev-parse --short=7 HEAD` desde `env!("CARGO_MANIFEST_DIR")`; si falla,
   el test solo comprueba que la línea empieza por `pcode ` seguido de la versión.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-cli/build.rs
use std::process::Command;

fn git(args: &[&str]) -> Option<String> {
    let out = Command::new("git").args(args).output().ok()?;
    if !out.status.success() {
        return None;
    }
    let s = String::from_utf8_lossy(&out.stdout).trim().to_string();
    if s.is_empty() { None } else { Some(s) }
}

fn main() {
    let pkg = std::env::var("CARGO_PKG_VERSION").unwrap_or_default();
    let commit = git(&["rev-parse", "--short=7", "HEAD"]).filter(|c| c.chars().all(|x| x.is_ascii_hexdigit()));
    let long = match commit {
        Some(c) => format!("{pkg} ({c})"),
        None => pkg,
    };
    println!("cargo:rustc-env=PCODE_VERSION_LONG={long}");
    println!("cargo:rerun-if-changed=build.rs");
    for path in [git(&["rev-parse", "--git-path", "HEAD"]), git(&["rev-parse", "--git-path", "packed-refs"])]
        .into_iter()
        .flatten()
    {
        println!("cargo:rerun-if-changed={path}");
    }
    if let Some(r) = git(&["symbolic-ref", "-q", "HEAD"]) {
        if let Some(p) = git(&["rev-parse", "--git-path", &r]) {
            println!("cargo:rerun-if-changed={p}");
        }
    }
}
```

## Tests (con estos nombres)

- `version_incluye_el_commit`: `pcode --version` → una línea `pcode <CARGO_PKG_VERSION> (<git rev-parse --short=7 HEAD>)`
- `version_empieza_por_el_numero`: `pcode --version` → empieza por `pcode ` + CARGO_PKG_VERSION y acaba en salto de línea

## Notas

Las rutas de `--git-path` son relativas al directorio desde el que se ejecuta git (el del paquete), que es el mismo que usa cargo para `rerun-if-changed`: funciona también en worktrees.
