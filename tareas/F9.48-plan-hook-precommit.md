# F9.48-plan-hook-precommit — Hook `pre-commit` que valida el plan cuando el commit toca `tareas/plan*` (que la CI no se rompa)

**Fase** F9 · **Ejecutor** haiku · **Hito** 1.2 · **Talla** S · **Depende de** —

> Generado desde `tareas/plan/`. Sigue `AGENTS.md` y la skill `tarea-haiku`.

## Contexto (lee esto y nada más)

- .github/workflows/ci.yml (el paso que ejecuta `generar.py --comprobar`)

## Objetivo

El 11 nov 2026 llegaron al repositorio reglas nuevas en `generar.py` sin migrar 10 tareas antiguas y la CI quedó en
rojo con 98 errores. Un hook de git lo habría parado en el equipo de quien hizo el commit.
1. Crea `tools/hooks/pre-commit` (`#!/usr/bin/env sh`, `set -eu`, bit de ejecución) como en *Firmas*: si
   `git diff --cached --name-only` incluye algo que empiece por `tareas/` o es `tools/tareas/generar.py`, ejecuta
   `${PCODE_GENERAR:-python3 tools/tareas/generar.py} --comprobar`; si falla, escribe por stderr
   `El plan no valida: corrige los errores o regenera con tools/tareas/generar.py` y sale con 1. Si el commit no toca
   esas rutas, sale con 0 sin ejecutar nada.
2. En la docstring de `tools/tareas/generar.py`, al final de «Uso», añade la línea
   `Para validarlo antes de cada commit: git config core.hooksPath tools/hooks`. No cambies nada más de ese archivo.
3. Crea `tools/hooks/test_pre_commit.py` (con `#!/usr/bin/env python3` y bit de ejecución). Cada test crea un repo
   temporal (`git init -q`, `git -c user.name=t -c user.email=t@t commit` para los commits), copia el hook a
   `.git/hooks/pre-commit` con permiso 755 y pone `PCODE_GENERAR` a un script sh falso del directorio temporal que
   escribe un archivo `llamado` y sale con 0 o con 1 según el test. Todas las llamadas con `timeout=30`.

## Firmas (cópialas tal cual)

```sh
# tools/hooks/pre-commit
cambios="$(git diff --cached --name-only)"
if printf '%s\n' "$cambios" | grep -Eq '^(tareas/|tools/tareas/generar\.py$)'; then
  if ! ${PCODE_GENERAR:-python3 tools/tareas/generar.py} --comprobar; then
    echo "El plan no valida: corrige los errores o regenera con tools/tareas/generar.py" >&2
    exit 1
  fi
fi
exit 0
```

## Tests (con estos nombres)

- `test_plan_invalido_bloquea_el_commit`: se añade `tareas/plan/F1.toml` y el validador falso sale con 1 → el commit falla y `git log` sigue vacío
- `test_plan_valido_deja_hacer_el_commit`: mismo archivo y validador falso que sale con 0 → el commit se hace y existe `llamado`
- `test_otros_archivos_no_validan`: se añade `README.md` → el commit se hace y `llamado` no existe
