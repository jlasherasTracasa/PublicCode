## Objetivo

1. Crea `folder.rs` con lo de *Firmas* y sus tests; en `lib.rs`, `pub mod folder;` en orden alfabético.
2. `FolderPicker::new(start)`: `dir = start`, filtro vacío y `refresh()`. `refresh`: `entries` = nombres de las
   subcarpetas de `dir` que no empiezan por `.`, ordenados sin distinguir mayúsculas; si no se puede leer, vacío;
   `selected = 0`. `visible()`: las de `entries` que contienen `filter` (sin distinguir mayúsculas), en orden.
3. `enter(name)`: `dir = dir.join(name)`, filtro vacío, `refresh()`. `up()`: si `dir` tiene padre, pasa a él y
   `refresh()`. `move_selection(delta)`: suma `delta` a `selected` sin salir de `0..visible().len()` (con lista
   vacía, 0). `selected_dir()`: `dir.join(visible()[selected])`, o `dir` si no hay ninguna visible.
4. `parse_recent(text)`: una ruta por línea, recortada, sin vacías ni repetidas, solo las que existen como carpeta.
   `load_recent()`: lee `recientes.txt` en la carpeta de `pcode_config::user_config_path()` (vacío si no hay).
5. `open_folder_command(pcode, dir)`: `Command::new(pcode)` con argumentos `["ide", <dir>]` y `stdin(Stdio::null())`.
   `open_folder(pcode, dir)`: si `dir` no es una carpeta → `Err(InvalidInput, "no es una carpeta")`; si no,
   `open_folder_command(..).spawn()` sin esperar.

## Firmas (cópialas tal cual)

```rust
// crates/pcode-ide/src/folder.rs
//! Abrir otra carpeta desde el IDE: navegar por carpetas y lanzar `pcode ide <ruta>`.
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};

/// Estado del selector de carpetas.
#[derive(Debug, Clone, PartialEq)]
pub struct FolderPicker { pub dir: PathBuf, pub entries: Vec<String>, pub filter: String, pub selected: usize }

impl FolderPicker {
    pub fn new(start: &Path) -> FolderPicker;
    pub fn refresh(&mut self);
    pub fn visible(&self) -> Vec<&str>;
    pub fn enter(&mut self, name: &str);
    pub fn up(&mut self);
    pub fn move_selection(&mut self, delta: i32);
    pub fn selected_dir(&self) -> PathBuf;
}

/// Proyectos recientes de un `recientes.txt` que aún existen.
pub fn parse_recent(text: &str) -> Vec<PathBuf>;
/// Proyectos recientes guardados por `pcode ide`.
pub fn load_recent() -> Vec<PathBuf>;
/// Orden `pcode ide <dir>`.
pub fn open_folder_command(pcode: &Path, dir: &Path) -> Command;
/// Abre `dir` en otra ventana del IDE (no espera).
pub fn open_folder(pcode: &Path, dir: &Path) -> std::io::Result<()>;
```

## Tests (con estos nombres)

- `lista_solo_subcarpetas_visibles`: tempdir con `b/`, `A/`, `.oculta/` y `c.txt` → `entries == ["A", "b"]`
- `filtra_sin_mayusculas`: filtro `B` → `visible() == ["b"]`
- `entrar_y_subir`: `enter("A")` → `dir` acaba en `A` y filtro vacío; `up()` → vuelve al tempdir
- `seleccion_sin_salirse`: dos visibles y `move_selection(5)` → 1; `move_selection(-9)` → 0; `selected_dir` es `tempdir/A`
- `recientes_solo_los_que_existen`: texto con el tempdir, una ruta inexistente, una vacía y el tempdir repetido → solo el tempdir una vez
- `orden_de_abrir`: `open_folder_command("/x/pcode", "/p")` → programa `/x/pcode` y argumentos `["ide", "/p"]`
- `abrir_un_archivo_es_error`: `open_folder` con la ruta de `c.txt` → Err de tipo `InvalidInput`
